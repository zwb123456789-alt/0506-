## 4. 关键口径

- clean rendered image 是理想图像上界，不代表真实外场性能。
- OCS 不是 clean image 条件下的性能上限来源；其价值在于低维、可解释、多观测几何和对图像像素退化不敏感。
- fusion 是条件性互补：干净图像下主要体现为边际和尾部增益，退化观测下价值更明显。
- 当前工作没有真实光学望远镜验证，应表述为 physically consistent simulation and controlled inversion study。
- `all_raw` 只能作为 semi-oracle diagnostic representation，不能写成实际可操作特征。

## 5. 可能被老师问到的问题

| 问题 | 建议回答口径 |
|---|---|
| 为什么 ResNet 比 OCS 更强？ | clean rendered image 保留了稳定形状、阴影、质心和亮度分布线索，强 CNN 能充分利用；但这是理想上界，不代表外场性能。 |
| 为什么还需要 OCS？ | OCS 低维、可解释、多观测几何，且不受图像像素噪声直接影响；在真实观测退化或图像质量不足时更有价值。 |
| 为什么 fusion 不是永远最优？ | 当某一模态已经很强或另一模态噪声较大时，融合可能只提供边际收益甚至引入干扰；因此应写成条件性互补。 |
| 固定 roll 是否合理？ | 当前论文限定 yaw-pitch controlled benchmark；roll 敏感性已显示平均相对变化约 20.3%、max 约 26.2%，三轴扩展应作为 future work。 |
| 下一步是否需要真实数据？ | 真实光学数据会显著增强外推可信度，但当前还没有完成；应请导师判断是否作为投稿前硬门槛，还是写入 limitation/future work。 |
