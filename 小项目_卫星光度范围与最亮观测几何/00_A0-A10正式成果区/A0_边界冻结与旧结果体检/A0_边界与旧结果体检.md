## 关键结论

### 1. 小项目只有两个任务

**任务一**：通过调研获得常规高轨/GEO类卫星可见光亮度或视星等范围，并记录来源、观测条件和可信度。

**任务二**：基于当前卫星 STL、材料 BRDF、遮挡和 OCS 计算链路，系统寻找"什么太阳-目标-观测几何、什么卫星姿态、什么材料/部件朝向条件下观测最亮"，并解释最亮机制。

**关键区分**：

- 本小项目**不是论文写作附属任务**
- 不是为了复用旧图而补一段解释
- 不是大项目论文的附录或延伸实验

### 2. 第二任务的完整内涵

第二任务的核心**不是输出一个孤立的最大 OCS 数字**，而是找到并归纳最亮构型：

```
在某相位角、太阳方向、观测方向下，
卫星处于某 yaw/pitch/roll 姿态，
使某个材料/部件同时受照、可见、遮挡少，
或其法向接近太阳-观测角平分方向，
因此该部件主导 OCS，观测最亮。
```

最终答案可以不是唯一姿态点，而可能是一组最亮构型族。不同相位角、roll、材料参数下可能出现多个局部最亮结果，但它们必须能归纳到清楚的几何-材料机制。

**预期输出形态**（每个最亮构型族）：

- 相位角
- 太阳方向
- 观测方向
- 距离/场景
- 姿态 yaw/pitch/roll
- total OCS
- 相对星等差 Delta m
- 主导部件/材料
- 部件贡献占比
- 遮挡比例
- 物理解释
- 证据等级
- 适用边界

### 3. 旧 phase63 与五几何结果只能作为预实验

#### 当前已有基础

| 内容 | 当前状态 |
|---|---|
| phase63 OCS top-K | 已完成初步分析（yaw=300°, pitch=15°, roll=0, OCS=14.823573，当前模型输出值） |
| 五个旧几何 phase24/45/63/90/120 | 原结果存在，可用于预实验复核 |
| 姿态网格 | yaw 0-360°、pitch -90-90°、roll 固定 0，实际约 5° 步长 |
| phase63 相对亮度 | 最亮相对中位姿态亮约 7.948 mag，相对最暗亮约 9.559 mag |
| phase63 主导部件 | 金属主体贡献约 99.9% |

#### 当前结果的证据边界

**可以作为**：

- 旧链路预实验和脚本验证
- 固定 phase63、固定 roll=0、当前材料参数和遮挡语义下的离散网格最大值
- 相对亮度排序（Delta m）参考
- 部件贡献机制假设来源

**不能直接说明**：

- 真实高轨/GEO 全局最亮姿态（只是 phase63 单一相位角下的结果）
- 真实绝对视星等（OCS 未经真实观测标定，STL 比例尺、BRDF 参数未验证）
- 排除 roll 扫描或更密相位角下出现太阳能板/金属面 glint（roll=0 固定，只扫描了 yaw-pitch 二维切片）
- 多几何、多姿态、多材料机制的最终结论（只有 5 个离散相位角）

#### 旧五几何的特殊口径问题

**关键修正**：旧五几何（phase24/45/63/90/120）的 OCS 数据来自模块 A 的 **face-center 扫描表**（face-level 采样），与后续可能实施的 Blender pixel-level pass 口径不统一。

**处理原则**：

- 旧五几何仅作**相对排序预实验**（部件贡献占比、姿态 top-K、Delta m 趋势）
- 不与后续 pixel-level 结果直接混表
- 不作为绝对 OCS 数值的主结论来源
- 在 A6 预实验复核时必须明确标注"face-center 口径（旧）"

### 4. 后续阶段需求初步判断

#### 是否需要多几何粗扫（A3）

**判定：需要**

理由：

1. 五个几何只是代表性抽象方向，不是完整太阳-目标-观测几何空间
2. 缺少小相位角（<24°，后向散射方向通常最亮）
3. 缺少大相位角（>120°，前向散射弱区）
4. 不能自然对应真实高轨观测（需记录 `range_km`、相位角、太阳方向、观测方向和姿态约束）

**推荐**：A3 设计几何搜索空间，覆盖更多相位角和观测方位。

#### 是否需要 yaw/pitch/roll 三自由度姿态搜索（A4）

**判定：必须**

理由：

1. roll 固定为 0，可能漏掉太阳能板或金属面镜面高光
2. 太阳能板 glint 通常在特定 roll 值触发（太阳翼法向对齐太阳-观测平面）
3. yaw/pitch 欧拉网格不是均匀三维姿态采样，且存在 yaw=0 与 360° 重复
4. 第二任务要求归纳"什么姿态下最亮"，缺少 roll 维度无法完整回答

**推荐**：A4 设计粗到细搜索策略（多几何粗扫 → 三自由度姿态粗扫 → top-K 局部细化）。

#### 是否需要 top-K 局部细化（A4）

**判定：需要**

理由：

1. yaw/pitch 5° 间隔可能错过窄峰（specular 峰的 FWHM 可能 <5°）
2. roll 全扫描后仍需在峰值附近做 1-2° 局部加密
3. 相位角离散采样可能遗漏中间峰值

**推荐**：A4 设计局部加密方案（yaw/pitch/roll 在 top-K 附近 ±5-10° 做 1° 步长扫描）。

#### 是否需要部件贡献、遮挡比例、材料参数的机制归纳（A8）

**判定：必须**

理由：

1. 第二任务的核心是"解释最亮机制"，不是只输出最大 OCS 数值
2. 必须回答：该最亮是否来自镜面角平分、受照可见面积、遮挡最少或材料参数
3. 需要将数值峰值归纳为物理机制（镜面主导、太阳板主导、满相增强、遮挡控制等）

**推荐**：A8 设计机制归纳框架，基于 top-K 结果分析几何条件、材料参数和遮挡影响。

#### 是否需要在 A9 才做情景绝对星等估计

**判定：是**

理由：

1. 绝对星等换算需要 OCS 物理定义满足 `E_obs / E_sun = OCS / R²` 且波段/太阳星等口径确认
2. 当前 OCS 未经真实观测标定，STL 比例尺、BRDF 参数未验证
3. 相对结果（Delta m、OCS 排序、部件占比）可直接使用，不需要绝对标定
4. 情景星等估计需明确"情景估计"，不冒充实测

**推荐**：A9 在相对结果闭合后，给定 R 与 K_cal/m_sun 口径做情景估计，并标注假设和局限。

## 不能支持的结论

### 1. 关于"全局最亮"的声称

**不能说**：

- "当前 phase63 结果就是真实高轨/GEO 全局最亮"
- "yaw=300°, pitch=15°, roll=0 是卫星在任何观测条件下的最亮姿态"
- "金属主体在所有几何条件下都是主导部件"

**原因**：

1. 只有 5 个离散相位角，未覆盖完整相位角空间
2. roll 固定为 0，未扫描三维姿态空间
3. yaw/pitch 5° 步长可能错过窄峰
4. 材料参数为名义值，未经验证

### 2. 关于绝对视星等的声称

**不能说**：

- "本仿真 OCS 已覆盖真实卫星亮度范围"
- "不需要标定即可给出绝对星等"
- "仿真星等与文献范围一致，因此仿真正确"

**原因**：

1. OCS 未经真实观测标定
2. STL 比例尺、BRDF 参数未验证
3. 文献范围不能反过来硬约束仿真结果

### 3. 关于旧五几何的过度声称

**不能说**：

- "五几何已完整覆盖高轨观测条件"
- "五几何结果可直接与后续 pixel-level 结果混表"
- "五几何的绝对 OCS 数值可作为主结论"

**原因**：

1. 五几何为 face-center 扫描口径（旧），与 pixel-level 采样不统一
2. 只是代表性抽象方向，不是完整几何空间
3. 仅作相对排序预实验，不作为绝对数值主结论
