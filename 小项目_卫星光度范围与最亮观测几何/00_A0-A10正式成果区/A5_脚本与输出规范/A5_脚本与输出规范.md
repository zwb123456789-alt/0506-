## is_near_halfvector字段处理

### 4.1 half-vector 镜面条件定义（继承 A4）

**物理含义**：镜面反射最强的条件是反射面法向接近太阳-观测角平分方向（half-vector）。

**数学定义**：

```python
half_vector = normalize(sun_direction_I + det_direction_I)
```

**判据**：若部件法向或主导面法向与 half_vector 夹角 < 10°，标记为接近镜面条件。

### 4.2 法向数据获取难度

| 数据级别 | 可获得性 | 精度 | 实施难度 |
|---|---|---|---|
| **mesh 级面元法向** | ✅ 可从 STL 直接获取 | 精确到每个三角形 | 低 |
| **部件级平均法向** | ⚠️ 需主导贡献面元的加权平均 | 近似 | 中 |
| **太阳能板法向（设计值）** | ✅ 已知设计方向（如 ±Y） | 粗略 | 低 |
| **真实部件法向（含变形）** | ❌ 需详细几何模型 | 精确 | 高（超出 A5 范围） |

### 4.3 is_near_halfvector 字段规范

**字段类型**：`boolean` 或 `null`

**取值规则**：

| 取值 | 条件 | 说明 |
|---|---|---|
| `true` | 主导部件法向与 half-vector 夹角 < 10° | 接近镜面条件 |
| `false` | 主导部件法向与 half-vector 夹角 ≥ 10° | 不接近镜面条件 |
| `null` 或 `"unknown"` | 法向数据不足或不可获得 | 不得强行判定 |

**推荐实施方案**：

**方案 A：使用设计法向（推荐用于 A6 预实验复核）**

若只做旧五几何复核，不重新运行 OCS 代码，则法向数据不可得：
```python
# A6 阶段：只读旧结果，无法获得法向
df['is_near_halfvector'] = None  # 或 "unknown"
```

**方案 B：使用主导部件设计法向（简化估算）**

若已知太阳能板设计法向为 ±Y，金属主体主要朝向为 ±Z：
```python
# 根据主导部件和姿态估算法向
if row['dominant_component'] == 'taiyangnengban':
    # 太阳能板设计法向在 M 系为 [0, 1, 0] 或 [0, -1, 0]
    # 需将姿态旋转到 I 系
    R_M_to_I = attitude_to_rotation_matrix(row['yaw_deg'], row['pitch_deg'], row['roll_deg'])
    normal_I = R_M_to_I @ np.array([0, 1, 0])
else:
    # 法向不确定
    normal_I = None

if normal_I is not None:
    half_vec = normalize(sun_dir + det_dir)
    angle = np.arccos(np.dot(normal_I, half_vec)) * 180 / np.pi
    row['is_near_halfvector'] = (angle < 10)
else:
    row['is_near_halfvector'] = None
```

**方案 C：使用 mesh 级主导面法向（精确但复杂）**

若重新运行 OCS 代码，可记录主导贡献面元的法向：
```python
# 在 OCS 积分中记录贡献最大的面元
max_contrib_face_idx = np.argmax(ocs_per_face)
normal_I_dominant = normals_I[max_contrib_face_idx]

# 判断是否接近 half-vector
half_vec = normalize(sun_dir + det_dir)
angle = np.arccos(np.dot(normal_I_dominant, half_vec)) * 180 / np.pi
is_near_halfvector = (angle < 10)
```

### 4.4 A5 对 A6/A7 的要求

**A6 旧五几何预实验复核**：
- 只读旧结果，法向数据不可得
- `is_near_halfvector` 字段记为 `null` 或 `"unknown"`
- 不得强行猜测或估算

**A7 新几何/roll 实施**（若实施）：
- 若采用旧代码（face-center），法向数据仍不可得，记为 `null`
- 若采用新方法（pixel-level）并修改代码记录主导面法向，可用方案 C
- 若不修改代码，可用方案 B（设计法向估算）
- 若两方案均不可行，记为 `null`

**关键原则**：不得在法向数据不足时强行给出 `true`/`false` 判定。
