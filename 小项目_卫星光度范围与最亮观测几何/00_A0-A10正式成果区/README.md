# A0-A10 正式成果区

本目录是小项目的唯一正式成果区。通过 Codex 审阅的 A0-A10 阶段成果都放在这里，每个阶段一个子目录。

## 目录规则

| 子目录 | 用途 |
|---|---|
| `A0_边界冻结与旧结果体检/` | 小项目边界、两任务冻结、旧结果证据边界 |
| `A1_OCS定义与采样逻辑审计/` | OCS、Delta m、绝对星等边界、采样逻辑审计 |
| `A2_亮度范围调研/` | 常规高轨/GEO 亮度范围调研与调研表 |
| `A3_几何搜索空间设计/` | 太阳-目标-观测几何、相位角、方向向量与场景元数据 |
| `A4_三维姿态搜索方案/` | yaw/pitch/roll 搜索策略、粗到细方案 |
| `A5_脚本与输出规范/` | 小项目脚本边界与结果字段规范 |
| `A6_旧五几何预实验复核/` | 旧五几何预实验复核结果 |
| `A7_新几何与roll实施计划/` | 新几何/roll 是否实施及计算预算 |
| `A8_最亮机制归纳/` | 最亮构型族与物理机制归纳 |
| `A9_情景绝对星等估计/` | 情景星等估计、距离和标定口径 |
| `A10_总结闭合/` | 两任务最终闭合结论 |
