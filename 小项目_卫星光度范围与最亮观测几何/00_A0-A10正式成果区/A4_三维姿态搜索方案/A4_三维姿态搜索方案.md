## 姿态变量定义

### 1.1 欧拉角约定（继承阶段4与A1）

卫星姿态用欧拉角 (yaw, pitch, roll) 表示，旋转约定为 **ZYX 内旋顺序**：

1. **Yaw（偏航角）**：绕本体坐标系 Z 轴旋转
2. **Pitch（俯仰角）**：绕本体坐标系 Y 轴旋转
3. **Roll（滚转角）**：绕本体坐标系 X 轴旋转

### 1.2 姿态角范围约定

| 角度 | 范围 | 周期性 | 物理含义 |
|---|---|---|---|
| yaw | 0°–360° | 周期 360° | 卫星绕自身 Z 轴旋转 |
| pitch | -90°–90° | 非周期 | 卫星俯仰姿态 |
| roll | 0°–360° | 周期 360° | 卫星绕自身 X 轴旋转 |

### 1.3 旧采样网格的已知问题（继承A1）

**问题1：yaw=0° 与 yaw=360° 重复**
- 旧网格：yaw = 0, 5, 10, ..., 355, 360（共 73 个点）
- yaw=0° 与 yaw=360° 对应同一姿态，导致重复计算
- **A4 修正**：yaw = 0, 5, 10, ..., 355（共 72 个点，不含 360°）

**问题2：yaw/pitch 欧拉网格不均匀**
- pitch 接近 ±90° 时，yaw 变化对姿态的实际影响趋近于零（万向节死锁）
- pitch = 0° 附近，yaw 步长对应的姿态变化较大
- **A4 处理**：承认欧拉网格不是 SO(3) 均匀采样，但作为粗筛可接受；若需精确均匀采样，需切换到四元数或 Fibonacci 球面采样（超出 A4 范围）

**问题3：roll=0 固定，缺失三维姿态自由度**
- 旧预实验只扫描 yaw×pitch 二维切片（roll=0）
- 可能漏掉太阳能板 glint（需特定 roll 才能触发）
- 可能漏掉金属主体某些曲面的镜面反射峰（需 roll≠0）
- **A4 核心任务**：设计 roll 扫描策略，补全三维姿态空间

## 三维姿态搜索总体策略

### 3.1 分级搜索流程（5 阶段）

**核心原则**：不对所有 A3 几何 × 全 yaw/pitch/roll 做笛卡尔积全扫描（组合爆炸），采用"粗扫 → 候选提取 → roll 扫描 → 局部细化"策略。

| 阶段 | 名称 | 输入 | 输出 | 计算量 |
|---|---|---|---|---|
| **A4-S1** | 旧结果候选提取 | 旧 phase63 top-20 + 部件贡献 | 候选姿态集 C0（约 50-100 个姿态） | 0（只读旧数据） |
| **A4-S2** | 代表几何粗扫 | G1 子集（2-3 个几何）× yaw×pitch 网格 | 每个几何的 top-K 姿态 | ~5,000-10,000 次 OCS |
| **A4-S3** | 候选姿态 roll 扫描 | C0 ∪ S2_topK × roll 网格 | roll 敏感度分析 + top-K' | ~5,000-20,000 次 OCS |
| **A4-S4** | 局部三维细化 | S3_topK' × 局部加密 | 精确最亮姿态 | ~2,000-5,000 次 OCS |
| **A4-S5** | 机制标注 | S4 结果 | 部件主导/镜面条件/遮挡分析 | 0（后处理） |

**总计算量估算**：12,000-35,000 次 OCS 计算（若每次 1 秒，约 3-10 小时）

### 3.2 为什么不全扫描

**全扫描规模**：
- A3 G1 几何：12 个
- yaw×pitch：72×37 = 2,664 个（修正 yaw 重复后）
- roll：假设 36 个点（10° 步长）
- **总计**：12 × 2,664 × 36 = 1,150,272 次 OCS 计算
- **耗时**：若每次 1 秒，约 320 小时 = 13 天（不可行）

**分级搜索规模**（A4 推荐）：
- S1：0 次（只读旧数据）
- S2：3 × 2,664 = 7,992 次（3 个代表几何粗扫）
- S3：100 × 36 = 3,600 次（100 个候选姿态 × 36 roll）
- S4：20 × 50 = 1,000 次（20 个 top-K × 局部 50 点）
- **总计**：12,592 次 OCS 计算
- **耗时**：若每次 1 秒，约 3.5 小时（可行）

### 3.3 代表几何选择策略（A4-S2）

**不对所有 12 个 G1 几何做全姿态扫描**，只选 2-3 个代表几何：

**推荐代表几何**：
1. **phase = 0°**（满相/后向散射）：文献常见最亮方向
2. **phase = 63°**（中相位角）：旧预实验已有 roll=0 基准，便于对照
3. **phase = 120°**（大相位角）：覆盖前向散射过渡区

**理由**：
- 3 个几何覆盖小/中/大相位角，代表性足够
- phase63 有旧预实验基准，可验证 roll 扫描是否发现新峰值
- 若 3 个代表几何都显示金属主体主导且 roll 不敏感，只能作为降低其他相位角优先级的依据，不能直接外推为所有几何均类似；必要时由 A7 扩展到更多 G1 几何
- 若某个几何显示太阳能板 glint 或 roll 强敏感，再扩展到其他几何

**替代方案**（若计算预算充足）：
- 可选 5 个代表几何：0°, 30°, 63°, 90°, 120°
- 或先做 3 个，根据 S3 结果决定是否扩展

## 多来源top-K候选设计

### 4.1 候选来源设计原则（继承A1）

**关键约束**：roll 扫描候选集不能只从"总 OCS top-K"出发，必须从**多来源候选并集**出发。

**理由**：roll=0 时总 OCS 最高的姿态，可能在 roll≠0 时不再最亮；但某个部件在 roll=0 时 OCS 不高的姿态，可能在 roll≠0 时因 glint 而成为该部件的最亮点。

### 4.2 候选来源清单（A4-S1）

| 来源 | 说明 | 预期候选数 | 理由 |
|---|---|---|---|
| **L1：总 OCS top-K** | roll=0 粗扫中总 OCS 最高的 K 个姿态 | K = 20 | 保证全局最亮候选不遗漏 |
| **L2：金属主体 OCS top-K** | roll=0 粗扫中金属主体 OCS 最高的 K 个姿态 | K = 10 | 保证金属主体最亮点不遗漏 |
| **L3：太阳能板 OCS top-K** | roll=0 粗扫中太阳能板 OCS 最高的 K 个姿态 | K = 10 | 保证太阳能板最亮点不遗漏（可能在 roll≠0 时 glint） |
| **L4：太阳能板占比 top-K** | roll=0 粗扫中太阳能板占比最高的 K 个姿态 | K = 10 | 保证太阳能板主导的姿态不遗漏 |
| **L5：遮蔽板 OCS top-K**（可选） | roll=0 粗扫中遮蔽板 OCS 最高的 K 个姿态 | K = 5 | 若遮蔽板贡献显著（>1%）则纳入 |
| **L6：旧 phase63 top-20** | 旧预实验已有的 top-20 姿态（roll=0） | 20 | 作为对照基准，验证新方法 |

**候选集合构造**：
```
C0 = L1 ∪ L2 ∪ L3 ∪ L4 ∪ L5 ∪ L6
```

去重后预期总候选数：50-100 个姿态（因为不同来源可能重叠）

### 4.3 K 值推荐

**推荐方案 A**（保守）：
- L1: K=20, L2: K=10, L3: K=10, L4: K=10, L5: K=5, L6: 20
- 预期 C0 ≈ 50-70 个姿态

**推荐方案 B**（激进）：
- L1: K=30, L2: K=20, L3: K=20, L4: K=20, L5: K=10, L6: 20
- 预期 C0 ≈ 80-120 个姿态

**不在 A4 固化具体 K 值**，由 A5 实施时根据计算预算和存储能力决定。

### 4.4 太阳能板候选的特殊处理

**观察**：旧 phase63 预实验显示，太阳能板在 roll=0 条件下最大 OCS 仅 0.009981（yaw=10°, pitch=-75°），占比 < 0.5%。

**问题**：若只从"总 OCS top-20"选候选，太阳能板主导的姿态可能全部被金属主体主导的姿态挤出。

**解决方案**：
- 单独提取 L3（太阳能板 OCS top-K）和 L4（太阳能板占比 top-K）
- 即使太阳能板在 roll=0 时 OCS 很低，roll 扫描后可能因 glint 而显著增强
- L3/L4 的候选进入 roll 扫描后，若太阳能板 OCS 仍然很低（< 金属主体 1%），可在 S4 前剔除

## roll扫描方案

### 5.1 roll 扫描步长候选方案

**不在 A4 固化唯一步长**，给出 3 个候选方案供 A5 选择：

| 方案 | roll 步长 | roll 点数 | 优点 | 缺点 | 适用场景 |
|---|---|---|---|---|---|
| **R1：粗扫** | 10° | 36 | 计算快，适合大规模候选 | 可能跳过窄 glint 峰（FWHM < 10°） | 第一轮快速筛查 |
| **R2：中扫** | 5° | 72 | 平衡精度与速度 | 计算量翻倍 | 推荐作为标准方案 |
| **R3：细扫** | 2° | 180 | 精度高，不易漏峰 | 计算量 5 倍，可能过度采样 | 仅用于 S4 局部细化 |

**推荐策略**：
- S3 阶段：对所有 C0 候选用 R1 或 R2 方案扫描
- S4 阶段：对 top-K' 候选用 R3 方案局部细化

### 5.2 roll 范围选择

**方案 A：全周期扫描**（推荐）
- roll ∈ [0°, 360°)，步长 10°/5°/2°
- 覆盖完整 roll 自由度

**方案 B：半周期扫描**（若卫星关于 roll 对称）
- roll ∈ [0°, 180°)，步长 10°/5°/2°
- 若卫星结构关于 X 轴对称，roll=0° 与 roll=180° 的 OCS 应相同
- 计算量减半

**判断**：当前三件套 STL（金属主体 + 太阳能板 + 遮蔽板）是否关于 X 轴对称？
- 若太阳能板只在 +Y 或 -Y 一侧，则不对称，必须全周期扫描
- 若太阳能板在 ±Y 对称分布，可能半周期足够

**推荐**：优先采用方案 A（全周期扫描），除非明确验证了 roll 对称性。

### 5.3 roll 扫描输出字段

每个 (yaw, pitch, roll) 三元组计算一次 OCS，记录：

| 字段 | 说明 |
|---|---|
| `yaw_deg`, `pitch_deg`, `roll_deg` | 姿态三元组 |
| `total_ocs_model` | 总 OCS（当前模型输出值） |
| `ocs_jinshuzhuti_model` | 金属主体 OCS |
| `ocs_taiyangnengban_model` | 太阳能板 OCS |
| `ocs_yinshenban_model` | 遮蔽板 OCS |
| `pct_jinshuzhuti` | 金属主体占比 |
| `pct_taiyangnengban` | 太阳能板占比 |
| `pct_yinshenban` | 遮蔽板占比 |
| `occlusion_ratio_percent` | 遮挡率 |
| `roll_sensitivity_flag` | roll 敏感度标记（后处理判断） |

**roll 敏感度判断**（后处理）：
- 若某姿态的 OCS(roll) 在 [0°, 360°) 范围内动态范围 > 5 倍（即 max/min > 5），标记为"roll 敏感"
- 若动态范围 < 2 倍，标记为"roll 不敏感"

## 局部细化方案

### 6.1 局部细化触发条件（A4-S4）

从 S3 roll 扫描结果中提取 top-K' 候选，满足以下任一条件：

| 条件 | 说明 |
|---|---|
| **C1：总 OCS top-K'** | 总 OCS 最高的 K' 个 (yaw, pitch, roll) 三元组 |
| **C2：部件 OCS top-K'** | 金属主体/太阳能板/遮蔽板各自 OCS 最高的 K' 个 |
| **C3：roll 峰值候选** | 在 roll 扫描中出现尖峰的姿态（相邻 roll 点 OCS 变化 > 50%） |

**推荐 K' 值**：K' = 10-20

### 6.2 局部细化步长

在 top-K' 候选的 (yaw, pitch, roll) 周围局部加密：

**方案 A：固定步长细化**
- yaw: ±10° 范围内，步长 1°（共 21 点）
- pitch: ±10° 范围内，步长 1°（共 21 点）
- roll: ±10° 范围内，步长 1°（共 21 点）
- 若做笛卡尔积：21×21×21 = 9,261 点（对单个候选）
- 若做分离扫描：21+21+21 = 63 点（对单个候选，但可能漏掉耦合峰）

**方案 B：自适应步长细化**
- 先用 2° 步长在 ±10° 范围内扫描（6×6×6 = 216 点）
- 找到新峰值后，再用 0.5° 步长在 ±2° 范围内细化（5×5×5 = 125 点）
- 总计 216+125 = 341 点（对单个候选）

**推荐**：
- 若 K' = 10，方案 A 分离扫描：10×63 = 630 点（可行）
- 若 K' = 20，方案 B 自适应：20×341 = 6,820 点（偏多但可接受）
- 若峰值极窄（FWHM < 2°），可能需要 0.5° 或更细步长

**不在 A4 固化唯一方案**，由 A5 根据 S3 结果的峰宽特征决定。

### 6.3 局部细化的边界处理

**问题**：若候选姿态接近边界（如 yaw=5°, pitch=85°, roll=355°），局部加密可能超出范围。

**处理**：
- yaw: 周期边界，yaw < 0° 折回 360°，yaw ≥ 360° 折回 0°
- pitch: 硬边界 [-90°, 90°]，若超出则截断
- roll: 周期边界，处理同 yaw

## 计算预算与组合爆炸控制

### 7.1 各阶段计算量估算

**假设**：
- 代表几何数：N_geom = 3（phase = 0°/63°/120°）
- yaw×pitch 网格：72×37 = 2,664 点
- 候选集 C0：N_cand = 70 个姿态
- roll 扫描步长：10°（36 点）
- top-K'：K' = 15
- 局部细化：每个候选 63 点（分离扫描）

| 阶段 | 计算公式 | 估算值 |
|---|---|---|
| S1 | 0（只读旧数据） | 0 |
| S2 | N_geom × 2,664 | 3 × 2,664 = 7,992 |
| S3 | N_cand × 36 | 70 × 36 = 2,520 |
| S4 | K' × 63 | 15 × 63 = 945 |
| **总计** | | **11,457 次 OCS 计算** |

**耗时估算**（若每次 OCS 计算 1 秒）：
- 总耗时：11,457 秒 ≈ 3.2 小时（可行）

### 7.2 计算量敏感性分析

| 参数变化 | 影响阶段 | 计算量变化 | 可行性 |
|---|---|---|---|
| N_geom: 3 → 5 | S2 | +5,328 次（总计 16,785） | 可行（约 4.7 小时） |
| N_geom: 3 → 12（全 G1） | S2 | +23,976 次（总计 35,433） | 偏多（约 9.8 小时） |
| roll 步长：10° → 5° | S3 | 翻倍（总计 14,097） | 可行（约 3.9 小时） |
| N_cand: 70 → 120 | S3 | +1,800 次（总计 13,257） | 可行（约 3.7 小时） |
| K': 15 → 30 | S4 | +945 次（总计 12,402） | 可行（约 3.4 小时） |

**结论**：A4 推荐方案的计算量在可接受范围内（< 10 小时）。

### 7.3 不可行的全扫描方案（对比）

**全扫描方案**：12 个 G1 几何 × 72 yaw × 37 pitch × 36 roll = 1,150,272 次
**耗时**：若每次 1 秒，约 320 小时 = 13 天

**A4 分级搜索优势**：
- 计算量减少 100 倍（11,457 vs 1,150,272）
- 耗时从 13 天降至 3 小时
- 仍能覆盖关键候选（多来源 top-K + roll 扫描 + 局部细化）

## 机制判据与记录字段

### 8.1 机制分类（A4-S5）

对每个 top-K' 最亮姿态，标注以下机制标签：

| 机制类型 | 判据 | 标签 |
|---|---|---|
| **镜面主导（金属主体 specular）** | 金属主体占比 > 80% + 峰宽窄（FWHM < 10°） | `mechanism: metal_specular` |
| **太阳能板 glint** | 太阳能板占比 > 50% + roll 敏感度高 | `mechanism: solar_glint` |
| **满相增强（小相位角）** | phase_angle < 30° + 总 OCS 高 | `mechanism: full_phase_boost` |
| **遮挡控制** | 遮挡率变化与 OCS 变化强相关 | `mechanism: occlusion_control` |
| **漫反射主导** | 所有部件占比均 < 60% + 峰宽宽（FWHM > 30°） | `mechanism: diffuse_dominant` |

### 8.2 机制记录字段

每个 top-K' 姿态记录以下字段（供 A8 机制归纳使用）：

| 字段 | 类型 | 说明 |
|---|---|---|
| `mechanism_label` | string | 机制标签（如 "metal_specular"） |
| `dominant_component` | string | 主导部件（如 "jinshuzhuti" / "taiyangnengban"） |
| `dominant_component_fraction` | float | 主导部件占比（0-1） |
| `occlusion_ratio_percent` | float | 遮挡率（%） |
| `peak_fwhm_yaw_deg` | float | yaw 方向峰宽（FWHM，度） |
| `peak_fwhm_pitch_deg` | float | pitch 方向峰宽（FWHM，度） |
| `peak_fwhm_roll_deg` | float | roll 方向峰宽（FWHM，度） |
| `roll_sensitivity_ratio` | float | roll 敏感度（max_OCS / min_OCS in roll scan） |
| `is_near_halfvector` | boolean/null | 是否接近 half-vector 镜面条件（若可获得部件或主导面法向，则判断其与 sun+det 角平分方向夹角是否 < 10°；若缺少可用法向数据，则记录为 null/unknown） |

**峰宽（FWHM）计算**：
- 在局部细化结果中，找到峰值 OCS_max
- 沿某个方向（yaw/pitch/roll），找到 OCS > OCS_max / 2 的角度范围
- FWHM = 该范围的宽度（度）

**half-vector 镜面条件判断**（后处理，需要部件法向或主导面法向数据）：
```
half_vector = normalize(sun_direction_I + det_direction_I)
```
若部件法向或主导面法向与 half_vector 夹角 < 10°，标记为接近镜面条件。若当前脚本只能得到 mesh 级/面元级法向，则允许先用主导贡献面元的面积加权平均法向作近似；若法向信息不足，不得强行给出 half-vector 判定。
