# 小项目领头文件：卫星光度范围与最亮几何-姿态-材料机制

最后更新：2026-06-09

## 当前定位

本小项目不是论文写作附属任务，也不是为了复用旧图而补一段解释。它只服务两个明确任务：

1. 通过调研获得常规高轨/GEO类卫星可见光亮度或视星等范围，并记录来源、观测条件和可信度。
2. 基于当前卫星 STL、材料 BRDF、遮挡和 OCS 计算链路，系统寻找“什么太阳-目标-观测几何、什么卫星姿态、什么材料/部件朝向条件下观测最亮”，并解释最亮机制。

第二个任务的核心不是输出一个孤立的最大 OCS 数字，而是找到并归纳最亮构型：

```text
在某相位角、太阳方向、观测方向下，
卫星处于某 yaw/pitch/roll 姿态，
使某个材料/部件同时受照、可见、遮挡少，
或其法向接近太阳-观测角平分方向，
因此该部件主导 OCS，观测最亮。
```

最终答案可以不是唯一姿态点，而可能是一组最亮构型族。不同相位角、roll、材料参数下可能出现多个局部最亮结果，但它们必须能归纳到清楚的几何-材料机制。

## 关键方法判断

### OCS 与星等

当前 OCS 是模型计算得到的散射指标，可用于相对排序、部件贡献和相对星等差：

```text
Delta m = -2.5 log10(OCS_2 / OCS_1)
```

绝对视星等作为后续情景估计处理：

```text
m = K_cal - 2.5 log10(OCS) + 5 log10(R)
```

只有在 OCS 物理定义满足 `E_obs / E_sun = OCS / R^2` 且波段/太阳星等口径确认后，才可使用无标定常数形式。

### 当前采样问题

现有 5 几何 + yaw/pitch + roll=0 的采样能做预实验，但不足以完成第二任务。原因：

1. 五个几何只是代表性抽象方向，不是完整太阳-目标-观测几何空间。
2. roll 固定为 0，可能漏掉太阳能板或金属面镜面高光。
3. yaw/pitch 欧拉网格不是均匀三维姿态采样，且存在 yaw=0 与 360 重复。
4. 当前采样不能自然对应真实高轨观测，需要至少记录 `range_km`、相位角、太阳方向、观测方向和姿态约束。注：`range_km` 仅作为元数据字段记录，不进入 OCS 积分；距离只在 A9 情景星等估计后处理时使用。

### 推荐搜索策略

采用粗到细搜索，不一开始全空间高精度重跑：

1. 多几何粗扫：覆盖更多相位角和观测方位，找到亮度峰出现在哪些几何族。
2. 三自由度姿态粗扫：在候选几何下加入 roll，找到 top-K 姿态。
3. 局部细扫：围绕 top-K 进行 2 度、1 度或 0.5 度局部加密。
4. 机制归纳：判断最亮来自镜面角平分、受照可见面积、遮挡最小，还是材料参数驱动。
5. 情景星等估计：在相对结果闭合后，再引入距离和标定常数。
