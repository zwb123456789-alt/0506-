# Claude执行总览：小项目两任务闭合路线

最后更新：2026-06-09

## 执行总原则

本执行方案服务 `00_小项目总览.md`。Claude 必须先读取领头文件，再执行任何阶段任务。

小项目只有两个目标：

1. 调研常规高轨/GEO类卫星亮度或视星等范围。
2. 基于 STL、BRDF、遮挡和 OCS 链路，寻找最亮太阳-目标-观测几何、卫星姿态和材料/部件机制。

第二目标不是论文写作任务，也不是只找单个最大 OCS 数值。它要回答：

```text
什么材料/部件在什么太阳-观测几何与卫星姿态下最亮，
该最亮是否来自镜面角平分、受照可见面积、遮挡最少或材料参数。
```

## 文件保护规则

Claude 必须遵守：

1. 不删除原大项目文件。
2. 不修改原大项目文件。
3. 不移动、重命名、覆盖原大项目文件。
4. 不向小项目文件夹之外添加任何新文件。
5. 可以读取原大项目文件。
6. 如需固定证据，只能复制到小项目文件夹内，并记录来源路径。

小项目文件夹：

```text
小项目_卫星光度范围与最亮观测几何/
```

Claude 输出保存到：

```text
06_Claude执行方案/Claude输出/
```

Codex 审阅保存到：

```text
06_Claude执行方案/Codex审阅/
```

**编号归档说明**：

- 旧阶段成果（`阶段0–5_*.md`）为归档证据，保留原地，不删不改。
- 新产出统一使用 `A0–A10_*.md` 前缀，与旧文件编号不冲突。
- 旧阶段与新阶段的对应关系见 `00_小项目总览.md § 旧阶段成果归属`。

## Codex审阅标准

每阶段完成后，交给 Codex 审阅。Codex 默认检查：

1. 是否违反原大项目保护规则。
2. 是否服务两个任务，而不是转成论文写作叙事。
3. 是否把旧 phase63/五几何预实验写过头。
4. 是否混淆 OCS、相对星等差 `Delta m`、绝对视星等。
5. 是否遗漏太阳方向、观测方向、相位角、yaw/pitch/roll、材料参数、遮挡、per-part贡献。
6. 是否可以进入下一阶段。
