# 阶段3 Codex重审：按“常规高轨卫星普适范围”目标

重审时间：2026-06-07

重审对象：

```text
06_Claude执行方案/Claude输出/阶段3_常规卫星光度范围调研.md
```

## 用户目标重定义

用户要找的不是少数案例的亮度量级，而是：

```text
一般常规高轨/GEO卫星的视星等普适范围。
```

因此，阶段3的证据标准必须提高。零散业余观测、单颗卫星案例、未标明条件的经验范围，只能作为旁证，不能作为主结论。

## 总体结论

当前阶段3版本不能满足“普适范围”目标。它可以作为初步线索表，但不足以支撑“常规高轨卫星一般范围”的结论。

主要原因：

1. 证据多为混合来源，系统样本不足；
2. GEO 条目中不少是单案例或经验记录；
3. glint、常规亮度、表面亮度、视星等混在同一叙述中，虽然有区分意图，但证据层级不够；
4. 缺少最新、权威、系统性 SSA/SST 机构或论文资料；
5. 没有给出“普适范围”的统计定义，例如 median、5-95 percentile、typical range、operational range。

## 新审阅标准

阶段3若要支撑“普适范围”，必须满足以下要求。

### 1. 主证据必须来自 T1/T2 来源

优先级如下：

| 级别 | 来源类型 | 是否可支撑普适范围 |
|---|---|---|
| T1 | 同行评议论文、系统观测数据集、SSA/SST领域会议论文，有样本量和观测条件 | 可以 |
| T2 | 机构报告、国家实验室报告、ESA/NASA/USSF/AMOS/IAA/SPIE 等技术资料 | 可以作为强支撑 |
| T3 | 业余观测文章、社区数据库、杂志经验总结 | 只能作为旁证 |
| T4 | 无作者/无题名/无链接的经验值 | 不可用 |

### 2. 必须区分“常规范围”和“glint峰值”

最终表格至少应分为：

```text
GEO_regular_typical
GEO_bright_favorable_geometry
GEO_glint_peak
GEO_faint_tail
```

不要把 glint peak 混入 regular typical。

### 3. 必须定义“普适范围”的统计口径

Claude 需要明确采用哪种定义：

- 文献中的 typical range；
- 样本 median ± percentile；
- 多来源交叉重叠范围；
- conservative envelope；
- operational detection range。

如果文献没有统计分布，只能写：

```text
reported range in surveyed/observed cases
```

不能写：

```text
普适范围
```

### 4. 必须记录观测条件

每条资料至少记录：

```text
target/class
orbit regime
number of targets or observations
band/filter
range/slant range or orbit altitude
phase angle or solar phase condition
attitude/stabilization if available
regular vs glint
reported statistic
source type
confidence
```

## 当前阶段3的具体问题

### 1. GEO 11-14 mag 可以作为候选范围，但证据不足以叫“普适”

当前写：

```text
GEO 卫星常规视星等约 11-14 mag
```

这个量级合理，也有若干案例支撑。但要支撑“普适范围”，需要更多系统资料，例如：

- 多颗 GEO 卫星的光度测量样本；
- SSA/SST系统观测报告；
- 给出目标数量、观测次数、筛选条件；
- 明确 filter/band 和相位角范围。

建议改成：

```text
初步资料显示，部分常规GEO通信卫星在常见观测条件下多落在约 11-14 mag 量级；该范围需由系统观测样本进一步确认后才能作为普适范围。
```

### 2. 权威来源不足

当前可接受为线索的来源包括：

- AMOS 2013 stabilized GEO glints；
- PNNL/国家实验室报告中的 Galaxy 14 11-14 mag；
- LEO Steward Survey 2023，虽然是 LEO，不直接支撑 GEO；
- JRASC/S&T 类观测文章，只能旁证。

但阶段3需要继续补充：

- AMOS/Advanced Maui Optical and Space Surveillance Technologies Conference 中 GEO photometry/light curve 论文；
- SPIE/IAA/AMOS 中 “space object characterization / GEO photometry / lightcurve inversion” 论文；
- ESA Space Debris Office / IADC / USSF / NASA ODPO 相关 optical survey 或 brightness characterization 资料；
- 国内高轨目标光度建模/观测论文，但必须补齐题名、作者、期刊、年份。

### 3. MEO/LEO 不应占主导

用户现在目标是高轨/GEO。LEO/Starlink资料可作为距离效应和星等尺度背景，但不能成为阶段3主证据。

建议重构为：

1. GEO/HIGH-ORBIT main evidence；
2. GEO glint evidence；
3. LEO/MEO only as comparison appendix。

### 4. OCS sanity check 应从阶段3移出

阶段3的目标是“调研普适范围”。OCS 估算属于阶段4/5/6接口和对照工作。放在阶段3会混淆“文献范围”和“本项目估计”。

建议将第5节完全移到单独附录：

```text
附录：非结论性 OCS量级 sanity check
```

并明确：

```text
不得用于支撑普适范围。
```

## 给 Claude 的重做任务

请 Claude 按以下标准重做阶段3，而不是只小修。

### 任务A：建立权威来源表

至少寻找并记录 8-12 条资料，其中 GEO/high-orbit 主资料不少于 5 条。

每条必须包含：

```text
authors
title
year
venue/report
doi/url/report number
source tier
target count / observation count
orbit class
band/filter
reported magnitude statistic
regular or glint
limitations
```

### 任务B：给出证据分级

每条资料标注：

```text
A: 系统样本 + 同行评议/机构报告 + 条件清楚
B: 单案例或样本较小，但来源权威
C: 社区/业余/经验资料，只作旁证
D: 未核验，不进入结论
```

### 任务C：形成普适范围时使用保守语言

如果资料不足，只能写：

```text
reported typical range
```

不能写：

```text
universal range / 普适范围
```

建议最终输出三档：

| 类别 | 目标范围 | 证据要求 |
|---|---|---|
| 常规高轨/GEO typical | 由多来源重叠范围决定 | A/B 主证据 |
| 有利几何 bright range | 区分非glint和glint | A/B + 条件说明 |
| glint/flare peak | 单独列，不混入常规范围 | 专门文献 |

### 任务D：不要使用未核验负星等

除非找到 integrated apparent magnitude 的权威资料，否则删除：

```text
极端 glint 可达负星等
```

特别注意：`mag/arcsec²` 是表面亮度，不是整目标视星等。

## 对当前目的的建议结论口径

在资料未补齐前，阶段3最多只能提供临时口径：

```text
已有观测和报告显示，常规GEO卫星在非极端glint条件下常见视星等多在约 11-14 mag 量级；有利几何或太阳翼/镜面部件 glint 可带来数个星等增亮。该范围目前应视为reported typical range，而非严格普适统计范围。
```

这句话可以作为临时背景，但不能作为最终论文/报告中的强结论。

## 重审结论

阶段3需要按“普适范围”目标重做。当前版本不通过。

通过条件：

1. GEO/high-orbit 主证据不少于 5 条；
2. 至少 2-3 条来自系统观测论文或机构/国家实验室/SSA会议资料；
3. 每条资料可追溯；
4. regular、bright favorable geometry、glint peak 分开；
5. 给出统计口径或明确说明只是 reported range。
