# 阶段4 Claude提示词：高轨几何到 OCS 接口设计

请只设计接口，不实施代码。

## 任务目标

设计从高轨/STK几何数据到现有 OCS 扫描代码的输入接口。

## 必须解决

1. STK/高轨几何中的坐标系与 OCS 代码坐标系如何对应。
2. `sun_direction` 和 `det_direction` 应该在哪个坐标系表达。
3. 目标姿态 yaw/pitch/roll 与 STL 本体系如何定义。
4. 是否需要把 STK 时间序列离散成多个 OCS scan case。
5. 每个 case 的命名规范。
6. `range_km` 如何只用于星等/光度换算，而不误入 OCS 积分。

## 输出要求

- 文件命名规范；
- 质量检查清单；
- 与阶段1公式审计的衔接。
