## 本阶段目标

完成 A1：OCS定义与采样逻辑审计。

请重点回答：

1. 当前 OCS 在小项目中应如何定义？
   - 是模型散射指标；
   - 可用于相对排序、部件贡献和 Delta m；
   - 是否可直接带面积单位，需要审计后谨慎说明。
2. `Delta m = -2.5 log10(OCS_2 / OCS_1)` 的适用条件是什么？
   - 只比较同一口径、同一链路、同一波段/参数假设下的 OCS；
   - 不跨 face-center 与 pixel-level 口径混算；
   - 不与未标定绝对星等混淆。
3. 绝对视星等为什么必须推迟到 A9？
   - 需要距离 `R`；
   - 需要 `K_cal` 或太阳星等/波段口径；
   - 需要确认 OCS 物理定义是否满足 `E_obs / E_sun = OCS / R^2`；
   - 只能作为情景估计，不冒充实测。
4. 旧采样逻辑有哪些缺陷？
   - yaw/pitch 欧拉网格不是均匀三维姿态采样；
   - yaw=0 与 yaw=360 重复；
   - roll 固定为 0，不能覆盖三自由度姿态；
   - 五个旧几何不是完整太阳-目标-观测几何空间；
   - 五几何 face-center 旧口径不能与后续 pixel-level 结果直接混表。
5. A1 对 A3/A4/A5 的约束是什么？
   - A3 必须定义相位角、太阳方向、观测方向、range_km 元数据；
   - A4 必须处理 yaw/pitch/roll 和局部细化，但具体角度数不要在 A1 固化；
   - A5 必须规定输出字段，支持机制归纳和口径追踪。
