# 阶段6 Claude提示词：综合结论框架与证据等级

请只整合框架，不写最终结论。

## 任务目标

设计最终报告/论文段落如何组织，并为每类结论分配证据等级。

## 必须包含

1. 可以直接写的结论；
2. 需要条件限定的结论；
3. 只能作为假设或待验证的问题；
4. 不能写的表述；
5. 每个结论对应的证据来源；
6. Codex 审阅清单。

## 证据等级建议

| 等级 | 含义 |
|---|---|
| A | 有真实文献/观测数据支持，条件明确 |
| B | 有本项目仿真数据支持，几何/材料/姿态条件明确 |
| C | 有物理机制支持，但尚未完成仿真或调研 |
| D | 仅为待验证假设 |

## 输出要求

输出《阶段6_综合结论框架与证据等级.md》，包含：

- 结论表；
- 证据表；
- 红线表述；
- 最终报告结构建议；
- 交给 Codex 的审阅要点。

## 禁止

- 不生成最终论文段落；
- 不新增未验证数值；
- 不把 C/D 级结论写成 A/B 级。

## 交付物

保存为：

```text
06_Claude执行方案/Claude输出/阶段6_综合结论框架与证据等级.md
```

## 交给 Codex 审阅时重点

- 证据等级是否匹配；
- 是否过度外推；
- 是否把真实光度与仿真 OCS 混用。
