## 1. 研究问题边界

本小项目限定回答以下四个问题，不超出此范围：

| 编号 | 问题 | 边界说明 |
|---|---|---|
| Q1 | 常规卫星光度的最大/最小/典型范围是多少？ | 需要文献调研支撑；本小项目自身不产生真实观测数据 |
| Q2 | 高轨/GEO 条件下什么观测几何最亮？ | 仅在引入 GEO 距离、观测站-目标几何后才能回答；当前 phase63 数据不含此信息 |
| Q3 | 太阳光打到哪个部件最亮、从哪个方向观测最亮？ | 可用现有 STL + OCS 仿真回答，但结论仅在指定几何/姿态/BRDF 下成立 |
| Q4 | 如何从现有 OCS 结果建立与光度/星等的换算？ | 需先确认 OCS 物理定义，再决定是否引入距离和标定 |

- 不做真实外场观测或望远镜验证
- 不预测特定卫星型号的在轨亮度
- 不实施高轨轨道仿真（STK 等），除非后续阶段明确授权
- 不对大项目的论文写作、反演实验或模块 A/B/C 产生任何影响

## 2. 术语定义

### 2.1 OCS（Optical Cross Section，等效光学散射截面）

本项目模块 A 计算的物理量。候选换算关系之一为：

```
E_obs / E_sun = OCS / R^2
```

但当前项目中的 OCS 是否满足该定义，需要在阶段1审计 `ocs_core.py`、BRDF 归一化和单位后确认。可能存在 `4π`、`π`、BRDF 归一化常数、方向性散射量或标定常数的差异。

- `E_obs`：观测者处接收到的目标辐照度
- `E_sun`：目标处太阳辐照度
- `R`：目标到观测者距离
- OCS 单位预期为 m^2，但需核验 `ocs_core.py` 确认；OCS 也可能是相对量而非可直接进入绝对辐照度公式的物理量

**注意**：本项目的 OCS 是在固定太阳方向 (`SUN_VECTOR`) 和固定观测方向 (`DET_VECTOR`) 下，对卫星 STL 模型在 2D 姿态网格 (yaw × pitch) 上扫描得到的物理量。它不包含轨道高度、目标-观测站距离或波段响应。

### 2.2 观测通量 / 观测辐照度 / 视亮度（Observed Irradiance / Apparent Brightness）

卫星反射太阳光后在观测者处产生的辐照度或通量。不使用"Luminosity"一词，因 luminosity 通常指源的总发光功率，本项目关注的是观测者处的接收通量。观测亮度取决于：

- 太阳-目标-观测者几何（相位角）
- 目标表面材料的 BRDF
- 目标姿态（决定哪些面受照、哪些面可见）
- 目标-观测者距离
- 观测波段

### 2.3 视星等（Apparent Magnitude）

观测者看到的卫星亮度，以星等标度表示。若阶段1确认 OCS 满足 `E_obs/E_sun = OCS/R^2`，则可考虑使用：

```
m = m_sun - 2.5 log10(OCS / R^2)
```

若 OCS 定义不同，则可能需要 `4π`、`π`、波段响应或 `K_cal` 标定常数。具体形式待阶段1审计后确定。

- 数值越小越亮
- 视星等是距离相关的；同一颗卫星在不同距离下视星等不同
- 本项目在未完成标定前，不能给出绝对视星等

### 2.4 相对星等差（Delta Magnitude）

两个 OCS 值之间的星等差：

```
Delta m = -2.5 log10(OCS_2 / OCS_1)
```

- 不依赖距离、波段或绝对标定
- 本项目已有 phase63 的相对星等差结果：最亮 vs 中位 = -7.948 mag，最亮 vs 最暗 = -9.559 mag
- 这是本小项目目前唯一可安全使用的星等口径

### 2.5 高轨 / GEO（Geostationary Earth Orbit）

- GEO 特指地球同步轨道，高度约 35,786 km，轨道倾角接近 0°
- "高轨"在本项目中泛指 GEO 及附近轨道（如 GTO 远地点）
- **关键限制**：现有 phase63 数据只定义了太阳方向和观测方向的相对角度（相位角约 63°），没有写入任何轨道高度或目标距离。因此，现有 OCS 结果不能直接称为"高轨结果"或"GEO 结果"

### 2.6 Glint / Flare（镜面反射闪耀）

- Glint：卫星表面（尤其是太阳能板或金属面）在特定姿态下产生镜面反射，使亮度突然增加
- Flare：极端 glint 事件，亮度可能超过卫星常态数个星等
- Glint 条件：表面法线接近太阳-观测者双矢量的角平分线
- 本项目 OCS 的峰值姿态（如 phase63 中 yaw=300, pitch=15）可能对应 glint 条件，但在未标定前不能确认

### 2.7 相位角（Phase Angle）

太阳-目标-观测者之间的夹角。项目已有多观测几何结果使用 phase24/45/63/90/120 等标签。以下为基于标签的近似理解，具体太阳/观测向量与实际相位角应以各目录 `config_used.json` 或 `ocs_scan.json` 为准：

| 标签 | 近似相位角 | 太阳-观测几何含义 |
|---|---|---|
| phase24 | ~24° | 近背向散射（太阳和观测者几乎同侧） |
| phase45 | ~45° | 中等前向散射 |
| phase63 | ~63° | 中等角度 |
| phase90 | ~90° | 侧向散射 |
| phase120 | ~120° | 前向散射 |

## 3. 结论边界：可以说什么、不可以说什么

### 3.1 目前可以说的

| 结论类型 | 示例 | 依据 |
|---|---|---|
| 相对亮度排序 | "在 phase63 几何下，yaw=300/pitch=15 的姿态 OCS 最大" | `ocs_scan.csv` 直接可得 |
| 部件贡献比例 | "最亮姿态下金属主体贡献 99.9% 的 OCS" | per-part OCS 字段 |
| 相对星等差 | "最亮姿态比中位姿态亮约 7.95 mag" | Delta m 从 OCS 比值计算 |
| 多几何趋势 | "在 phase63 下金属主体主导；需验证其他相位角" | 已有 phase63 结果 + 计划扩展 |
| 姿态敏感性 | "OCS 在 2701 个姿态间动态范围约 6660 倍" | max/min OCS 比值 |

### 3.2 目前不可以说的

| 禁止结论 | 原因 |
|---|---|
| "GEO 卫星视星等范围为 X 到 Y" | 未引入 GEO 距离，未完成绝对标定 |
| "高轨卫星最亮部件是金属主体" | phase63 不等于高轨；且仅一个相位角 |
| "本仿真证明真实卫星亮度为..." | 无真实观测验证，仅为仿真 |
| "OCS 越大就能直接给出真实观测星等" | 未标定；OCS 可能只是相对量。但"在同一几何、同一BRDF、同一距离/波段口径下，OCS 越大可作为相对更亮的判据"是允许的 |
| "太阳能板一定不是最亮部件" | 仅 phase63 一个相位角下的结果，其他相位角未验证 |
| "相位角 63° 是高轨典型观测几何" | 需要 STK 场景或文献支撑 |

### 3.3 条件性结论（需满足前提后才可说）

| 条件结论 | 前提条件 |
|---|---|
| "在距离 R=X km 时，OCS=Y 对应视星等 Z" | 确认 OCS 物理定义为 m^2 + 确定 m_sun + 确定波段 |
| "高轨典型观测几何下最亮姿态为..." | 引入 GEO 距离/观测站几何 + 完成星等换算 |
| "金属主体在多数相位角下主导" | 完成 phase24/45/90/120 的多几何扫描 |

## 4. 原大项目文件保护规则

本小项目的工作边界为：

```
D:/我的文件/研究生学术/光学项目/0506新/小项目_卫星光度范围与最亮观测几何/
```

### 4.1 绝对禁止

1. 删除原大项目任何文件
2. 修改原大项目任何文件（包括代码、数据、论文、配置）
3. 向原大项目既有目录添加新文件
4. 移动、重命名、覆盖原大项目文件
5. 对原大项目代码/数据做格式化、清理或重生成

### 4.2 允许操作

1. 在小项目文件夹内新建文档、表格、脚本草案和分析记录
2. 复制原大项目文件到小项目文件夹作为只读证据副本
3. 读取原大项目文件内容用于分析，以路径索引和摘要方式引用

### 4.3 引用原大项目数据的方式

- 优先使用路径索引（如 `结果/模块A_重构/.../ocs_scan.csv`）
- 需要固定证据版本时，复制到小项目的 `备份_原项目只读副本/` 目录
- 备份文件保留来源路径记录，不反向覆盖原文件
