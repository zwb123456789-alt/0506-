## 2. OCS 积分的数学形式

### 2.1 代码核心公式（ocs_core.py 第 78 行、第 101 行）

```python
ocs = sum( areas_PI * scale_sq * brdf_vec * cos_i_vec * cos_r_vec )
```

展开为数学形式：

```
OCS = Σ_f  A_f · s² · f_r(N_f, L, V) · (N_f · L) · (N_f · V)
```

其中：
- `A_f`：面元 f 的面积（STL 原始单位，见下文单位分析）
- `s` = `UNIT_SCALE` = 1e-3（mm → m 转换因子）
- `s²` = 1e-6（面积从 mm² → m²）
- `f_r`：BRDF 值（单位 sr⁻¹）
- `N_f · L`：面元法向与太阳方向的余弦（cos_i）
- `N_f · V`：面元法向与观测方向的余弦（cos_r）
- 求和仅对满足 `(N·L > 0) & (N·V > 0)` 的面元（双面可见）

### 2.2 物理含义

这是标准的离散面元散射辐照度积分。从辐射度学出发：

```
E_obs = Σ_f  E_sun · f_r(N_f, L, V) · cos_i_f · cos_r_f · (A_f / R²)
```

整理得：

```
E_obs / E_sun = [Σ_f  A_f · f_r · cos_i · cos_r] / R² = OCS_code / R²
```

因此代码计算的 `OCS_code` 在物理上对应：

```
OCS_code = E_obs · R² / E_sun
```

其量纲为面积（m²），前提是 `UNIT_SCALE` 正确且 `f_r` 是物理 BRDF。

## 3. OCS 输出的物理定性

### 3.1 判定：按本代码定义具有面积量纲，可作为方向性 OCS-like 量使用

| 条件 | 状态 | 说明 |
|---|---|---|
| 单位转换 | ✅ 已确认 | `UNIT_SCALE=1e-3` 正确将 mm STL 转为 m，面积因子 `s²=1e-6` |
| BRDF 模型 | ⚠️ 物理形式可用 | Cook-Torrance 微表面模型，漫反射 `base_color/π` + 镜面 `DGF/(4·NoL·NoV)`；严格能量守恒未做半球积分审计，当前 nominal 参数下可作为合理近似 |
| BRDF 参数 | ⚠️ 待验证 | 名义参数（铝合金 F0=0.91、玻璃 ior=1.5 等）是否匹配真实材料未确认 |
| STL 几何精度 | ⚠️ 待验证 | 真实 STL 的单位是否确实是 mm、面元密度是否足够 |
| 绝对标定 | ❌ 未完成 | 无真实卫星观测数据用于校准 |

### 3.2 GGX BRDF 能量守恒性分析

代码中 `brdf_models.py` 的 GGX 实现：

```python
f_diffuse  = (1 - metallic) * (base_color / π)
f_specular = D_GGX(NoH, α) · G_Smith(NoL, NoV, α) · F_Schlick(VoH, F0) / (4·NoL·NoV)
```

- 漫反射项：`1/π` 归一化确保半球积分 ≤ base_color ✅
- 镜面项：GGX NDF `D` 满足 `∫ D·NoH dω = 1`；Smith-GGX `G ≤ 1`；`F ≤ 1` ✅
- 金属（metallic=1.0）：无漫反射，纯镜面，F0=0.91（铝），物理合理 ✅
- 电介质（metallic=0.0）：F0 从 ior 计算，`(1.5-1)²/(1.5+1)² = 0.04`，物理合理 ✅

**结论**：当前 GGX 实现采用标准 Cook-Torrance 镜面项和 Lambert 漫反射项，具有明确物理形式。在当前 nominal 低反射非金属参数下可作为物理近似使用。但其漫反射-镜面能量分配未做严格半球积分审计（例如电介质 diffuse 项未乘 `(1-F)`），因此不要写成已严格能量守恒。

### 3.3 LegacyPhong 的问题（非当前运行，但需记录）

`materials.py` 中 LegacyPhong 的镜面项 `rho_s * (NoH)^n` **缺少归一化因子** `(n+2)/(2π)`。这意味着 LegacyPhong 的 OCS 不严格具有 m² 的物理意义。当前运行使用的是 GGX（`config_used.json` 确认 `brdf_model: "ggx"`），因此此问题不影响当前结果。

## 4. 星等换算公式审计

### 4.1 相对星等差（Delta m）

```text
Delta m = -2.5 log10(OCS_2 / OCS_1)
```

**可信度：可靠 ✅**

- 仅依赖 OCS 比值，距离 R、太阳星等 m_sun、波段响应、标定常数全部约掉
- 前提：两个 OCS 来自同一代码、同一 BRDF、同一 `UNIT_SCALE`（当前满足）
- 当前 phase63 姿态扫描使用同一抽象观测距离，因此 Delta m 可只由 OCS 比值给出；若比较高轨时间序列（不同时间、不同距离），则观测星等差应为 `Delta m_obs = -2.5 log10(OCS_2/OCS_1) + 5 log10(R_2/R_1)`
- 已有结果：phase63 中 Delta m(最亮/中位) = -7.948 mag，Delta m(最亮/最暗) = -9.559 mag

### 4.2 绝对星等公式候选分析

#### 候选 A：`m = m_sun - 2.5 log10(OCS / R²)`

**推导**：
```
E_obs / E_sun = OCS / R²
m - m_sun = -2.5 log10(E_obs / E_sun)
=> m = m_sun - 2.5 log10(OCS / R²)
```

**条件**：
1. OCS 必须是物理 m² 量纲（GGX 模型满足，但需验证 STL 几何和 BRDF 参数）
2. R 必须使用与 `sqrt(OCS)` 一致的单位（即 R 用米）
3. m_sun 必须与观测波段一致（可见光 V 波段候选值 m_sun ≈ -26.74，待阶段3/4引用确认和波段锁定）

**可信度：条件成立时可用 ⚠️**

当前缺失：
- STL 模型的绝对尺寸是否与真实卫星一致（比例尺问题）
- BRDF 参数是否经过真实材料标定
- 观测波段未定义

#### 候选 B：`m = m_sun - 2.5 log10(OCS / (4πR²))`

**分析**：此公式适用于各向同性点源（辐射强度 → 照度的 4π 立体角归一化）。对于本代码中直接由 BRDF 面元积分得到的 directional OCS，不应再额外除以 `4π`。但不同文献可能把 OCS/phase function/散射截面定义为总散射量或各向同性等效量，届时可能出现 `4π` 或相位函数归一化。因此后续与文献公式对接时必须核对定义。

**可信度：对本代码 directional OCS 不适用；与外部文献对接时需核查 ❌**

#### 候选 C：`m = K_cal - 2.5 log10(OCS) + 5 log10(R)`

**分析**：等价于候选 A，但将 m_sun 和其他标定因子合并为 `K_cal`。当 OCS 可能是相对量（非物理 m²）时，用 `K_cal` 吸收未知标定因子。

**可信度：最保守的候选形式 ⚠️**

- `K_cal` 需要通过文献中已知卫星在已知距离/相位角下的星等来标定
- 仅做相对比较时不需要确定 `K_cal`

## 5. 公式可信度分级总结

| 公式 | 可信度 | 条件 |
|---|---|---|
| `Delta m = -2.5 log10(OCS_2/OCS_1)` | ✅ 可靠 | 同一代码/BRDF/UNIT_SCALE |
| `m = m_sun - 2.5 log10(OCS/R²)` | ⚠️ 条件可用 | GGX + 物理 STL + 波段确定 + 材料标定 |
| `m = m_sun - 2.5 log10(OCS/(4πR²))` | ❌ 对本代码不适用 | 本代码 directional OCS 不应额外除以 `4π`；但与外部文献对接时需核查其 OCS/相位函数定义 |
| `m = K_cal - 2.5 log10(OCS) + 5 log10(R)` | ⚠️ 最保守 | 需要外部标定确定 K_cal |

## 7. 推荐后续换算口径

### 7.1 当前可直接使用

- **相对星等差** `Delta m = -2.5 log10(OCS_2/OCS_1)`：用于姿态间亮度比较、部件贡献比较、多几何比较
- **OCS 排序**：在同一相位角下，OCS 越大 = 相对越亮
- **per-part OCS 占比**：部件贡献百分比

### 7.2 条件使用（需标注假设）

若需给出绝对视星等估算，推荐使用：

```
m = m_sun - 2.5 log10(OCS / R²) + Δm_atm
```

其中：
- `m_sun` = -26.74（V 波段候选值，待阶段3/4引用确认和波段锁定）
- `R` = 目标-观测站距离（米），如 GEO 约 36,000 km = 3.6×10⁷ m
- `Δm_atm` = 大气消光修正（可选，GEO 仰角 30° 时约 0.3-0.6 mag）
- **必须声明**：此估算假设 STL 为真实尺寸、GGX 参数为名义值、未做真实标定

### 7.3 估算示例（非结论性 sanity check，不得引用为结果）

**警告**：以下计算仅供量级 sanity check，不得写入结论证据表或论文。绝对星等公式仍需阶段3/4确认波段、太阳星等、距离、STL尺度、材料参数后才能使用。

以 phase63 最大 OCS = 14.82 m²、GEO 距离 R = 3.6×10⁷ m 为例：

```
m ≈ -26.74 - 2.5 log10(14.82 / (3.6e7)²)
  = -26.74 - 2.5 log10(14.82 / 1.296e15)
  = -26.74 - 2.5 log10(1.143e-14)
  = -26.74 - 2.5 × (-13.942)
  = -26.74 + 34.86
  ≈ 8.1 mag
```

对于中位 OCS = 0.00981：

```
m ≈ -26.74 - 2.5 log10(0.00981 / 1.296e15)
  = -26.74 - 2.5 log10(7.57e-18)
  = -26.74 - 2.5 × (-17.121)
  = -26.74 + 42.80
  ≈ 16.1 mag
```

**注意**：以上仅为量级参考。GEO 卫星典型视星等约 10-14 mag（文献待调研），8.1 mag 可能偏亮（因为 glint 姿态 + 名义高反射率参数），16.1 mag 可能偏暗。这些差异正说明需要 C1-C5 的确认。

## 9. 审计结论

### 9.1 核心发现

1. **OCS 积分公式正确**：代码实现的 `Σ A·f_r·cos_i·cos_r` 是标准的离散面元散射积分。
2. **GGX BRDF 具有物理形式**：当前实现采用标准 Cook-Torrance 镜面项和 Lambert 漫反射项，在 nominal 参数下可作为合理近似；但严格能量守恒未做半球积分审计。按本代码定义，OCS 具有面积量纲，可作为方向性 OCS-like 量使用；绝对可信度依赖 STL 比例尺、BRDF 参数、mesh 精度和遮挡语义。
3. **相对星等差可靠**：`Delta m = -2.5 log10(OCS_2/OCS_1)` 可直接使用（同一距离下）；若跨距离比较需加入 `5 log10(R_2/R_1)` 项。
4. **绝对星等有条件可用**：`m = m_sun - 2.5 log10(OCS/R²)` 需要 C1-C5 确认后才能声称成立。
5. **当前绝对星等估算仅供量级参考**：8-16 mag 的范围与 GEO 卫星观测大致可比，但偏差来源（STL 比例尺、BRDF 参数、波段）需逐一排查。

### 9.2 对后续阶段的建议

- **阶段3（文献调研）**：重点收集 GEO 卫星 V 波段视星等数据，用于与本项目 OCS 估算做量级对照。
- **阶段4（高轨几何设计）**：引入 GEO 距离后，用候选 A 做绝对星等估算时必须声明假设。
- **阶段5（STL 实验）**：部件贡献排序和最亮姿态判定可直接使用 OCS 排序和 Delta m，无需绝对标定。
- **阶段6（结论整合）**：论文中只写 Delta m 和 OCS 排序；绝对星等若需给出，必须标注"基于名义 BRDF 参数和 STL 比例尺假设"。
