### 2. ✅ Phase 2a roll扫描候选集扩展

**修正位置**：§2.2.1、§9.1

**修正内容**：

  3. 太阳能板OCS top-5

**计算量变化**：

- 修正后：5×20×73 ≈ 7,300点（增加1倍，能覆盖roll≠0时才最亮的部件和glint）

### 3. ✅ Glint几何公式明确符号

**修正位置**：§5.1

**修正内容**：提供两种等价严格写法，遵守阶段4方向向量约定（卫星→太阳/观测者）

**写法1（half-vector形式）**：
```
h = normalize(s + v)
dot(n_panel, h) > cos(θ_h_threshold)
```

**写法2（镜面反射向量形式）**：
```
r = 2 * dot(n_panel, s) * n_panel - s
dot(r, v) > cos(θ_glint_threshold)
```

**关键点**：
- 不使用`abs(dot(...))`，避免背面误判
- `s`和`v`的方向约定明确（从卫星指向太阳/观测者）

### 5. ✅ visible_faces降级为辅助判据

**修正内容**：

**修正位置**：§5.3

**修正内容**：
- 删除"时间持续性"指标（需要轨道角速度+姿态时间序列，静态扫描无法推导）
- 改为输出"姿态空间峰宽"（yaw/pitch/roll FWHM）
- 添加注释明确区分"静态姿态扫描输出"与"文献背景参考"

### 7. ✅ 相位角加密触发条件扩展

**修正位置**：§9.3

**修正内容**：从单一触发条件扩展为三种方式（满足其一即触发）：
1. 相邻相位角top-1差异 > 2×（原有）
2. 几何glint缺失触发（新增）：glint候选的half-vector与太阳能板法向接近，但5个离散相位角未命中
3. 固定安全加密（新增建议）：至少补phase15和phase35/75中一个
