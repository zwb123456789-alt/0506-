## 必改问题修正清单

### 1. ✅ 材料GGX参数修正

**问题**：原方案§7.1材料参数与`materials.py`实际代码不一致（金属主体α错写0.3实为0.20，太阳能板α错写0.1实为0.40）。

**修正位置**：
- §7.1 完整替换为从`materials.py`读取的真实GGX参数表
- §7.2 材料敏感性分析根据真实参数重写（金属主体α=0.20是最强镜面候选，太阳能板α=0.40并非镜面）

**修正后参数**：
```
金属主体:  roughness=0.20, metallic=1.0, F0=0.91
太阳能板:  roughness=0.40, metallic=0.0, ior=1.5
隐身板:    roughness=0.90, metallic=0.0, ior=1.5
```

**修正后判断**：
- 金属主体（α=0.20，高F0）→ 最强specular候选
- 太阳能板（α=0.40）→ 介于镜面和漫反射之间，glint若出现更多由几何（平面法向对齐）而非材料驱动
- 隐身板（α=0.90）→ 接近完全漫反射

### 2. ✅ Phase 2 roll扫描候选集扩展

**问题**：原方案只对总OCS top-K做roll扫描，会漏掉roll=0时不亮但roll≠0时才出现glint或部件最亮点的姿态。

**修正位置**：
- §2.2.1 Roll精扫候选集改为多来源并集：
  1. 总OCS top-10
  2. 金属主体OCS top-5
  3. 太阳能板OCS top-5
  4. 高太阳能板占比 top-5
  5. 可选：几何glint候选

- §9.1 Roll精扫方案同步修改，并集去重后每相位角约15-20个候选

**计算量变化**：
- 原方案：5×10×73 = 3,650点
- 修正后：5×20×73 ≈ 7,300点（增加1倍，但能覆盖部件最亮点）

### 3. ✅ Glint几何公式明确符号

**问题**：原方案§5.1 glint判据使用模糊表述`R_specular`和`abs(dot(...))`，未遵守阶段4锁定的方向向量约定。

**修正位置**：
- §5.1 太阳能板Glint判据S1，提供两种等价严格写法：

**写法1（half-vector形式，推荐）**：
```
h = normalize(s + v)
dot(n_panel, h) > cos(θ_h_threshold)
```

**写法2（镜面反射向量形式）**：
```
r = 2 * dot(n_panel, s) * n_panel - s
dot(r, v) > cos(θ_glint_threshold)
```

其中`s = sun_direction_M`（卫星→太阳），`v = det_direction_M`（卫星→观测者），遵守阶段4约定。

**明确声明**：不使用`abs(dot(...))`，除非明确考虑双面板；否则背面反射会被误判为glint。
