# Claude/Codex 对话区说明

本目录只作为 Claude 执行、Codex 审阅和往返修订的对话工作区。

## 子目录用途

| 目录 | 用途 |
|---|---|
| `Claude提示词/` | 保存给 Claude 的阶段提示词 |
| `Claude输出/` | 保存 Claude 草稿输出、未审阅输出和旧阶段中间过程 |
| `Codex审阅/` | 保存 Codex 审阅、复审和给 Claude 的修订意见 |

## 正式成果位置

通过审阅、可作为小项目阶段成果的文件，不长期保留在本目录，应移入：

```text
00_A0-A10正式成果区/
```

每个阶段放入对应 A 阶段子目录，例如：

| 阶段 | 正式成果目录 |
|---|---|
| A0 | `00_A0-A10正式成果区/A0_边界冻结与旧结果体检/` |

| A2 | `00_A0-A10正式成果区/A2_亮度范围调研/` |
| A3 | `00_A0-A10正式成果区/A3_几何搜索空间设计/` |
| A4 | `00_A0-A10正式成果区/A4_三维姿态搜索方案/` |
| A5 | `00_A0-A10正式成果区/A5_脚本与输出规范/` |
| A6 | `00_A0-A10正式成果区/A6_旧五几何预实验复核/` |
