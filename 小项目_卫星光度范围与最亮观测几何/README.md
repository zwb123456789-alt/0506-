# 小项目目录结构说明

本小项目当前采用四块结构：

| 目录 | 用途 |
|---|---|
| `00_A0-A10正式成果区/` | 唯一正式成果区。通过 Codex 审阅的 A0-A10 阶段成果放入对应子目录 |
| `01_说明文档区/` | 当前仍有用、需要反复读取的口径说明、几何说明、STL/材料说明 |
| `06_Claude执行方案/` | Claude/Codex 对话区。保存提示词、Claude 草稿输出、Codex 审阅和过程记录 |
| `90_旧结构与支撑材料归档/` | 历史阶段成果、旧草案、预实验脚本和旧支撑材料归档 |

根目录只保留项目级说明文件：

```text
00_小项目总览.md
00_原大项目文件保护规则.md
README.md
```

## 工作流

1. Claude 草稿输出先放入 `06_Claude执行方案/Claude输出/`。
2. Codex 审阅写入 `06_Claude执行方案/Codex审阅/`。
3. 审阅通过并完成必要修订后，正式成果移入 `00_A0-A10正式成果区/` 对应阶段子目录。
4. 说明文档区可作为当前阶段的常用支撑口径读取。
5. 旧结构归档区只读复用，不再作为正式成果输出位置。
