# 旧结构与支撑材料归档

本目录保存整理前的旧主题文件夹、旧阶段成果、预实验脚本和历史支撑材料。它们不再作为 A0-A10 的正式成果区，也不再作为常用说明文档区。

当前仍需要反复读取的说明文档已移入：

```text
01_说明文档区/
```

## 归档内容

| 目录 | 内容 |
|---|---|
| `00_边界与旧阶段资料/` | 旧阶段0等边界类历史文件 |
| `01_调研_常规卫星光度范围/` | 旧调研总览、文献笔记、旧阶段3调研成果 |
| `02_OCS_光度换算标准/` | 仅保留旧阶段1审计成果；常用 OCS/星等说明已移入 `01_说明文档区/02_OCS与星等口径说明/` |
| `03_高轨最亮观测几何/` | 常用几何说明和接口材料已移入 `01_说明文档区/03_高轨几何问题说明/`；若为空可保留作历史目录 |
| `04_STL实验判断/` | 旧实验计划、旧阶段5方案、phase63 预实验输出和脚本 |
| `05_结论整合/` | 旧结论模板、证据表和位置说明 |

## 使用规则

- 可以读取本目录作为历史证据、旧方案和预实验数据来源。
- 不在本目录继续写 A0-A10 的正式成果。
- 当前阶段需要反复引用的说明口径，应优先查看 `01_说明文档区/`。
- 后续正式成果统一写入 `00_A0-A10正式成果区/` 对应阶段子目录。
- Claude 草稿输出先进入 `06_Claude执行方案/Claude输出/`，经 Codex 审阅通过后再移入正式成果区。
