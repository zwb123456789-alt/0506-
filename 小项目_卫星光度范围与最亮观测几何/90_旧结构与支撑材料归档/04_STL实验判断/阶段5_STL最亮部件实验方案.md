# 阶段5：STL最亮部件实验方案

最后更新：2026-06-07

---

## 1. 实验目标与问题拆解

### 1.1 核心问题

> "太阳光打到哪里最亮、从哪里观测最亮？"

拆解为三个可独立回答的子问题：

| 编号 | 子问题 | 输出形式 |
|---|---|---|
| **Q1** | 哪个**部件**对总OCS贡献最大？ | per-part OCS占比排序（绝对最亮部件） |
| **Q2** | 在什么**姿态+相位角**组合下，该部件最亮？ | 最亮姿态记录表（top-K） |
| **Q3** | 不同部件的最亮条件是否互斥？是否有姿态区间使所有部件都暗？ | 部件贡献交叉矩阵 |

### 1.2 实验定位

本阶段实验是**粗筛→精扫两阶段设计**：

- **粗筛（Phase 1）**：复用现有5相位角 + yaw/pitch二维网格，roll=0，锁定候选最亮区间
- **精扫（Phase 2）**：对top-K候选做roll扫描、相位角加密、局部姿态加密

**不追求全局最亮**（计算代价不可承受），而是回答："在多大搜索精度下，可以多确定地给出最亮估计"。

### 2.2 Phase 2：精扫矩阵

#### 2.2.1 Roll精扫

**候选集生成（关键修正）**：Phase 2a的roll扫描不能只从Phase 1的总OCS top-K出发（会漏掉roll=0时不亮但roll≠0时glint的姿态），必须从**多来源候选并集**出发：

| 候选来源 | 定义 | 每相位角K值 |
|---|---|---|
| **总OCS top-K** | `ocs_with_occ_total` 排序的前K个姿态 | K=10 |
| **金属主体 top-K** | `ocs_with_occ_jinshuzhuti` 排序的前K个 | K=5 |
| **太阳能板 top-K** | `ocs_with_occ_taiyangnengban` 排序的前K个 | K=5 |
| **高太阳能板占比 top-K** | `pct_taiyangnengban` 排序的前K个（即使总OCS不高） | K=5 |
| **几何glint候选**（可选） | 基于太阳能板法向与half-vector接近度筛选 | K=0-5 |

**并集去重后预计**：每相位角约15-20个独立候选（有重叠）。

对每个候选，展开roll维度：

| 参数 | 范围 | 步长 | 点数 | 说明 |
|---|---|---|---|---|
| yaw | 取候选的yaw值 | — | ~20 | 从多来源候选并集继承 |
| pitch | 取候选的pitch值 | — | ~20 | 从多来源候选并集继承 |
| roll | 0°–360° | 5° | 73 | **新增维度** |

**Phase 2a总计（roll粗扫）**：5 × 20 × 73 ≈ **7,300 个增量姿态点**（比原方案增加1倍，但能覆盖部件最亮点）

#### 2.2.2 局部加密

对roll精扫后仍保持top-K的姿态点，做局部加密：

| 参数 | 范围 | 步长 | 点数 | 说明 |
|---|---|---|---|---|
| yaw | yaw_best ± 5° | 1° | 11 | 局部加密 |
| pitch | pitch_best ± 5° | 1° | 11 | 局部加密 |
| roll | roll_best ± 10° | 1° | 21 | 局部加密 |

**Phase 2b总计（局部加密）**：5 × K' × (11 × 11 × 21) ≈ 5 × 3 × 2541 ≈ **38,115 个增量姿态点**。此数字过大，实际执行时建议仅加密**最亮部件的top-1**，即 5 × 1 × 2541 ≈ 12,705 个增量点。

### 2.3 相位角是否需要加密？

| 加密需求 | 判定依据 | 执行条件 |
|---|---|---|
| 在two top-K相位角之间新增相位角 | Phase 1的top-K分布在相邻相位角有显著跳跃（ΔOCS > 2×） | 仅当相邻相位角间OCS峰值差异 > 2×时触发 |
| 在0°–24°之间新增小相位角 | 后向散射方向（phase < 24°）尚未覆盖 | 如果phase24的top-K OCS显著高于其他相位角，则加密15° |
| 在120°–180°之间新增大相位角 | 大相位角（前向散射弱）尚未覆盖 | 如果phase120的top-K仍有显著值，则加密150° |

**建议加密相位角**（条件触发，最多3个）：phase15、phase75、phase150。

## 4. Top-K指标定义

### 4.1 K值选取

| 阶段 | K值 | 选取依据 |
|---|---|---|
| Phase 1（粗筛） | K=20 per相位角 | 覆盖每个相位角最亮的前20个姿态 |
| Phase 1（汇总） | K=30 跨相位角 | 5相位角汇总后的全局top-30 |
| Phase 2a（roll扫描） | K=10 per相位角 | 对每个相位角的top-10做roll扫描 |
| Phase 2b（局部加密） | K'=3（全局汇总） | 仅对跨相位角汇总的top-3做局部加密 |

### 4.2 排序指标

**主指标**：`ocs_with_occ_total_m2`（含遮挡的总OCS，单位m²）

- 理由：OCS with occlusion 是最终进入星等换算的量，最直接对应"亮度"
- 星等对应：m ∝ -2.5 log10(OCS)，OCS越大星等越小（越亮）

**辅助指标**：
- `ocs_no_occ`：用于诊断遮挡损失
- `occlusion_ratio`：用于判断"最亮"是否被遮挡严重削弱
- per-part OCS占比：用于判定哪个部件驱动了亮度

### 4.3 相对星等差输出规则

对于任意两个姿态点A和B：

```
Delta_mag(A→B) = -2.5 × log10(OCS_B / OCS_A)
```

- 正值 = B比A暗（OCS更小）
- 负值 = B比A亮（OCS更大）
- **输出约定**：以Phase 1全局最大值 `OCS_max` 为基准，输出 `Delta_mag_i = -2.5 × log10(OCS_i / OCS_max)`，即所有Delta_mag ≥ 0，表示"比最亮姿态暗多少"

## 5. Glint判据

### 5.1 太阳能板Glint判据

太阳能板glint定义为：平坦反射面（太阳能板表面）的镜面反射方向与观测方向重合或接近。

**判据S1（几何条件，两种等价写法）**：

**写法1（half-vector形式，推荐）**：
```
h = normalize(s + v)
dot(n_panel, h) > cos(θ_h_threshold)
```
其中：
- `s = sun_direction_M`（本体系下，面元→太阳）
- `v = det_direction_M`（本体系下，面元→观测者）
- `n_panel` = 太阳能板可见面法向（本体系）
- `θ_h_threshold` = half-vector对齐阈值（建议3°，即cos(3°) ≈ 0.9986）

**写法2（镜面反射向量形式）**：
```
r = 2 * dot(n_panel, s) * n_panel - s
dot(r, v) > cos(θ_glint_threshold)
```
其中 `r` 为太阳方向关于 `n_panel` 的镜面反射方向。

**注意**：不使用 `abs(dot(...))`，除非明确考虑双面板；否则背面反射会被误判为glint。阶段4已锁定方向向量约定（卫星→太阳/观测者），S1公式必须遵守此约定。

**判据S2（OCS贡献条件）**：
- `pct_taiyangnengban > 50%`（太阳能板贡献超过总OCS的50%）

**判据S3（振幅条件）**：
- 相较于相邻roll角（±5°），OCS变化 > 5×（突增特征）

**综合判定**：
- S1+S2同时满足 → **确定glint**
- S1满足但S2不满足 → **可能glint但被遮挡或太阳能板面积小**，标记为"弱glint候选"
- S2+S3满足但S1不满足 → **疑似镜面反射但方向有偏差**，标记为"类glint候选"

### 5.2 金属主体Specular峰识别

金属主体specular峰定义为：金属主体曲面对太阳方向产生镜面反射的局部姿态区间。

**判据M1（金属贡献突增）**：
- `pct_jinshuzhuti > 60%`（金属主体贡献占主导）
- 且相较于相邻yaw/pitch（±5°），`ocs_jinshuzhuti`变化 > 3×

**判据M2（局部OCS集中度，推荐）**：
- top 5%面元的OCS贡献占金属主体总OCS的比例 > 50%（说明少数面元贡献集中，符合specular峰特征）
- 或：面元法向与half-vector的对齐度分布有显著峰值（cos(angle) > 0.95的面元占比 > 10%）

**辅助判据M2'（可见面元/遮挡率）**：
- 金属主体可见面元数在峰值处显著增加（Δvisible_faces > 30%）
- 同时遮挡率显著下降（Δocclusion_ratio < -10%）
- **注**：可见面元数增加可能只是暴露面积变化，不是specular峰的必要条件，降级为辅助判据

**判据M3（峰值锐度）**：
- yaw方向半高宽 FWHM_yaw < 15°
- pitch方向半高宽 FWHM_pitch < 15°

**综合判定**：
- M1+M2+M3同时满足 → **确定metal specular peak**
- 仅M1满足 → **候选metal主导亮区**（可能是大面积暴露而非specular）

### 5.3 Glint与常规亮度的区分

| 特征 | 常规亮度（quiescent） | Glint/Specular峰 |
|---|---|---|
| OCS随姿态变化 | 平缓（相邻姿态ΔOCS < 2×） | 陡峭（ΔOCS > 5×） |
| 主导部件 | 部件占比稳定 | 单一部件瞬时占比 > 50% |
| Roll敏感性 | 低（roll=0±10°变化 < 2×） | 极高（roll=0±3°变化 > 5×） |
| 姿态空间峰宽 | yaw/pitch FWHM > 15° | yaw/pitch/roll FWHM < 10° |
| 星等振幅 | 0.2-2 mag | 1-10 mag |

**注**：本阶段实验是静态姿态/相位角扫描，**不能直接推导时间持续性**（需要轨道角速度+姿态时间序列）。上表"时间持续性"仅作文献背景参考，不作为本实验输出指标。本实验输出的是**姿态空间峰宽**（yaw/pitch/roll FWHM）。

## 6. Per-Part OCS贡献占比判定规则

### 6.1 部件标识映射

| 部件名（中文） | 部件名（CSV列） | STL文件 | 材料类型 |
|---|---|---|---|
| 金属主体 | `jinshuzhuti` | `jinshuzhuti.stl` | 铝合金/镀铝外壳（GGX, 中等粗糙度） |
| 太阳能板 | `taiyangnengban` | `taiyangnengban.stl` | 玻璃盖片+半导体（GGX, 低粗糙度） |
| 隐身板 | `yinshenban` | `yinshenban.stl` | 低反射率黑色涂层（GGX, 高粗糙度+低albedo） |

### 6.2 贡献占比计算

对每个姿态点：

```
pct_part_i = ocs_with_occ_part_i / ocs_with_occ_total × 100%
```

其中 `ocs_with_occ_total = Σ_i ocs_with_occ_part_i`。

### 6.3 主导部件判定规则

| 条件 | 判定 |
|---|---|
| `pct_part_i ≥ 50%` | **单一部件主导**，标记为 `dominant_part = part_i` |
| `pct_part_i ≥ 35%` 且 `pct_second < 30%` | **部件i偏主导**，标记为 `dominant_part = part_i (moderate)` |
| 所有 `pct_part_i < 35%` | **混合贡献**，标记为 `dominant_part = mixed` |
| 两部件同时 ≥ 35% | **双部件主导**，标记为 `dominant_part = part_i+part_j` |

### 6.4 最亮姿态下必须记录的信息

对每个Phase 2确认的最亮候选姿态，同步记录：

| 类别 | 字段 | 说明 |
|---|---|---|
| **姿态** | yaw, pitch, roll | 卫星本体姿态角（度） |
| **太阳方向** | sun_direction_I (x,y,z) | 惯性系下卫星→太阳单位向量 |
| **观测方向** | det_direction_I (x,y,z) | 惯性系下卫星→观测者单位向量 |
| **相位角** | phase_angle_deg | 太阳-目标-观测者夹角 |
| **OCS** | ocs_no_occ, ocs_with_occ (m²) | 无遮挡/含遮挡总OCS |
| **遮挡** | occlusion_ratio | 遮挡率 |
| **per-part OCS** | ocs_jinshuzhuti, ocs_taiyangnengban, ocs_yinshenban | 各部件OCS（m²） |
| **per-part 可见面元** | visible_faces_jinshuzhuti, ... | 各部件可见面元数 |
| **BRDF** | brdf_model, material_params | GGX参数（粗糙度、F0、albedo） |
| **搜索分辨率** | yaw_step, pitch_step, roll_step | 该结果的搜索步长（度） |
| **星等估算** | magnitude_estimate_38000km | GEO典型斜距（38,000 km）下的估算视星等 |

## 7. 材料敏感性分析

### 7.1 当前三材料GGX参数（以materials.py为准）

**重要**：以下参数直接读取自 `ocs_project/01_code/materials.py` 的 `_GGX_DB`，是阶段6执行时实际使用的参数：

| 参数 | 金属主体 (jinshuzhuti) | 太阳能板 (taiyangnengban) | 隐身板 (yinshenban) | 说明 |
|---|---|---|---|---|
| **roughness α** | **0.20** | **0.40** | **0.90** | GGX粗糙度，越低越接近镜面 |
| **metallic** | **1.0** | **0.0** | **0.0** | 1.0=纯金属（导体），0.0=电介质 |
| **base_color** | 0.91 | 0.15 | 0.08 | 基础颜色/漫反射albedo |
| **F0** | 0.91 | — | — | 金属直接指定F0；电介质从ior计算 |
| **ior** | — | 1.5 | 1.5 | 折射率（仅电介质）→ F0 ≈ 0.04 |

**关键修正**：
- **金属主体 roughness=0.20，metallic=1.0，F0=0.91** → 是最强镜面反射候选，specular峰值高
- **太阳能板 roughness=0.40** → 并非接近镜面（原方案错误写0.1），但因平面几何和较大面积仍可能形成方向性峰值
- **隐身板 roughness=0.90** → 接近完全漫反射，几乎不产生specular峰

**最亮部件预判**（基于当前参数）：
- **高相位角（phase90-120）金属主体可能因强F0主导**
- **小相位角（phase24-45）太阳能板虽α较高但大面积平面可能仍贡献显著OCS**
- **隐身板在所有条件下预计都是暗弱对照**

### 7.2 推荐材料敏感性扫描

**不建议在阶段5做全面敏感性扫描**（计算代价大，3000+姿态 × 多参数组合）。建议用以下策略：

**策略A（理论分析—阶段5执行）**：基于GGX BRDF行为和当前真实参数（α_metal=0.20, α_solar=0.40, α_dark=0.90）分析各材料对相位角/粗糙度/入射角的定性响应。

| 敏感维度 | 金属主体 (α=0.20, metallic=1.0, F0=0.91) | 太阳能板 (α=0.40, ior=1.5) | 隐身板 (α=0.90, base=0.08) |
|---|---|---|---|
| **相位角敏感度** | **极高**（低α+高F0，specular lobe窄） | **中**（α=0.40介于镜面和漫反射之间） | **低**（α=0.90接近漫反射） |
| **粗糙度敏感度** | **极高**（α从0.15→0.30，specular峰变化5-10×） | **高**（α从0.30→0.50，方向性显著变弱） | **低**（已接近漫反射极限） |
| **F0敏感度** | **高**（金属主导，F0直接控制反射率） | **低**（电介质F0≈0.04，由ior确定） | **极低**（低base_color主导） |
| **法向角敏感度** | **极高**（金属Fresnel效应强） | **中**（电介质Fresnel曲线平缓） | **低** |
| **面积/几何敏感度** | 中（曲面主体，可见面积随姿态变化） | **高**（大面积平面阵列，姿态变化剧烈） | 低（小面积，贡献本底较低） |

**关键修正**（相比原方案）：
- **金属主体（α=0.20而非0.3）是最强specular候选**，不是太阳能板
- **太阳能板（α=0.40而非0.1）不是镜面材料**，但大平面几何可能在特定姿态形成方向性增强
- **太阳能板glint若出现，更可能由几何（平面法向对齐half-vector）而非材料（α偏高）驱动**

**策略B（数值验证—留待阶段6或独立实验）**：
- 选Phase 2确认的最亮姿态（1-3个点），仅对这1-3个姿态做材料参数扫描
- 扫描参数（围绕真实参数）：
  - 金属主体 roughness: **0.10 / 0.20 / 0.30 / 0.40**
  - 太阳能板 roughness: **0.20 / 0.40 / 0.60**
  - 隐身板 roughness: **0.70 / 0.90**（高α对结果影响小，扫描优先级低）
- 输出：材料参数→OCS敏感度曲线

### 7.3 三材料体系充分性与边界

#### 7.3.1 能覆盖的材料/表面类型

| 真实卫星表面 | 材料映射 | 覆盖程度 | 主要局限 |
|---|---|---|---|
| 铝合金/镀铝主体 | 金属主体GGX (α=0.3) | **较好** | 实际航天器多层隔热材料(MLI)可能有不同的α和F0 |
| 玻璃盖片太阳能板 | 太阳能板GGX (α=0.1) | **较好** | 实际GaAs/硅电池+ARC涂层的BRDF更复杂，可能存在波长选择性 |
| 黑色热控涂层/消光表面 | 隐身板GGX (α=0.6) | **部分覆盖** | 实际Z306/Z307涂层有特定BRDF谱特征；无热控白漆 |
| OSR（光学太阳反射器）散热面 | **未覆盖** | **缺失** | 第二表面镜的高反射+透明基底是常见卫星特征 |
| 天线反射面（抛物面） | **未覆盖** | **缺失** | 大型抛物面天线的聚焦反射BRDF与平面材质不同 |
| 星敏/光学载荷遮光罩 | **未覆盖** | **缺失** | 遮光罩的腔体效应不等价于表面BRDF |
| 多层隔热材料(MLI) | **部分覆盖** | 金属主体近似 | 实际MLI有褶皱和β布外层，BRDF是方向性的 |

#### 7.3.2 不能下的结论

- 不能声称"三材料覆盖所有真实卫星表面"
- 不能将"GGX最亮姿态"直接等同于"真实卫星最亮姿态"（未经标定）
- 不能将当前材料的"哪个部件最亮"顺序推广到所有卫星

#### 7.3.3 对本项目的充分性判断

**对本项目目的（"卫星光度范围与最亮观测几何"方法探索）而言，三材料体系基本充分**：

1. 三种材料覆盖了**漫反射→弱specular→强specular**的粗糙度谱（α=0.1→0.6）
2. 三种材料覆盖了**亮→暗**的albedo谱（F0=0.9→0.02）
3. 三种部件覆盖了**曲面主体→平面阵列→混合结构**的几何类型
4. 该方法框架对**新增材料**具有直接扩展性（替换GGX参数或新增BRDF模型即可）

**论文中应写明**：当前材料体系覆盖了典型高轨卫星的主要表面类型（金属主体、玻璃太阳能板、暗表面涂层），但OSR散热面、天线反射面和大面积MLI的BRDF行为超出当前覆盖范围，是后续材料扩展的优先方向。

## 8. 覆盖局限性说明

### 8.1 5相位角覆盖的局限

| 局限 | 具体影响 | 缓解措施 |
|---|---|---|
| **5个相位角是离散采样** | 最亮姿态可能出现在phase24和phase45之间的某个中间相位角（如phase35） | Phase 2对top-K相位角区间做加密 |
| **缺少小相位角（<24°）** | 后向散射方向（太阳在观测者背后）通常是最亮的几何条件，未被覆盖 | 如phase24的top-K OCS显著高于其他，触发phase15加密 |
| **缺少大相位角（>120°）** | 前向散射方向可能对某些材料有增强（如隐身板的diffuse lobe） | 如phase120仍有显著OCS，触发phase150加密 |
| **缺乏相位角连续扫描** | 无法捕获glint只在极窄相位角范围（<5°）出现的现象 | 对glint候选做相位角局部加密 |

### 8.2 roll=0二维姿态网格的局限

| 局限 | 具体影响 | 缓解措施 |
|---|---|---|
| **roll维完全缺失** | 太阳能板glint通常在特定roll值触发（太阳翼法向对齐太阳-观测平面） | Phase 2a roll全扫描 |
| **yaw/pitch 5°间隔可能错过窄峰** | specular峰的FWHM可能<5°，5°步长可能刚好跳过峰值 | Phase 2b局部1°加密 |
| **5°网格覆盖13,505点但姿态空间总量巨大** | 完整3D姿态空间（yaw 360°×pitch 180°×roll 360° @1°）≈ 2.3×10⁷点 | 采用粗筛→精扫策略，不追求全局最亮 |

### 8.3 不保证全局最亮的声明

**必须明确写入最终报告**：

> Phase 1的5相位角 + yaw(5°)×pitch(5°)×roll=0网格共13,505姿态点只能作为粗筛，**不保证该13,505个点中的最大值即为全局最大值**。Phase 2的roll扫描和局部加密提高了top-K候选附近的搜索精度，但：
> 1. 只加密了top-K候选附近的局部区域，未覆盖全部姿态空间
> 2. 相位角加密是条件触发的（最多3个额外相位角），未做相位角连续扫描
> 3. 材料参数固定在名义值，未扫描材料不确定性空间
>
> 因此，实验输出的是 **"在指定搜索分辨率下的最亮估计"** ，而非 **"物理上可达到的全局最亮"**。

## 9. Roll扫描和局部精扫方案

### 9.1 Roll精扫方案（Phase 2a）

**触发条件**：必须执行（不可选），因为roll=0的top-K无法保证覆盖roll≠0时的部件最亮点和glint。

**候选集生成（关键）**：从多来源并集出发（见§2.2.1）：
1. 总OCS top-10
2. 金属主体OCS top-5
3. 太阳能板OCS top-5
4. 太阳能板占比 top-5
5. 可选：几何glint候选（half-vector对齐度筛选）

并集去重后预计每相位角约15-20个独立候选。

**扫描参数**：

```
对于每个相位角:
  候选集 = union(total_top10, metal_top5, solar_top5, solar_frac_top5, glint_candidates)
  对于每个候选 (yaw_i, pitch_i):
    对于 roll_j in [0, 5, 10, ..., 355]:
      固定(yaw_i, pitch_i, roll_j)，计算OCS
```

**输出分析**：

- Roll-OCS曲线（每个候选的OCS随roll变化）
- Roll敏感度指数：`RSI = max(OCS_roll) / min(OCS_roll)` （越大越敏感）
- 若 `RSI > 10`，标记为"强roll敏感"，说明该候选的roll维度不能忽略
- 若 `RSI < 2`，标记为"roll不敏感"，roll=0的近似可接受

### 9.2 局部加密方案（Phase 2b）

**触发条件**：Phase 2a后仍保持top-K'的姿态（K'=3）。

**加密步骤**：

```
Step 1: 粗定位 → 对top-K'每个候选，取(yaw*, pitch*, roll*)
Step 2: yaw加密 → (yaw*-5° : 1° : yaw*+5°)，共11点
Step 3: pitch加密 → (pitch*-5° : 1° : pitch*+5°)，共11点
Step 4: roll加密 → (roll*-10° : 1° : roll*+10°)，共21点
Step 5: 全组合 → 11 × 11 × 21 = 2,541点（每个候选）
```

**注意**：如果yaw*或pitch*靠近边界（yaw≈0/360, pitch≈±90），加密范围应向周期方向延伸或截断。

### 9.3 相位角局部加密方案（条件触发）

**触发条件（两种方式，满足其一即触发）**：

1. **相邻相位角差异触发**：phase_A的top-1 OCS与phase_B的top-1 OCS（A、B为相邻相位角）差异 > 2×，且A和B之间有至少15°的间距
2. **几何glint缺失触发**：若任一glint-geometry candidate的half-vector与太阳能板法向接近，但当前5个离散相位角未命中峰值（即5个相位角的该候选OCS均低于理论峰值的50%），则在理论最优相位角附近加密
3. **固定安全加密**（建议）：至少补充phase15（后向散射加密）和phase35或phase75中一个（中间区域加密），不完全依赖top-1差异

**加密方式**：在候选相位角插入1-2个中间角度，仅对该相位角的最亮候选附近做yaw/pitch局部扫描（而非全网格，节约计算）。

**例如**：
- phase24 top-1 OCS = 20 m²，phase45 top-1 OCS = 5 m²，差异4×，触发加密 → 在phase34.5做yaw/pitch局部扫描（yaw ±10°, pitch ±10°, 步长2°）
- 或固定补phase15（后向散射区）：在phase15附近取yaw/pitch coarse grid（步长10°）扫描

## 10. 实验执行流程（总览）

### 10.1 阶段划分

```
Phase 1: 粗筛（纯数据分析，不新增计算）
  输入：现有5相位角ocs_scan.csv
  输出：per-phase top-20 + 跨相位top-30 + 热力图

  计算量：5×10×73 = 3,650姿态点

Phase 2b: 局部加密（新增OCS计算，条件触发）
  输入：Phase 2a的K'=3全局top
  输出：1°分辨率的局部最亮姿态
  计算量：~12,705姿态点（top-1最亮部件的3个候选）

Phase 3: 材料敏感性验证（条件触发，建议1-3个姿态点）
  输入：Phase 2b的最亮姿态
  输出：材料参数→OCS敏感度曲线
  
Phase 4: 报告汇总
  输出：最亮姿态汇总表 + glint诊断报告 + 材料敏感性分析
```

## 16. Codex审阅重点

按任务要求，将以下三点提交Codex审阅：

1. **实验是否能区分太阳能板、金属主体、隐身板**
   - per-part OCS占比判定规则（§6.3）
   - glint判据S1-S3专为太阳能板设计，M1-M3专为金属主体设计
   - 隐身板的低OCS使其几乎不会成为最亮主导部件（除非极特殊几何）

2. **Glint判据是否合理**
   - S1（镜面反射方向对齐）是物理上严格的glint必要条件
   - S2（太阳能板OCS占比>50%）确保了部件归因
   - S3（振幅条件）区分了glint和常规亮度的关键特征
   - θ_glint_threshold=3°是可以讨论的参数，建议审阅者评估是否需要收紧至1-2°

3. **是否考虑姿态、相位角、材料敏感性**
   - 姿态：yaw/pitch二维粗筛 + roll精扫 + 局部三维加密（§2, §9）
   - 相位角：5离散角度 + 条件加密（§2.3, §9.3）
   - 材料敏感性：理论分析（§7.2策略A）+ 条件数值验证（§7.2策略B）
