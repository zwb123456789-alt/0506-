# 调研总览：常规卫星光度范围

最后更新：2026-06-05

## 调研目标

建立一个可引用、可追溯的卫星光度范围表，回答：

1. 低轨、中轨、高轨/GEO卫星的可见星等范围分别是多少。
2. 常规稳定亮度、最亮 flare/glint、最暗或不可见条件分别是什么。
3. 星等范围对应的观测条件是什么：距离、相位角、太阳高度、目标姿态、波段、曝光/观测设备。
4. 哪些资料可作为论文或报告引用，哪些只能作为背景参考。

## 需要分开的量

| 量 | 含义 | 注意 |
|---|---|---|
| apparent magnitude | 观测到的视星等 | 随距离、相位角、姿态、波段变化 |
| absolute magnitude | 标准距离/标准几何归一后的亮度 | 不同资料定义可能不同 |
| flare/glint magnitude | 镜面反射短时峰值 | 不能代表常规亮度 |
| phase angle | 太阳-目标-观测者夹角 | 最亮几何高度依赖它 |
| range | 目标到观测者距离 | GEO与LEO不可直接比较视星等 |

## 调研资料优先级

1. 同行评议论文、会议论文、学位论文。
2. 天文/空间目标监测机构报告或数据库说明。
3. 观测者数据库或社区记录，仅作范围参考，需要标明非严格控制条件。

## 输出文件

- `卫星光度调研表.csv`：结构化记录每条资料。
- `文献笔记.md`：对关键文献逐条摘录和可信度判断。
