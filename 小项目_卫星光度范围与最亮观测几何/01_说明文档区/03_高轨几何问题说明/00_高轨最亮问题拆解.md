# 高轨卫星最亮观测几何：问题拆解

最后更新：2026-06-05

## 需要回答的问题

1. 高轨卫星什么几何条件下最亮。
2. 太阳光打到哪个部件时最亮。
3. 从哪个方向观测最亮。
4. 最亮结论是否依赖材料 BRDF、遮挡、姿态和相位角。

## 基础物理判断

最亮通常来自两类机制：

1. 大面积漫反射/弱镜面反射部件在可见且受照时贡献高，例如太阳能板。
2. 镜面或强 specular 部件满足镜面反射方向时出现 glint，例如高反射金属面或太阳翼表面。

因此不能只问“哪个部件最亮”，必须同时给出：

- 太阳方向 `s`
- 观测方向 `v`
- 部件法向 `n`
- 相位角 `alpha = angle(s, v)`
- 目标姿态 yaw/pitch/roll
- 遮挡语义和材料参数

## 最亮几何的判据

### 漫反射主导

粗略要求：

```text
n · s > 0
n · v > 0
可见面积大
遮挡少
```

### 镜面反射主导

粗略要求部件法向接近太阳方向与观测方向的角平分线：

```text
n ≈ normalize(s + v)
```

这意味着观测者位于该部件的镜面反射方向附近时最亮。若相位角较小，背向散射/近满相通常更容易整体变亮；若某部件镜面性强，则中等或特定相位角也可能出现尖峰。

## 当前数据与“高轨道”的关系

现有 `phase63_backscatter` 数据不是轨道传播或地基观测仿真，配置中没有轨道高度、GEO距离或观测站位置。它定义的是：

- 太阳方向；
- 观测方向；
- 相位角约 63.11 deg；
- yaw-pitch 姿态网格；
- STL/BRDF/遮挡条件。

因此当前 phase63 结果只能回答“在这组太阳-观测方向下哪个姿态/部件最亮”，不能单独回答“高轨道卫星真实视星等是多少”。要成为高轨/GEO结论，需要额外指定 `range_km`，通常还要指定观测站、目标轨道位置和太阳-地球-目标几何。

## 实验输出要求

每次实验至少输出：

- total OCS top-K 姿态与几何；
- per-part OCS top-K；
- top-K 中每个部件贡献占比；
- 对应 yaw/pitch/roll、相位角、太阳方向、观测方向；
- 是否存在单个尖峰 glint，还是宽区域高亮；
- 相对星等差 `Delta m = -2.5 log10(OCS / OCS_ref)`。

## 结论模板

最终结论不要写成“高轨卫星总是在某方向最亮”，而写成：

```text
在 [BRDF参数]、[相位角]、[姿态扫描范围]、[遮挡语义] 下，
最高 OCS 出现在 [姿态/观测几何]；
主要贡献部件为 [部件]，贡献占比 [x%]；
相对中位姿态亮 [Delta m] mag。
```
