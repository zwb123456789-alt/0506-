# 说明文档区

本目录保存仍在当前 A0-A10 路线中会被反复引用的说明文档、口径说明和支撑输入。它不是正式成果区，也不是历史归档区。

## 与其他目录的区别

| 目录 | 定位 |
|---|---|
| `00_A0-A10正式成果区/` | 通过 Codex 审阅后的阶段正式成果 |
| `01_说明文档区/` | 当前仍有用、需要经常读取的说明文档和支撑口径 |
| `06_Claude执行方案/` | Claude/Codex 对话、提示词、草稿输出、审阅记录 |
| `90_旧结构与支撑材料归档/` | 历史阶段成果、旧草案、预实验输出和不再作为当前说明口径的材料 |

## 当前说明文档分组

### `02_OCS与星等口径说明/`

| 文件 | 当前用途 |
|---|---|
| `00_OCS与光度换算标准.md` | OCS 与星等换算的口径说明；A1/A9 会用到 |
| `01_为什么OCS不需要场景而星等需要.md` | 解释 OCS 不含距离、绝对星等需要距离和标定；A1/A3/A9 会用到 |
| `换算算例表.csv` | A9 情景星等估计可复用或更新的算例表 |

### `03_高轨几何问题说明/`

| 文件 | 当前用途 |
|---|---|
| `00_高轨最亮问题拆解.md` | 解释“最亮几何”必须同时看太阳方向、观测方向、姿态、材料和遮挡 |
| `01_高轨定位要求_不实施.md` | 明确抽象方向几何与真实高轨/GEO场景的差异 |
| `阶段2_高轨与STK场景需求设计.md` | A3 的场景字段和高轨语境支撑 |
| `阶段4_高轨几何到OCS接口设计.md` | A3 的方向向量、坐标和 OCS 接口支撑 |
| `几何实验矩阵_旧预实验.csv` | 旧几何矩阵，只作 A3 对照和字段参考，不作为完整搜索空间 |

### `04_STL材料与模型说明/`

| 文件 | 当前用途 |
|---|---|
| `00_STL模型与现有结果索引.md` | 当前 STL、原项目结果和 phase63 预实验索引 |
| `01_材料体系充分性与边界.md` | 当前三材料体系的适用边界 |
| `02_三材料参数审查.md` | 当前材料参数来源和边界；A4/A8 会用到 |

## 过时与可用边界

- 本目录中的文件可以作为当前阶段的说明口径读取。
- 若内容与 `00_A0-A10正式成果区/` 中已通过成果冲突，以正式成果区为准。
- 旧阶段编号文件放在本目录时，表示其仍有说明价值，但不是当前阶段正式成果。
