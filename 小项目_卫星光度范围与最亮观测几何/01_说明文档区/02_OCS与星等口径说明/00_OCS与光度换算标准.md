# OCS 与光度/星等换算标准

最后更新：2026-06-05

## 目的

建立本项目内部统一换算口径，用于把 OCS 仿真值转换为可与观测光度/视星等讨论的量。

## 首要确认

需要先确认 `ocs_project` 当前 OCS 的物理定义是否满足：

```text
E_obs / E_sun = OCS / R^2
```

其中：

- `E_obs`：观测者处接收到的目标辐照度。
- `E_sun`：目标处太阳辐照度，或同一波段下的太阳参考辐照度。
- `R`：目标到观测者距离，单位必须与 `sqrt(OCS)` 一致。
- `OCS`：等效光学散射截面，单位通常按 m^2 理解。

如果项目代码中的 OCS 只是相对量或缺少距离归一化，则必须引入标定常数 `K_cal`。

## 推荐换算形式

若 OCS 定义满足上式，则视星等可写为：

```text
m = m_sun - 2.5 log10(OCS / R^2)
```

等价于：

```text
m = m_sun - 2.5 log10(OCS) + 5 log10(R)
```

注意：

- `R` 使用米时，`OCS` 也应使用平方米。
- `m_sun` 应选择与观测波段一致的太阳星等，常见可见光/V波段值需调研确认后固定。
- 若 OCS 输出已包含太阳距离、波段响应、BRDF常数或非物理缩放，则不能直接套用。

## 带标定常数的保守形式

当 OCS 只是项目相对亮度时，使用：

```text
m = K_cal - 2.5 log10(OCS) + 5 log10(R)
```

其中 `K_cal` 由以下方式确定：

1. 用文献中某类卫星在已知距离/相位角下的星等标定。
2. 用实验室标定或真实观测标定。
3. 只做相对比较时，不求 `K_cal`，只比较 `Delta m`：

```text
Delta m = -2.5 log10(OCS_2 / OCS_1)
```

## 本项目最建议先做的事

1. 检查 `ocs_project/01_code/ocs_core.py` 的 OCS 积分定义。
2. 确认输出 `ocs_total`、`per_part` 是否有单位。
3. 用 `Fig_3_ocs_heatmaps.csv` 或原始 `ocs_scan.csv` 计算：
   - 全局 OCS 最大/最小/中位数；
   - 金属主体、太阳能板、隐身板的 per-part 最大贡献；
   - 最大与最小 OCS 对应的相对星等差 `Delta m`。
4. 再决定是否引入 GEO 距离进行绝对视星等估算。
