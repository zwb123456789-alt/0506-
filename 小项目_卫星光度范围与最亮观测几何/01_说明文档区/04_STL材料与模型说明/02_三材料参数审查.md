## 审查结论

### 1. 金属主体/镀铝膜

当前 GGX 参数：

```text
base_color=0.91, metallic=1.0, roughness=0.20, F0=0.91
```

可以代表高反射铝/镀铝类金属表面的第一阶行为：反射率高、镜面贡献强、可能出现明显 specular peak。

适合用于当前目的：

- 判断金属主体是否主导最亮姿态；
- 检查金属 roughness 对 glint 峰的敏感性；
- 与太阳能板和低反射板做对照。

限制：

- `roughness=0.20` 是 nominal 假设，不是实测镀铝膜参数；
- 实际镀铝膜可能因氧化、污染、表面加工和涂层结构改变 roughness/F0；
- 对最亮姿态问题，金属 roughness 是关键待标定参数。

已有补充实验也显示：金属主体 roughness ±20% 对 OCS 影响最大，中位变化约 30-42%，最大约 46.2%。

### 2. 太阳能板

当前 GGX 参数：

```text
base_color=0.15, metallic=0.0, roughness=0.40, ior=1.5
```

可以代表“非金属、玻璃盖片/半导体复合表面”的简化太阳能板。`ior=1.5` 对玻璃盖片是合理的第一阶近似；`metallic=0` 也符合太阳能板不是金属镜面的处理。

适合用于当前目的：

- 判断太阳能板是否因大面积或方向性反射成为主亮源；
- 与金属主体的强镜面峰做对照；
- 在 roll 或相位角变化下检查太阳翼 glint 是否出现。

限制：

- 真实太阳能板是多层结构，可能包含玻璃盖片、抗反射膜、电池片栅线和蓝黑色半导体表面；
- 当前 `base_color=0.15` 偏暗，适合保守表示深色太阳能板，但可能低估高反射玻璃盖片或特定角度 glint；
- 如果研究重点转向太阳能板 glint，应增加太阳能板参数敏感性或分层模型，而不是直接认定当前参数完全代表真实太阳翼。

已有补充实验显示：太阳能板 base_color ±20% 影响约 4%，最大约 6.5%；roughness 影响 <1%。这说明在当前几何/模型下太阳能板不是最敏感部件，但不能排除特定 roll/几何下出现 glint。

### 3. 隐身板/防探测低反射板

当前 GGX 参数：

```text
base_color=0.08, metallic=0.0, roughness=0.90, ior=1.5
```

可以代表低反射、粗糙、非金属暗表面的第一阶行为：整体反射弱，镜面峰被强烈压宽/压低。

适合用于当前目的：

- 验证低反射板件是否显著降低 per-part OCS；
- 判断它是否主要通过遮挡/几何而不是自身反射贡献影响总 OCS；
- 与金属主体、太阳能板形成亮-中-暗材料梯度。

限制：

- “隐身/防探测材料”真实机理可能包含波段选择性吸收、微结构散射、偏振效应等；
- 当前 GGX 只能表示低反射粗糙表面，不能证明真实防探测材料的绝对性能；
- 适合作为“低反射暗表面代表”，不应写成真实隐身材料标定。

已有补充实验显示：隐身板 base_color ±20% 影响约 1.7%，最大约 3.1%；roughness 影响 <0.2%。在当前模型下它对最亮姿态不敏感。

## 能否代表三种材料情况？

可以，前提是表述为“代表性 nominal 参数”：

```text
当前三材料参数足以代表高反射金属/镀铝表面、深色太阳能板表面、低反射粗糙暗表面三类第一阶光学行为，可用于判断当前 STL 模型中最亮姿态和主要部件贡献。
```

不能表述为：

```text
这些参数已经真实标定了所有镀铝膜、太阳能板和隐身材料。
```

## 对最亮姿态问题的影响

当前三材料设置对“最亮姿态”任务是合适的，因为它刻意拉开了三类材料的光学差异：

- 金属主体：高反射 + 强镜面；
- 太阳能板：中低反射 + 非金属方向性反射；
- 隐身板：低反射 + 高粗糙度。

这能帮助判断最亮峰值到底来自：

1. 金属主体 specular peak；
2. 太阳能板大面积/特定 glint；
3. 低反射板是否仍因几何或遮挡贡献；
4. 姿态与相位角是否比材料本身更主导。

## 建议

1. 主实验继续使用当前三材料参数，不需要现在改 STL 或新增材料。
2. 最亮姿态结论必须写清楚“当前 nominal GGX 材料参数下”。
3. 金属主体 roughness/F0 应作为最重要敏感性参数。
4. 如果后续发现太阳能板在特定 roll/几何下可能 glint，再增加太阳能板 `roughness/base_color/ior` 的敏感性。
5. 隐身板只称为“低反射粗糙暗表面代表”，不要称为真实防探测材料标定。
