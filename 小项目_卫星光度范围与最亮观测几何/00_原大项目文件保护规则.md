# 原大项目文件保护规则

最后更新：2026-06-05

## 适用范围

本规则适用于小项目文件夹之外的整个原大项目：

```text
D:/我的文件/研究生学术/光学项目/0506新/
```

小项目文件夹为：

```text
小项目_卫星光度范围与最亮观测几何/
```

## 绝对规则

在本小项目推进过程中：

1. 不删除原大项目文件。
2. 不修改原大项目文件。
3. 不向原大项目既有目录添加新文件。
4. 不移动、重命名、覆盖原大项目文件。
5. 不对原大项目代码、数据、结果、论文文件做格式化、清理或重生成。

## 允许操作

只允许在小项目文件夹内进行以下操作：

1. 新建小项目文档、表格、脚本草案和分析记录。
2. 复制原大项目文件到小项目文件夹作为备份或只读证据副本。
3. 记录原大项目文件路径、字段名、参数和摘要。

## 备份原则

如果需要引用原大项目文件内容，优先使用路径索引和摘要。只有在确实需要固定证据版本时，才复制到小项目文件夹，例如：

```text
小项目_卫星光度范围与最亮观测几何/备份_原项目只读副本/
```

备份文件必须满足：

- 文件名保留来源信息；
- 记录原始路径；
- 不反向覆盖原文件；
- 不作为原项目的新正式结果。

## 对 Codex 的执行约束

后续任何与本小项目有关的操作，默认工作边界是小项目文件夹。除非用户明确授权，不能改动小项目外的任何文件。
