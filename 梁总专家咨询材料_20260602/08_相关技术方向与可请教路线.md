# 相关技术方向与可请教路线

> 用途：会前内部准备，帮助把问题从“我做了什么”提升到“下一步该往哪里走”。  
> 可选用法：可摘取其中一部分放入发给梁总的材料或 PPT。

## 1. 当前项目所在技术交叉点

本项目位于以下几个方向的交叉处：

```text
空间目标光学观测
  + BRDF / 材料反射建模
  + OCS / 光变曲线 / 光度标量
  + 光度图像姿态反演
  + 多观测几何可观测性
  + 多模态融合与鲁棒性
```

当前已有工作更接近“统一仿真与受控反演 benchmark”，还不是完整真实观测系统。

## 2. 可向梁总请教的技术方向

### 2.1 光学观测方向

要问的核心不是“怎么拍图”，而是：

- 地基光学观测中，哪些因素最影响姿态反演？
- seeing、PSF、跟踪误差、背景光、曝光、SNR 中，哪些最应该优先建模？
- 真实观测条件下，OCS/光变与二维图像的可获取性和成本差别有多大？
- 如果目标是论文补强，最低可行观测实验是什么？

### 2.2 姿态反演方向

重点请教：

- 当前 yaw-pitch fixed-roll 是否可作为合理第一步？
- 三轴姿态扩展最难的地方是数据量、简并性，还是观测几何设计？
- 多观测几何如何设计才更有物理意义？
- 反演评价指标只用 mean error / Hit@5 是否够，是否应增加 tail risk 或可观测性指标？

### 2.3 光谱/多光谱方向

可问：

- 光谱信息在空间目标姿态反演中是否真的有用，还是主要用于材料识别？
- 多光谱 light curve / OCS 是否比单波段 OCS 更能破除姿态简并？
- 光谱维度是否能帮助反演 BRDF 参数，而不是只反演姿态？
- 如果引入光谱，实验设备和数据处理复杂度会增加多少？

### 2.4 偏振方向

可问：

- 偏振是否比光谱更直接约束表面法向和镜面反射？
- 偏振 BRDF 是否适合空间目标材料与姿态联合反演？
- 国内是否有相关观测或实验条件？
- 偏振方向适合作为当前论文补充，还是更适合作为后续新方向？

### 2.5 BRDF 与材料方向

可问：

- 当前使用 GGX/Cook-Torrance 是否适合航天器材料？
- nominal material 参数作为论文假设是否可接受？
- 如果需要材料实验，最小实验如何做？
- 是否需要真实材料片、太阳能板样片、金属表面粗糙度测量？

## 3. 后续创新方向候选

### 方向 A：多观测几何 OCS 可观测性

核心问题：

```text
哪些太阳-观测几何组合最能破除姿态简并？
```

可能创新：

- 定义 OCS 姿态可观测性指标。
- 做观测几何优化。
- 将 OCS 从反演输入升级为观测规划依据。

适合请教梁总：

- 实际观测中可控/不可控的几何因素是什么？
- 观测规划能否落地？

### 方向 B：真实观测退化下的图像-OCS互补

核心问题：

```text
真实图像退化时，OCS 是否能提供更稳定的姿态约束？
```

可能创新：

- 从 clean synthetic image 转向 degraded observation benchmark。
- 建立退化模型，如 PSF、噪声、跟踪误差、背景污染。
- 评估 OCS、图像、融合在不同观测质量下的临界点。

适合请教梁总：

- 哪些退化最接近真实望远镜观测？
- 有无真实数据或场地可验证？

### 方向 C：光谱/多光谱 OCS

核心问题：

```text
不同波段的光度响应是否能增强材料识别和姿态可观测性？
```

可能创新：

- 从 scalar OCS 扩展到 spectral OCS。
- 材料反射谱与姿态反演联合建模。
- 多波段光变曲线与图像融合。

适合请教梁总：

- 光谱设备和数据获取是否现实？
- 光谱方向在该领域是否有前沿价值？

### 方向 D：偏振 BRDF 与姿态反演

核心问题：

```text
偏振能否提供比强度图像更稳定的表面法向/材料约束？
```

可能创新：

- 偏振 BRDF 仿真。
- 偏振观测与姿态、材料联合反演。
- 偏振-光谱-图像多模态组合。

适合请教梁总：

- 偏振方向是否值得投入？
- 实验难度与论文价值如何？

### 方向 E：实验室缩比验证

核心问题：

```text
能否用缩比模型和可控光源验证 OCS/图像仿真链路？
```

可能创新：

- 暗室/转台/相机/光源测量。
- 已知姿态 ground truth。
- 对比仿真 OCS/图像与实测光度响应。

适合请教梁总：

- 哪些场地可以做？
- 需要什么设备？
- 多大工作量能形成论文补充？

## 4. 会上建议请梁总排序的问题

建议最后请梁总按优先级排序：

```text
1. 当前论文投稿前，最必须补的是什么？
2. 哪些内容可放 future work，不必当前硬补？
3. 后续最值得做的新方向是什么？
4. 如果只有 1-2 个月，最现实的实验补强是什么？
5. 如果有半年到一年，最值得投入的前沿方向是什么？
```

## 5. 内部判断

当前最可能形成短期论文补强的是：

1. 图像退化模型进一步完善，如 blur/downsample/PSF。
2. 跨 phase 小规模 sanity test。
3. 实验室缩比模型或已有观测数据的小规模验证。

更适合中长期发展的方向是：

1. 多观测几何优化。
2. 多光谱/光谱 OCS。
3. 偏振 BRDF。
4. 真实地基观测数据与数字孪生结合。
