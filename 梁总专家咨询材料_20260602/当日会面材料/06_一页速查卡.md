# 一页速查卡

> 用途：现场放在手边，避免数字说错、问题问漏、口径过强。

---

## 一、项目一句话

当前工作是一个统一 BRDF 驱动的 OCS 与光度图像仿真框架，用于受控空间目标 yaw-pitch 姿态反演 benchmark，重点分析 OCS、图像和融合方法在理想图像与退化观测条件下的互补关系。

---

## 二、可用关键数字

| 类别 | 数字 |
|---|---|
| 单平板前向验证 | 平均相对误差约 0.253% |
| 立方体前向验证 | 误差不超过约 0.25% |
| fast/full OCS 对比 | mean 差异约 2.0%，max 差异约 0.5% |
| 姿态网格 | 2701 个 yaw-pitch 姿态 |
| OCS观测几何 | 5 个 |
| OCS MLP all_raw | 3.98 +/- 0.60 deg，Hit@5 = 90.7%，semi-oracle |
| OCS MLP per_part_log | 约 5.91 deg |
| TinyCNN image-only | 11.87-12.38 deg |
| Feature fusion | 4.10 +/- 0.77 deg |
| ResNet image-only | 1.69 +/- 0.07 deg，Hit@5 = 97.6% |
| ResNet + OCS fusion | 1.47 +/- 0.07 deg，Hit@5 = 99.7%，worst 9.9 -> 6.6 deg |
| 1% Gaussian image noise | ResNet 约 85.85 deg，Hit@5 = 2.2% |
| OCS-noise fusion gain | +1.97 deg -> +6.29 deg |
| 遮挡率 | 约 60-78.5% |
| Roll OCS变化 | mean 约 20.3%，max 约 26.2% |

## 三、推荐口径

- 当前是受控仿真 benchmark，不是真实外场系统。
- clean rendered image 是理想图像上界，不代表真实地基观测性能。
- OCS 的价值：低维、可解释、多观测几何、对图像像素退化不敏感。
- fusion 的价值：条件性互补，尤其是尾部误差和退化观测条件。
- all_raw 是 semi-oracle / diagnostic，不作为实用特征主线。
