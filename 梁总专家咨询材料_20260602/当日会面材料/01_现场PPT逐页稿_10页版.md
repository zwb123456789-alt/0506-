## 第2页：研究问题

**页标题**：核心问题：OCS 与光度图像分别能提供什么姿态信息？

**页面内容**：

- 非合作目标缺少可直接使用的姿态遥测。
- 光学观测中有两类信息：OCS/光变类积分光度、二维光度图像。
- 想比较 OCS-only、image-only 和 OCS-image fusion。
- 重点不是简单证明融合最好，而是分析各模态的适用条件。

**建议图**：

- 左侧：OCS/光变曲线或多几何光度响应。
- 右侧：光度图像。
- 中间箭头指向姿态反演。

**现场讲法**：

我现在的问题是：OCS 是低维的积分光度信息，图像是二维空间信息。两者都和姿态有关，但信息来源不同。我想做一个受控仿真 benchmark，看它们分别在什么条件下有用，什么时候能互补。

**抛出问题**：

- 实际观测中，OCS/光变信息和分辨图像的获取难度、稳定性差别大吗？

## 第3页：统一物理仿真框架

**页标题**：方法：统一 BRDF 驱动的 OCS-图像仿真链路

**页面内容**：

```text
卫星STL几何
  -> 部件材料分区
  -> GGX/Cook-Torrance BRDF
  -> 自遮挡与可见性计算
  -> 多观测几何OCS + Blender光度图像
  -> 姿态反演模型
```

- OCS 与图像共享同一套几何、材料、姿态、BRDF 和遮挡假设。
- 三端闭合验证：解析解、面元积分、Blender 渲染相互核对。
- 单平板平均相对误差约 0.253%，立方体误差不超过约 0.25%。

**建议图**：

- 一张流程图。
- 下方放小表格展示前向链路验证误差。

**现场讲法**：

我这里最想保证的是物理假设一致。OCS 和图像不是两套互不相关的数据，而是从同一个几何、材料和 BRDF 假设生成。这样后面比较 OCS、图像和融合时，至少能避免前向模型不一致带来的干扰。

**抛出问题**：

- 这种 BRDF 和自遮挡建模方式，在航天器光学观测论文里是否站得住？
- 还需要补哪些材料或 BRDF 文献支撑？

## 第5页：前向仿真与可观测性发现

**页标题**：前向分析：自遮挡和 roll 对光度响应有实质影响

**页面内容**：

- 5 个观测几何下，平均遮挡率约 60-78.5%。
- 自遮挡会影响 OCS 和图像亮度分布，不是装饰性模块。
- roll 小规模敏感性实验：OCS 平均相对变化约 20.3%，max 约 26.2%。
- 这支持后续做三轴扩展和观测几何分析。

**建议图**：

- 自遮挡率柱状图。
- OCS 随 roll 变化示意曲线。

**现场讲法**：

前向分析里比较明确的一点是，自遮挡不是可忽略细节。不同观测几何下遮挡率变化很大，roll 变化也会让 OCS 有明显变化。这说明姿态信息确实进入了光度响应，但也说明后续三轴问题会更复杂。

**抛出问题**：

- 真实观测中，自遮挡、相位角和姿态简并通常怎样处理？
- 观测几何是否值得作为后续重点？

## 第6页：姿态反演核心结果

**页标题**：结果：clean image 很强，但 OCS 仍提供独立光度约束

**页面内容**：

| 方法 | 输入 | mean error | 解释 |
|---|---|---:|---|
| OCS MLP | per_part_log | 约 5.91 deg | 更接近实用的 OCS-only 特征 |
| TinyCNN image-only | clean rendered image | 11.87-12.38 deg | 早期轻量图像基线 |
| Feature fusion | per_part_log + image | 4.10 +/- 0.77 deg | 轻量分支下融合有增益 |
| ResNet-18 image-only | clean rendered image | 1.69 +/- 0.07 deg | 理想干净图像上界 |
| ResNet + OCS fusion | clean image + OCS | 1.47 +/- 0.07 deg | Hit@5 = 99.7%，尾部误差改善 |

**建议图**：

- 方法对比表。
- 或误差分布图，突出尾部误差改善。

**现场讲法**：

补充强图像模型以后，我现在不再把论文写成“融合一定最好”。更合理的解释是：clean rendered image 条件下，ResNet 可以非常强，但这是理想图像上界；OCS 的价值是低维、可解释、多几何，而且不直接依赖图像像素质量。融合在 clean 条件下有边际增益，尤其改善尾部误差。

**抛出问题**：

- ResNet clean image 已经很强时，论文里怎么讲 OCS 的价值最有说服力？
- 审稿人会不会质疑“既然图像强，为什么还需要 OCS”？

## 第7页：观测退化与现实差距

**页标题**：clean image 不是真实外场性能

**页面内容**：

- ResNet-18 clean image-only：1.69 +/- 0.07 deg。
- 1% Gaussian image noise 下，ResNet 退化到约 85.85 deg，Hit@5 约 2.2%。
- OCS 不受图像像素噪声影响，是独立低维光度约束。
- 当前退化模型还很简单，需要请教真实观测中最关键的退化因素。

**建议图**：

- clean/noise 条件下 image-only 与 OCS 的对比。
- 或图像退化示意：模糊、噪声、背景、低分辨。

**现场讲法**：

这个结果提醒我，clean image 的性能不能直接外推到真实观测。现在我只做了比较简单的 Gaussian noise，还没有完整模拟大气、PSF、背景和探测器链路。所以这里特别想请您判断：真实地基观测里最关键的退化到底是什么。

**抛出问题**：

- 真实地基观测中，最影响姿态反演的是大气、PSF、SNR、背景、跟踪误差，还是分辨率？
- 投稿前补哪些退化实验最有价值？
