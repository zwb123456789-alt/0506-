## 1. 项目介绍

梁总您好，我目前的课题围绕非合作空间目标的光学观测与姿态反演展开。核心目标是在缺少合作遥测的情况下，利用空间目标反射太阳光形成的光度信息，推断目标姿态。

目前项目主要关注两类光学信息：

1. **OCS（optical cross section / 光学截面积）**：可理解为目标在特定太阳-观测几何下的积分光度响应，具有低维、可解释、适合多观测几何组合的特点。
2. **光度图像（photometric image）**：二维图像中包含目标轮廓、部件布局、阴影、高光和亮度分布等空间信息。

当前工作建立了一套统一 BRDF 驱动的 OCS-光度图像仿真与反演流程：

```text
真实卫星 STL 几何
  -> 部件材料分区
  -> GGX/Cook-Torrance BRDF
  -> 自遮挡与可见性建模
  -> 多观测几何 OCS 扫描
  -> 光度图像渲染
  -> OCS-only / image-only / OCS-image fusion 姿态反演
```

当前姿态任务聚焦 yaw-pitch 二轴姿态反演，roll 固定，作为当前论文边界。

## 2. 当前进展与结果总结

### 2.1 工程与复现进展

- 模块 A/B/C 已经跑通：
  - 模块 A：OCS 计算、多观测几何扫描、自遮挡建模。
  - 模块 B：Blender 光度图像渲染与 BRDF 后处理。
  - 模块 C：OCS-only、image-only、late fusion、feature fusion 姿态反演。
- 复现 Step 0-8 已完成。
- BRDF 前向链路做过三端闭合验证：
  - 单平板平均相对误差约 0.253%。
  - 立方体误差不超过约 0.25%。
- fast/full 面元精度对比显示：
  - OCS mean 差异约 2.0%。
  - OCS max 差异约 0.5%。

### 2.2 主要反演结果

| 方法 | 输入 | mean error | 当前解释 |
|---|---|---:|---|
| OCS MLP | all_raw 45D | 3.98 +/- 0.60 deg | semi-oracle 上界，不作为实际可操作特征主张 |
| OCS MLP | per_part_log 30D | 5.91 deg 左右 | 更接近实际可解释的 OCS-only 结果 |
| TinyCNN image-only | phase63 image | 约 11.87-12.38 deg | 旧轻量图像基线 |
| Feature fusion | per_part_log + image | 4.10 +/- 0.77 deg | 旧 TinyCNN 分支下的融合 sweet spot |
| ResNet-18 image-only | clean rendered image | 1.69 +/- 0.07 deg | 理想干净图像上界 |
| ResNet + per_part_log | clean image + OCS | 1.47 +/- 0.07 deg | 强图像模型下 OCS 仍有边际和尾部增益 |

### 2.3 最新论文口径调整

补充 ResNet-18 后，论文主线已经从“fusion 一定最优”调整为更稳妥的方向：

- clean rendered image 下强 CNN 可以达到很高精度，但这是理想图像上界，不代表真实外场性能。
- OCS 不再被表述为 clean image 条件下的精度上限来源，而是低维、可解释、多观测几何、对图像像素退化不敏感的光度约束。
- OCS-图像融合的价值是条件性互补，尤其体现在尾部误差改善和观测退化条件下。

### 2.4 鲁棒性与边界

- ResNet 在 clean synthetic image 下表现很强，但 1% Gaussian image noise 下退化到约 85.85 deg，Hit@5 约 2.2%。
- OCS 噪声实验显示，fusion gain 随 OCS noise 从 0% 到 20% 增加，约从 +1.97 deg 增至 +6.29 deg。
- 自遮挡分析显示跨几何平均遮挡率约 60-78.5%，说明自遮挡对 OCS 有实质影响。
- Roll 小规模敏感性显示 OCS 平均相对变化约 20.3%，完整三轴扩展仍需后续工作。

当前工作尚未完成真实光学望远镜观测验证，也未显式建模大气、探测器响应、PSF、地球反照、背景污染等完整观测链路。

## 4. 相关技术方向

目前我理解本项目可向以下方向延展，希望请梁总帮助判断优先级。

### 4.1 光度/OCS 方向

- 多观测几何 OCS 姿态可观测性分析。
- 光变曲线与 OCS 特征的关系。
- OCS 特征在低分辨率或非成像观测条件下的应用价值。
- OCS 噪声、几何误差、材料误差对姿态反演的影响。

### 4.2 图像姿态反演方向

- clean rendered images 与真实观测图像之间的 domain gap。
- 图像退化，如噪声、模糊、下采样、跟踪误差、PSF、背景污染。
- 强 CNN / Transformer 图像模型在规则仿真图像中的上界能力与外推风险。
- 跨 phase / 跨观测几何图像泛化。

### 4.3 BRDF 与材料方向

- GGX/Cook-Torrance BRDF 在空间目标材料建模中的合理性。
- nominal material 参数与真实材料标定之间的差距。
- 金属 roughness、F0、太阳能板/遮光板参数对 OCS 的敏感性。
- 材料老化、镜面峰、非均匀表面反射对姿态可观测性的影响。

### 4.4 光谱、多光谱、偏振方向

- 多光谱/高光谱光度响应用于材料识别和姿态反演。
- 光谱维度下的 OCS 或 light curve。
- 偏振 BRDF 对表面法向、材料和镜面反射的约束。
- 光谱/偏振与图像、OCS 的多模态融合。

### 4.5 真实观测与实验验证方向

- 地基望远镜观测数据与仿真结果的对齐。
- 实验室缩比模型、转台、可控光源与相机测量。
- 观测场地、相机/望远镜、滤光片、光谱仪、偏振片等设备选型。
- 没有真实姿态 ground truth 时的间接验证策略。
