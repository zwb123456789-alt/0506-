# 给梁总的预约消息模板

## 1. 微信首发版

```text
梁总您好，冒昧打扰您。我是 XXX 老师的学生 XXX，目前在做空间目标光学观测与姿态反演相关课题，主要涉及 OCS、光度图像、BRDF 建模、自遮挡仿真和姿态反演。

XXX 老师和我提到，您在光学观测、姿态反演以及相关实验设计方面经验非常丰富，也建议我如果方便的话专门向您请教一次。我目前项目已经有一套仿真与反演结果，也在准备论文方向，但在前沿定位、创新点凝练、真实实验补充设计、投稿方向等方面还很需要专家把关。

如果您近期方便，我想专门飞到西安，当面向您汇报和请教半天时间，上午或下午都可以，时间完全按您方便安排。我会提前整理一个简洁的项目材料和问题清单，尽量提高交流效率。相关专家咨询费用也可以按您方便的形式或单位规定执行。

不知道您近期是否方便安排一次？如果您愿意，我可以先把项目简介发给您，您看是否值得进一步交流。
```

## 2. 梁总回复愿意后的跟进版

```text
非常感谢梁总！我会提前准备一份简洁材料，主要包括：项目背景、当前仿真与反演结果、论文主线、目前困惑以及希望请您重点把关的问题。

我这边时间比较灵活，可以根据您的安排飞到西安。您看是更方便上午还是下午？我也可以先给您几个备选日期，或者完全按您的空档来。
```

## 3. 确认时间后的材料发送版

```text
梁总您好，我把会前材料整理成了一个简洁版，主要是方便您提前了解背景，不需要您提前细看。

这次我最希望向您请教的是四类问题：
1. 这个课题在光学观测与姿态反演领域的创新点是否成立；
2. 论文主线和投稿方向是否合适；
3. 后续真实实验或外场验证应该如何设计；
4. 如果拓展到光谱/多光谱/偏振等方向，哪些路线更有前沿价值。

我到现场会控制汇报时间，尽量多留时间听您的建议。
```

## 4. 语气注意

- 不要一开始就问“专家费多少钱”，用“专家咨询费用可按您方便的形式或单位规定执行”更稳妥。
- 强调“我飞到西安，当面请教”，体现诚意。
- 强调“半天，按您方便安排”，尊重对方时间。
- 一开始不要发过长 PPT，先发一页项目简介即可。
