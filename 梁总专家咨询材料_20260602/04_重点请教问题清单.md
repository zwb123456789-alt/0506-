# 重点请教问题清单

> 用途：面谈时放在手边，不必逐条照念，但要确保核心问题都问到。  
> 建议：每个大类最后请梁总给出“优先级排序”。

## 1. 方向价值与创新点

1. 从光学观测和空间目标姿态反演领域看，OCS + 光度图像 + BRDF 统一仿真这个方向是否有价值？
2. 这个项目最值得强调的创新点应该是：
   - 统一物理前向模型？
   - OCS 与图像的条件性互补？
   - clean image 上界与退化鲁棒性分析？
   - 多观测几何下的姿态可观测性？
3. 目前的工作更像“方法论文”、“benchmark 论文”、“工程仿真论文”，还是“观测实验论文”的前置版本？
4. 如果要提高创新性，最应该补哪一块：理论指标、真实数据、光谱/偏振、多观测几何优化，还是三轴姿态？

## 2. 论文主线与表述边界

1. 没有真实光学望远镜验证时，论文主线是否应定位为 controlled simulation benchmark？
2. clean rendered image 下 ResNet 很强，这个结果应该如何解释才不被误读？
3. OCS 不如 clean ResNet 的均值精度时，如何讲 OCS 的价值最有说服力？
4. fusion 只有边际均值提升，但改善 tail error 和退化场景，这样的贡献够不够支撑论文？
5. 审稿人最可能攻击哪些点？
6. 哪些表述一定不能写？

## 3. 投稿方向

1. 以当前工作，比较适合投：
   - Acta Astronautica
   - Advances in Space Research
   - Optics Express
   - Remote Sensing
   - 其他更合适的光学/航天/遥感期刊？
2. 如果目标是 SCI 二区，最小补强项是什么？
3. 如果想冲更高层次，必须补什么实验或理论？
4. 论文题目里是否应该突出：
   - BRDF-driven simulation
   - OCS-image benchmark
   - attitude inversion
   - conditional complementarity
   - robust optical observation
5. Table 1 文献对比应该和哪些工作比，哪些文献是必须补读的？

## 4. 真实实验补充设计

1. 如果要做最低可行真实实验，最现实方案是什么？
   - 地基望远镜观测真实空间目标？
   - 实验室缩比模型光度测量？
   - 暗室/转台/光源/相机测量？
   - 使用已有公开或合作观测数据？
2. 真实实验是否必须有 ground truth 姿态？如果没有，怎样设计可验证任务？
3. 实验对象应选：
   - 真实卫星/空间碎片？
   - 缩比卫星模型？
   - 标准几何体与部件模型？
4. 场地和设备方面，西安或国内哪些单位/场地更适合？
5. 如果只能补一个短周期实验，最能支撑论文的是哪一种？
6. 真实实验结果应该作为主文结果、补充验证，还是 future work？

## 5. 光谱、多光谱、偏振等前沿方向

1. 光谱信息在空间目标姿态反演中最可能提供什么增益？
   - 材料识别？
   - BRDF 参数反演？
   - 姿态可观测性增强？
   - 与光度图像互补？
2. 多光谱/高光谱与 OCS 的结合点在哪里？
3. 偏振观测是否比光谱更适合补充 BRDF 和姿态信息？
4. 光谱方向做论文，应该偏“观测物理”还是“反演算法”？
5. 如果下一阶段要做前沿拓展，梁总建议优先做：
   - 多光谱/光谱 OCS
   - 偏振 BRDF
   - 光变曲线与图像融合
   - 三轴姿态反演
   - 真实望远镜数据
   - 数字孪生与观测规划

2. 是否有适合请教或合作的实验场地、团队、观测站或数据渠道？
3. 目前项目距离可投稿论文还差什么？
