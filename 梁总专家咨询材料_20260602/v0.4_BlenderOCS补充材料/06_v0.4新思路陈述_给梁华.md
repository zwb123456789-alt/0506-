# v0.4 新思路陈述（给梁华专家）

> 用途：在前次 v0.4 重启摘要基础上，向梁华专家汇报项目最新的定位与方法思路。
> 核心：研究问题已从"做一套姿态反演系统"收敛为"在已知几何条件下，研究 OCS 与图像两个观测通道分别能告诉我们什么、何时互补、何时可信"。
> 性质：这是定位与指标层面的思路，尚未产生新实验结果；当前停在代码实施前。

---

## 一、一句话概括新思路

v0.4 不再做"真实未知非合作目标姿态反演系统"，而是改为：

```text
在目标几何已知（model-known、但不配合）的条件下，
让 OCS 光度通道与光学图像通道共享同一套物理前向模型，
研究两个通道对姿态信息的：
可观测性（什么能被知道）、
互补性（何时互补、何时一起失效）、
置信一致性（跨通道一致能否作为可信度判据）。
```

把题目从"我能不能反演出姿态"，换成"在同一物理前提下，这两种观测各自携带多少姿态信息、在哪互补、什么时候该信"。

---

## 二、为什么换这个思路

### 2.1 旧定位的根本风险

旧定位是"提出一种 OCS+图像融合的非合作目标姿态反演方法，并在仿真中证明精度与鲁棒"。它有三处容易被审稿人击穿：

- **目标若真未知**，就没有目标专属的 OCS/图像前向查找表，姿态反演本质是欠定问题。
- **仿真 OCS 不能默认等于真实 OCS**：材料、BRDF、几何、观测链、定标都会带来偏差，没有真实锚点时只能说"在假设物理内成立"。
- **旧 OCS 与图像不同源**：旧 OCS 来自模块 A 的面中心扫描，图像来自 Blender 像素级渲染。两者采样口径不一致，所以旧的 OCS-only / fusion / 噪声 / 退化结果，差异里混进了"两套仿真链路的差异"，而不纯是"两种观测模态的差异"。这也是 v0.3 暂停投稿的真正原因。

### 2.2 新思路把风险变成贡献

- **边界更诚实**："非合作"不等于"完全未知"。合理对象是己方失效卫星、公开型号航天器、有设计资料的目标、实验室缩比件、或由其他手段先验重建出近似几何的目标。这既不夸大成任意未知目标，也不是没有价值的玩具问题。
- **统一前向模型修掉了 v0.3 的根问题**：OCS 与图像共享同一 STL、姿态、太阳/观测几何、BRDF、可见性与渲染口径。OCS 是这套模型的"积分读出"，图像是"空间分布读出"。两者差异此后只来自观测通道本身。
- **科学问题比误差表更立得住**：论文主轴从"融合后误差更低"升级为 what can be known / when complementary / when trustworthy 三个可审稿、可复现的问题。

## 三、两个定义级决策（这是新思路的关键）

### 决策 1：OCS 当作"独立光度通道"，不是"从图像里抠出来的亮度"

- **主口径 A**：OCS = 独立非成像光度通道。它和图像共享几何/姿态/光照/BRDF，但**不共享图像退化链路**。
- **对照口径 B**：image-derived OCS = 从（退化后的）图像里做孔径测光得到的亮度。

为什么这样分？因为只有当 OCS 和图像有**不同的退化源和失败模式**时，"两个通道给出一致答案"才真正是两份独立证据互相印证。如果 OCS 是从图像里抠的，那它俩共用一条退化链，所谓"一致"可能只是**共模失败**——一起错得一样，反而不能当高置信。口径 B 专门用来展示这个失效边界。

### 决策 2：主线 OCS 是"跨几何多观测向量"，不是单个瞬时亮度

一个非成像光度通道在某一瞬时只能给一个总亮度标量。单标量对 2–3 个姿态自由度约束太弱，会导致 OCS 几乎全程"分不出姿态"，沦为图像的陪跑。

所以主线 OCS 定义为：

```text
同一目标姿态下，在多个受控的太阳/观测几何下分别测得总光通量，
组成一个"跨几何光度观测向量"。
```

- 单瞬时标量（F1）→ 只作"信息下界"，用来说明单点确实不够。
- per-part 分部件亮度（F2）→ 与"非成像通道"不自洽（非成像分辨不出部件），只能当半 oracle 的诊断上界。
- 时域光变曲线（L2，含自转/曝光/轨道时变）→ 留作 Future Work。

> 这里有一个需要向梁总确认的现实假设：跨几何向量隐含"在一段较短时间窗内、目标姿态基本不变（或已被姿态传播补偿）时，主动在多个几何下分别采光度"。我们会单独做一个 Δθ 敏感性分析，量化"姿态在窗口内漂移多大就会破坏这个假设"，并诚实标注它是离散后处理、不是真实自转光变仿真。

## 四、怎么把"信息量"和"可信度"做成可计算的指标

为了让上面三个问题不停留在口号，我们在进代码前先冻结了一份**指标实现规范**，核心是把姿态反演做成"在已知候选网格上打分"，而不是直接回归角度。

### 4.1 反演范式：在候选网格上打分

- 姿态候选 = 一个 2664 点的 (yaw, pitch) 网格（5° 步长）。
- 对每个候选，由模型给一个分数，归一化成一个**类后验分布**（posterior-like）。
- 有了分布，才能算熵（信息够不够集中）、top-k（前几名命中没有）、两通道分布的 JS 散度（一致不一致）等。直接回归一个角度是给不出这些量的。

### 4.2 主口径用"距离/模板相似度"，softmax 分类作对照

- **主实现**：在通道特征空间里，把待测样本和每个候选的"干净前向签名"比相似度（距离/核似然或模板似然），相似度归一成分布。这种做法不要求训练集覆盖全部 2664 类，和我们"每个姿态每个几何只有一条记录"的数据结构天然契合。
- **增强对照**：2664 类 softmax 分类作为一个对照口径，不当唯一主范式。

> 这是我已和协作审阅来回确认后定的口径：**主范式 = 候选网格打分；主实现 = 距离/模板似然；softmax 只是对照**。下面的核函数、温度、特征空间、各种阈值这些"实现级旋钮"，都留到小规模标定后再定，不提前拍死。

### 4.3 可信度怎么判

对同一个样本，比较 OCS 分布和图像分布：

- 两者高度一致、且各自分布集中 → 高置信。
- 一方信、一方不信 → 回头查那个姿态本身是不是不可观测，或图像是不是退化了。
- 两者高度冲突 → 不硬给姿态，标成低置信/失配，必要时拒识。
- 最终用一条 **risk-coverage 曲线**（保留多少样本 vs 这些样本的错误率）来证明"按一致性拒识"到底有没有用。

## 五、和上次汇报相比，新增了什么

上次（v0.4 重启摘要）讲的是"为什么要重建统一前向模型、当前进度到哪"。这次新增的是**定位与方法的收敛结果**：

1. 研究问题正式收敛为 what can be known / when complementary / when trustworthy 三问。
2. OCS 的两个定义级决策（独立光度通道口径 A、跨几何多观测向量 L1）已冻结。
3. 信息量与置信指标已写成可执行规范：候选网格打分 + 距离/模板似然主口径 + 一致性即置信 + 拒识曲线。
4. FIM/CRLB 这类理论信息量工具被放在"可选升级层"：先用离散网格上的稳健指标保底，只有在梯度数值稳定的光滑姿态子集上，才升级到正式的 Fisher 信息/最优观测设计，绝不写成已闭合的强理论。

当前仍然停在"代码实施前"。下一步是搭代码骨架、做单姿态 smoke test、depth/几何/阴影门控验证，全部过了才全量生成和训练。**不会跳过验证直接出结果。**

## 六、想请梁华专家重点判断的问题

1. 把 OCS 和图像讲成"同一物理前向模型的积分读出与空间分布读出"，这个叙事在光学观测物理上站得住吗？
2. "OCS 当独立光度通道、不从图像导出"这个口径，是否符合真实空间目标光度监测的实际获取方式？跨多个太阳/观测几何采一个光度向量，现实中可行吗？
3. "短时间窗内姿态准静态、主动换几何采光度"这个假设，在真实在轨观测里大约能成立到什么程度？姿态漂移多大就不能忽略？
4. 把"两个通道一致性"当可信度判据，并用 image-derived OCS 的共模失败作反衬——这个逻辑在审稿人那里有没有明显漏洞？
5. 如果之后严格物理口径下的反演指标不如旧结果，论文把它解释为"更严格定义下的真实信息边界"，这种讲法专家是否认可？
