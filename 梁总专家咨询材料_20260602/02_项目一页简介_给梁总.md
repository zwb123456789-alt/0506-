# 项目一页简介：OCS-光度图像联合仿真与空间目标姿态反演

> 面向对象：梁总  
> 用途：会前快速了解项目背景与当前困惑  
> 建议发送方式：确认梁总愿意沟通后，以 PDF 或微信文字摘要形式发送

## 1. 项目背景

当前课题面向非合作空间目标的光学观测与姿态反演。目标是在缺少合作遥测的情况下，利用空间目标反射太阳光形成的光度信息，推断目标 yaw-pitch 姿态。

项目目前聚焦两类光学信息：

- OCS：光学截面积/光度标量响应，低维、可解释、适合多观测几何。
- 光度图像：二维渲染图像，包含轮廓、部件布局、阴影、亮度分布和高光等空间信息。

## 2. 当前方法框架

已建立一套统一 BRDF 驱动的仿真与反演流程：

```text
真实卫星 STL 几何
  -> 三部件材料分区
  -> GGX/Cook-Torrance BRDF
  -> 自遮挡与可见性建模
  -> 多观测几何 OCS 扫描
  -> Blender 光度图像渲染
  -> OCS-only / image-only / OCS-image fusion 姿态反演
```

当前姿态任务：

- yaw-pitch 二轴姿态反演。
- roll 固定，作为当前论文边界。
- 主要采用 5 deg 姿态网格，共 2701 个 yaw-pitch 姿态。
- OCS 使用 5 个观测几何。
- 图像主分支目前主要采用 phase63 clean rendered images。

## 3. 当前关键结果

### 3.1 前向仿真验证

- 模块 A/B/C 已跑通。
- BRDF 三端闭合验证完成。
- 单平板平均相对误差约 0.253%。
- 立方体 B/解析误差不超过约 0.25%。
- fast 与 full 面元精度对比：OCS mean 差异约 2.0%，max 差异约 0.5%。

### 3.2 姿态反演结果

代表性结果：

| 方法 | 输入 | mean error | 作用 |
|---|---|---:|---|
| OCS MLP | all_raw 45D | 3.98 +/- 0.60 deg | semi-oracle 上界 |
| OCS MLP | per_part_log 30D | 5.91 deg | 更接近实用的 OCS 特征 |
| TinyCNN image-only | phase63 image | 约 11.87-12.38 deg | 旧轻量图像基线 |
| Feature fusion | per_part_log + image | 4.10 +/- 0.77 deg | 旧融合 sweet spot |
| ResNet-18 image-only | clean image | 1.69 +/- 0.07 deg | 理想干净图像上界 |
| ResNet + per_part_log | clean image + OCS | 1.47 +/- 0.07 deg | 对强图像模型仍有边际增益 |

### 3.3 鲁棒性与补充实验

- ResNet 在 clean synthetic image 下很强，但 1% Gaussian image noise 下退化到约 85.85 deg，Hit@5 约 2.2%。
- OCS 不受图像像素噪声影响，是独立的低维光度约束。
- OCS 噪声实验中，fusion gain 随 OCS noise 从 0% 到 20% 增加，约从 +1.97 deg 增至 +6.29 deg。
- 自遮挡分析显示跨几何平均遮挡率约 60-78.5%，说明自遮挡不是装饰模块。
- Roll 小规模敏感性显示 OCS 平均相对变化约 20.3%，完整三轴扩展仍需后续工作。

## 4. 当前论文主线

当前论文不再表述为“fusion 永远最优”，而是更谨慎地定位为：

> 统一 BRDF 驱动的 OCS 与光度图像仿真框架，支持受控姿态反演 benchmark。clean rendered image 给出图像反演的理想上界；OCS 提供低维、可解释、多观测几何、对图像像素退化不敏感的光度约束；OCS-图像融合的价值是条件性互补，尤其体现在尾部误差改善和观测退化条件下。
