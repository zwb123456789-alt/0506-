## 一、项目背景

我的课题围绕非合作空间目标的光学观测与姿态反演展开。由于非合作目标通常缺少可直接使用的姿态遥测，光学观测中的亮度、形状、阴影和反射特征就成为姿态判断的重要信息来源。

目前重点关注两类信息：

- **OCS（Optical Cross Section，光学截面积）**：可理解为目标在给定太阳-目标-观测几何下的积分光度响应。它是低维、可解释的光度特征，适合在多观测几何或非高分辨成像条件下使用。
- **光度图像**：包含目标轮廓、部件布局、阴影、高光和空间亮度分布等二维信息。它信息量更丰富，但也更依赖图像质量、分辨率、跟踪稳定性和观测链路条件。

本研究想回答的核心问题是：在统一物理仿真条件下，OCS 与光度图像分别承载哪些姿态信息？在图像质量变化或观测条件受限时，两者是否能形成互补约束？

## 二、当前方法框架

当前已建立一套统一 BRDF 驱动的 OCS-光度图像仿真与反演流程：

```text
卫星STL几何模型
  -> 部件材料分区（金属主体 / 太阳能板 / 遮光板）
  -> GGX/Cook-Torrance BRDF建模
  -> 可见性与自遮挡计算
  -> 多观测几何OCS扫描 + Blender光度图像渲染
  -> OCS-only / image-only / OCS-image fusion 姿态反演
```

当前任务边界：

- 聚焦 yaw-pitch 二轴姿态反演，roll 固定为 0，作为受控基准研究的第一步。
- 姿态网格为 5 deg，共 2701 个 yaw-pitch 姿态。
- OCS 使用 5 个观测几何；图像反演目前主要在同分布仿真图像条件下评估。
- 当前工作是受控仿真 benchmark，尚未完成真实光学望远镜观测验证。

前向链路已完成基础物理一致性验证：

- 单平板平均相对误差约 0.253%。
- 立方体误差不超过约 0.25%。
- fast/full OCS 对比中，mean 差异约 2.0%，max 差异约 0.5%。

## 三、当前进展与主要结果

### 1. 前向仿真与可观测性

自遮挡分析显示，在 5 个观测几何下，平均遮挡率约为 60-78.5%。这说明自遮挡对 OCS 和图像亮度分布有实质影响，不是可忽略的渲染细节。

roll 小规模敏感性实验显示，OCS 对 roll 变化的平均相对变化约 20.3%，最大约 26.2%。这提示完整三轴姿态反演有继续扩展的必要，但目前论文主任务仍限定在 yaw-pitch。

### 2. 姿态反演结果

目前已经完成 OCS-only、image-only 和 OCS-image fusion 的多组对比。核心结果如下：

| 方法 | 输入 | mean error | 说明 |
|---|---|---:|---|
| OCS MLP | all_raw | 3.98 +/- 0.60 deg | semi-oracle/diagnostic 特征，不作为实用主线 |
| OCS MLP | per_part_log | 约 5.91 deg | 更接近实用的 OCS-only 特征 |
| TinyCNN image-only | clean rendered image | 11.87-12.38 deg | 早期轻量图像基线 |
| Feature fusion | per_part_log + image | 4.10 +/- 0.77 deg | 旧轻量图像分支下融合有增益 |
| ResNet-18 image-only | clean rendered image | 1.69 +/- 0.07 deg | 理想干净仿真图像上界 |
| ResNet + OCS fusion | clean image + OCS | 1.47 +/- 0.07 deg | Hit@5 = 99.7%，尾部误差从 9.9 deg 改善到 6.6 deg |

因此，目前论文主线不再写成“融合永远优于所有方法”，而是更审慎地定位为：

- clean rendered image 上，强 CNN 可以达到很高精度，但这更像理想上界。
- OCS 是低维、可解释、多几何的光度约束，不直接依赖图像像素质量。
- OCS-image fusion 的价值是条件性互补，尤其体现在尾部误差改善和观测退化条件下。

### 3. 观测退化与鲁棒性

一个重要发现是：强图像模型对像素级退化非常敏感。在 1% Gaussian image noise 条件下，ResNet image-only mean error 退化到约 85.85 deg，Hit@5 降至约 2.2%。这说明 clean rendered image 的结果不能直接外推为真实地基观测性能。

另一方面，OCS 不受图像像素噪声影响。在 OCS 噪声实验中，fusion gain 随 OCS 噪声从约 +1.97 deg 到 +6.29 deg 变化，说明多模态互补需要放在具体退化条件下讨论，而不能简单声称某一模态绝对最优。

## 四、当前论文定位与边界

我目前倾向于将论文定位为：

> **统一 BRDF 驱动的 OCS 与光度图像仿真框架，用于受控空间目标姿态反演 benchmark，并分析 OCS、图像和融合方法在理想图像与退化观测条件下的互补关系。**

希望突出：

- 统一物理仿真框架：OCS 与图像共享几何、材料、姿态、观测几何、BRDF 和自遮挡假设。
- 受控 benchmark：在可控条件下比较 OCS-only、image-only 和 fusion。
- 结果重估：强 CNN 在 clean image 上表现很强，但这应解释为理想上界。
- 现实意义：真实观测存在大气、PSF、噪声、背景、分辨率、跟踪误差等退化，OCS 这类低维光度约束仍可能有价值。

当前边界也比较明确：

- 尚无真实光学望远镜观测验证。
- 尚未完整建模大气湍流、探测器响应、PSF、背景污染、地球反照等完整观测链路。
- 当前只做 yaw-pitch，roll 固定。
- 图像实验仍以仿真同分布为主，离真实外场图像还有差距。
