# 会前材料包清单

> 用途：确认和梁总见面前需要准备、发送和携带的材料。

## 1. 会前发送材料

建议只发精简版，不要一次性发完整项目文件夹。

| 材料 | 建议形式 | 发送时机 |
|---|---|---|
| 项目一页简介 | PDF 或微信长图/文字 | 梁总确认愿意沟通后 |
| 交流问题清单 | PDF 或 Markdown 转 PDF | 确认见面时间后 |
| 简版 PPT | PDF，8-12 页 | 见面前 1-2 天 |

## 2. 现场携带材料

| 材料 | 用途 |
|---|---|
| 1 页项目简介纸质版 | 让梁总快速抓住项目 |
| 8-12 页 PPT | 现场汇报 |
| 重点问题清单 | 防止谈散 |
| 当前论文主线摘要 | 讨论投稿和写作方向 |
| 关键结果表 | 梁总追问时展示 |
| 空白纸/平板 | 记录建议 |

## 3. PPT 必备内容

PPT 不需要很长，建议包括：

1. 研究问题：非合作空间目标光学姿态反演。
2. 当前框架：STL、材料、GGX BRDF、自遮挡、OCS、图像、反演。
3. 当前结果：OCS-only、ResNet image-only、fusion、鲁棒性实验。
4. 当前论文主线：controlled simulation benchmark + conditional complementarity。
5. 当前边界：无真实光学验证、fixed roll、nominal material、phase63 image。
6. 希望梁总重点指导的问题。

## 4. 不建议会前发送的材料

- 完整代码。
- 过长论文初稿。
- 所有实验日志。
- 大量未解释图表。

如果梁总明确表示愿意看细节，再补充对应材料。

## 5. 会后需要整理

会后当天整理：

1. 梁总对论文主线的判断。
2. 梁总建议补的实验。
3. 梁总建议投的期刊。
4. 梁总提到的关键文献、团队、实验场地。
5. 下一步行动清单。
