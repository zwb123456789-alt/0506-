# 会前发送材料包建议

> 用途：决定实际发给梁总哪些文件，避免一次性发太多。

## 1. 建议发送的最小材料包

建议只发送 2 个文件：

```text
07_发给梁总的会前预读材料.md
04_重点请教问题清单.md
```

如果转成 PDF，建议命名为：

```text
梁总会前材料_项目简介与请教问题.pdf
梁总会前材料_重点问题清单.pdf
```

## 2. 不建议会前发送太多材料

暂时不要发：

- 完整论文初稿。
- 代码目录。
- 所有实验日志。
- 大量结果图。
- 过长 PPT。

原因：梁总比较忙，预读材料应让他快速知道“你是谁、做了什么、想问什么”。

## 3. 建议在微信里附带的说明

```text
梁总您好，我把会前材料整理成了一个简洁版，主要是方便您提前了解背景，不需要您提前细看。材料里包括项目简介、当前结果、我想请教的问题以及可能延展的技术方向。

我现场会用 10 页左右 PPT 控制在 20-30 分钟内讲清楚，尽量把更多时间留给您帮我判断论文方向、真实实验设计和后续研究路线。
```

## 4. 现场再携带的材料

现场可以带更多，但不必会前发：

```text
02_项目一页简介_给梁总.md
03_半天面对面交流议程.md
04_重点请教问题清单.md
07_发给梁总的会前预读材料.md
08_相关技术方向与可请教路线.md
简版 PPT
关键结果图表
```

## 5. 还可以补充的内容

如果时间允许，可以再准备一个 8-10 页 PPT，结构如下：

1. 项目问题与目标。
2. OCS 与光度图像统一仿真框架。
3. 模块 A/B/C 当前进展。
4. 前向验证结果。
5. 主要反演结果。
6. ResNet 后的论文口径调整。
7. 鲁棒性与边界。
8. 想请梁总重点把关的问题。
9. 真实实验和前沿方向设想。
10. 希望形成的专家建议。
