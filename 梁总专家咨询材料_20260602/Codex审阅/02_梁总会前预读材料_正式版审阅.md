# 梁总会前预读材料正式版审阅报告

> 审阅日期：2026-06-08  
> 审阅对象：`最终发送版/梁总会前预读材料_正式版.md`  
> 审阅结论：需小修。整体方向可用，GGX 口径和真实验证边界基本守住，但结构重心仍偏向 v0.4，需要进一步汇入前期关键操作和路线演进。

---

## 一、总体结论

当前版本已经比早版更适合发给梁华老师：开头补充了现实意义，调研判断也有了，`GGX` 口径已经统一，没有再出现 `Cook-Torrance`，并且明确说明当前尚未完成真实光学望远镜观测验证。

主要问题不是事实红线，而是结构重心：材料仍容易给人一种“主要是在讲 v0.4 重启”的感觉。用户明确要求“不只是 v0.4，之前操作的这些也要汇入重点”，因此还需要把前期路线演进讲清楚：OCS-only 起步、加入图像、跑通融合、退化实验、叙事从“融合最优”调整为“条件性互补”，最后才进入 v0.4 方法审计与重建。

---

## 二、P0 主要问题

### 1. 第三节“五阶段路线”仍偏 v0.4

位置：`最终发送版/梁总会前预读材料_正式版.md` 第 35-64 行。

当前写法把路线概括为：

1. 前向物理建模
2. 数据生成与门控验证
3. 姿态反演
4. 观测退化与鲁棒性
5. 论文与实验补充

问题是：这个结构没有充分体现项目已经经历的关键操作和决策链。尤其缺少：

- OCS-only 为什么是起点；
- 为什么加入光度图像；
- OCS-only、image-only、late fusion、feature fusion 是如何比较的；
- clean image 很强之后，为什么不能再写“融合永远最优”；
- 退化实验如何支撑“什么时候信 OCS、什么时候信图像、什么时候融合”。

建议改为“已完成的路线演进与当前重建方案”，阶段可调整为：

1. OCS-only 探索：验证低维光度响应是否能反演 yaw/pitch。
2. 图像反演：引入光度图像补充空间结构、阴影、高光和部件亮度分布。
3. 融合比较：比较 OCS-only、image-only、late fusion、feature fusion。
4. 退化与鲁棒性：用噪声、模糊、降采样、背景等判断 clean image 能否外推真实观测。
5. 方法审计与 v0.4 重建：发现 OCS/image 数据源不同源后，进入 Blender-derived pixel-level OCS 重建。

### 2. 第五节标题仍把重点压到 v0.4

位置：第 110 行。

当前标题：

```text
五、v0.4主要方案改进与下一步重跑计划
```

建议改为：

```text
五、已完成工作、方法审计与后续主要方案改进
```

这样能先说明前期工作形成了哪些判断，再说明为什么这些判断反过来要求 v0.4 方法重建。否则专家可能会觉得材料主要是在解释“为什么要重做”，而不是展示一个已经形成完整研究判断的项目。

### 3. 个别新结果数字需要核验或降级

位置：第 97 行。

当前表述：

```text
退化感知融合训练后，fusion在噪声条件下稳定在约2-2.3°，但worst-case仍有离群点
```

这个数字在当前正式材料中显得比较突然，也不像原正式版已经确认的核心结果。建议处理方式：

- 如果确有对应实验记录，补成“某补充实验阶段性结果显示……”；
- 如果暂未核验，删掉具体数值，改为“退化感知融合提示融合策略在噪声条件下可能更稳，但仍存在尾部离群样本，需要在 v0.4 中重跑确认”。

## 三、P1 修改建议

### 1. “真实卫星STL几何”建议改弱

位置：第 41 行。

当前：

```text
真实卫星STL几何 + 三部件材料分区
```

问题：容易被专家理解为真实卫星精确模型。

建议：

```text
卫星STL几何模型 + 三部件材料分区
```

或：

```text
典型三部件卫星STL模型 + 材料分区
```

位置：第 47 行、第 79 行。

- `2700+姿态`
- `2664个yaw-pitch姿态`

```text
2664个训练/反演姿态；绘图时可另处理 0°/360° 闭合显示。
```

BRDF前向链路已完成三端闭合验证

```text
前期在单平板、立方体等基础几何/单体算例中完成了三端闭合验证……
```

6. v0.4 的方法审计逻辑基本讲清：旧 OCS face-center 与 Blender pixel-level 图像不同源，因此需要统一前向模型。
