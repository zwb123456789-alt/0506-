# 空间目标光学姿态反演研究：OCS-光度图像联合仿真与反演

> 面向：梁总  
> 日期：2026年6月  
> 用途：会前预读材料，现场将有更简洁的PPT汇报

---

## 一、研究背景与目标

随着空间目标数量持续增长，非合作空间目标的姿态反演已成为空间态势感知的重要需求。在缺少合作遥测的情况下，光学观测成为获取目标状态信息的主要手段之一。

本研究聚焦两类光学信息在姿态反演中的作用：

**光学截面积（OCS）**：目标在特定太阳-观测几何下的积分光度响应。OCS具有低维、可解释、适合多观测几何组合的特点，可在低分辨率或非成像条件下获取。

**光度图像**：二维分辨图像，包含目标轮廓、部件布局、阴影分布、高光和亮度信息等空间细节。

当前研究的核心问题是：**在非均匀材料反射、自遮挡和观测质量变化条件下，OCS与光度图像分别承载何种姿态信息？两者在什么条件下能够提供互补约束？**

---

## 二、当前方法框架

本研究建立了统一BRDF驱动的OCS-光度图像仿真与反演流程：

```text
真实卫星STL几何
  → 三部件材料分区（金属主体/太阳能板/遮光板）
  → GGX/Cook-Torrance BRDF建模
  → 解析射线自遮挡与可见性计算
  → 多观测几何OCS扫描（5个太阳-观测几何）
  → Blender光度图像渲染
  → OCS-only / image-only / OCS-image fusion 姿态反演
```

**任务边界**：当前聚焦yaw-pitch二轴姿态反演（5°网格，2701个姿态），roll固定为0，作为受控基准研究的第一步。

**物理一致性验证**：
- BRDF前向链路已完成三端闭合验证（解析解-面元积分-Blender渲染）
- 单平板平均相对误差约0.253%，立方体误差不超过0.25%
- fast/full面元精度对比：OCS均值差异约2.0%，最大差异约0.5%

## 三、主要研究结果

### 3.1 前向仿真与可观测性分析

**自遮挡率分析**：跨5个观测几何，平均遮挡率为60-78.5%。其中phase120前向散射几何遮挡最严重（78.5%），金属主体部件遮挡率最高（75.8%-80.7%）。结果表明自遮挡对OCS有实质性影响，不是装饰模块。

**BRDF参数敏感性**：金属主体粗糙度（roughness）是最敏感参数，±20%扰动导致OCS变化30-42%；非金属部件参数变化影响<5%。金属base_color对OCS零影响（metallic=1完全压制漫射项），符合GGX物理模型。

**Roll敏感性**：小规模实验显示OCS对roll变化的平均相对变化约20.3%，最大达26.2%。完整三轴姿态扩展需后续工作。

### 3.2 姿态反演结果

基于10°→5°姿态网格split（更严格的泛化测试），主要结果如下：

| 方法 | 输入 | mean error | Hit@5° | 解释 |
|------|------|-----------|--------|------|
| OCS MLP | per_part_log 30D | 5.91° | 73.8% | 更接近实用的OCS-only特征 |
| TinyCNN image-only | phase63 image | 11.87-12.38° | - | 旧轻量图像基线 |
| Feature fusion | per_part_log + image | 4.10±0.77° | 87.3% | 旧TinyCNN分支下的融合 |
| **ResNet-18 image-only** | **clean rendered image** | **1.69±0.07°** | **97.6%** | **理想干净图像上界** |
| **ResNet + OCS fusion** | **clean image + OCS** | **1.47±0.07°** | **99.7%** | **OCS对强图像模型仍有边际和尾部增益** |

**关键发现**：补充ResNet-18后，论文主线已从"fusion永远最优"调整为更审慎的定位。

### 3.3 观测退化与鲁棒性分析

**图像退化脆弱性**：
- ResNet在clean synthetic image下表现极强（1.69°），但对轻微图像噪声高度敏感
- 1% Gaussian噪声下，ResNet image-only退化至85.85°，Hit@5降至2.2%
- 这一结果表明强CNN依赖干净同分布图像，对现实观测退化敏感

**OCS鲁棒性**：
- OCS不受图像像素噪声影响，是独立的低维光度约束
- OCS噪声实验显示，当OCS噪声从0%增至20%，fusion的增益从+1.97°增至+6.29°
- 这表明当某一模态退化时，另一模态可提供互补约束

**退化感知融合（实验12）**：
- 在图像退化增强训练下，融合模型在noise σ=0.01/0.10条件下稳定在约1.95-2.31°
- 但worst-case仍存在164°离群点（0.084%），不能声称fully robust
- 机制分析表明这是OCS-image co-utilization，而非OCS standalone fallback

**跨观测几何泛化（实验12d）**：
- phase24测试：image-only 11.34°，fusion 6.85°
- phase120测试：两者均约80°，为失效边界案例
- 说明clean-image性能依赖phase63同分布，跨大相位角泛化有限

## 四、当前论文定位

基于上述结果，论文主线定位为：

> **统一BRDF驱动的OCS与光度图像仿真框架，用于受控姿态反演基准研究。**
> 
> - Clean rendered image提供图像反演的理想上界，但真实地基观测很难满足这种理想条件
> - OCS作为低维、可解释、多观测几何、对图像像素退化不敏感的光度约束，在现实观测条件下仍具有价值
> - OCS-图像融合的价值不是"永远最优"，而是条件性互补，尤其体现在尾部误差改善和观测退化条件下
> - 当前工作是physically consistent simulation benchmark，**尚未完成真实光学望远镜观测验证**

**论文边界**：
- 无真实光学观测数据
- 未显式建模完整大气湍流、探测器响应、PSF、地球反照、背景污染等观测链路
- 固定roll，仅yaw-pitch反演
- 图像训练/测试为同分布仿真（phase63）
