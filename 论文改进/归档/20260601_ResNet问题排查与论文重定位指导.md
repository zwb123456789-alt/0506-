## 1. 当前核心问题

补充实验中，`ResNet-18 image-only baseline` 得到异常强的结果：

| 方法 | 输入 | mean error | Hit@5° |
|---|---|---:|---:|
| ResNet-18 image-only | phase63 log1p 128x128 | **1.69 ± 0.07°** | **97.6%** |
| TinyCNN image-only | phase63 log1p 128x128 | 11.87 ± 0.69° | 27.1% |
| OCS-only MLP all_raw 45D | concat5 all_raw | 3.98 ± 0.60° | 90.7% |
| Feature fusion per_part | concat5 per_part + image | 4.10 ± 0.77° | 87.3% |

这个结果会动摇原论文叙事：

```text
原叙事：
OCS 是主力，图像是互补辅助，fusion 在中等 OCS 信息下最有价值。

ResNet 结果带来的冲击：
单张图像 + 强 CNN 已经显著优于 OCS-only 和旧 fusion。
如果该结果稳健，则不能继续声称“OCS 提供主要姿态信息”或“融合是最优反演方案”。
```

因此，在进入正式论文写作前，必须先完成 ResNet 问题排查，并据此决定论文重定位。

## 4. 实验任务 A：ResNet 图像分支版 Fusion

### 4.1 目的

当前旧 fusion 使用的是较弱图像分支，不能公平回答“强图像模型下融合是否仍有价值”。

需要重测：

```text
ResNet image-only
ResNet feature fusion: ResNet image branch + OCS per_part_log
ResNet feature fusion: ResNet image branch + OCS all_raw 或 all_log（可选）
Late fusion: ResNet prediction + OCS MLP prediction（可选）
```

### 4.2 最小模型组合

必须至少完成：

| 编号 | 模型 | 输入 | 目的 |
|---|---|---|---|
| A1 | ResNet image-only | phase63 image | 强图像基线 |
| A2 | ResNet-feature-fusion | phase63 image + concat5 per_part_log 30D | 判断 OCS 是否给强图像补充信息 |
| A3 | ResNet-feature-fusion | phase63 image + phase63 per_part_log 6D | 公平单几何融合 |

可选：

| 编号 | 模型 | 输入 | 目的 |
|---|---|---|---|
| A4 | ResNet-feature-fusion | image + concat5 all_raw 45D | 测强 OCS 上界下 fusion 是否更强 |
| A5 | Late fusion | ResNet + OCS MLP | 判断简单预测融合是否优于特征融合 |

### 4.3 评价指标

所有模型统一输出：

```text
mean angular error
std across 5 seeds
median
p90
Hit@5°
Hit@10°
worst-case error
```

### 4.4 成功判据

如果 `ResNet-feature-fusion` 相比 `ResNet image-only` 有稳定提升：

```text
mean error 降低 >= 0.2°
或 Hit@5° 提升 >= 1 pp
或 p90 明显降低
且 5 seeds 趋势一致
```

则可以保留“OCS 对强图像模型仍有边际补益”的主张，但不能夸大。

如果 fusion 不提升甚至退化，则应承认：

```text
在干净单相位渲染图像条件下，强 CNN 已能充分利用姿态信息；
OCS 的主要价值不在该理想图像场景下提升上限，而在低成本、多几何光度观测、可解释性、噪声鲁棒性和观测条件受限场景。
```

## 5. 实验任务 B：ResNet 严苛泛化测试

### 5.1 目的

判断 `1.69°` 是否只在“同分布、干净、统一光照、统一渲染管线”的图像上成立。

必须测试至少两类扰动：

```text
1. 图像观测退化：噪声、模糊、亮度扰动、裁剪/平移
2. 物理条件泛化：跨 phase / 跨观测几何 / BRDF 参数扰动
```

### 5.2 图像观测退化测试

建议设置：

| 退化类型 | 参数 |
|---|---|
| Gaussian noise | sigma = 0.01, 0.03, 0.05, 0.10 |
| brightness scale | ×0.5, ×0.75, ×1.25, ×1.5 |
| Gaussian blur | kernel 3 / 5 |
| random shift | ±2 px / ±4 px |
| downsample-upsample | 128→64→128, 128→32→128 |

优先级：

```text
P0: Gaussian noise + brightness scale
P1: blur + downsample
P2: random shift
```

对比模型：

```text
ResNet image-only
OCS MLP per_part_log
ResNet-fusion per_part_log（若任务 A 已完成）
```

预期论文价值：

```text
如果 ResNet 对图像退化敏感，而 OCS/fusion 更稳，则可强化“多模态鲁棒性”。
如果 ResNet 仍稳定最强，则论文需转向“强图像基线揭示高保真光度图像的姿态信息密度”。
```

### 5.3 跨观测几何测试

当前 ResNet 只在 `phase63_backscatter` 图像上训练/测试。需要验证它对其他几何是否泛化。

最低方案：

```text
训练：phase63 图像
测试：phase24 / phase90 / phase120 中至少 1-2 个代表几何
```

如果没有其他 phase 图像，需要先确认是否已有渲染产物；若没有，不要立刻全量渲染 5 几何，可只渲染小规模代表集。

推荐代表几何：

```text
phase24_near_backscatter
phase90_side
phase120_forward_scatter
```

注意：

```text
跨几何测试不一定要求训练完整模型。
可以先做小规模 sanity check，确认图像分布是否明显变化。
```

## 6. 实验任务 C：数据与标签再审计

虽然已排除明显泄漏，仍需做一次结构化审计，形成可写入补充材料的证据。

### 6.1 必查项

输出一个 `audit_report.md`，至少包括：

```text
1. train/val/test 样本数
2. train/val/test yaw-pitch 分布图或统计
3. 测试集中是否包含训练姿态
4. 图像文件名与姿态标签是否一一对应
5. 是否存在按排序产生的隐式标签泄漏
6. 图像像素强度是否直接编码 yaw/pitch 的非物理信息
7. normalization 是否使用了 test 统计量
```

### 6.2 特别关注

ResNet 极强可能来自以下非显性因素：

```text
1. 渲染图像背景、裁剪框、目标位置随姿态系统变化，导致网络利用了非预期线索
2. 文件名排序或 DataLoader 顺序间接编码姿态
3. 图像归一化使用了全数据统计，带入 test 信息
4. 姿态网格本身过于规则，强 CNN 学到近似查表式插值
5. 渲染管线在图像中保留了与姿态强相关但真实观测中不稳定的线索
```

这些不是说结果一定无效，而是决定论文表述边界。

## 7. 论文主线决策树

完成任务 A/B/C 后，按以下决策。

### 情况 1：ResNet-fusion 优于 ResNet-only，且退化测试中 fusion 更稳

论文主线可保留“多模态融合”，但要升级表述：

```text
OCS 与图像的互补性不仅存在于弱 CNN，也存在于强图像 backbone；
OCS 主要改善高误差尾部、退化观测和跨条件鲁棒性，而不一定显著降低干净图像下的平均误差。
```

推荐贡献写法：

```text
We show that OCS provides complementary constraints to photometric images, particularly under degraded image quality or medium-information OCS settings.
```

### 情况 2：ResNet-only 始终最强，但对退化/跨几何明显敏感

论文主线需要改为：

```text
统一物理仿真框架 + 多观测模态基准评估 + 鲁棒性分析。
```

OCS 的定位：

```text
不是干净图像条件下的性能上限来源；
而是低成本、多几何、可解释、对图像退化有补充价值的光度观测量。
```

推荐贡献写法：

```text
High-capacity image models achieve the best accuracy under clean simulated images, whereas OCS remains valuable as a physically interpretable and low-cost modality under constrained or degraded observations.
```

### 情况 3：ResNet-only 始终最强，且退化/跨几何仍稳定

必须彻底重定位：

```text
论文主贡献不再是 fusion 性能提升；
而是证明统一 BRDF-driven 光度图像仿真可以产生高可辨识姿态线索，
同时给出 OCS、图像、融合的系统对照。
```

标题也应调整，减少 “joint inversion” 的绝对主导地位。

候选标题：

```text
A Unified BRDF-Driven Optical Simulation Benchmark for Space Object Attitude Inversion Using OCS and Photometric Images
```

或：

```text
BRDF-Driven Optical Cross Section and Photometric Image Modeling for Space Object Attitude Observability
```

### 情况 4：发现 ResNet 结果由隐性泄漏或渲染伪线索导致

必须修正数据或实验，不可继续使用当前 1.69° 作为正式结果。

处理原则：

```text
1. 记录问题来源
2. 修复数据/训练流程
3. 重跑 ResNet、TinyCNN、fusion 关键实验
4. 更新补充实验进度文件
```
