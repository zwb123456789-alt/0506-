## 4. 实验12c：Observation-style degradation stress test

建议新增脚本：

```text
论文改进/补充实验/代码/run_observation_style_degradation_12c.py
```

建议结果目录：

```text
论文改进/补充实验/结果/observation_style_degradation_12c/run_YYYYMMDD_HHMMSS/
```

必须沿用实验12b的基本协议：

- 数据：phase63 exact BRDF images，concat5 per_part OCS。
- Split：`split_coarse_to_fine(..., coarse_step=10.0)`，不得改成 random split。
- Target encoding：`[sin(yaw), cos(yaw), sin(pitch), cos(pitch)]`。
- 指标：great-circle angular error、mean、std、p50、p90、p95、worst、Hit@5、Hit@10。
- Seeds：0-4；若减少 seeds，必须说明资源原因。
- 所有 OCS 标准化统计只能由 train split 拟合。
- 若图像文件已是 `log1p`，应先 `expm1` 回到线性强度域，在强度域施加退化，再 `log1p` 回模型输入域。

退化包至少包含：

- clean。
- mild combined degradation。
- medium combined degradation。
- severe combined degradation。
- PSF/defocus blur only。
- photon noise only。
- read noise only。
- background offset / sparse star-like contamination only。
- clipping / saturation only。
- downsample / low-resolution only。

退化算子必须采用 `expm1 -> linear-domain degradation -> log1p`，不得直接复用旧脚本中的 log1p 域退化函数。必须输出 degradation_config 表，说明 photon/read/background/clipping 等参数相对 train split 强度统计的定义。

最低模型对照：

- ResNet image-only clean-trained。
- image-only same/simple augmentation。
- U1 simple-degradation-aware fusion。
- OCS-only MLP per_part_log。
- 若资源允许，新增 image-only obs-aug 和 U2 fusion obs-aug。

## 6. 实验12e：Centered-image / centroid-control experiment

目的：回应实验10中 centroid_x 与 yaw 相关 `r=0.66` 的潜在质疑。

建议新增脚本：

```text
论文改进/补充实验/代码/run_centered_control_12e.py
```

建议结果目录：

```text
论文改进/补充实验/结果/centered_control_12e/run_YYYYMMDD_HHMMSS/
```

最低设计：

- 对 phase63 图像按渲染质心或可复现图像质心进行居中。
- 质心计算必须在线性强度域进行，即对 log1p 图像先 `expm1` 后再计算 intensity-weighted centroid。
- 重训 ResNet image-only，建议至少 3 seeds；若执行 5 seeds 更佳。
- 保持原 split、target encoding、指标和训练协议。
- 输出居中前后对比表。

判读红线：

- 居中后仍强：可写 clean-image upper bound 不只是质心漂移。
- 居中后退化：写成 clean-image 性能部分依赖固定相机框定，进一步强化 upper-bound limitation；不得隐瞒。

## 7. 实验12f：Late-fusion beta sweep under image degradation

目的：补足推理端显式 fallback 路径对照，检验 late fusion 是否能通过权重调整比 naive feature fusion 更稳。

建议新增脚本：

```text
论文改进/补充实验/代码/run_late_fusion_beta_sweep_12f.py
```

建议结果目录：

```text
论文改进/补充实验/结果/late_fusion_beta_sweep_12f/run_YYYYMMDD_HHMMSS/
```

最低设计：

- 尽量不重训，复用 ResNet image-only 预测与 OCS MLP per_part_log 预测。
- 先检查权重或 per-sample predictions 是否存在；若不存在，按既有协议重训/重推理并保存 per-sample predictions，不得假设 12b 结果目录已有模型权重。
- 对 clean / noise 0.01 / noise 0.10 / brightness 0.50 / brightness 1.50 做 beta sweep。
- beta grid 至少包含 `0, 0.1, ..., 1.0`，其中 beta 定义必须清楚。
- beta 方向锁定为 image 权重：`pred_blend = beta * pred_image + (1 - beta) * pred_ocs`；`beta=1` 为 image-only，`beta=0` 为 OCS-only。
- 与实验11 naive feature fusion 和实验12 U1 结果并列表达。

判读红线：

- late fusion 若表现好，只能写成 explicit weighting can provide an inference-time robustness path。
- 不得写成 U1 已自动 fallback。
- late fusion 若仍崩，也必须诚实报告。
