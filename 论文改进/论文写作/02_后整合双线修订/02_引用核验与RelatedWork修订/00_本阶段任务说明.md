# 02 引用核验与 Related Work 修订：本阶段任务说明

> 当前阶段目标：核验 v0.1 中全部引用占位和 Related Work / Table 1 字段，形成可用于 v0.2 的真实引用清单和修订建议。

## 1. 输入文件

必须基于以下文件工作：

```text
论文写作/00_总控流程.md
论文写作/02_后整合双线修订/00_后整合双线总览.md
论文写作/02_后整合双线修订/阶段整合输出/01_作者确认与数值审计_整合清单.md
论文写作/01_初稿生成与整合/最终整合/最终整合版_v0.1_基于GPT吸收Claude.md
论文改进/20260529_论文写作完整规划.md
论文项目总览 copy.md
论文改进/20260529_补充实验进度.md
```

## 2. 本阶段必须处理

1. 全部 `[CITATION: ...]`。
2. 全部 `[to verify]`。
3. Table 1 每一行每一列的事实性字段。
4. Related Work 四小节中每个“已有研究做了什么”的判断。
5. 不可证实或不够相关的文献替换建议。

## 3. 输出目标

阶段最终整合输出：

```text
阶段整合输出/02_引用核验与RelatedWork修订_整合清单.md
```

该清单应包括：

- 已核验引用表。
- 未能核验或建议删除的引用表。
- Table 1 修订版字段建议。
- Related Work 段落级修订建议。
- 下一步可进入 v0.2 的安全替换项。

## 4. 禁止事项

0. 禁止编造引用、DOI、期刊、页码、作者或文献内容。
1. 未查证原文或可靠书目信息前，不得把 `[to verify]` 删除。
2. 不得把检索关键词当作引用。
3. 不得为了保留 Table 1 而猜测文献字段。
4. 不做全文润色，不重写 Results / Method。
