## 2. 本阶段目标

1. 列出投稿前必须准备的材料类型和依赖项。
2. 梳理 Data Availability、Code Availability、Author Contributions、Conflict of Interest、Funding、Acknowledgements 的作者确认问题。
3. 规划 Supplementary 文件结构，承接完整图表、超参数、逐 seed、完整噪声表和扩展 Table 1。
4. 草拟 Cover Letter 的安全要点，不夸大贡献，不声称真实验证。
5. 形成进入 v0.2 主稿修订前的最终作者提问清单。

## 3. 必须覆盖的投稿组件

| 组件 | 输出要求 |
|---|---|
| Data Availability | 给出可选模板和必须问作者的问题，不代填事实 |
| Code Availability | 区分 scripts、trained models、rendering code、data-processing code 的共享状态 |
| Author Contributions | 只给 CRediT 角色框架，不编造作者姓名和贡献 |
| Conflict of Interest | 给出待确认项，不代写最终声明 |
| Funding / Acknowledgements | 提醒作者提供项目号、资助机构和致谢对象 |
| Supplementary | 规划文件目录、图表清单、与主文对应关系 |
| Cover Letter | 提供保守要点和禁用表述，不绑定具体期刊格式 |
| Submission checklist | 列出投稿前检查项：引用、图表、表格、占位、作者确认、伦理/数据声明 |

## 4. 输出目标

GPT / Claude 输出后，由 Codex 整合为：

```text
阶段整合输出/06_投稿材料_整合清单.md
```

该清单至少包括：

- 投稿材料组件总表。
- Data / Code / Author / COI / Funding 的作者确认问题。
- Supplementary 目录和图表分配建议。
- Cover Letter 安全要点。
- 投稿前 checklist。
- 进入 v0.2 主稿修订前必须向作者统一提问的问题。

## 5. 禁止事项

0. 禁止编造作者、单位、贡献、资助、利益冲突、数据共享状态或期刊要求。
1. 不生成最终投稿文件。
2. 不把候选期刊当作已选期刊。
3. 不声称已有 real optical telescope validation。
4. 不把 clean rendered images 写成 field performance。
5. 不把 controlled stress tests 写成完整 observation-chain model。
6. 不把 `all_raw` 写成 operational feature。
7. 不把 fusion 写成 universal superiority。
8. 不删除第 5 阶段最低通过线中的阻塞项。
