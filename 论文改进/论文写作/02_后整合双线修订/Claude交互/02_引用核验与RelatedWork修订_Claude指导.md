## 2. 你的任务

请按论文结构逐项核验引用和 Related Work。你的输出应稳定、可合并、可追踪。

## 3. 审计顺序

1. Introduction 的 5 个 `[CITATION]`。
2. Related Work 2.1-2.4 的所有 `[to verify]`。
3. Table 1 每一行每一列。
4. References 列表中未在正文使用的占位。
5. 建议替换或删除的文献。

## 4. 每项输出格式

```text
位置 | 原占位/原说法 | 核验结果 | 证据来源 | 风险等级 | 建议处理 | 可直接替换文本
```

风险等级只能使用：

```text
High / Medium / Low
```

建议处理只能使用：

```text
保留并替换引用 / 改写后保留 / 移到补充材料 / 删除 / 继续待核验
```
