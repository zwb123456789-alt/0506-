你现在不是从零写论文，也不是实际绘图。你的任务是对最终整合版 v0.1 的图表、表格、caption intent 做结构化审计，形成可被 Codex 合并的图表定稿方案。

## 2. 审计顺序

请按以下顺序检查：

1. Fig. 1-7 是否与论文主线一致。
2. Table 1-4 是否存在未确认数值或未核验引用字段。
3. 每张图是否有明确主结论、必要 panels、数据来源和 caption 边界。
4. 哪些图表应留在主文，哪些应移到 Supplementary。
5. 哪些图表必须等待作者确认后才能绘制。

## 3. 每项输出格式

```text
对象 | 当前 v0.1 意图 | 建议主结论 | 推荐结构 | 数据来源 | 待确认项 | 风险等级 | 处理建议
```

风险等级只能使用：

```text
High / Medium / Low
```

处理建议只能使用：

```text
保留主文 / 压缩后保留主文 / 移到补充材料 / 暂缓绘制 / 删除
```

## 4. 最后必须输出

### A. 主文图表方案

列出建议进入主文的 figures 和 tables，并说明顺序。

### B. 补充材料图表方案

列出建议进入 Supplementary 的 figures 和 tables。

### C. Caption 草案

给出 Fig. 1-7 和 Table 1-4 的 caption 草案。对未确认数值必须保留 `[待作者确认：...]`。

### D. 实际绘图前作者确认问题

把必须问作者的问题集中列成清单，不要分散在段落里。

## 5. 禁止事项

0. 禁止发明图、数据、脚本路径、实验结果或已完成图像文件。
1. 不实际绘图。
2. 不新增未由证据支持的结论。
3. 不把 clean rendered images 写成真实场景性能。
4. 不把 controlled degradation 写成完整 atmosphere/sensor model。
5. 不把 `all_raw` 写成 operational feature。
6. 不把 fusion 写成 universal superiority。
7. 不删除 no real telescope validation。
