## 2. 本阶段目标

1. 以 SCI 二区/一区边缘通用审稿标准模拟审稿，不绑定某一具体期刊格式。
2. 识别方法、实验、数值、引用、图表、语言和边界表述中的高风险问题。
3. 区分必须在 v0.2 前处理的问题、可在 Supplementary 处理的问题和可在 response 中解释的问题。
4. 形成返修优先级和作者确认问题清单。
5. 为后续 v0.2 主稿修订提供执行顺序，而不是直接生成 v0.2。

## 3. 必须覆盖的审稿维度

| 维度 | 检查重点 |
|---|---|
| Scientific framing | 研究问题是否清楚；controlled benchmark 定位是否足够明确 |
| Method credibility | BRDF、self-occlusion、feature definitions、split、metrics 是否可复现 |
| Experimental evidence | clean-image upper-bound、image degradation、OCS-only、fusion、ablation 是否支撑主张 |
| Claim boundaries | 是否误写 real validation、operational robustness、universal fusion superiority |
| Citation and Related Work | 已核验引用是否落地；Table 1 是否过度审计或字段不稳 |
| Figures and tables | 主文图表是否过多；caption 是否保留边界；Supplementary 分配是否合理 |
| Writing and style | 是否冗余、过度防御、术语不一致 |
| Author-confirmation risks | 是否仍有不能由模型代答的事实问题 |

## 4. 输出目标

GPT / Claude 输出后，由 Codex 整合为：

```text
阶段整合输出/05_模拟审稿与返修_整合清单.md
```

该清单至少包括：

- 模拟审稿总体判断。
- Major comments 和 Minor comments。
- 每条审稿意见的风险等级、证据位置、建议返修动作。
- 需要作者确认的问题。
- v0.2 修订优先级。
- 不应通过过度承诺或新增未经验证事实来回应的意见。

## 5. 禁止事项

0. 禁止新增实验结果、引用、图表、方法细节或期刊要求。
1. 不重写全文。
2. 不把候选审稿意见写成真实审稿意见。
3. 不把待确认数值、作者事实或未核实引用写成事实。
4. 不建议通过夸大贡献来回应审稿风险。
5. 不把 clean rendered images 写成 field performance。
6. 不把 controlled stress tests 写成完整 observation-chain model。
7. 不把 `all_raw` 写成 operational feature。
8. 不把 fusion 写成 universal superiority。
9. 不删除 no real optical telescope validation。
