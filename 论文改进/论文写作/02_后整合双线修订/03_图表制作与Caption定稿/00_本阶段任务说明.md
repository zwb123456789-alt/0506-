## 4. Caption 红线

所有图表 caption 必须保留以下边界：

1. clean rendered images 是 idealized upper-bound / controlled benchmark，不是真实场景性能。
2. Gaussian image noise、brightness scaling、OCS noise 是 controlled stress tests，不是完整 atmosphere/sensor model。
3. `all_raw` 是 semi-oracle / diagnostic，不是 operational OCS feature。
4. fusion 是 conditional complementarity，不是 universal superiority。
5. `r = 0.003` 是 TinyCNN/OCS diagnostic，不是 ResNet-pair evidence。
6. Present work 没有 real optical telescope validation。
