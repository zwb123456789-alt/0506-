# 01 作者确认与数值审计：本阶段任务说明

> 当前阶段目标：把最终整合版 v0.1 中所有未确认事实、所有数值、所有表格数值和所有审稿风险项列清楚，为 v0.2 修订做准备。

## 1. 输入文件

必须基于以下文件工作：

```text
论文写作\00_总控流程.md
论文写作\02_后整合双线修订\00_后整合双线总览.md
论文写作\01_初稿生成与整合\最终整合\最终整合版_v0.1_基于GPT吸收Claude.md
论文改进\20260529_论文写作完整规划.md
论文项目总览 copy.md
论文改进\20260529_补充实验进度.md
```

硬性约束：

- 未读主稿、全局背景和总览前，不得直接改写论文正文，只能列检查框架、问题清单或要求补充材料。
- 禁止编造实验结果、引用文献、方法细节、模型配置、期刊要求或任何作者尚未确认的事实。
- GPT/Claude 的输出必须交给 Codex 审阅整合后，才能进入主稿版本线；任何交互端不得直接覆盖主稿。

必要时参考：

```text
论文写作\01_初稿生成与整合\对比评分\最终初稿_GPT_vs_Claude_评分决策.md
论文写作\01_初稿生成与整合\GPT交互\GPT writing\07_GPT输出_全文整合初稿.md
论文写作\01_初稿生成与整合\Claude交互\claude writing\07_Step7_Claude输出_全文整合初稿.md
```

## 2. 输出目标

本阶段最终应形成：

```text
阶段整合输出\01_作者确认与数值审计_整合清单.md
```

该清单用于指导 v0.2 修订。

## 3. 必须审计的内容

1. 所有 `[需要作者确认：...]`。
2. 所有 `[CITATION: ...]`。
3. 所有 `[to verify]`。
4. 所有数值，包括 mean error、Hit@5、Hit@10、P90、worst-case、noise level、phase range、grid size、sample count、material parameters。
5. 所有表格数值和表格解释。
6. 所有可能被审稿人质疑为 field-performance claim 的句子。
7. 所有未确认方法细节，如 Euler convention、target encoding、model architecture、angular error formula。
8. 所有应降级为 Supplementary 或 Future Work 的内容。

## 4. 输出字段

每个审计项应包含：

| 字段 | 说明 |
|---|---|
| ID | 编号，如 A001、N001、C001 |
| 位置 | 章节或表格位置 |
| 原文/数值 | 摘录关键内容 |
| 类型 | 作者确认 / 数值核验 / 引用核验 / 过度表述 / 方法细节 |
| 风险等级 | High / Medium / Low |
| 当前状态 | 已确认 / 待确认 / 建议删除 / 建议降级 |
| 需要作者提供 | 具体需要什么证据或回答 |
| 建议处理 | 保留 / 补证 / 改写 / 移到补充 / 删除 |

## 5. 本阶段不做

0. 禁止编造实验结果、引用文献、方法细节、模型配置、期刊要求或任何作者尚未确认的事实。
1. 不做全文润色。
2. 不画图。
3. 不重写 Related Work。
4. 不做最终投稿格式。
5. 不新增实验设计，除非只是标记“可选补充实验”。
