## 1. 总体结论

GPT 与 Claude 判断一致：

- v0.1 没有明显把 clean rendered images 写成 field performance。
- `all_raw` 基本保持为 semi-oracle / diagnostic，没有被写成 operational feature。
- fusion 基本保持 conditional complementarity，没有写成 universal superiority。
- `r = 0.003` 已限定为 TinyCNN/OCS diagnostic，没有被写成 ResNet-pair 证据。
- 最大投稿风险集中在可复现方法细节、引用核验、表格缺项、材料参数来源、模型训练细节和补充实验进入正文的取舍。

## 5. 表述红线保留要求

v0.2 修订和后续语言压缩时必须保留：

- clean rendered images = idealized upper-bound / controlled benchmark，不是真实场景性能。
- Gaussian noise / brightness scaling = controlled stress tests，不是完整 atmosphere/sensor model。
- OCS = independent of image-pixel degradation in this benchmark，不是 universally robust。
- Fusion = conditional complementarity，不是 universal superiority。
- `all_raw` = semi-oracle / diagnostic，不是 operational feature。
- `r = 0.003` = TinyCNN/OCS diagnostic，不是 ResNet-pair evidence。
- no real optical telescope validation 必须在 Abstract、Method/Discussion 或 Limitations 中显性保留。
