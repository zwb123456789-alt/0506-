## 1. 总体结论

## 3. 术语统一表

| 概念 | 推荐写法 | 禁止或慎用写法 | 说明 |
|---|---|---|---|
| OCS | `optical cross section (OCS)` 首次出现，后文 `OCS` | 多次混用 `light-curve-like OCS` | 保持全文章法一致 |
| 本文图像 | `clean rendered photometric images` | `real images`, `field images` | 强调渲染和 clean 条件 |
| clean 图像结果 | `clean-image upper-bound condition` | `field performance`, `real image performance` | Abstract、Results、Discussion、Conclusion 必须统一 |
| 研究定位 | `controlled simulation benchmark` / `controlled inversion benchmark` | `validation benchmark` | 避免暗示真实验证 |
| 物理一致性 | `under shared forward-model assumptions` | `physically validated` | 可写 BRDF/visibility/geometry shared assumptions |
| 图像退化 | `controlled image-degradation stress tests` | `atmosphere/sensor simulation` | Gaussian noise 与 brightness scaling 只能写 stress test |
| OCS 噪声 | `feature-level OCS-noise perturbation` | `real OCS measurement noise model` | 当前为受控 feature perturbation |
| `all_raw` | `semi-oracle diagnostic representation` | `operational OCS feature`, `best OCS feature` | 表格、Results、Discussion 中必须带限定 |
| practical OCS | `practical component-level OCS feature` | `real measured OCS` | 当前 OCS 仍为仿真输出 |
| fusion | `OCS-image fusion`, `conditional complementarity` | `fusion superiority`, `universally best` | 只写条件性互补 |
| 姿态任务 | `yaw-pitch attitude inversion under fixed roll` | `full 3-DOF pose recovery`, `6-DOF pose` | 全文任务边界 |
| forward model checks | `sanity checks`, `numerical consistency checks` | `real optical validation` | 避免 validation 误读 |

## 4. 风险表述与安全替换

| 风险表述 | 风险 | 安全替换 |
|---|---|---|
| `state-of-the-art`, `first`, `novel` | 当前证据未支撑优先权或 SOTA | 删除，或改为 `controlled benchmark` |
| `robust attitude inversion` 单独出现在标题或结论 | 容易被读成真实场景鲁棒性 | `controlled benchmark for ... attitude inversion` |
| `physically consistent` | 可能暗示真实材料/观测验证 | `consistent under shared BRDF, visibility and geometry assumptions` |
| `validated` / `validation` | 容易与真实光学验证混淆 | `evaluated`, `checked`, `sanity checks` |
| `operational` | 当前没有真实观测验证 | 仅用于否定式边界：`before operational field-performance claims can be made` |
| `OCS is robust to image degradation` | 容易泛化到真实 OCS 观测 | `OCS is independent of image-pixel degradation in this benchmark` |
| `fusion is best` | 过度泛化 | `fusion reduces selected tail errors under tested conditions` |
| `fusion gain increases as OCS quality degrades` | 当前 image branch remains clean | `when OCS features are perturbed while the image branch remains clean` |
| `all_raw achieves best OCS performance` | 容易变成可操作特征 | `the semi-oracle all_raw representation indicates information potential` |
| `r = 0.003 proves modality independence` | 该值来自 TinyCNN/OCS diagnostic | `a TinyCNN/OCS diagnostic suggests weak error correlation in that setting` |

## 7. v0.2 实施优先级

1. 先完成作者确认问题统一提问与回复归档，不在待确认状态下写死 Euler、target encoding、angular error、TinyCNN、kNN、OCS-noise 等事实。
2. 清理引用和 Related Work：按第 2/2b 阶段修正 Yang、Lu、Wang、Burton、Kumar、Dickinson、Yi 等引用，不保留旧 `[to verify]`。
3. 压缩 Abstract 和 Introduction contribution paragraph。
4. 将 Table 1 降为 conservative scope comparison，无法全文核实的字段不硬填。
5. 压缩 Results 4.2-4.5，把解释性重复转移到 Discussion 或 Supplementary。
6. 统一 `all_raw`、clean-image upper-bound、controlled stress tests、conditional fusion 等术语。
7. 将 TinyCNN/OCS diagnostic 和 `r = 0.003` 从主结果中降级，或保留一句带限定的补充诊断。
8. 合并 Discussion 中重复的 clean-image/fusion/robustness 解释。
9. 保留但压缩 Limitations，确保 no real telescope validation 和 fixed-roll 边界至少在 Abstract/Limitations/Conclusion 中出现。
10. v0.2 完成后再进入实际图表绘制、投稿格式和补充材料整理。
