## 1. 总体判断

GPT 与 Claude 均认为当前 v0.1 的核心主线可以成立，但不适合直接投稿。主要问题不是证据链完全缺失，而是仍具有明显“未完成稿”特征：方法确认项未清零、引用占位未清理、Table 1/2/4 存在未核实字段或缺值、图表和 Supplementary 分配未最终确定、投稿材料占位仍未填写。

Codex 整合判断：

1. 稿件应按“major revision before submission”处理，但当前不要求新增实验作为默认路径。
2. v0.2 前必须先处理作者确认项、引用占位、方法可复现性和表格缺值。
3. 不得用过度承诺来回应审稿风险；必须继续保持 controlled benchmark、clean-image upper-bound、no real telescope validation 和 conditional fusion 的边界。
4. GPT 输出作为本阶段主要依据，Claude 输出补充 reviewer 分类、物理建模复现性和 protected boundaries。

## 7. 不应采用的返修方式

1. 不为回应“缺少真实验证”而声称已有 real optical telescope validation。
2. 不把 clean rendered images 或 phase63 clean images 写成 field performance、real image performance 或 operational performance。
3. 不把 Gaussian image noise、brightness scaling、OCS-noise perturbation 写成完整 atmosphere/sensor/telescope observation-chain model。
4. 不把 `all_raw` 写成 operational OCS feature。
5. 不把 fusion 写成 universally superior、best in all settings 或 guaranteed robust。
6. 不把 `r = 0.003` 写成 ResNet-pair evidence。
7. 不新增未完成实验，例如 ResNet-fusion image-degradation、cross-phase 泛化、真实望远镜数据或完整 3-DOF 数据集。
8. 不硬填引用、Table 1 技术字段、BRDF/self-occlusion 细节。
9. 不删除 no real telescope validation、fixed roll、phase63、nominal materials、controlled stress tests 等边界。
10. 不在作者未确认前写死 Euler convention、target encoding、angular error formula、TinyCNN version、OCS-noise table values 或投稿声明。

## 8. v0.2 最低通过线

进入 v0.2 主稿修订前，至少应满足：

1. 全部影响方法和数值的作者确认项有明确处理方案。
2. 全部 `[CITATION]`、`[to verify]` 已删除或替换为已核验引用。
3. Method 包含可复现的姿态定义、target encoding、metrics、split、features 和模型训练要点。
4. Table 1、Table 2、Table 4 不再含无说明缺值或未核实字段。
5. Abstract、Results、Discussion、Conclusion 明确区分 clean-image upper-bound、controlled stress tests 和 no real telescope validation。
6. `all_raw`、`r = 0.003`、fusion、OCS-noise 的边界在表格、图注和正文中一致。
7. Supplementary 计划能承接完整噪声、ablation、逐 seed、超参数和扩展 Table 1。
