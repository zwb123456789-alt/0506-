# 投稿定稿目录说明

> 最后更新：2026-06-01  
> 用途：本目录用于存放最终投稿前的干净材料。当前暂未进入投稿定稿阶段。

## 1. 本目录职责

本目录只放投稿前可交付材料，不放 GPT/Claude 过程输出。

建议用途：

```text
manuscript_md/          # 干净 Markdown 主稿
figures/                # 最终图件
tables/                 # 最终表格
references/             # bib / ris / 文献核验表
cover_letter/           # cover letter 和 highlights
submission_checklist/   # 投稿检查表
```

## 2. 进入条件

只有当以下任务完成后，才进入本目录：

1. 作者确认与数值审计完成。
2. 引用核验完成。
3. 图表与 caption 定稿。
4. 全文压缩与期刊风格调整完成。
5. 至少一轮模拟审稿与返修完成。
