# 初稿生成与整合归档说明

> 最后更新：2026-06-01  
> 用途：本目录归档 Step 1-7 的 GPT/Claude 双线初稿生成历史、Codex 单边审阅、最终对比评分和最终整合版 v0.1。

## 1. 本目录职责

本目录是历史归档区，不是当前工作区。

包含：

- `GPT交互/`：GPT Step 1-7 提示词、输出和 GPT 写作总览。
- `Claude交互/`：Claude Step 1-7 指导文件、输出和 Claude 总览。
- `对比评分/`：Codex 单边审阅、阶段审阅、最终 GPT vs Claude 评分决策。
- `最终整合/`：最终整合版 v0.1 和版本日志。

当前后续工作请进入：

```text
论文写作\02_后整合双线修订\
```

投稿定稿材料后续放入：

```text
论文写作\03_投稿定稿\
```

## 2. 当前最重要文件

```text
最终整合\最终整合版_v0.1_基于GPT吸收Claude.md
最终整合\00_版本日志.md

```

## 3. 使用规则

1. 新会话恢复时，不要从本目录重新生成初稿。
2. 只有需要追溯 GPT/Claude 原始表达、单边审阅意见或最终评分决策时，才读取本目录文件。
3. v0.1 之后的所有任务应通过 `02_后整合双线修订/` 的阶段提示词进行。
4. GPT/Claude 的新输出不要再放入本目录。
