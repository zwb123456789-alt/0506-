## 一、应用方向

新定位下应用落点不是"姿态反演系统"，而是两类不依赖真机即成立的产出。叙事核心：从 system claim（"我们能反演"，立不住）换成 decision-support claim（"我们告诉你什么时候值得观测、什么时候该信结果"，立得住）。

### 1.1 强落点：最优观测几何指南（observation planning）

唯一不依赖任何反演主张就能用的产出。地基光学探测中"什么时候去看一个已知型号目标才有姿态信息"是真问题。

核心洞察（建议放大为应用第一卖点）：

```text
最亮 != 信息量最高。
最亮往往是镜面闪烁主导，此时亮度对姿态极度敏感但多解（信息塌缩），
反而是次优观测窗。
```

产出形态：相位角—太阳方向 vs 姿态可分性地图，直接告诉排程系统该避开哪些窗口、优先选哪些窗口。

### 1.2 中落点：置信门控（confidence gating）

"OCS 与图像后验冲突时拒绝输出姿态"——可接到任意下游 pose 系统前面的安全阀。应用价值是降低高风险误判，而非提高平均精度。诚实边界：现阶段是 model-known 受控条件下验证的机制，不是真机部署能力。

### 1.3 弱落点（只进 Future Work）

传感器选型 / 观测调度的先验输入。点到为止，不展开实现。

## 二、论文方向

### 2.1 核心判断：够 1 篇扎实的，不要硬拆

信息机理 + 可观测性地图 + 一致性置信 + 最优观测几何，单独任何一个都偏薄，合起来才是一篇有分量的"统一前向模型下的 OCS-图像信息学研究"。拆开会互相抽血。

### 2.2 建议骨架

```text
1. 统一同源前向模型        解决 OCS/图像采样口径问题，立 framing
2. 可观测性与混淆地图      OCS-only / image-only 各自在姿态空间哪里有效
3. 互补性与 fusion 机制诊断 真互补 vs 单模态主导 vs 退化继承（旧实验11/12b 转正）
4. 一致性即置信            consistency-as-confidence，最强 novelty
5. mismatch 边界 + 最优观测几何  护城河 + 应用尾巴
```

### 2.3 投稿方向重判

新定位偏信息/可观测性，不再纯航天工程，投稿排序相应调整：

| 优先级 | 方向 | 理由 |
|---|---|---|
| 第一选择 | 遥感/光学类（IEEE TGRS、Remote Sensing、Optics Express 视角）或 Sensors 类 | 吃"信息量/可观测性/多模态一致性"这套话语 |
| 第二选择 | 航天档（CJA / AST / ASR） | 保留，但 intro 工程动机（在轨服务、碎片监测）要写足 |
| 不建议 | IEEE TAES / JGCD | 期待 estimation system + 高保真验证，受控仿真信息学研究在此偏轻 |

## 三、价值意义

分三层说，答辩与 intro 都好用。关键是顺序不能颠倒——先科学后工程，否则一上来谈工程会被追着问真机。

### 3.1 科学价值（主，论文立身）

首次在同源、可审计的物理前向模型下，把 OCS 和图像当作同一光度响应的两种读出，定量回答"各自携带多少姿态信息、何处互补、一致性如何指示可信度"。这是回答 *what can be known*（认识论问题），不是 *how well our system performs*（工程问题）。

### 3.2 工程价值（辅，应用尾巴）

观测几何指南 + 置信门控，对探测排程和误判规避有参考价值，且不依赖真机部署即成立。

### 3.3 方法学价值（备注）

"多模态信息量 + 一致性评估范式"可迁移到其它双模态状态估计。Discussion 点到为止，不过度声称。

### 3.4 答辩话术

被问"意义"时，按此顺序：先说科学价值（做的是 information study）→ 再补工程价值（顺带产出观测指南）→ 最后用 model-known 真实场景（己方失效卫星、公开型号、在轨服务抵近、碎片监测）锚定这不是纯学术玩具。

## 四、后续方法

新定位最大工作量和最大风险都在"信息量/可观测性怎么量化"。以下是有理论根基、不做虚的方法武器库，按推荐度排。

### 4.1 可观测性量化——双轨制

**连续姿态：Fisher 信息矩阵（FIM）+ Cramér-Rao 下界。**
对前向模型求姿态梯度，FIM 行列式 / 最小特征值即"该姿态在此观测几何下可不可估、各轴谁强谁弱"的硬指标。估计论正统语言，审稿人认。

**离散姿态：posterior entropy / top-k confusion。**
网格化后做混淆地图，直观、可视化强。

两轨互相印证：FIM 给理论，entropy 给可视化。

### 4.2 最优观测几何——D-optimality

FIM 行列式最大即 D-optimality。一句话把热图升格为最优实验设计问题：

```text
最优观测窗 = 最大化姿态 FIM 的观测几何。
```

这是让"最优观测几何"这条线有理论骨头的关键。

### 4.3 一致性即置信——校准 + 保形预测

- 一致性度量：OCS 与图像后验的 JS divergence / top-k overlap / margin。
- 置信验证：ECE + 可靠性图（reliability diagram），证明"一致性↑→错误率↓"。
- 进阶（强烈建议）：conformal prediction，把"该不该信"做成有覆盖率保证的拒识机制，比纯 ECE 更有理论分量，且契合置信门控应用。

### 4.4 fusion 机制诊断——沿用并升格旧手段

branch masking、OCS noise monotonicity（实验12b 做法）保留；再加 modality attribution（积分梯度 / Shapley）量化每个模态贡献，把"co-utilization"从定性说成定量。

### 4.5 方法选择总建议

三件套是新定位从"画热图"升级到"有理论的信息学研究"的关键：

```text
FIM / CRLB        ← 可观测性
D-optimality      ← 最优观测几何
conformal / ECE   ← 置信
```

若三选一最先做：先做 FIM 可观测性。它同时喂养"可观测性地图"和"最优观测几何"两条主线，杠杆最高。
