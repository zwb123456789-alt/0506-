# v0.4 研究方向重定位：问题边界、意义修正与后续路线

生成时间：2026-06-08

本文记录 v0.4 阶段对 OCS + 图像联合仿真与姿态反演项目的根本性反思。本文不是代码实施规范，也不是论文正文，而是后续论文重写、实验设计和项目答辩时必须遵守的研究定位文件。

---

## 一、触发本次重定位的核心问题

v0.4 原本从旧 v0.3 封存问题出发：旧 OCS 来自模块 A face-level / face-center 扫描，图像来自 Blender pixel-level geometry/pass，二者采样口径不统一。因此 v0.4 计划以 Blender-derived OCS 作为 canonical OCS，重建统一前向模型。

但进一步讨论后发现，项目不仅存在采样口径问题，还存在更根本的应用边界问题：

1. 非合作目标如果几何未知，就没有 STL 或 CAD 模型，无法生成目标专属 OCS 查找表。
2. 即使有 STL，仿真 OCS 与真实 OCS 也很难绝对对应，因为材料/BRDF、真实结构、在轨状态、观测链和定标都可能偏离名义模型。
3. 因此，不能继续把项目主张写成“面向真实未知非合作目标的直接姿态反演系统”。

这不意味着项目没有意义，而是意味着项目意义必须从“直接部署式反演”转向“理想化条件下的信息机理、可观测性与置信度研究”。

---

## 二、必须放弃或降级的强主张

### 2.1 不能再主张：任意未知非合作目标姿态反演

如果“非合作目标”被理解为：

```text
目标不配合 + 几何未知 + 材料未知 + 观测链未知
```

那么当前 OCS lookup / OCS-image fusion 路线不能直接成立。

原因是 OCS 前向表本质依赖：

```text
目标几何 + 材料/BRDF + 太阳/观测方向 + 姿态 -> OCS signature
```

没有几何模型时，目标姿态、几何形状、尺度、材料反射特性和观测链增益会共同影响亮度与图像。单独从 OCS 或图像中反演姿态是欠定问题。

因此，本文后续不得把适用对象写成“任意未知非合作目标”。

### 2.2 不能再主张：仿真 OCS 与真实 OCS 可直接绝对匹配

即使存在 STL，仿真 OCS 与真实 OCS 的绝对值也通常不能直接对应。主要原因包括：

- 材料/BRDF 参数未知：roughness、F0、albedo、diffuse/specular ratio 等。
- 真实几何与名义 STL 不一致：制造公差、展开状态误差、在轨变形、局部损伤。
- 观测链未知：大气透过率、探测器非线性、曝光、背景、点扩散函数、绝对定标误差。
- 姿态/轨道/太阳观测几何本身也可能有误差。

因此，不应写：

```text
真实观测 OCS 可以直接与仿真 OCS 查找表匹配，从而得到可靠姿态。
```

最多只能在明确假设下写：

```text
在已知或近似已知几何、名义材料参数、受控或可校准观测链条件下，
仿真 OCS signature 可用于分析姿态信息、混淆性和跨模态一致性。
```

### 2.3 不能再主张：真实图像 + 仿真 OCS 可直接部署反演

OCS-image fusion 的实验结果不能被解释为真实系统已经可部署。fusion 在 v0.4 中应被解释为：

```text
同一统一前向模型下，低维积分光度读出与空间图像读出的互补机制。
```

而不是：

```text
真实图像和仿真 OCS 可以直接融合并完成真实卫星姿态反演。
```

## 三、仍然成立的研究意义

### 3.1 核心价值重写

本项目的核心价值应重写为：

```text
在统一、可审计的物理前向模型下，定量回答 OCS 与图像分别携带哪些姿态相关信息，
在哪些观测几何下互补，在哪些条件下失效，以及二者一致性如何用于置信度评估。
```

这比“造一个真实卫星姿态反演系统”更准确，也更可防守。

### 3.2 适用对象重新定义

后续论文中，“非合作目标”必须谨慎定义。推荐表述为：

```text
non-cooperative but model-known target
```

即：

- 目标不通信。
- 目标不主动配合。
- 没有人工标志器或合作信标。
- 但目标几何模型、候选几何模型或近似结构模型已知。

可接受对象包括：

- 己方失效卫星。
- 已知型号或结构公开的航天器。
- 有设计资料或历史模型的目标。
- 实验室缩比模型。
- 由其他传感器或先验重建得到近似几何的目标。

不可接受对象包括：

- 完全未知几何、未知材料、无先验类别的任意空间目标。

### 3.3 反演实验的角色降级

姿态反演实验仍可保留，但其角色必须从“应用终点”降级为“信息量验证工具”。

也就是说，反演误差、Hit@5、posterior entropy、top-k ambiguity、confusion map 等指标用于回答：

```text
在给定前向模型和观测条件下，该姿态是否可区分？
OCS 和图像分别贡献了多少信息？
fusion 是否真正利用了互补信息？
```

而不是用于证明：

```text
真实未知卫星已经可以被可靠反演。
```

## 四、推荐的新论文主线

### 4.1 新主线一句话

推荐论文主线为：

```text
OCS and image are two readouts of the same physically consistent forward model:
OCS is an integrated photometric readout, while image is a spatially resolved readout.
The study investigates their attitude information content, observability, complementarity,
and confidence consistency under idealized but controlled conditions.
```

中文表述：

```text
OCS 与图像是同一物理一致前向模型下的两种读出方式：
OCS 是积分光度读出，图像是空间分布读出。
本文研究二者在理想化但受控条件下的姿态信息量、可观测性、互补性与置信度一致性。
```

### 4.2 建议标题方向

可选标题方向：

1. Unified Forward Modeling of OCS and Optical Images for Spacecraft Attitude Information Analysis
2. Assessing Attitude Observability from Integrated and Spatial Photometric Readouts
3. OCS-Image Consistency for Confidence-Aware Attitude Inference under a Unified Synthetic Forward Model
4. What Do OCS and Images Tell Us About Spacecraft Attitude? A Physically Consistent Simulation Study

### 4.3 推荐贡献点

后续论文贡献建议写为：

1. 建立一个 OCS 与图像同源的统一物理前向模型，避免旧流程中 OCS 与图像采样口径不一致。
2. 将 OCS 和图像定义为同一 clean photometric response 的两种读出：integrated readout 与 spatially resolved readout。
3. 在姿态空间和观测几何空间中分析 OCS/image 的可观测性、混淆性与信息量分布。
4. 研究 OCS-image fusion 的互补机制，区分真正互补、单模态主导和退化继承。
5. 构建 OCS-image consistency / confidence 指标，用于识别高置信候选、低置信区域和跨模态冲突。
6. 通过材料扰动、几何扰动和观测链退化实验，明确该方法在何种假设下有效、何种条件下失效。

## 五、后续实验路线调整

### 5.1 从“姿态反演误差表”转向“信息量与可观测性地图”

建议新增或强化以下实验：

| 实验方向 | 目的 | 可能指标 |
|---|---|---|
| 姿态混淆图 | 找出哪些姿态天然不可区分 | pairwise distance, nearest-neighbor ambiguity, top-k confusion |
| 观测几何信息量地图 | 找出最佳 sun/det/phase 观测角度 | Fisher-like score, signature gradient, entropy reduction |
| OCS-only 可观测性 | 判断积分光度在何处有效 | OCS distance map, posterior entropy |
| image-only 可观测性 | 判断空间图像在何处有效 | image embedding distance, CNN posterior entropy |
| OCS-image 互补性 | 判断二者是否提供不同信息 | error decorrelation, top-k overlap, disagreement map |
| fusion 机制诊断 | 判断 fusion 是否真实利用 OCS | branch masking, OCS noise monotonicity, modality attribution |
| confidence consistency | 判断一致性是否对应更低错误率 | JS divergence, top-k agreement, margin, ECE |

### 5.2 置信度指标建议

可定义以下指标：

```text
H_img        = image posterior entropy
H_ocs        = OCS posterior entropy
H_fusion     = fusion posterior entropy
M_img        = top1-top2 margin of image branch
M_ocs        = top1-top2 margin of OCS branch
Overlap_k    = top-k candidate overlap between image and OCS
JS_img_ocs   = Jensen-Shannon divergence between image and OCS posterior
Conf_consist = function(M_img, M_ocs, Overlap_k, -JS_img_ocs)
```

解释方式：

- image 与 OCS 高一致且 posterior 集中：高置信。
- image 高置信、OCS 低置信：可能是图像主导，需检查 OCS 是否本身不可观测。
- OCS 高置信、image 低置信：可能是图像退化或空间结构弱。
- image 与 OCS 高冲突：不能强行输出姿态，应标记低置信或模型失配。

### 5.3 最佳观测角度分析

该方向具有实际意义，推荐作为新主线的重要结果。

目标不是证明每个角度都能反演，而是回答：

```text
在哪些相位角、太阳方向、观测方向下，姿态信息最丰富？
哪些观测窗口天然低信息量，不适合做姿态估计？
OCS 与图像在最佳观测几何上是否一致？
```

输出可以包括：

- phase angle vs attitude separability heatmap。
- sun/det geometry vs posterior entropy。
- OCS/image/fusion 的最佳观测窗口对比。
- 高混淆姿态案例画廊。

### 5.4 mismatch 边界实验

必须主动加入失配实验，避免论文被质疑“只在完美仿真条件下成立”。

建议至少包含：

| mismatch 类型 | 扰动方式 | 目的 |
|---|---|---|
| BRDF mismatch | roughness/F0/albedo ±20% 或更宽 | 看材料误差是否破坏 OCS/image 结论 |
| gain/offset mismatch | OCS 乘性增益、加性背景 | 看绝对定标误差下归一化特征是否仍有效 |
| STL mismatch | 部件角度、面积、位置、小尺度扰动 | 看几何偏差对 signature 和置信度的影响 |
| image degradation | noise, blur, background, saturation, downsample | 看图像退化下 OCS 是否提供不同失败模式 |
| phase mismatch | train/test phase 外推 | 找出观测几何分布外失效边界 |

这些实验的目的不是保证鲁棒，而是诚实回答：

```text
哪些结论对失配稳定，哪些结论只在理想模型内成立？
```

## 六、真实实验或半真实实验应如何定位

### 6.1 可以验证的内容

真实实验、实验室缩比实验或半真实观测可以用于验证“特性结论”，例如：

- 不同观测角度的信息量确实不同。
- 某些姿态区域天然混淆。
- 图像退化时，低维光度量仍可能保留部分姿态相关信息。
- 图像与 OCS 一致性高时，候选姿态更集中。
- 图像与 OCS 冲突时，错误风险上升。

这些属于机制验证、趋势验证和边界验证。

### 6.2 不应宣称验证的内容

不应宣称：

- 完整真实卫星姿态反演系统已经验证。
- 真实 OCS 绝对值与仿真 OCS 完全一致。
- 未知几何目标可以直接用本方法反演。
- 名义 STL + 名义 BRDF 可以直接外场部署。

### 6.3 合理的真实实验表述

推荐表述：

```text
Real or laboratory measurements are used to examine whether selected qualitative trends
predicted by the unified forward model can be observed under controlled conditions.
They are not used as evidence of field-ready attitude inversion.
```

中文表述：

```text
真实或实验室测量用于检查统一前向模型预测的若干趋势是否能在受控条件下观察到，
而不是用于证明该方法已具备真实外场姿态反演能力。
```

## 七、与 v0.4 代码阶段的关系

v0.4 代码阶段仍然值得继续，但目标解释要调整。

原目标：

```text
重建 Blender-derived OCS，然后重跑 OCS-only / image-only / fusion 姿态反演。
```

建议调整为：

```text
重建同源 OCS/image 前向模型，然后用反演、混淆图、posterior、置信度和观测几何分析，
回答 OCS 与图像在姿态信息表达中的互补与边界。
```

因此，`06_v0.4_code/` 后续应优先支持：

1. 统一 manifest 生成。
2. OCS/image/fusion 训练与推理。
3. 姿态 pairwise distance / confusion matrix 输出。
4. posterior 或 softmax 分布保存。
5. OCS-image top-k overlap 与 JS divergence 计算。
6. 观测几何扫描与信息量 heatmap。
7. BRDF/STL/观测链 mismatch stress test。

## 八、后续写作红线

后续论文、汇报和答辩中必须遵守：

1. 不写“任意未知非合作目标”。
2. 不写“真实 OCS 与仿真 OCS 可直接绝对匹配”。
3. 不写“真实图像 + 仿真 OCS 可直接部署反演”。
4. 不写 “field-proven”, “operational-ready”, “fully robust”。
5. 不把合成实验写成真实望远镜验证。
6. 不把名义材料参数写成真实材料参数。
7. 不把反演误差写成外场性能。
8. 不隐瞒 phase 外推、BRDF mismatch、STL mismatch 和 severe degradation 下的失败边界。

允许写：

1. known-geometry / model-known non-cooperative target。
2. idealized but physically consistent synthetic forward model。
3. OCS-image information complementarity。
4. attitude observability under controlled observation geometry。
5. confidence-aware consistency analysis。
6. qualitative trend validation by real or laboratory measurements, if available。

## 九、最终定位结论

本项目的意义不应再建立在“直接解决真实未知非合作目标姿态反演”上。该强应用主张受到几何未知、材料未知和观测链失配的根本限制。

本项目仍然有意义，但意义应定位为：

```text
在已知或近似已知几何、名义材料参数和受控观测链假设下，
建立 OCS 与图像同源的统一物理前向模型，
研究二者在姿态信息表达、可观测性、互补性和置信度判断中的作用，
并通过失配实验与可能的真实/半真实实验明确其适用边界。
```

一句话版本：

```text
不是造一个直接可用的真实卫星姿态反演系统，
而是在同一物理一致框架下回答 OCS 和图像各自能提供什么信息、什么时候值得信、什么时候不该信。
```
