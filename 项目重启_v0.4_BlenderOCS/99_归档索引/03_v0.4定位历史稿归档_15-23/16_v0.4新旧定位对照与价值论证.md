# v0.4 新旧定位对照与价值论证

生成时间：2026-06-08
配套文件：`15_v0.4研究方向重定位_问题边界与后续路线.md`

本文在 15 号文件（问题边界与后续路线）基础上，系统对照 v0.1–v0.3（第一档 Acta/ASR 方法稿）与 v0.4 重定位之间的差异，论证本次转向是研究层级的升级而非退却，并系统发掘新定位下的核心价值与可写入备注的扩展价值。

本文是论文重写、汇报与答辩时的价值论证依据，不是代码规范，也不是论文正文。

---

## 一、核心结论（一句话）

旧定位押注"误差表好不好看"（performance claim）；新定位押注"机理讲没讲透、边界划没划清"（information & observability claim）。这不是同一篇论文的润色，而是论文类型的切换：**方法/系统论文 → 信息机理与可观测性论文**。

一句话新定位：

```text
不声称解决真实未知目标的姿态反演；
而是在同源、可审计的物理前向模型下，量化 OCS 与图像各自的姿态信息量、互补边界，
并用跨模态一致性给出"何时可信、何时不该信"的置信判据。
```

---

## 二、本质差异：从"做系统"到"做科学问题"

- **旧定位（v0.3）**："我们提出一个 OCS + 图像姿态反演方法/系统，在受控仿真下精度多少、退化下鲁棒性如何。" 论文成败押在误差表。
- **新定位（v0.4）**："我们建立同源前向模型，定量回答 OCS 和图像各自携带什么姿态信息、在什么观测几何下互补、一致性如何指示该不该信。" 论文成败押在机理与边界。

旧定位是 performance claim，最怕"clean rendered images 凭什么代表真机"。新定位是 information/observability claim，从主张层面就不碰真机部署，审稿人无从攻击。

| 维度 | 旧定位 v0.3（Acta/ASR） | 新定位 v0.4 |
|---|---|---|
| 论文类型 | 方法/系统 benchmark | 信息机理 / 可观测性研究 |
| 核心主张 | fusion 在受控仿真下精度高、退化下需 aug | OCS/image 是同源前向模型的两种读出，研究信息量与互补 |

## 四、为什么这是升级，不是退却

表面上 v0.4 放弃了"真实卫星反演系统"像缩水，实际解决了旧定位的几个致命问题。

### 4.1 可防守性质变

旧主线最怕的审稿意见是"你全在 clean rendered images 上做，凭什么说能反演真实卫星？"——旧红线第 1、6 条整条都在防这个。新定位从主张层面就不碰真机部署，审稿人无从攻击，因为根本没声称要上真机。

### 4.2 旧的"防御性实验"全部转正（最大红利）

已完成的实验在新框架下身价翻倍：

| 实验 | 旧框架角色 | 新框架角色 |
|---|---|---|
| 实验11（naive fusion 继承图像脆弱性） | 方法缺陷说明 | modality dominance / degradation inheritance 的正面机理发现 |
| 实验12b（OCS-image co-utilization，非 standalone fallback） | 自证清白 | "fusion 是否真利用 OCS"贡献点的核心证据 |
| 实验12c（observation-style 退化） | 防御性审稿材料 | mismatch boundary 的系统性测绘 |
| 实验12d（phase 外推失效） | 诚实交代失败 | 观测几何分布外失效边界 |
| 实验12e（质心居中控制） | 消融补充 | 信息来源归因（质心 vs 结构） |

旧定位里这些实验是被迫加的"自证清白"，新定位里它们是论文的肉。

### 4.3 拿到理论深度

旧定位是工程精度数字；新定位引入可观测性、posterior entropy、Fisher-like score、JS divergence、ECE——这是信息论/估计论的语言，会被认为是"有思想的研究"而非"调了个网络"。

### 4.4 多了一个真正实用的落点

"最佳观测几何 / 信息量地图"有独立工程价值：告诉别人什么相位角、太阳方向下值得做姿态估计，什么窗口天然没信息。即使方法不部署也有用。

## 五、新定位的核心 novelty（必须立住的卖点）

按差异化强弱排序：

1. **跨模态一致性即置信度（consistency-as-confidence）** —— 最有辨识度的卖点。"OCS 与图像后验高度一致时姿态更可信，冲突时应拒绝输出"。光变反演和图像 pose 估计两个圈子都很少把二者一致性当置信度信号。若能给出"一致性↑ → 错误率↓"的量化曲线（ECE / 可靠性图），即为独立贡献。

2. **同源统一前向模型** —— 把 v0.3 封存根因（OCS/图像采样口径不一致）反转成卖点。"现有工作的 OCS 和图像往往来自不同管线，本文首次让二者作为同一 clean photometric response 的 integrated readout 与 spatially-resolved readout"。

3. **可观测性 / 混淆地图 + 最佳观测几何** —— 实用、可视化强、易被引用。

4. **mismatch 边界测绘** —— 不是卖点但是护城河，让审稿人无法说"只在完美仿真成立"。

## 六、扩展价值（写入备注，不作为主方向）

以下价值点不进主线贡献，但可写入论文 Discussion / Future Work / 答辩备注，用于回应"这研究除了发论文还有什么用"。

### 6.1 物理补足：为后续数据驱动方法提供物理先验底座

纯数据驱动的图像 pose 网络是黑箱，缺乏物理可解释性，且在分布外迅速失效（实验11/12d 已证）。本项目的同源前向模型与可观测性地图，可作为后续工作的**物理补足层**：

- 为图像网络提供物理一致的合成训练数据与可观测性标注（哪些姿态本就不可区分，可作为 label noise / 不确定性先验）。
- 把"信息量地图"作为后续 active sensing / 观测调度的先验，而非每次盲采。
- 一致性指标可作为后续真实数据上的弱监督 / 自检信号。

**备注定位**：本文不实现这些下游系统，但明确指出本框架是它们的物理底座。

### 6.2 条件已知预备：为"逐步逼近真实"铺设台阶

新定位限定在 model-known + 名义材料 + 受控观测链。这不是终点，而是一条**可逐级松绑的研究路径**的第一级：

```text
几何已知 + 材料已知 + 观测链受控          ← 本文（v0.4）
几何已知 + 材料近似已知 + 观测链可校准      ← 下一步（mismatch 实验已在探边界）
几何近似（候选库 / 先验重建）+ 材料/观测链估计 ← 中期
几何未知 + 联合估计                        ← 远期（明确超出本文）
```

mismatch 实验（BRDF / gain-offset / STL / phase）正是在量化"松绑每一级会损失多少结论稳定性"。

**备注定位**：本文是"条件已知"这一级的完整刻画，并为下一级（条件近似已知）提供了可量化的边界数据，是后续放松假设的预备工作（preparatory study）。

### 6.3 最亮 / 最优观测角度几何发现分析

独立于姿态反演，本框架可产出一组**纯几何-光度发现**：

- 哪些相位角 / 太阳-目标-观测几何下目标整体最亮（信噪比最高、最易被探测）。
- 最亮角度与"姿态信息量最高角度"是否重合——这两者很可能不一致（最亮时往往镜面主导、信息反而塌缩），这个 mismatch 本身就是一个有意思的发现。
- 不同部件（帆板 / 本体）主导亮度的姿态-几何区间。

**备注定位**：可作为论文一个小节或附录的"观测几何指南"，对地基光学探测任务的观测窗口规划有直接参考价值，且不依赖任何反演主张即可成立。

### 6.4 可观测性作为传感器/任务设计输入

信息量地图回答"什么时候做姿态估计才有意义"，可反向用于：

- 观测排程：优先在高信息窗口安排观测。
- 传感器选型权衡：某场景下积分光度（OCS）已够，无需高分辨成像；某场景必须成像。

**备注定位**：Future Work 中点到即可，不展开实现。

### 6.5 方法学价值：一套可复用的"多模态信息量评估范式"

"用 posterior entropy / top-k overlap / JS divergence / ECE 评估两种读出各自及联合的信息量与置信一致性"这套流程，不限于 OCS+图像，可迁移到任意双模态姿态/状态估计。

**备注定位**：Discussion 中提一句方法可迁移性即可，不宜过度声称。

## 七、风险与必须补强（诚实评估）

转型有真实代价，不能只看好处。

| 风险 | 描述 | 应对 |
|---|---|---|
| 降级观感 | 审稿人问"所以到底做出可用东西没有？" | 叙事钉死在 information/observability study，用第五节 novelty 正面立论，不用"我们没做真机"防守式表述 |
| model-known 现实性被质疑 | "几何都已知了，姿态还要光度反演干嘛？" | intro 预先回答：失效卫星翻滚、在轨服务抵近、碎片监测中型号/几何常已知（己方卫星、公开型号），但实时姿态未知，这正是 model-known non-cooperative 的真实战场 |
| 信息量分析做虚 | 只画几张热图、Fisher-like score 无定义 | 所有信息量/置信指标必须有明确定义与计算口径，这是新定位工作量最大、最易做虚的部分 |
| 旧数字不能直接搬（硬约束） | 旧 1.69°/5.91°/1.47°、12b/12c/12f/12g 全基于模块A face-center OCS | 新口径（Blender-derived canonical OCS）下必须重跑；现阶段旧结论只能作为待验证假设/方向，不能作为新论文最终数字 |

最后一条决定了：新定位不是改写就能交付，而要重跑全链路，成本要算清。

## 八、最终定位结论

这次重定位方向正确，且是升级：把一篇容易被打的方法论文，换成立意更高、护城河更深、且能让既有实验全部转正的信息机理论文。代价是诚实——放弃"造了个能用系统"的强主张，换来"说清楚什么时候该信什么时候不该信"的可信度。

主线（一句话）：

```text
不声称解决真实未知目标的姿态反演；
而是在同源、可审计的物理前向模型下，量化 OCS 与图像各自的姿态信息量、互补边界，
并用跨模态一致性给出"何时可信、何时不该信"的置信判据。
```

扩展价值（备注层，按可写入强度排序）：

1. 最亮/最优观测几何发现（6.3）—— 不依赖反演主张即成立，最易写入。
2. 物理补足底座（6.1）—— 为后续数据驱动方法提供物理先验。
3. 条件已知预备（6.2）—— 本文是"逐级松绑真实假设"路径的第一级完整刻画。
4. 可观测性作为任务设计输入（6.4）、多模态信息量评估范式（6.5）—— Future Work / Discussion 点到为止。
