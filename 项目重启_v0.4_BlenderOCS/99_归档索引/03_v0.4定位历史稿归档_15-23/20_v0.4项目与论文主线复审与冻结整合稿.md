## 一、Codex 复审结论

### 1.1 总体判定

15/16/17/18 的方向调整总体成立，建议采纳为 v0.4 新主线。

核心判断：

```text
v0.4 不应继续以“真实未知非合作目标姿态反演系统”为论文主线。
v0.4 应转向“同源前向模型下 OCS/image 双读出的姿态信息可观测性、互补性与置信一致性研究”。
```

该转向不是简单降级，而是论文类型切换：

```text
旧类型：方法/系统 benchmark，成败押在误差表。
新类型：信息机理与可观测性研究，成败押在科学问题、指标定义、边界解释和证据闭环。
```

### 1.2 是否正向影响投稿

总体正向，但有条件。

| 投稿层级 | 影响 | 说明 |
|---|---|---|
| SCI 可投性 | 正向 | 主张更稳，避开真实部署证据不足的致命攻击点 |
| 中高水平 SCI | 正向 | 更像物理建模、信息分析、多模态一致性研究 |
| 一区/强刊冲刺 | 有条件正向 | 必须把 observability / confidence / mismatch 指标做实 |
| TAES / JGCD 类强系统期刊 | 可能变弱 | 这类期刊更期待完整 estimation system、高保真或真实验证 |
| Nature / Science 级顶刊 | 当前不现实 | 除非后续有真实观测验证或更普适理论突破 |

### 1.3 是否可以进入代码重跑

不建议立刻进入全链路重跑。建议先完成本文主线冻结，并在训练/反演代码前补一份“信息量与置信指标实现规范”。

但这不阻断统一前向模型的 phase 0 验证：

```text

V_sun_macro reprojection、20 姿态 shadow validation。
```

## 二、旧定位的问题

旧 v0.3 定位大致是：

```text
提出一种 OCS + 图像融合的非合作目标姿态反演方法，
并在受控仿真中证明其精度和鲁棒性。
```

这个定位的问题不是“证据还不够强”，而是“问题定义本身过宽”。

### 2.1 根本风险 1：任意未知非合作目标没有目标专属前向表

OCS lookup / OCS-image fusion 依赖：

```text
目标几何 + 材料/BRDF + 太阳/观测方向 + 姿态 -> OCS signature
```

若目标几何未知，就没有 STL 或 CAD，也无法生成目标专属 OCS 查找表。此时目标姿态、几何形状、尺度、材料反射特性和观测链增益会共同影响亮度与图像，单独从 OCS 或图像中反演姿态是欠定问题。

### 2.2 根本风险 2：仿真 OCS 与真实 OCS 不能默认绝对匹配

即使存在 STL，真实 OCS 也不可能天然等于仿真 OCS。偏差来源包括：

- 材料/BRDF 参数未知，如 roughness、F0、albedo、diffuse/specular ratio。
- 真实结构与名义 STL 不一致，如制造公差、展开状态误差、在轨变形、局部损伤。
- 观测链未知，如大气透过率、探测器非线性、曝光、背景、PSF、绝对定标误差。
- 姿态、轨道、太阳和观测几何本身也可能存在误差。

因此不能写：

```text
真实观测 OCS 可以直接与仿真 OCS 查找表匹配，从而得到可靠姿态。
```

### 2.3 根本风险 3：旧 OCS 与图像不是同源前向模型

旧 v0.3 的 OCS 来自模块 A face-level / face-center 扫描，图像来自 Blender pixel-level geometry/pass。二者采样口径不统一，会影响：

- OCS-only。
- fusion。
- OCS noise。
- branch masking。
- 12b / 12c / 12f / 12g 等机制实验。

因此 v0.3 旧结果不能作为 v0.4 主结果，只能作为历史证据、机制假设和代码结构参考。

## 三、建议冻结的新项目定位

### 3.1 完整定位

建议冻结为：

```text
面向几何已知或近似已知的非合作航天器，
建立 OCS 与光学图像同源的可审计物理前向模型，
系统研究积分光度读出与空间分布图像读出在姿态信息表达、
可观测性、互补性和置信一致性中的作用边界。
```

### 3.2 短定位

```text
不是做真实未知目标姿态反演系统，
而是做 OCS/image 双读出的姿态信息可观测性与置信评估框架。
```

### 3.3 适用对象

论文中的非合作目标必须限定为：

```text
non-cooperative but model-known target
```

含义：

- 目标不通信。
- 目标不主动配合。
- 没有人工标志器或合作信标。
- 但目标几何模型、候选几何模型或近似结构模型已知。

可接受场景：

- 己方失效卫星。
- 已知型号或结构公开的航天器。
- 有设计资料或历史模型的目标。
- 实验室缩比模型。
- 由其他传感器或先验重建得到近似几何的目标。

不可接受场景：

- 完全未知几何、未知材料、无先验类别的任意空间目标。
- 真实外场可部署姿态反演系统。
- 仿真 OCS 与真实 OCS 的绝对值直接匹配。

## 四、建议冻结的新论文主线

### 4.1 英文主线

```text
OCS and optical images are two readouts of the same physically consistent forward model:
OCS is an integrated photometric readout, while images are spatially resolved photometric readouts.
This paper studies what attitude information each readout carries,
where they are ambiguous or complementary,
and whether their consistency can indicate confidence under controlled model-known conditions.
```

## 五、核心科学问题

论文应围绕三个科学问题展开。

### 5.1 What can be known?

在已知几何和名义材料条件下，OCS 与图像分别对姿态有多少可区分信息？

对应结果形态：

- OCS-only 可观测性地图。
- image-only 可观测性地图。
- 姿态混淆图。
- pairwise distance。
- nearest-neighbor ambiguity。
- top-k confusion。
- posterior-like entropy。

### 5.2 When are they complementary?

哪些姿态或观测几何下 OCS 有效，哪些地方图像有效，哪些地方二者互补或共同失效？

对应结果形态：

- OCS/image 错误互补图。
- OCS/image 混淆互补图。
- top-k candidate overlap。
- OCS-image disagreement map。
- branch masking。
- OCS noise monotonicity。
- modality attribution。

### 5.3 When should we trust the estimate?

OCS 与图像的候选姿态是否一致，能不能作为置信度或拒识依据？

对应结果形态：

- OCS-image posterior-like distribution agreement。
- JS divergence。
- top-k overlap。
- top1-top2 margin。
- consistency vs error 曲线。
- ECE / reliability diagram。
- 可选 conformal prediction 拒识机制。

## 六、贡献点建议

建议贡献点按以下顺序组织。

1. 建立 OCS 与图像同源的统一物理前向模型，将 OCS 定义为 integrated photometric readout，将图像定义为 spatially resolved photometric readout，避免旧流程中 OCS 与图像采样口径不一致。
2. 构建姿态空间和观测几何空间中的 OCS/image 可观测性与混淆性分析框架，回答二者分别在何处携带有效姿态信息。
3. 定量研究 OCS 与图像的互补性和 fusion 机制，区分真正互补、单模态主导和退化继承。
4. 提出 OCS-image consistency-as-confidence 思路，验证跨模态一致性是否能提示高置信、低置信和冲突样本。
5. 通过材料、几何、观测链和 phase mismatch 试验，明确该框架在何种假设下有效、何种条件下失效。

贡献点主次：

```text
贡献点 1 是地基。
贡献点 2 和 4 是科学核心。
贡献点 3 和 5 是支撑与边界，不宜喧宾夺主。
```

## 七、结果形态必须升级

v0.4 主结果不应再以 mean error / Hit@5 / worst-case 为唯一中心。它们可以保留，但角色应降级为信息验证工具。

主结果建议包括：

| 结果类型 | 目的 |
|---|---|
| OCS-only / image-only 可观测性地图 | 展示两种读出分别在哪里有姿态信息 |
| 姿态混淆图 | 找出天然不可区分姿态 |
| 观测几何信息量地图 | 支撑最优观测窗口和 observation planning |
| OCS-image top-k overlap / disagreement map | 展示互补与冲突区域 |
| consistency vs error 曲线 | 支撑 consistency-as-confidence |
| mismatch 边界图 | 说明材料、几何、观测链和 phase 偏差下何处失效 |
| 反演误差表 | 作为验证工具，而不是应用终点 |

## 八、应用价值排序

### 8.1 强应用落点：最优观测几何指南

最优观测几何是最稳的工程尾巴，因为它不依赖“真实姿态反演系统已经可部署”这个强主张。

核心洞察：

```text
最亮 != 信息量最高。
最亮往往是镜面闪烁主导，此时亮度对姿态极度敏感但多解，
反而可能出现信息塌缩。
```

可交付形式：

- 相位角 - 姿态可分性地图。
- 太阳方向 / 观测方向 - 信息量地图。
- 最亮窗口与最高信息窗口对比。
- 高信息观测窗口推荐。

### 8.2 中应用落点：置信门控

```text
OCS 与图像候选分布一致时，提高置信；
OCS 与图像冲突时，拒绝输出或标记低置信。
```

应用价值是降低高风险误判，而不是单纯提高平均精度。

### 8.3 弱应用落点：传感器选型和观测调度先验

可写入 Discussion / Future Work，不作为主贡献展开。

## 九、方法学路线与待冻结项

17 号文件提出的 FIM / CRLB / D-optimality / conformal prediction 方向有价值，但不能直接当作已经闭合的方法主线。进入训练与反演代码前，需要另行冻结一份“信息量与置信指标实现规范”。

### 9.1 可观测性指标

优先采用离散姿态网格上的稳健指标：

```text
pairwise signature distance
nearest-neighbor ambiguity
top-k confusion
posterior-like entropy
```

FIM / CRLB 的处理建议：

- 先写为 Fisher-like local sensitivity / local observability score。
- 不建议一开始就把 FIM / CRLB 写成唯一硬理论主轴。
- 若数值梯度在 visibility、shadow mask、边缘像素、GGX 镜面峰附近稳定，再升级为 FIM / D-optimality。

### 9.2 posterior-like distribution 必须定义

confidence / JS divergence / entropy / ECE 都依赖候选姿态分布。若模型是角度回归，天然没有 posterior。

进入训练代码前必须确定：

- posterior-like score 来自网格分类 softmax，还是 kNN likelihood，还是距离归一化分布。
- OCS 和 image 是否输出同一姿态网格上的候选分布。
- top-k、entropy、JS divergence、margin 的计算口径。

### 9.3 consistency-as-confidence 指标

建议最小指标集：

```text
H_img        = image posterior-like entropy
H_ocs        = OCS posterior-like entropy
H_fusion     = fusion posterior-like entropy
M_img        = top1-top2 margin of image branch
M_ocs        = top1-top2 margin of OCS branch
Overlap_k    = top-k candidate overlap between image and OCS
JS_img_ocs   = Jensen-Shannon divergence between image and OCS distributions
Conf_consist = function(M_img, M_ocs, Overlap_k, -JS_img_ocs)
```

解释方式：

- image 与 OCS 高一致且候选分布集中：高置信。
- image 高置信、OCS 低置信：可能是图像主导，需检查 OCS 是否本身不可观测。
- OCS 高置信、image 低置信：可能是图像退化或空间结构弱。
- image 与 OCS 高冲突：不应强行输出姿态，应标记低置信或模型失配。

### 9.4 conformal prediction 的位置

conformal prediction 有价值，但应作为进阶增强项，而不是当前重跑前置条件。

适合写法：

```text
We further explore whether cross-modal consistency can support confidence-aware rejection,
with conformal prediction considered as a possible calibration mechanism.
```

不宜写法：

```text
本文已经给出真实外场有覆盖率保证的姿态反演系统。
```

## 十、重跑必须服务的新指标

v0.4 代码与 manifest 设计必须确保后续能计算信息量与置信指标。因此重跑时除传统 summary 外，应保存以下中间量：

- 每个姿态的 OCS total / per-part / multi-geom features。
- 每个姿态的 clean image linear response 与 log1p PNG。
- 姿态 record_id、yaw、pitch、geom_id、sun_dir、det_dir。
- OCS-only 模型的候选姿态分数或 posterior-like distribution。
- image-only 模型的候选姿态分数或 posterior-like distribution。
- fusion 模型的候选姿态分数或 posterior-like distribution。
- top-k candidates。
- per-attitude error。
- branch masking 输出。
- OCS noise monotonicity 输出。
- modality attribution 输出。

如果训练代码只输出 mean error 和 model_best.pt，v0.4 新论文主线会缺证据。因此训练阶段必须要求保存候选分布和 per-attitude 结果。

## 十二、投稿策略

### 12.1 推荐方向

| 档位 | 方向 | 判断 |
|---|---|---|
| 冲刺 | IEEE TGRS / Optics Express / 高水平遥感光学期刊 | 有机会，但要求 observability / confidence 方法非常扎实 |
| 主投稳健 | Aerospace Science and Technology / Acta Astronautica / ASR / Remote Sensing | 更现实，适合物理建模 + 信息分析 + 航天应用背景 |
| 保底 SCI | Sensors / Applied Sciences 类或更应用型期刊 | 可投性较高，但不建议一开始就降到这里 |

### 12.2 投稿话术顺序

论文和答辩中应按以下顺序说价值：

```text
先说科学价值：what can be known。
再说工程价值：观测几何指南、置信门控。
最后说应用场景：model-known 非合作目标，如己方失效卫星、公开型号、在轨服务抵近、碎片监测。
```

不要一开头就谈工程部署，否则会被追问真实观测、真实材料、真实定标和外场验证。

### 12.3 不建议方向

当前不建议把 TAES / JGCD 作为优先目标，因为新定位不主张完整 field-ready estimation system。

当前不建议把 Nature / Science 级别作为现实目标，除非后续补充真实观测验证或形成普适理论突破。

## 十三、写作红线

后续论文、汇报和答辩必须遵守：

1. 不写“任意未知非合作目标姿态反演”。
2. 不写“真实 OCS 与仿真 OCS 可直接绝对匹配”。
3. 不写“真实图像 + 仿真 OCS 可直接部署反演”。
4. 不写 field-proven、operational-ready、fully robust。
5. 不把合成实验写成真实望远镜验证。
6. 不把名义材料参数写成真实材料参数。
7. 不把反演误差写成外场性能。
8. 不隐瞒 phase 外推、BRDF mismatch、STL mismatch 和 severe degradation 下的失败边界。
9. 不把旧 v0.3 数字写成 v0.4 主结果。
10. 不把 FIM / CRLB / conformal prediction 写成已经闭合的强理论结果，除非后续实现和验证支撑。

允许写：

1. known-geometry / model-known non-cooperative target。
2. idealized but physically consistent synthetic forward model。
3. OCS-image information complementarity。
4. attitude observability under controlled observation geometry。
5. confidence-aware consistency analysis。
6. qualitative trend validation by real or laboratory measurements, if future data become available。
