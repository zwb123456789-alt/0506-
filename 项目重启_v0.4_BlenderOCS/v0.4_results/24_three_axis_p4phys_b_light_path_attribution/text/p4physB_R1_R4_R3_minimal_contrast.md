## 1. R4 是否与 top-1 同一机制？

**是同一类机制。** R4 与 top-1 都是金属主体近镜面对齐探测器：

- 两者主贡献部件都是金属主体（>95%）。
- 两者加权法向都几乎重合半程向量（top-1 0.57°，R4 0.19°），反射方向都近乎正对探测器（1.06° / 0.33°）。
- 两者金属贡献像素 N·H≥0.99 比例都很高（81% / 84%），镜面项均值接近（0.81 / 0.84）。

R4 的镜面对齐甚至略优于 top-1（角度更小），但 R4 总 OCS 略低。

## 2. 为什么 top-1 反而超过 R4？

差异**不在金属镜面项**（R4 金属 0.19872 ≈ top-1 金属 0.19850，几乎相等），而在**隐身板**：

- top-1 隐身板贡献 0.008775 m²（1408 贡献像素）。
- R4 隐身板贡献 0.000931 m²（152 贡献像素）。
- 差额 ≈ 0.00784 m²，与 top-1 − R4 总差（0.20889 − 0.20115 = 0.00774）基本吻合。

即 **top-1 之所以是当前局部 top-1，是因为在金属近镜面高亮几乎持平 R4 的同时，其 roll=+15 姿态让隐身板一片大面积面元额外进入受照+可见+贡献状态**，贡献了决定性的微弱增量。这解释了 R144/R148 记录的"top-1 与 R4 仅差约 3%"。

## 3. R3 为什么暗/低信息？

R3（yaw55/pitch60）虽然金属仍占 98.5%，但镜面几何被破坏：

- 加权法向与半程向量差 **12.45°**（top-1/R4 均 <1°），反射方向偏离探测器 **21.8°**。
- 金属像素中 N·H≥0.99 比例仅 0.2%，镜面项均值 0.11（约为 top-1/R4 的 1/8）。
- 隐身板贡献为 0。

因此 R3 只有漫反射底座、没有近镜面瓣对准探测器，总 OCS 仅 0.066（约 top-1 的 1/3），是典型低亮/负面对照。

## 4. R1 与 R4：同机制，但增量来源不同（留给 P4-PHYS-C）

- **共同高亮机制**：金属主体大面元近镜面对齐探测器（quasi-specular）。
- **top-1 相对 R4 的额外增量**：来自 roll=+15 下隐身板的附加受照可见面。
- 这是否构成一类"金属近镜面 + 副部件补充"的普遍高亮机制，需 P4-PHYS-C 在 top-N / R1 加密邻域 / R4 鲁棒区上做机制签名匹配统计，本轮不做。
