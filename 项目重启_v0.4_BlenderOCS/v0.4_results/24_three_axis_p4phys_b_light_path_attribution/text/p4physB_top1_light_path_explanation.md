# top-1 入射-表面-探测器光路解释（C 子任务）

固定几何：phase63 / L1-G1。所有方向为惯性系单位向量，法向为 camera EXR 的 world-frame Normal pass。

## 1. 入射与观测方向（直接）

- 太阳入射方向（单位化 SUN=[1,0,0.3]）：**S = [0.9578, 0, 0.2873]**。
- 探测器视线方向（单位化 DET=[0.5,-1,0.1]）：**D = [0.4454, -0.8909, 0.0891]**。
- 半程向量 H=(S+D)/|S+D|：**H = [0.7791, -0.5806, 0.2364]**。
- 太阳-探测器夹角（相位角 proxy）：约 63°（phase63 命名来源）。

## 2. 主贡献面的法向几何（直接计算，I_linear 加权）

以金属主体贡献像素、按 I_linear 加权的平均法向 N̄：

| 量 | top-1 值 | 含义 |
|---|---|---|
| N̄ 与 S 夹角 | 31.1° | 入射角 proxy |
| N̄ 与 D 夹角 | 32.0° | 观测角 proxy |
| N̄ 与 H 夹角 | **0.57°** | 与理想镜面法向几乎重合 |
| 加权 N·H | 0.9978 | 镜面项核心接近 1 |
| 镜面反射方向 R 与 D 夹角 | **1.06°** | 反射光几乎正对探测器 |

金属贡献像素中 **81.3%** 满足 N·H≥0.99；镜面项 (N·H)^80 的均值达 0.81。

## 3. 光路物理解释

综合以上，top-1 高亮的物理光路是：

```
太阳沿 S≈[0.96,0,0.29] 入射
→ 照到卫星金属主体一片法向 N̄ 几乎等于半程向量 H 的大面元（入射角约31°）
→ B0 高镜面材料（金属 rho_s=0.60, Phong n=80）在近镜面条件 (N·H≈0.998) 产生强镜面瓣
→ 理想反射方向 R 与探测器视线 D 仅差约 1°，反射光几乎正对探测器
→ 在探测器方向形成大面积近饱和高亮（saturation_flag=1，glint_flag=0）
```

即：**top-1 是"金属主体大面元近镜面对齐探测器"的准镜面（near-specular / quasi-glint）高亮**，由一片面而非单点主导，因此表现为近饱和平台而非离散 glint 尖峰。

## 4. 饱和/风险（直接 + proxy）

- I_linear 平台值 ~0.566，中位≈最大 → 存在 saturation-associated 高亮（与 23A topN 表 saturation_flag=1 一致）。
- glint_flag=0：不是被判为离散镜面点的 glint，而是面状近镜面高亮。
- 隐身板 4.2% 贡献来自大量低亮度掠射像素（1408 px），是 top-1 相对 R4 的额外增量来源（见对照文件）。

## 5. 直接 vs proxy 边界

- **直接**：S、D、H 向量；逐像素/加权法向夹角；N·H 分布；反射方向-探测器夹角；per-part 贡献。
- **proxy**：
  - 材料响应到 B0 phong 参数级，无 material pass → "金属高镜面材料"为 material proxy。
  - N̄ 为亮度加权平均法向，代表主贡献面朝向，非单一物理平面解析。
  - "近镜面/准 glint"是基于 N·H 与反射-探测器夹角的几何 proxy 判断，未做 BRDF 分量能量解析。
