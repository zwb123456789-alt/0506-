## P0-1 OCS 定义

- 核对结论：原清单位置正确。OCS 定义位于第2章 2.4.2，书页 p35，源图 `第二章/微信图片_20260618115809_1680_74.png`。
- 源文主题：`2.4.2 OCS 定义和相关理论`。
- 核准公式：

```tex
\mathrm{OCS}=\int_A f_r(\theta_i,\phi_i,\theta_r,\phi_r)\cos\theta_i\cos\theta_r\,dA
\tag{2.29}
```

```tex
\mathrm{OCS}=\frac{E_d\cdot R_1^2}{E_{\mathrm{sun}}}
\tag{2.30}
```

```tex
d\Omega=\frac{dS}{r^2}
=\frac{r^2\sin\theta\,d\theta\,d\phi}{r^2}
=\sin\theta\,d\theta\,d\phi
\tag{2.31}
```

- 变量核对：
  - `f_r`：BRDF。
  - `theta_i, phi_i`：入射方向天顶角、方位角。
  - `theta_r, phi_r`：出射/观测方向天顶角、方位角。
  - `A, dA`：目标表面积分域与面元面积。
  - `E_d`：探测系统接收到的目标辐射照度。
  - `R_1`：探测距离。
  - `E_sun`：太阳辐射照度。
  - `dOmega`：立体角微元；`theta` 为天顶角，`phi` 为方位角。
- 单位核对：源文指出 OCS 单位存在表达不统一问题；按式 (2.30) 可视为 `m^2`，按式 (2.29) 从 BRDF 积分看为 `m^2 sr^-1 = m^2/sr`。写作中应说明该书对此进行了梳理，不宜混写为唯一无争议单位。
- 项目用途：可作为 v0.4 前向模型中 OCS 物理量定义的主依据。
- 写作边界：可以引用 OCS 与目标表面材质、外形尺寸、太阳入射方向和观测方向有关；不能把该页写成 v0.4 已完整复现实验系统指标。

## P0-2 BRDF 定义

- 核对结论：原清单位置正确。BRDF 定义位于第2章，书页 p32，源图 `第二章/微信图片_20260618115748_1677_74.png`。
- 核准公式：

```tex
f_r(\theta_i,\phi_i;\theta_r,\phi_r)
=\frac{dL_r(\theta_i,\phi_i;\theta_r,\phi_r)}
{dE_i(\theta_i,\phi_i)}
\tag{2.17}
```

- 图题核对：图 2.16 `BRDF 的几何关系`。
- 变量核对：
  - `(theta_i, phi_i)`：入射光线的天顶角和方位角。
  - `(theta_r, phi_r)`：出射光线的天顶角和方位角。
  - `dE_i`：入射光线沿 `(theta_i, phi_i)` 方向、于空间角 `domega_i` 内入射到面元 `dA` 上的辐射照度。
  - `dL_r`：入射光线照射面元 `dA` 后，于 `(theta_r, phi_r)` 方向、在空间角 `domega_r` 内的出射光辐射亮度。
  - `f_r`：双向反射分布函数微分量。
- 单位核对：`sr^-1`。
- 源文补充性质：
  - 能量守恒：`\int f_r\cos\theta_r\,d\omega_r \le 1`。
  - 亥姆霍兹互易性：源图写作 `f_r(theta_i, phi_i)=f_r(theta_r, phi_r)`，含义为入射与出射方向互换可得到相同散射情况。
- 项目用途：可作为材质散射建模和 BRDF 参数解释的定义依据。
- 写作边界：可引用定义、单位、几何关系；不要把该定义页写成具体材料模型或测量参数来源。

f_r(\theta_i,\phi_i;\theta_r,\phi_r)

## P0-4 经典冯模型

- 核对结论：原清单位置正确。经典冯模型位于第3章 3.3，书页 p56-p57，源图 `第三章/微信图片_20260618135049_1703_74.png`、`第三章/微信图片_20260618135056_1704_74.png`。
- 源文标题：`3.3 改进冯模型参数反演`，其中 p56 先介绍经典冯模型。
- 图题核对：图 3.12 `冯模型角度关系图`；图 3.13 `入射天顶角高阶余弦倒数的曲线变化情况`。
- 核准公式：

```tex
f(l \to v)=\rho_d+\rho_s\frac{(r\cdot v)^\alpha}{(l\cdot z)}
\tag{3-14}
```

源图式号显示为 `(3-14)`，不是常见点号格式。

```tex
f=\rho_d+\rho_s\frac{\cos^\alpha\beta}{\cos\theta_i}
\tag{3.15}
```

- 变量核对：
  - `rho_d`：材质漫反射系数。
  - `rho_s`：材质镜面反射系数。
  - `alpha`：镜向指数，用于调节材质镜面反射特性强度。
  - `r`：镜面反射方向单位向量。
  - `v`：观测方向单位向量。
  - `z`：材质平均表面法向单位向量。
  - `l`：入射光反方向单位向量。
  - `beta`：观测方向与镜面反射方向夹角。
  - `theta_i`：入射天顶角。
  - `theta_r`：图 3.12 中为观测天顶角。
  - `phi`：图 3.12 中为观测方位角；源文提醒它与 BRDF 方位角、测量系统内方位角不同，换算关系为 `phi = pi - phi_b`。
- 局限核对：经典冯模型预测时，一旦 `rho_s` 固定，任意入射天顶角下 BRDF 峰值随 `1/cos(theta_i)` 固定变化，不能描述不同材质的非涅耳反射差异。
- 项目用途：可作为 B0/B1 Phong-like baseline 和改进模型对照来源。
- 写作边界：不能把经典冯模型误放到第3章 p48-p50；不能声称 v0.4 已完整复现书中参数反演。

## P0-5 改进冯模型

- 核对结论：原清单位置正确。改进冯模型的正式公式位于 p59 / `第三章/微信图片_20260618142222_1718_74.png`，前置解释位于 p56-p58。
- 图题核对：
  - 图 3.13 `入射天顶角高阶余弦倒数的曲线变化情况`。
  - 图 3.14 `参数 b、c 对指数项的影响`。
- 核准公式：

```tex
f_r
=
\rho_d\cos\theta_i
+
\rho_s
\frac{\cos^\alpha\beta}{\cos^a\theta_i}
\exp\left[-b(1-\cos\beta)^{1/\pi}\right]
\tag{3.16}
```

```tex
E(x)
=
\frac{
\sum_{\theta_i}\sum_{\theta_r}
\left(f_r\cos\theta_r-f_r^0\cos\theta_r\right)^2
}{
\sum_{\theta_r}
\left(f_r^0\cos\theta_r\right)^2
}
\tag{3.17}
```

- 变量核对：
  - `rho_d, rho_s, alpha, beta`：与经典冯模型相同。
  - `a`：大于 0，用于调节非涅耳反射强度；源文将经典冯模型镜面反射部分分母 `cos(theta_i)` 修正为 `cos^a(theta_i)`。
  - `b`：大于 0，用于调节镜面反射分量的增降速度。
  - 指数项：先引入 `exp[-b(1-cos beta)^c]`，源文经比较后将 `c` 取定值 `1/pi`，所以式 (3.16) 中不再把 `c` 作为待反演参数。
  - `x=(rho_d,rho_s,alpha,a,b)^T`：模型参数向量。
  - `f_r`：模型预测值。
  - `f_r^0`：实际测量值。
- 参数反演核对：源文说明参数集包括改进冯模型中的 5 个待定参数 `rho_d, rho_s, alpha, a, b`；适应度函数选择标准均方误差；遗传算法示例设置包括初始种群数量 1000、最大迭代次数 20、交叉概率 0.3、变异概率 0.01。
- 项目用途：可作为路线一 C 的 B1 书中改进冯模型候选分支。
- 写作边界：只能说书中模型可作为候选与对照；不能写成 v0.4 已采用或已反演出书中三部件材料参数。

## P0-6 Torrance-Sparrow 五参数模型

- 核对结论：原清单位置正确。Torrance-Sparrow 五参数模型位于第3章 3.4.1，书页 p63-p64，源图 `第三章/微信图片_20260618141949_1709_74.png`、`第三章/微信图片_20260618141957_1710_74.png`。

  - `1. 五参数模型分析`
- 图题核对：图 3.20 `五参数模型角度示意图`，子图 `(a) 五参数模型角度关系；(b) 微观入射`。
- 核准公式：

```tex
f_r
=
k_b
\frac{k_r^2\cos\alpha}{1+(k_r^2-1)\cos\alpha}
\exp\left[b(1-\cos\gamma)^a\right]
\frac{G(\theta_i,\theta_r,\phi_r)}{\cos\theta_i\cos\theta_r}
+
\frac{k_d}{\cos\theta_i}
\tag{3.18}
```

```tex
\begin{cases}
\cos\alpha=\dfrac{\cos\theta_i+\cos\theta_r}{2\cos\gamma} \\
\cos^2\gamma=\left(\cos\theta_i\cos\theta_r+\sin\theta_i\sin\theta_r\cos\phi_r+1\right)/2
\end{cases}
\tag{3.19}
```

- 变量核对：
  - 第一项为镜面反射分量。
  - `k_b`：镜面反射系数。
  - `k_r`：旋转椭球体水平轴与垂直轴之比，取值 `0-1`，与材质镜面反射特性相关；源文说明 BRDF 镜向峰值越大，`k_r` 越小。
  - `a, b`：指数项参数，与材质复折射率有关；用于改变定向散射分量的增长速度。
  - `G(theta_i,theta_r,phi_r)`：遮蔽函数，大小取决于微观面元间掩盖和遮蔽概率。
  - 第二项为漫散射分量。
  - `k_d`：漫反射系数。
  - `V_i`：入射光向量。
  - `V_o`：反射光向量。
  - `alpha`：微观面元法线向量与材质平均表面法线向量夹角。
  - `gamma`：微观面元平面的入射角。
- 项目用途：可作为 B2 BRDF 对照/扩展分支。
- 写作边界：当前不进入 Phase 0 Method 主线；不得写成已经完整实现书中五参数模型。
