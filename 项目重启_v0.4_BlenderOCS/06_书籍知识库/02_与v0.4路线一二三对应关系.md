# 《空间目标光学特性原理与应用》与 v0.4 路线一二三对应关系

最后更新：2026-06-18

## 1. 总体定位

本书不是 v0.4 的实验结果来源，而是理论、术语、公式和相关工作背景来源。它可帮助把当前项目从“自建仿真流程”提升到“有空间目标光学特性学科依据的可审计研究”。

## 2. 与路线一的关系

路线一主题：

```text
fixed-roll yaw-pitch 纯仿真可观测性 benchmark
```

可重点参考：

| 章节 | 对路线一的用途 |
|---|---|
| 第2章 空间目标光学散射特性的基本理论 | 支撑 OCS、光度、散射几何、辐射度量、星等/光度表达等基础概念 |
| 第3章 空间目标表面材质散射特性建模 | 支撑 BRDF、材质反射、glint / mismatch 边界的理论背景 |
| 第4章 空间目标非分辨光学散射特性数值模拟技术 | 支撑路线一 OCS 光度向量的数值仿真合理性 |
| 第7章 基于光学散射特性的空间目标识别与姿态分析 | 支撑“光学散射特性可用于姿态相关分析，但需限定条件”的相关工作 |
| 第10章 空间目标光学图像特性分析 | 支撑图像通道位置/姿态估计背景，与 OCS-image 双通道主线衔接 |

路线一使用边界：

- 只引用书中理论和已有方法背景，不声称路线一已经完成真实验证。
- 若书中存在姿态估计案例，需区分其数据条件、传感器条件和是否有真值标签，不能直接平移到 v0.4。
- 重点服务 24 号三问：what can be known / when complementary / when trustworthy。

## 3. 与路线二的关系

路线二主题：

```text
GEO 真实光度数据库作为 sim-to-real 光度锚点
```

可重点参考：

| 章节 | 对路线二的用途 |
|---|---|
| 第2章 空间目标光学散射特性的基本理论 | 支撑真实测光、光度/星等、观测几何与光学散射之间的关系 |
| 第4章 空间目标非分辨光学散射特性数值模拟技术 | 支撑“仿真光度 vs 真实光度”的比较口径 |
| 第6章 基于光度特性的空间目标运动状态分析 | 支撑“光度常用于运动状态/异常/变化分析，而非直接精确定姿”的立论 |
| 第7章 基于光学散射特性的空间目标识别与姿态分析 | 支撑光学散射特性与姿态信息之间存在关联，但需要数据条件和模型边界 |

路线二使用边界：

- GEO 数据库没有三轴姿态真值，不能把书中“姿态分析”泛化为本项目具备监督姿态反演闭环。
- 路线二只能做光度统计、趋势、分布和 sim-to-real gap 锚定。
- 书中光度/运动状态分析内容可用于支持“光度具有状态信息”，但不能直接支持“真实未知目标精确定姿成功率”。

## 4. 与路线三的关系

路线三主题：

```text
暗室缩比独立验证与姿态可控反演闭环
```

可重点参考：

| 章节 | 对路线三的用途 |
|---|---|
| 第3章 空间目标表面材质散射特性建模 | 支撑缩比模型材料与 BRDF / 反射差异的边界分析 |
| 第5章 空间目标光学散射特性实验测量 | 支撑暗室测量系统、实验流程、散射特性测量口径 |
| 第7章 基于光学散射特性的空间目标识别与姿态分析 | 支撑在姿态可控条件下建立验证闭环的理论背景 |

路线三使用边界：

- 暗室实验是地面缩比验证，不是 GEO 在轨望远镜验证。
- 暗室通过只能证明同系统、同缩比条件下的前向保真或小规模姿态闭环，不外推到真实在轨目标。
- 如果缩比模型材料、照明、探测器链路与仿真 gap 不可解释，应降级为 Discussion / Future Work。
