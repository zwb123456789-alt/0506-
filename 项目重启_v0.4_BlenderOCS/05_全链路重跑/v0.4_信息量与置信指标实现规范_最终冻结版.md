## 一、姿态候选集与角距离定义

### 1.1 候选网格（继承 13 号 §4.2 / 00 重跑清单 §1.2）

```text
candidate_grid = { (yaw, pitch) }
yaw   ∈ [0°, 355°], 步长 5°  → 72 个值（0° 与 360° 不重复）
pitch ∈ [-90°, 90°], 步长 5° → 37 个值
N_candidates = 72 × 37 = 2664
```

- 训练 / 反演 / manifest / 候选打分一律用 **2664** 网格。
- 仅绘图 heatmap 复制 0° 为 360°（73 yaw 值），不参与打分，避免重复姿态进入候选集。
- 候选集是 closed grid：所有候选姿态在前向模型下都有 clean 签名（OCS 向量 / image）。这是 closed-grid candidate scoring 的物理前提。

### 1.2 record_id 与候选 id

- `record_id`：继承 14 号 §3.1，格式 `{geom_id}_yaw{yyy}_pitch{ppp}`，是数据记录唯一 key。
- `cand_id`：候选姿态在 2664 网格上的稳定索引，建议 `c{index:04d}` 或直接复用 `yaw{yyy}_pitch{ppp}`。二者映射关系写入 split / manifest 派生表，全流程固定，不随 run 变化。
- query（被反演样本）与 candidate（候选网格姿态）在主线 closed-grid 设定下取自同一网格；§4 的评估边界负责区分"候选鉴别"与"未见姿态泛化"。

### 1.3 角距离 d_ang

姿态以 (yaw, pitch) 表示，定义统一角距离用于 top-k 命中、soft-label、误差统计和混淆分析。

**主用定义（球面/测地角距离，推荐缺省）**：将 (yaw, pitch) 视为方向单位向量

```text
u(yaw, pitch) = [cos(pitch)cos(yaw), cos(pitch)sin(yaw), sin(pitch)]
d_ang(q_i, q_j) = arccos( clip(<u_i, u_j>, -1, 1) )   （单位：度）
```

理由：避免 yaw 在极区（pitch=±90°）的过度计数，且对 yaw 周期性自然封闭。

**备用定义（分量周期距离，仅诊断用）**：

```text
d_yaw   = min(|Δyaw|, 360 - |Δyaw|)
d_pitch = |Δpitch|
d_comp  = sqrt(d_yaw^2 + d_pitch^2)
```

- 主线指标（top-k、误差、Hit@k）一律用 `d_ang`。
- `d_comp` 仅作诊断对照，不进主结果，避免与 `d_ang` 混读。
- **待确认 C8**：是否对 yaw 单一自由度对称几何引入对称等价折叠（symmetry-folding）。默认不折叠（model-known 已知几何下保留全姿态可分性），若几何存在严格对称导致天然不可分姿态，则在混淆图中标注，不在 d_ang 中折叠。

### 1.4 Hit@k 与命中判据

```text
Hit@k_angle(δ) = 1 if min_{c in topk} d_ang(q_true, c) ≤ δ else 0
```

- 主线汇报 `Hit@5°` 与 `Hit@10°`（继承 14 号 summary 习惯，但以 `d_ang` 重新定义，标注角距离口径）。
- top-k 的 k 与角阈 δ 解耦：top-k 取候选数（k∈{1,5,10}），δ 是命中角容差。两者都需在 summary 显式记录。

## 三、反演输出范式：两层结构（CR-SOFT-002 核心）

### 3.1 为什么必须分两层

24 号需要的是"同一候选姿态网格上的**可比 posterior-like 分布**"，用于 entropy / top-k / JS / consistency。这个需求**不等价于**"必须用某个特定网络末层"。R02 CR-SOFT-002 要求先把两件事分开：

```text
层 1 · closed-grid candidate scoring（评估契约层 / 论文口径层）
    给定候选姿态网格，对每个候选输出一个分数 → 归一化为 posterior-like distribution。
    这一层是论文指标的唯一契约：entropy / top-k / margin / JS / consistency 全部在这一层计算。
    OCS-only / image-only / fusion 三个通道都必须输出"同一 2664 网格上的可比分布"。

层 2 · learned model evaluation（实现层 / 模型如何产生分数）
    模型从 OCS 向量 / image / fusion 输入产生候选分数的具体机制。
    可选实现：distance/kernel likelihood、template likelihood、metric learning、
    softmax grid classification、energy score、calibrated regression-to-grid。
    实现可换，只要它能稳定输出层 1 要求的"同一候选网格上可比分布"。
```

**主口径判定准则（照搬 R02）**：主口径以"能稳定输出同一候选网格上可比分布"为准，**不以网络末层形式为准**。

### 3.2 作者已确认的高层范式与主实现族（冻结）

```text
高层范式（冻结）：closed-grid candidate scoring。
    姿态反演建模为"在 2664 已知候选网格上对每个候选打分并排序"，
    不直接回归连续 (yaw, pitch) 标量（回归范式天然无候选分布，无法支撑 §5/§6 指标）。

主实现族（冻结）：distance / kernel likelihood 或 template likelihood。
    在通道特征空间对 query 与候选模板计算相似度/距离，经核函数 + 归一化生成 posterior-like 分布。

增强口径与对照（冻结地位）：softmax grid classification 作为 learned-scoring 增强口径和对照实验，
    不作为唯一主范式。
```

> 高层范式与主实现族已冻结；其下子参数（核/温度/特征/模板来源/阈值）为 phase0 标定项（§0.4），范式不因子参数标定而动摇。

主实现族的优势（与本项目数据结构契合）：

- 不要求训练集覆盖全部 2664 类，天然适配"每姿态每几何一条记录、样本重复度有限"的数据结构（R02 CR-SOFT-002 第 3 点关切）。
- 候选分布直接来自 query 与候选模板的相似度，三通道（OCS/image/fusion）口径统一、可比。
- closed-grid 下模板可直接取自 clean 前向签名，posterior 物理含义清晰。

### 3.3 层 2 候选实现清单

#### 3.3.A 主口径：distance / kernel likelihood + template likelihood

```text
步骤：
1. 取通道特征 φ(·)：
   - OCS_A_L1：对数域 k 维 OCS 向量（特征化见 §5.2）。
   - image：image-only 网络的嵌入向量（penultimate embedding）或模板相关。
   - fusion：拼接/对齐后的联合特征。
2. 候选模板 T(c)：
   - template likelihood（主，待确认 C4）：T(c) = clean 前向签名 φ_clean(c)（OCS 用 clean L1 向量；image 用 clean 嵌入）。
   - 或学习嵌入模板：T(c) = 训练得到的候选 c 的代表向量。
3. 相似度/距离 s(query, c) = -D(φ(query), T(c)) 或 +K(φ(query), T(c))。
4. 经核函数 + 温度 τ 归一化为 posterior-like 分布（§5.3）。
```

适用：OCS-only（k 维向量，距离/核 likelihood 直接可算）、image-only（嵌入 + 余弦/欧氏核）、fusion。

**image template / embedding 来源实现边界（R03 P1-2，必须遵守）**：

OCS_A_L1 模板是闭合的（clean L1 向量直接来自前向模型）。image 侧的 embedding template 尚需以下边界，防止把"未训练网络嵌入"当成已闭合物理签名：

```text
- encoder 必须在每个 split 内单独定义、训练或冻结；不得跨 split 复用泄漏了 test 信息的 encoder。
- query image 与 candidate clean image 必须通过同一 encoder / 同一 feature_config 得到嵌入。
- 不得用 test query 或 test label 信息更新候选模板（模板只能由 train/clean 前向签名构建）。
- clean / degraded 是否共用同一 encoder 必须显式声明（退化实验中 query 退化、模板取 clean，共用 encoder）。
- 降级预案：若 phase0 尚无可靠 learned encoder，则
    (a) image 主口径先降级为 deterministic image signature（如 clean image 的固定特征/相关），或
    (b) 仅保留 image 分支为"待标定项"，OCS_A_L1 的 distance/kernel likelihood 先行闭合，
  先把 OCS 主线跑通，image 主口径在 encoder 就绪后补齐。
- 上述 encoder 配置写入 posterior_spec.feature_space 与 source_data（§11.1）。
```

#### 3.3.B 增强口径与对照：softmax grid classification

地位：**learned-scoring 增强口径 + 对照**，默认纳入主表对照（待确认 C7）。不作为唯一主范式。

若启用 softmax 增强口径，必须**同步定义并记录**以下项（R02 CR-SOFT-002 末段硬要求）：

```text
- split 策略：训练集是否覆盖全部 2664 类；若覆盖，则随机 split 属于 closed-grid candidate
  discrimination，不是姿态外推测试（见 §4 评估边界，必须如实标注）。
- 类别覆盖：n_classes_trained / 2664，未覆盖类别的处理（softmax 无法预测未见类则不得用于
  interpolation/held-out 泛化评估）。
- soft-label：用角距离 d_ang 构造 angular soft-label（邻域候选按 d_ang 衰减赋概率），
  或 label smoothing，缓解 2664 类硬标签丢失姿态流形结构的问题。soft-label 宽度待确认 C9。
- calibration：温度标定（temperature scaling）后再算 entropy/JS/ECE。
- ECE：reliability diagram + ECE，作为 softmax 分布是否可信的校准证据。
```

#### 3.3.C 其它可选实现（列为候选，不强制本轮实现）

- **metric learning**：学习嵌入 + 距离核（与 3.3.A 共享层 1 契约，可视为主口径的学习化变体）。
- **energy score**：能量模型对候选打分，经 softmax-over-grid 归一化。
- **calibrated regression-to-grid**：回归 + 高斯不确定度投影到网格，仅在显式给出投影协方差时允许，否则视为违反"候选分布"契约。

### 3.4 主口径选择条件与对照矩阵

主口径在 phase 0 / 小规模标定后按以下条件确认（范式不变，主口径已定，此处是实现达标校验）：

```text
主口径（distance/kernel likelihood）的 phase0 验收检查（acceptance check，非代码前硬 gate）：
  G1 三通道（OCS/image/fusion）都能输出同一 2664 网格上的归一化分布。
  G2 分布对 closed-grid candidate discrimination 有区分力（top-1 命中显著优于均匀）。
  G3 calibration diagnostic：验证集 reliability diagram / ECE / NLL 作为校准诊断观察。
若 G2 弱或 G3 校准暂不达标，优先排查特征化/核带宽/温度/模板来源（§5），记录为 calibration limitation，
不得据此推翻 closed-grid candidate scoring 范式（R03 P1-1）。
```

> R03 P1-1：G1–G3 是 phase0 验收 / 校准诊断，**不是进入代码阶段的硬 gate**。范式由作者确认冻结，子参数标定不影响范式成立。

最小对照矩阵（同一 split、同一候选网格、同一指标管线）：

| 通道 | 主口径（distance/kernel likelihood） | 增强对照（softmax，待确认 C7） |
|---|---|---|
| OCS-only (A_L1) | 必做 | 可选对照 |
| OCS-only (A_F1 下界) | 必做 | — |
| image-only | 必做 | 可选对照 |
| fusion | 必做 | 可选对照 |

> 所有通道在层 1 输出可比分布；主口径与增强口径的差异只在层 2 如何产生分数。JS / top-k overlap / consistency 只在"同一层 2 口径内"跨通道计算，禁止把主口径 OCS 分布与 softmax image 分布直接算 JS（口径不可比）。

## 四、split 与评估边界

closed-grid candidate scoring 下，"训练用什么、测什么"决定了一个结果到底是**候选鉴别**还是**未见姿态泛化**。R02 CR-SOFT-002 要求把这条边界写清，避免把随机 split 误称为姿态外推。三类评估边界必须分开命名、分开报告：

### 4.1 三类评估边界

| 评估类型 | `eval_boundary` 字段 | 训练/测试关系 | 回答的问题 | 适用口径 |
|---|---|---|---|---|
| **闭网格候选鉴别** | `closed_grid_discrimination` | 训练覆盖候选网格（含 query 姿态本身或其几何/噪声变体）；测试在同一网格上排序 | 在 model-known、候选已知时，通道能否把正确姿态从 2664 候选里挑出 | 主口径 + softmax 均可 |
| **插值/留出姿态泛化** | `interpolation_heldout` | 训练**不含**部分姿态网格点（按 yaw/pitch 留出格点），测试这些留出姿态 | 通道对未训练姿态的内插泛化能力 | 主口径（distance/template likelihood）天然支持；softmax 仅当留出类不参与分类输出时**不适用** |
| **相位/几何分布外移** | `phase_geometry_shift` | 训练用一组 sun/det 几何 / phase，测试移到分布外 phase 或几何 | 观测几何外推下的失效边界（24 号 mismatch 优先项 4） | 主口径 + softmax，均须诚实报告退化 |

### 4.2 命名与诚实声明红线

```text
- 随机 split + 全网格训练 = closed_grid_discrimination，必须如此命名，
  不得宣称为"姿态泛化 / 外推"。
- 只有 interpolation_heldout 与 phase_geometry_shift 可作泛化/外推证据。
- softmax 增强口径若训练未覆盖留出类，则在 interpolation_heldout 下无定义，
  不得强行用 softmax 输出留出类概率（违反 R02 CR-SOFT-002 第 1 点）。
- 每个 run 的 source_data 必须写 eval_boundary 字段，summary 必须显式标注。
```

### 4.3 split 文件与可追踪性（继承 14 号 §5/§6）

- split 文件独立存储（`04_splits/split_{split_id}.json`），含 train/val/test 的 record_id 列表与 `eval_boundary`、`split_seed`、`split_method`。
- 一个 run 通过 `split_id` 引用，不得 latest-run 自动发现（继承 14 号 §7）。
- 增量字段：split 文件新增 `eval_boundary`（enum）、`heldout_grid_spec`（留出格点规格，仅 interpolation_heldout 用）、`shift_spec`（分布外移规格，仅 phase_geometry_shift 用）。

## 五、posterior-like distribution 定义

这是 §6 一切置信/一致性指标的地基。所有通道、所有口径，最终都要落到"2664 候选上的归一化分布 p ∈ Δ^{2663}"。

### 5.1 统一契约

```text
对 query x，通道 m（m ∈ {ocs, image, fusion}），口径 paradigm（distance_kernel / template / softmax / ...）：
  raw score:  z_m(c) = s(x, c)        c = 1..2664
  分布:       p_m(c) = normalize(z_m; τ)   使 Σ_c p_m(c) = 1, p_m(c) ≥ 0
```

`p_m` 是 posterior-like 分布（非严格贝叶斯后验，全程称 posterior-like，遵守 24 号 §15.10 不夸大理论闭合）。

### 5.2 score / 特征空间 / 距离（主口径）

```text
distance/kernel likelihood:
  z_m(c) = K( φ_m(x), T_m(c) ; bandwidth h )
  常用核（待确认 C1，推荐缺省＝高斯核）：
    高斯核   K = exp( -D^2 / (2h^2) )
    学生 t 核 K = (1 + D^2/(νh^2))^{-(ν+1)/2}     （重尾，对离群更稳）
    余弦核   K = exp( cos_sim(φ, T) / τ )          （image 嵌入推荐）

特征 φ_m 与距离 D（待确认 C3）：
  - OCS_A_L1：φ = log1p 域 k 维向量（或 z-score 标准化）；D = 欧氏 / 马氏（用训练协方差）。
  - OCS_A_F1：φ = 标量 log1p；同核，预期分布接近均匀（下界对照）。
  - image：φ = image-only 网络 penultimate embedding；D = 1 - cos_sim 或欧氏。
  - fusion：φ = 对齐后的联合嵌入；D 同 image 口径。

template T_m(c)（待确认 C4）：
  - 主：clean 前向签名（OCS clean L1 向量 / image clean 嵌入）。
  - 备：学习嵌入模板（metric learning 得到的候选代表向量）。
```

### 5.3 归一化、温度与标定

```text
归一化：
  softmax-over-grid:  p(c) = exp(z(c)/τ) / Σ_{c'} exp(z(c')/τ)
  或核归一化:          p(c) = K(c) / Σ_{c'} K(c')

温度 / 带宽标定（待确认 C2）：
  - 缺省：在验证集上以 NLL（负对数似然，对真值候选）或 ECE 最优选 τ / h。
  - 固定备选：τ=1 / h=特征尺度中位数，作为无标定基线。
  - 标定后的 τ/h 写入 summary.calibration。

校准评估：
  - ECE（expected calibration error）+ reliability diagram。
  - calibration diagnostic（非代码前 gate，R03 P1-1）：验证集 ECE 作为校准诊断观察量；
    ECE_thr 仅为 phase0 初始观察值（初值 0.10，仅供观察，不是成败门槛）。
    最终阈值由验证集 reliability diagram、NLL/ECE 曲线和 risk-coverage 结果共同标定。
    ECE 暂不达标时记录为 calibration limitation 并排查 τ/h、特征尺度、模板来源，不推翻范式。
  - softmax 增强口径必须先 temperature scaling 再算 entropy/JS/ECE（§3.3.B）。
```

### 5.4 从分布导出的逐样本指标

对每个 query、每个通道 m，导出并保存：

```text
H_m       = -Σ_c p_m(c) log p_m(c)               posterior-like entropy（自然对数；归一化版 H/log(2664) 另存）
top1_m    = argmax_c p_m(c)                       预测姿态
M_m       = p_m(top1) - p_m(top2)                 top1-top2 margin（概率差）
topk_m    = 前 k 个候选 (cand_id, score, p)        k∈{1,5,10}
err_m     = d_ang(q_true, top1_m)                 逐样本角误差（验证工具，非主中心）
nll_m     = -log p_m(c_true)                      真值候选负对数似然（标定/可观测性用）
```

> H 高 = 分布平摊 = 弱可观测；M 大 = top1 突出 = 强判别。OCS_F1 预期 H 高、M 小（下界），L1 预期更尖锐，这正是 24 号"单几何 vs 多几何信息增益"的量化。

## 六、consistency-as-confidence 指标与拒识规则

这是 24 号科学核心（贡献点 5，"when should we trust"）。核心思想：两个**不同退化源**的通道（口径 A OCS 与 image）若给出一致候选分布，才可作为高置信证据；共模一致（口径 B）不可。

### 6.1 跨通道一致性指标

对同一 query，在**同一层 2 口径内**（见 §3.4 末段约束），计算 image 与 OCS 分布的一致性：

```text
Overlap_k    = |topk_set_img ∩ topk_set_ocs| / k         top-k 候选交叠率，k∈{1,5,10}
JS_img_ocs   = JSD(p_img ‖ p_ocs)                         Jensen-Shannon 散度（对称、有界 [0, log2]）
ang_top1     = d_ang(top1_img, top1_ocs)                  两通道 top1 的角距离
conflict_flag= 1 if (JS_img_ocs > js_thr) and (ang_top1 > ang_thr) else 0   冲突标记
```

- JS 用 log 底 2，落在 [0,1]（log2 归一）便于跨样本比较，记录所用底数。
- `Overlap_k` 与 `JS` 互补：Overlap 看候选集重叠，JS 看整条分布形状。
- **阈值约束（R03 P1-3）**：`js_thr`、`ang_thr` 不是本规范拍板的常数，而是 **validation-calibrated thresholds**，由验证集与 risk-coverage 曲线确定（§6.5）。本规范只冻结指标定义与标定流程，不冻结数值。

### 6.2 单通道置信量（已在 §5.4 导出）

`H_m`（熵）、`M_m`（margin）是单通道置信。consistency 把单通道置信与跨通道一致性聚合。

### 6.3 consistency-as-confidence 综合分

```text
Conf_consist = f(M_img, M_ocs, Overlap_k, -JS_img_ocs)
```

聚合形式（待确认 C5，给两个可执行缺省）：

```text
缺省 1（等权归一加权，推荐起步）：
  Conf_consist = w1·norm(M_img) + w2·norm(M_ocs) + w3·Overlap_k + w4·(1 - JS_img_ocs)
  缺省 w = (0.25, 0.25, 0.25, 0.25)；各项先 min-max / 分位归一到 [0,1]。

缺省 2（验证集学习权重）：
  在验证集上以 "Conf_consist 与 (1 - 正确性) 的负相关 / risk-coverage AUC" 为目标学 w。
```

### 6.4 解释规则（照搬 24 号 §10.3，作硬约束）

```text
- image 与 OCS 高一致 + 候选集中           → 高置信。
- image 高置信、OCS 低置信                 → 检查 OCS 是否本身不可观测（看 H_ocs / 该姿态 observability）。
- OCS 高置信、image 低置信                 → 检查图像退化 / 空间结构弱。
- image 与 OCS 高冲突（conflict_flag=1）   → 不强行输出姿态，标记低置信 / 模型失配。
- image-derived OCS_B 与 image 高一致      → 必须额外检查 common-mode failure，不可直接判高置信（§6.6）。
```

### 6.5 reject / low-confidence 规则

```text
low_confidence_flag = 1 if (Conf_consist < conf_thr) or (conflict_flag = 1) or (H_fusion > H_thr) else 0
reject_decision     = 1 if low_confidence_flag else 0
```

阈值标定（待确认 C6；全部为 validation-calibrated thresholds，R03 P1-3）：

- `js_thr` / `ang_thr` / `conf_thr` / `H_thr` / coverage 工作点**均为验证集与 risk-coverage 曲线确定的参数**，不是作者现在拍板的常数。
- 缺省按目标 coverage 反推阈（如保留 80% 样本时的 Conf_consist 分位）。
- 备选按 risk-coverage 工作点（选定可接受错误率下的最大 coverage）。
- 必须产出 **risk-coverage 曲线**（横轴 coverage，纵轴保留样本的角误差/错误率），作为 consistency-as-confidence 是否成立的主证据。

> 硬约束（R03 P1-3）：所有 reject/conflict 阈值均为 validation-calibrated thresholds；本规范只冻结指标定义、保存字段和标定流程，不冻结数值阈值。不得把"还没跑出来的论文结论"伪装成"代码前已知参数"。

### 6.6 口径 B common-mode 对照（禁止混用）

```text
- 跑一组 ocs_channel="B_image_derived" 的 consistency：OCS_B 从（退化）image 孔径测光得到。
- 对照量：Corr(err_ocsB, err_img)、JS_imgB_vs_img、common-mode consistency 在退化下是否"假高一致"。
- 结论方向：若退化下 OCS_B 与 image 仍高一致但同时高错误 → 证明 common-mode 一致 ≠ 可信，
  反衬口径 A（独立通道）一致性的价值。
- 硬约束：A 与 B 的 consistency 结论不得画在同一张结论图、不得合并统计（§2.1 assert）。
```

## 七、可观测性（observability）指标

回答 24 号"what can be known"。优先离散网格稳健指标（R02 CR-SOFT-004：离散指标保底，不依赖可微性）。

### 7.1 签名空间离散指标（不需梯度）

对每个候选姿态 c 的 clean 签名（OCS clean L1 向量 / image clean 嵌入），在签名空间计算：

```text
pairwise_signature_distance:  D_sig(c_i, c_j) = ||φ(c_i) - φ(c_j)||
nearest_neighbor_ambiguity(c) = min_{c'≠c} D_sig(c, c') ／ 局部签名差/角距离比
                                = "签名空间挨得多近但姿态差多远" → 小则易混淆
top_k_confusion(c)           = 与 c 签名最近的 k 个候选里，d_ang > δ 的比例（高 = 混淆）
posterior_like_entropy(c)    = §5.4 的 H，在 clean（无退化）下逐候选评估
```

### 7.2 可观测性地图（主图）

```text
- OCS-only 可观测性地图（基于 L1 多几何向量）：在 (yaw, pitch) 网格上画 H_ocs / ambiguity。
- OCS 单几何信息下界地图（F1）：对照说明单瞬时标量约束不足。
- image-only 可观测性地图。
- 姿态混淆图（confusion map）：标出天然不可区分姿态簇。
- 观测几何信息量地图：跨 sun/det 几何评估哪些几何最能压低 ambiguity（支撑 observation planning，对接作者观测规划小项目）。
```

### 7.3 互补性（complementarity，"when complementary"）

```text
- OCS/image 误差互补图：err_ocs 与 err_img 的逐姿态对照（谁在哪赢）。
- top-k overlap / disagreement map（§6.1 的 Overlap_k / JS 在姿态空间铺开）。
- branch masking：屏蔽某通道看 fusion 退化，定位主导通道（继承 24 号 §6.2）。
- OCS noise monotonicity：OCS 噪声递增时 fusion 性能单调性（机制诊断）。
- modality attribution：fusion 决策中 OCS/image 贡献归因。
```

> observability/complementarity 是 §6 consistency 的前置：解释"OCS 低置信"时要能回看该姿态本身是否可观测（§6.4 第 2 条）。

### 9.2 Δθ 敏感性分析（明确标注为离散后处理，非时域仿真）

R02 CR-SOFT-003 硬要求：Δθ 敏感性是**离散敏感性后处理**（网格邻域/插值），**不得写成完整时域光变仿真**。本规范据此定义：

```text
L1_quasi_static_sensitivity:
  目的:        量化"窗口内姿态漂移 Δθ"对 L1 可观测性的破坏边界。
  perturbation_deg: [0, 1, 2, 5, 10, ...]   （扫描列表，待确认 C10）
  construction:  grid-neighbor（用网格邻域姿态近似漂移分量）
               | interpolation（对签名插值）
               | regenerated-forward-pass（重生成前向签名，成本最高，可选）
  做法:         构造姿态 q 的 L1 向量时，让 k 个几何分量分别取自 q + 微扰（模拟漂移 Δθ），
               观察指标随 Δθ 退化。
  metric:       entropy / top-k confusion / nearest-neighbor ambiguity / consistency decay。
  产出:         "L1 对姿态漂移的鲁棒性边界图"——回答"漂移多大破坏 L1 有效性"，
               给出 quasi-static 假设的定量适用窗口。

  cost:         主线离散网格数据集上即可计算（grid-neighbor/interpolation 路径零额外渲染；
               regenerated-forward-pass 路径需补渲染，列为可选）。
```

> 写作纪律：成本表述从"零额外数据"收紧为"grid-neighbor/interpolation 路径零额外渲染"。审稿语境下绝不声称"已模拟真实自转光变"。

## 十、FIM / CRLB 降级-稳定-升级策略（CR-SOFT-004，可选升级层，非代码前 gate）

### 10.1 定位（硬约束）

```text
- FIM/CRLB 不是进入代码的硬 gate。代码可在不实现 FIM 的情况下推进。
- 主可观测性证据来自 §7 离散候选网格指标（降级档，几乎必达）。
- FIM/CRLB 仅作可选升级层；只在可微性/数值稳定性验证通过的光滑姿态子集报告，
  作局部理论佐证，不作全文理论主轴。
- 遵守 24 号 §15.10：不把 FIM/CRLB/conformal prediction 写成已闭合的强理论结果，
  除非后续实现与验证支撑。
```

### 10.2 三层策略

```text
降级（起步，近 100% 拿到）：
  不写 FIM/CRLB。用 §7 离散稳健指标：pairwise signature distance、
  nearest-neighbor ambiguity、top-k confusion、posterior-like entropy。
  术语用 "Fisher-like local sensitivity / local observability score"，不碰 CRLB 强声明。
  → 足以支撑 observability 主体论证。

稳定（中间，验证可微性 —— 这是闸门）：
  在 visibility / shadow mask / 边缘像素 / GGX 镜面峰附近检验数值梯度 ∂s/∂q 是否稳定。
  方法：soft visibility / soft shadow 平滑替代，或局部多次差分看收敛。
  非光滑源（13 号已知）：camera visibility 阶跃、V_sun_macro∈{0,1} 阴影边界阶跃、
  边缘像素 fractional coverage（13 号 §6.5 舍弃）、GGX 峰梯度陡。
  → 梯度稳则放行升级；不稳则停在降级档并诚实声明"局部不可微，采用离散稳健指标"。
    该可微性检验本身即可写为方法贡献。

升级（目标，有条件，大概率仅部分姿态子集）：
  仅当梯度验证稳定，才把局部敏感度升级为正式 FIM：
    FIM(q) = (∂s/∂q)^T Σ^{-1} (∂s/∂q)
    CRLB:    Cov(q̂) ⪰ FIM(q)^{-1}
  用于 observation planning 的 D-optimality / 信息量地图理论判据。
  必须标注：仅覆盖"几何光滑、无阴影遮挡、远离镜面峰"的姿态子集，
  阴影/自遮挡/强 glint 区不覆盖。
```

### 10.3 可采纳写法（照搬 R02）

```text
FIM tier is optional and conditional.
The main observability evidence is based on discrete candidate-grid metrics.
FIM/CRLB is reported only where differentiability and numerical stability are verified.
```

### 10.4 与 observation planning / 投稿的咬合

FIM 升级档是冲刺更高目标的**加分项**，不是底线档的入场券：observation-geometry 信息量地图用 §7.2 离散指标即可成立；FIM 跑通则给该地图加理论外衣，对接作者观测规划小项目（24 号科学新颖性三段承重墙之一）。跑不通不影响主线成立。
