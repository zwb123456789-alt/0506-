## 1. 背景与本轮问题

作者拟并行推进：路线一主干代码工作正常进行，同时先把属于旧版本的路线零（v0.3 已完稿）投出去作为保底 SCI。

本轮要回答：

```text
1. 路线零（旧 v0.3）现实可投什么等级的刊
2. 需要做哪些调整才能投
3. 顺带明确四路线各自可发刊层级
```

## 2. 路线零核心矛盾（不能原样投）

封存原因不是文字问题，而是数据源口径硬伤（见 `01_v0.3封存/00_v0.3封存说明.md` §2）：

- 主反演 + 补充实验全部依赖**模块 A 的 face-center OCS 扫描表**。
- v0.4 的 Blender 逐像素 OCS 没有进入旧主数据生成链。
- 已有 A/B 一致性记录显示差异**可能影响 OCS-based inversion 与 fusion 机制解释**。

这命中解封评估 E1（`03_项目说明与规划材料/01_写作规划/00_发刊路线规划与旧文评估说明.md` §3）：
若 face-center OCS 影响核心结论，就不能原样投。封存说明 §5"需替换内容"几乎覆盖旧稿全部 OCS/fusion 卖点（OCS-only、heatmap、ResNet-fusion、12b/c/f/g、OCS 噪声、分支遮蔽、beta sweep、source-data consistency）。

结论：**路线零不能原样投。** 关键问题不是"能发什么刊"，而是"愿意为它做多大调整"——调整量决定落档。

## 3. 三种处置方案

| 方案 | 改动量 | 可投层级（学校认定） | 风险 |
|---|---|---|---|
| **A. 收窄 claim，做"旧口径 benchmark / technical note"** | 小：删除/降级所有受 OCS 口径影响的强结论，OCS 部分降为"face-center 近似下的初步观测"，主卖点改为 image 通道 + 受控仿真框架 | 二类 B / 基本 SCI（Acta、ASR、IM 或稳健 SCI 源刊） | 中：审稿人可能质疑 OCS 近似物理意义，需诚实声明 |
| **B. 用 v0.4 Blender OCS 重跑替换旧结果** | 大：等于做掉部分路线一工作（E3） | 同路线一（二类 B→二类 A） | 失去"先保底投"的时间优势，与"并行发路线零"意图冲突 |
| **C. 彻底剥离 OCS，只发 image-only 受控反演** | 中：去掉所有 fusion/OCS 章节，只留 clean-image upper bound → degradation fragility | 基本 SCI / 二类 B 下沿 | 创新性下降，可能被嫌单薄 |

作者意图（并行、先保底）与方案 B 直接冲突。现实选择在 A 或 C 之间。

## 4. 推荐方案：A，目标 Acta / ASR（二类 B）

理由：

1. 旧稿本就按 Acta/ASR 第一档润色，结构、Cover Letter、降调措辞已齐（`04_四路线分工区/00_旧路线投稿/01_成果区/03_投稿策略_三档路线_v20260604.md` §2）。
2. 改动可控，不抢占路线一的 Blender OCS 重跑工作。
3. Acta/ASR 对"受控仿真 benchmark + 无真实望远镜验证"接受面较友好。

### 最小调整清单（待逐条落实，动正文前需作者确认）

```text
1. OCS 口径声明：Methods 明确"本文 OCS 为 face-center 近似口径"，说明其与逐像素方法的差异与局限。
2. 降级受影响结论：封存说明 §5 所列 OCS-only / fusion / heatmap / 12b-g 数值，降为"face-center 近似下初步观测"或移入 Limitation。
3. 重设主卖点：主线改为 image-channel 受控反演 + 物理一致仿真框架，OCS 作为补充观测而非核心结论支柱。
4. 自我抄袭 / claim 冲突检查（E5）：与路线一未来论文划清边界，避免数据重复。
5. 预警期刊核验：投稿前查 Acta / ASR 是否在中科院预警名单。
```

## 5. 四路线发刊层级速览

| 路线 | 现实可投档 | 强结果上探 |
|---|---|---|
| 路线零（旧 v0.3，方案 A） | 二类 B（Acta / ASR / IM） | 不上探，定位保底 |
| 路线一（纯仿真主干） | 二类 B（Acta / ASR） | 二类 A（TAES / TGRS / AIAA / AST），需可观测性/互补性/置信一致性/mismatch 闭合充分 |
| 路线二（GEO 真实光度锚点） | 二类 A | 一类 B（NSR / Engineering 等），需真实光度 pilot 成功 |
| 路线三（暗室真实闭环） | 二类 A | 一类 B，需暗室 pilot + 姿态真值闭环成功 |

学校认定层级依据见 `03_项目说明与规划材料/01_写作规划/01_学校认定论文表解读_投稿依据.md`。

## 6. 红线复核

- 不把 v0.3 旧稿直接恢复为投稿稿；必须先解封评估再决定调整。
- 不混用旧模块 A face-center OCS 与 v0.4 Blender-derived OCS 作为同一结果链。
- 不声称真实望远镜验证、field-proven、operational-ready。
- 路线零不阻塞路线一/二/三；并行推进，证据强度各自定档。
