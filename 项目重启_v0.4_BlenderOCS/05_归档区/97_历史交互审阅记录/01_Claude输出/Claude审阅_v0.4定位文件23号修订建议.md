## 二、修订建议

### 建议 1〔中等，建议落笔〕mismatch 优先项与所引复审依据的账面不一致

**问题。** 23 号第十一节自称依据"19 号 clean-sim 杀手判断"，但实际选项与之偏离：

- 19 号原文（判断四，第 298 行）的三个 clean-sim 杀手是：**Earthshine / glint+饱和 / 湍流 PSF**。
- Claude 复审 3.3 建议把这三个提回主线作为 mismatch 设计依据。
- 23 号第十一节实际列的 4 个优先项是：**BRDF/glint mismatch / 图像退化·PSF / 观测链饱和·gain-offset·background / phase shift**，并把 **Earthshine 降入"保留但不主攻"**。

这一调整**结论上合理**：Earthshine 需二次照明（global illumination 多次反弹）保真度，与 L2 同属"保真度负担大、本轮推迟"的逻辑；而 BRDF mismatch 与 phase shift 在 model-known + 口径 A + 纯仿真条件下确为核心，且 v0.3 已实证 phase120≈80° 为失效边界、BRDF 是 OCS 外场 gap 主源。问题只在于：**23 没有解释为何偏离自己引用的"三杀手"**，会让 Codex 同步与后续审稿对不上账，也容易被误读为遗漏。

**建议改法。** 在第十一节"当前主线优先测"列表之前，补一段重筛说明：

```text
本轮 mismatch 优先项在 19 号"三个 clean-sim 杀手"（Earthshine / glint+饱和 / 湍流 PSF）
基础上，按 model-known + 独立光度通道口径 A + 可纯仿真三项约束重新筛选：
- 保留 glint+饱和、湍流 PSF（对应下方 1/2/3 项），它们纯仿真即可施加且直击 OCS/image 失败模式；
- 新增 BRDF mismatch 与 phase / observation geometry shift（下方 1/4 项），
  二者在 model-known 纯仿真下是核心边界，且已有 v0.3 证据（phase120 失效、BRDF 为 OCS gap 主源）；
- Earthshine 因需二次照明（secondary illumination / 多次反弹）保真度负担，
  与 L2 时域光变曲线一并推迟到 19 号 / Future Work，不进本轮主攻。
```

同时把第十一节"保留但不主攻"列表中确认含 Earthshine（现已含），并在第十三节"19 号只吸收原则"第 5 条后补一句：Earthshine 属推迟项，不在本轮 mismatch 优先级内。

### 建议 2〔轻微，可选〕"明确排除"措辞与 L2 处置有张力

**问题。** 第 121-127 行的形态表把 L2 与 F1/F2 并列于"明确排除"标题下，但 9.5 节与第十三节均将 L2 表述为"保留到 Future Work"。L2 不是被否定，而是被推迟，与 F1（仅作下界基线）、F2（仅作 semi-oracle 上界）的处置语义不同。

**建议改法。** 将该表标题"明确排除"改为"非主线形态及处置"，并把 L2 行的结论列措辞由"保留到 Future Work / 19 号保真度路线，不并入本轮主线"维持不变即可（标题改后语义自洽）。F1/F2 行措辞不动。

### 建议 3〔轻微，可选〕F3 上位概念在 23 中消失

**问题。** 22 号用 F1/F2/**F3** 三层辨析，F3（多样本序列）再分 L1（跨几何）/ L2（跨时间）。23 号直接用 L1/L2 替换 F3，未出现 F3 字样。不算错——L1 本就是 F3 的跨几何实例——但读过 22 号的人会短暂找不到 F3 与 L1/L2 的归属关系。

**建议改法。** 在第 121-127 行形态表下方补一行脚注：

```text
注：L1/L2 同属 22 号文件中的 F3（多样本序列）形态，分别对应跨几何与跨时间两种采样。
```
