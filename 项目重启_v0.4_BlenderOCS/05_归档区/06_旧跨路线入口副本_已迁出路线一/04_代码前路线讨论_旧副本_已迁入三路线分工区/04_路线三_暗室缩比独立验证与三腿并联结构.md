## 2. 暗室约束的精确含义（路线三的事实地基）

### 2.1 暗室与 GEO 是两个互不连通的真实数据源

暗室所用相机、缩比模型、光源都不属于 GEO 数据库那套系统。两者之间没有共享目标、共享设备、共享定标。这条约束**必须诚实写进论文当红线**，否则会被一票否决。

### 2.2 暗室不能做的事（红线，越界即被一票否决）

| ❌ 禁止 | 原因 |
|---|---|
| 用暗室验证 GEO 数据库那批在轨目标的反演 | 两者目标不同，暗室通过不能传递到 GEO 目标 |
| 把暗室光度与 GEO 实测光度直接对比、互相印证 | 相机、定标、目标全不同，对比无物理意义 |
| 声称"暗室反演通过 → GEO 在轨目标反演也成立" | 这条 sim-to-real 传递链根本不存在，是断的 |
| 把暗室缩比结果写成"真实在轨望远镜验证" | 暗室是地面缩比，不是真实在轨链路 |

### 2.3 暗室能做的事（这才是暗室的真实价值）

| ✅ 能做 | 怎么用 | 价值 |
|---|---|---|
| 自洽闭环的独立前向保真验证 | 同一套（暗室相机+模型+光源），仿真它、又实测它，在这套系统内验证 v0.4 前向模型对不对 | 在真实光度上验证前向模型，不靠"仿真逼真实精度"，靠"同系统内仿真 vs 实测一致" |
| 真实姿态可控的监督反演闭环 | 暗室能摆**已知姿态** → 仿真+实测 → 反演 → 用已知姿态真值算**真实成功率** | GEO 数据库做不了（无姿态真值），这是反演主轴唯一能在真实光度上闭环的地方 |
| roll-aware / 三轴真实闭环 | 暗室姿态完全可控，可摆任意三轴姿态（含 roll≠面姿态） | 路线一/二守 fixed-roll，暗室纳入 roll 是路线三**独特增量** |

### 2.4 暗室的正确定位（一句话）

```text
暗室不是"GEO 数据链的延伸"，而是"一条平行的、姿态可控的、自洽的真实验证腿"。
它证明的是方法论本身在真实光度下成立（前向模型可信 + 反演可行），
而不是"某批在轨目标的反演成立"。
这个价值不依赖暗室与 GEO 连通，只依赖暗室自己姿态可控、自成体系。
```

## 3. 三腿并联结构（路线三的核心立论）

### 3.1 三腿各司其职总表

| 腿 | 数据性质 | 姿态真值 | 独立证明什么 | 边界 |
|---|---|---|---|---|
| **v0.4 纯仿真** | 合成 | 网格已知（但是仿真生成的标签） | 大规模可观测性地图：what can be known / when complementary / when trustworthy | observation-consistent synthetic forward model，非真实验证 |
| **GEO 真实数据库** | 真实在轨 | **无**（非合作目标姿态本就不可得） | 真实在轨光度统计特性、多几何现实性（破法 C）、"光度只能告警"的工程实证 | 有光度/几何/型号/时序，但无姿态真值，闭不了监督反演 |
| **暗室缩比实验** | 半真实（地面缩比） | **有**（姿态完全可控，含 roll） | 前向模型保真度（同系统仿真 vs 实测一致）+ 真实姿态可控的监督反演闭环（算真实成功率，纳入 roll） | 相机/模型/光源全独立于 GEO，自成体系，不可向 GEO 目标传递；是地面缩比，非真实在轨链路 |

### 3.2 为什么是"并联"而不是"串联"——以及为什么并联更抗审稿

```text
串联传递链（脆弱）：
v0.4 仿真 → GEO 校准 → 暗室验证 → 声称在轨反演成立
任何一环不可信 → 整条链崩 → 论文被一票否决。

并联互补结构（鲁棒）：
v0.4 纯仿真   ┐
GEO 真实数据库 ├→ 各自独立证明一个侧面 → 合起来支撑论文
暗室缩比实验   ┘
任何一腿弱化 → 只损失该侧面的强度 → 其余两腿仍独立成立。
```

并联结构的抗审稿优势：

1. **无单点失效**：不存在"中间环节不可信导致全链崩"的风险。审稿人攻击某一腿，最多削弱该侧面，不能一票否决整篇。
2. **职责清晰、不互相牵连**：v0.4 管规模与可观测性地图，GEO 管真实在轨统计与多几何现实性，暗室管前向保真与反演闭环。审稿人无法用"A 腿的弱点"否定"B 腿的结论"。
3. **各腿的局限恰好被另一腿补上**：
   - v0.4 缺真实性 → GEO 与暗室补真实光度。
   - GEO 缺姿态真值（闭不了反演）→ 暗室姿态可控，补上反演闭环。
   - 暗室缺在轨真实性与规模 → v0.4 补规模，GEO 补在轨统计现实性。
4. **诚实边界天然成立**：因为三腿不串联，论文不需要声称"暗室通过 → 在轨成立"这类危险传递，所有 claim 都落在各腿自己证明的范围内。

### 3.3 三腿与专家"收窄到一个方向"建议的关系

专家建议把"前向+仿真+反演三位一体"收窄到一个方向。三腿并联结构的回应是：

```text
专家"收窄"的正确解读不是"砍到只剩一条腿"，
而是"砍掉过度膨胀的、跨腿传递的应用 claim"。
三腿并联恰好做到了这一点——每条腿只声称自己能证明的，不做跨腿危险传递。
科学问题仍聚焦于一个：model-known 条件下 OCS/image 姿态信息的可观测性、互补性与置信一致性（24 号主线）。
三腿是支撑这一个科学问题的三类证据，不是三个互相竞争的应用方向。
```

## 4. 暗室双主轴展开（保真验证 + 反演闭环）

按作者确认，暗室在路线三里承担**保真 + 反演双主轴**，二者在同一套自洽系统内一起做。

### 4.1 主轴一：前向模型保真度验证（同系统仿真 vs 实测）

**目标**：在真实光度上验证 v0.4 统一前向物理模型对不对，但**不靠"仿真逼近真实绝对精度"**（这条走不通，与路线二 §3.1 同理），而靠"同一套系统内仿真 vs 实测一致"。

**可做的验证设计（仅设计，不进代码）**：

1. 在暗室摆已知姿态的缩比模型，用已知光源几何，用暗室相机实测光度/图像。
2. 用 v0.4 前向模型仿真**同一缩比模型、同一姿态、同一光源几何**下的光度/图像。
3. 对比仿真 vs 实测的分布、量级、随姿态/几何变化的趋势。
4. 报告一致区与失配区，失配归入 mismatch 边界（缩比材料 BRDF 未知、暗室杂散光、相机定标差异等）。

**与路线二保真验证的区别（关键）**：

| | 路线二 GEO 保真 | 路线三暗室保真 |
|---|---|---|
| 数据源 | 真实在轨 GEO 光度 | 暗室缩比实测 |
| 姿态 | 无真值（只能比统计分布/趋势） | **有真值**（可比同姿态点对点，更强的保真证据） |
| 几何 | 反算得到，精度待验证 | 暗室可控、可测，几何已知 |
| 边界 | sim-to-real gap（材料/定标/大气） | 缩比 gap（缩比材料/暗室杂散光/缩比尺度效应），但**无大气、无在轨链路不确定性** |

暗室保真因为姿态、几何都可控，能做**点对点（同姿态同几何）的仿真 vs 实测对比**，比 GEO 只能比统计分布更强。但暗室是缩比，有缩比尺度与材料近似的边界。

### 4.2 主轴二：真实姿态可控的监督反演闭环（算真实成功率，纳入 roll）

**目标**：在真实光度上做监督反演闭环——这是 GEO 数据库做不到的（无姿态真值），也是路线一/二做不到的（纯仿真 + 真实数据无真值）。

**为什么只有暗室能做**：

```text
监督反演需要姿态真值来算成功率。
v0.4 纯仿真：有真值，但是仿真标签，不是真实光度。
GEO 真实库：是真实光度，但无姿态真值。
暗室缩比：既是真实光度（实测），又有姿态真值（可控摆放）——唯一同时满足两条的腿。
```

**可做的反演闭环设计（仅设计，不进代码）**：

1. 在暗室按已知姿态网格（含 roll，路线三独特增量）摆放缩比模型，实测真实光度/图像。
2. 用这些**真实实测数据**做姿态反演（OCS-only / image-only / fusion）。
3. 用已知姿态真值算**真实成功率 / 真实误差**——这是在真实光度上的反演性能，不是仿真自评。
4. 与 v0.4 纯仿真反演结果对比：检验"仿真上可观测/可反演的姿态信息，在真实光度上是否仍可提取"。

**roll 纳入是路线三的独特增量**：

```text
路线一：fixed-roll（roll 只做敏感性探针，主实验 roll=0）。
路线二：fixed-roll（继承路线一，真实数据无姿态真值也做不了 roll 反演）。
路线三暗室：姿态完全可控 → 可摆任意三轴姿态（含 roll≠面姿态）→
           在真实光度上做 roll-aware / 三轴反演闭环，
           这是前两腿物理上做不到的能力。
```

这条增量直接回应路线一 §8 与 CLAUDE.md 03 号待决：roll 不再只是"敏感性探针 + 资源估计"的承重墙搪塞，而是在暗室这条腿上**真实闭环验证**——虽然规模受暗室实验工作量限制，但性质上是真实三轴反演证据。

### 4.3 反演降级原则仍然成立（与 24 号一致）

即使暗室能算真实成功率，路线三仍**不把反演成功率当应用终点**，而当**可观测性的真实验证工具**（与 24 号 §八、路线二 §3.3 一致）：

```text
暗室反演回答的是：
"仿真上声称可观测/可反演的姿态信息，在真实光度上是否真的可被估计器提取出来？"
而不是："反演成功率有多高、能不能部署到真实在轨目标？"
后者被三腿边界明确排除（暗室不可向 GEO/在轨传递）。
```

## 6. 逐一回应专家三方向质疑（路线三视角）

路线三在路线二的回应基础上，补上 GEO 数据库补不了的那一块——**反演闭环**。

### 6.1 方向一：前向模型统一

路线二已用 GEO 真实光度做统计校准。路线三再加一层：暗室因为姿态/几何可控，可做**点对点（同姿态同几何）仿真 vs 实测保真验证**，比 GEO 统计对比更强地坐实"前向模型正确性"。两层叠加：GEO 给在轨统计一致性，暗室给可控点对点一致性。

### 6.2 方向二：仿真

专家质疑"固定姿态无说服力""仿真不真实"。路线三的回应：

- 仿真不真实 → 暗室在真实光度上做点对点保真验证（除 GEO 统计校准外的第二重背书）。
- 固定姿态无说服力 → 暗室姿态可控，**纳入 roll 做真实三轴反演闭环**，直接证明方法不依赖固定姿态。这一刀在路线一/二只能用"受控研究设计 + roll 探针"软化，在路线三可用**暗室真实三轴闭环数据**硬回应。

### 6.3 方向三：反演

专家最强偏好"反演需真实闭环 + 主攻成功率"。路线二诚实承认：GEO 数据无姿态真值，监督反演闭环不可行。**路线三补上这一块**：

```text
暗室姿态可控 → 有真值 → 可做真实光度上的监督反演闭环 → 可算真实成功率。
这正面回应了专家"反演要真实闭环"的方向，
且因为暗室自洽，不需要"仿真逼真实"也能闭环。
```

但仍守红线：暗室反演成功率是**暗室自己系统内的真实反演性能**，不可外推为"GEO 在轨目标反演成功率"。专家的方向被满足，但 claim 被边界严格限定。

### 6.4 多几何质疑

路线二破法 C（GEO 真实数据固有多几何）仍主用。路线三补充：暗室可控光源/视角，能**主动设计多几何**做受控多几何反演验证（暗室里多几何是可控制造的，不是高成本同步观测）。但需诚实：暗室多几何是地面可控制造，GEO 多几何是真实在轨固有结构，两者性质不同，分别叙述。

## 7. 路线一 vs 路线二 vs 路线三 多维度对照

此处"路线三"指**路线一 + 路线二 + 路线三**的三腿并联合体形态。

| 维度 | 路线一（纯仿真可观测性） | 路线一 + 路线二（叠加 GEO 真实光度锚点） | 路线一 + 二 + 三（再叠加暗室独立验证腿） |
|---|---|---|---|
| 学位稳健度 | 高 | 高且更稳 | 最稳。三腿任一弱化不致全崩 |
| 发刊上限 | 现实落点偏稳健 SCI | 主攻冲刺档够得着 | 主攻冲刺档稳，并为更高档上探留口（真实反演闭环是稀缺证据） |
| 反演真实闭环 | 无（纯仿真自评） | 无（GEO 无姿态真值） | **有（暗室姿态可控，唯一能在真实光度算成功率）** |
| roll / 三轴 | fixed-roll + 探针 | fixed-roll | **暗室纳入 roll，真实三轴反演闭环** |
| 代码/实验成本 | 中等，单卡可全量 | 中等偏高（几何反算+型号匹配+校准） | 高（新增暗室实验：搭台、定标、实测、缩比建模），但反演规模不增 |
| 答辩/审稿最可能质疑 | 纯仿真凭什么说现实/固定姿态/多几何 | 校准充分性/失配边界诚实性 | 暗室缩比代表性/暗室与在轨的 gap/缩比尺度效应 |
| claim 一票否决风险 | 中 | 低 | 最低。三腿并联无单点失效，反演有真实闭环背书 |

**核心差异**：路线三买的是**反演真实闭环 + roll-aware 三轴能力 + 三腿无单点失效的抗审稿结构**，代价是暗室实验的真实工作量（搭台、定标、实测、缩比模型建模）与缩比代表性边界。

## 8. 暗室与小项目（最亮构型 / roll-aware）的衔接

路线一 §8 指出小项目（最亮构型搜索）本质是三维问题，`roll=0` 切片最亮点在答辩中是硬伤，必须 roll-aware。路线三暗室的 roll-aware 能力正好衔接：

```text
大论文 roll 探针（路线一）+ 暗室 roll-aware 真实反演闭环（路线三）
→ 喂给小项目的 roll-aware 最亮构型搜索。
暗室还能为小项目提供"最亮构型"的真实光度验证：
在暗室摆出仿真预测的最亮姿态，实测验证它是否真的最亮。
```

两者解耦但衔接：暗室不替小项目做全部工作，但为小项目的 roll-aware 与最亮构型结论提供真实光度锚点。

## 9. 路线三风险与最低可接受补强

### 9.1 风险

- **暗室缩比代表性**：缩比模型材料 BRDF、表面工艺与真实卫星不同，缩比尺度效应可能影响光度行为，保真结论有缩比 gap。
- **暗室定标与杂散光**：暗室相机定标、杂散光控制、光源稳定性影响实测光度质量。
- **暗室工作量**：搭台、定标、按姿态网格（含 roll）实测、缩比模型建模，工作量大，可能拉长周期。
- **暗室 vs 在轨 gap**：审稿人会问"暗室缩比能代表在轨吗"——必须诚实写成"地面缩比验证方法论，不代表在轨性能"。
- **三腿叙事复杂度**：三腿并联需在论文里讲清各腿职责与边界，讲不清会被审稿人误读为"串联传递"而打掉（同路线二 §4.1 措辞警告）。

### 9.2 最低可接受补强

若采用路线三，进入正式工作前至少规划：

1. 路线一 H1-H5 硬补丁先完成，路线一独立成立。
2. 暗室可行性 pilot：先用 1 个缩比模型、少量姿态（含 1-2 个 roll≠面姿态）做端到端管线验证（实测→仿真→保真对比→反演），仅验证管线通不通，不全量。
3. 暗室保真 sanity check：同姿态同几何下仿真 vs 实测光度，看是否在可解释范围，再决定姿态网格规模。
4. 暗室反演 pilot：小规模姿态网格做监督反演，看真实成功率是否合理，再决定 roll 网格密度。
5. mismatch 边界诚实预案：缩比 gap 大就明确写成 scale-model gap 边界，不强行声称代表在轨。
6. 守红线：暗室结果只写"方法论在真实光度上成立（前向可信+反演可行）"，绝不写"暗室通过→GEO/在轨反演成立"，绝不与 GEO 实测光度直接互证。

## 10. 暂定结论

```text
路线三暂定为：
作为路线一、路线二之外的第三条独立验证腿（非串联延伸、非 GEO 数据链延伸）；
暗室是一套完全独立的新实验系统（独立相机+模型+光源），与 GEO 互不连通；
暗室承担保真+反演双主轴：同系统点对点保真验证 + 姿态可控监督反演闭环；
暗室纳入 roll，做路线一/二做不到的真实光度三轴反演闭环（路线三独特增量）；
三腿（v0.4 纯仿真 / GEO 真实库 / 暗室缩比）并联互补、无单点失效，比串联 sim-to-real 链更抗审稿；
专家三方向质疑：前向/仿真由 GEO+暗室双重背书，反演方向由暗室真实闭环正面满足（但 claim 严格限定不可外推在轨）。
```

本结论仅为"路线三"候选，与路线一、路线二候选并列，供后续多路线统一比较：

- 学位大论文是否更稳：三腿并联最稳，任一腿弱化不致全崩。
- 发刊上限是否更高：暗室真实反演闭环是稀缺证据，把上限顶到主攻冲刺档稳态并留更高上探口。
- 代码与实验成本是否可承受：暗室新增真实实验工作量大（搭台/定标/实测/缩比建模），但反演规模不增；需评估周期。
- 答辩老师与审稿人最可能质疑什么：暗室缩比代表性、暗室与在轨 gap、缩比尺度效应、三腿是否被误读为串联。
- 哪条路线最不容易在 claim 上被一票否决：三腿并联 + 暗室真实闭环 + 诚实边界，最难被一票否决。
