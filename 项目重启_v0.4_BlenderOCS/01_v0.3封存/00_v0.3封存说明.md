## 2. 封存原因

v0.3 在文字、红线措辞、数值锚点和投稿定位层面曾被判断为可继续推进。但 2026-06-08 重新审计后确认：

- 主反演与补充实验依赖模块 A OCS 扫描表。
- 模块 A OCS 使用 face-level / face-center 积分与面中心遮挡射线。
- Blender geometry-pass / EXR 逐像素 OCS 方法没有进入主数据生成链。
- 已有 A/B 一致性记录显示差异可能影响 OCS-based inversion 和 fusion 机制解释。

因此 v0.3 不再进入投稿工程化。

## 3. 封存规则

- v0.3 不删除、不覆盖、不移动。
- v0.3 可作为论文结构、写作风格、贡献组织和风险措辞的参考。
- v0.3 的所有 OCS 相关数值、图表和补充实验结论必须在 v0.4 中重新验证后才能继续使用。
- v0.3 不得作为投稿稿。

## 4. 可保留内容

- 论文结构。
- 目标期刊策略：Acta Astronautica / ASR 第一档优先。
- 谨慎边界：无真实望远镜验证、synthetic benchmark、fixed roll、nominal material。
- 关于 naive fusion 不自动 fallback、U1 不是 discrete OCS-only mode 的保守表述框架。

## 5. 需替换内容

- OCS-only 结果。
- OCS heatmap 和 per-part OCS source data。
- Fusion / ResNet-fusion 中所有使用 OCS 特征的结果。
- 12b、12c、12f、12g 中所有 OCS/fusion 相关数值。
- OCS 噪声、分支遮蔽、beta sweep、source-data consistency 记录。
