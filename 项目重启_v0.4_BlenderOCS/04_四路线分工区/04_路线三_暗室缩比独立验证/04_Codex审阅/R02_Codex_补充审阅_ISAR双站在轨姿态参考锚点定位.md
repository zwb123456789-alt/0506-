## 3. 对 Claude 输出的判断

### 3.1 判断成立的部分

Claude 输出中以下判断成立，建议保留：

1. **不是第四条腿**  
   ISAR 不应被写成路线一/二/三之外的第四路线。它不独立承担完整方法论证明，只是给路线三增加一个“真实在轨同型号姿态参考”的辅助锚点。

2. **不是光度锚点**  
   ISAR 是 Ka 波段微波回波成像，不是 OCS 可见光光度，也不是光学图像通道。它不能做光度保真、不能和 GEO 光度库互证、不能进入 OCS 光度前向链。

3. **是姿态参考，不是真值**  
   双站 ISAR 可能提供姿态判读或三维姿态参考，但其结果依赖雷达成像质量、成像模型、散射中心解释、双站几何与解算算法。除非后续给出误差模型，否则只能写成姿态参考锚点，不能写成姿态真值。

4. **可软化专家“仿真姿态不真实”质疑**  
   真实在轨同型号目标存在可观测姿态，并可被独立雷达手段判读，这对路线三是加分项。它能说明暗室模型不是孤立玩具模型，而是可与真实同型在轨目标建立形态参照。作者持有的 ISAR 图像不止一帧、数据量较多，因此具备形成多姿态参考样本集合的潜力；但能形成多大规模、覆盖多少姿态差异，取决于后续数据处理与图像可解释性，现阶段不预判，只先确认“具备多帧多姿态潜力”。

5. **可支持真实图像反演案例 / 样本研究**  
   ISAR 图像是实测在轨图像，若姿态参考可解，可用于展示反演方法在真实在轨图像上的表现。是做成单图像案例研究，还是做成有一定规模的真实样本对照，取决于后续数据处理确认的可用图像数量与姿态覆盖；现阶段两种用法都先保留，不提前锁死，也不夸大为统计意义上的反演成功率验证。

### 3.2 需要收紧的部分

Claude 输出中“信息层面无障碍”“双站 ISAR 可解算三维姿态”等表述需要收紧。

推荐改写为：

```text
若 TLE、站点坐标、精确时刻、ISAR 图像本体与成像参数均可获得，
则具备开展双站几何重建和姿态参考解算的条件；
但能否形成可用于论文的姿态参考锚点，
还取决于 ISAR 图像质量、成像模式、散射中心可解释性和姿态解算误差。
```

理由：

- TLE + 站点 + 时间只能确定观测几何，不能自动给出姿态。
- 双站 ISAR 提高姿态判读可能性，但不是天然三轴姿态真值。
- “可解算三维姿态”必须以图像质量、目标散射模型、解算算法和误差评估为前提。
- 姿态多样性与样本规模取决于后续数据处理：作者持有多帧、数据量较多，具备多姿态潜力，但实际能覆盖多少可确认姿态构型，需由图像可解释性与姿态差异实际支撑，现阶段不预判上限或下限。

## 4. 工作量与闸门

该新增条件会显著增加路线三潜在工作量，不应直接并入路线三主任务。建议设置分级闸门。

### 4.1 L0：元数据与样本集合确认

最低确认项：

```text
1. 68414 的 TLE Line1 / Line2 原文；
2. 两个 ISAR 站点经纬高；
3. 成像时刻是否为 UTC；
4. 两站是否同时观测同一目标同一成像窗口；
5. ISAR 图像本体是否可获得；
6. “Line”模式含义与成像参数说明。
7. ISAR 图像总数量、覆盖日期/时刻、是否包含多姿态差异；
8. 每组图像是否均有可追溯文件名、站点、时刻和目标编号。
```

若 L0 不完整，ISAR 条件只能作为背景信息，不进入论文证据链。

### 4.2 L1：时间同步 / 配准硬闸门

双站 ISAR 联合姿态判读成立的前置物理条件是两站成像时刻严格同步，或可以精确配准到同一姿态状态。

```text
两站时标同步或可配准 -> 才能进入双站联合几何 / 姿态参考；
两站时标不同步且不可配准 -> 双站联合姿态解算不成立，只能退回单站图像判读 / 单站案例研究。
```

该闸门优先级高于“Line 模式含义”。原因是：若两站观测的不是同一时刻同一姿态，双站几何不能直接联立；即使各自图像质量很好，也不能声称“双站姿态参考锚点”。

最低确认项：

```text
1. 两站文件是否对应同一成像窗口；
2. 两站起止时间差是否在可接受同步误差内；
3. 若不同步，是否有目标姿态稳定或时序插值依据；
4. 是否有统一时间基准（UTC/GPS/本地时）与时钟误差说明。
```

若 L1 不成立，ISAR 子线仍可作为真实单站/单图像案例研究，但不能写成双站姿态参考。

### 4.3 L2：几何可复现

用 TLE + 站点 + 时间重建：

```text
1. 卫星位置/速度；
2. 两站视线、斜距、方位角、俯仰角；
3. 双站夹角；
4. 13.65 秒窗口内视线变化率；
5. 观测几何是否足以支持姿态参考判读。
```

若 L2 几何不能复现，则不能声称“双站姿态参考锚点”。

### 4.4 L3：ISAR 图像可解释

需要确认：

```text
1. 两站 ISAR 图像是否能稳定识别主体、帆板或关键散射中心；
2. 图像坐标/距离-多普勒坐标口径是否清楚；
3. 两站图像能否对应到同一目标结构；
4. 是否存在足够的姿态判读依据，而非只看到粗略亮斑。
```

若 L3 图像不可解释，只能写“有 ISAR 图像记录”，不能写“姿态参考”。

### 4.5 L4：姿态参考误差评估与坐标配准

若要进入主论文证据链，必须给出：

```text
1. 姿态参考的解算方法；
2. 误差来源；
3. 误差量级或置信范围；
4. 与暗室模型几何坐标系的配准方式。
```

其中第 4 项是最容易卡住的子项，必须展开而不能只写一句“配准”：

```text
ISAR 姿态通常定义在雷达视线系 / 惯性系 / 目标轨道相关坐标中；
暗室姿态定义在暗室台架系中；
二者要对齐，必须有共同的卫星本体坐标系定义。
```

若暗室模型与 68414 虽为同型，但本体坐标轴、帆板零位、初始姿态定义或模型装配基准不同，则会引入系统性偏差。未明确共同本体坐标系与配准基准前，ISAR 姿态只能作为定性 / 半定量参考，不能作为可计算误差的姿态真值。

未完成 L4 前，不得写成“姿态真值”，只能写成“姿态参考/旁证”。

### 4.6 L5：与暗室/仿真的受限对照

即使 L4 成立，也只能做受限对照：

```text
真实在轨 ISAR 姿态参考
-> 同型几何模型的姿态形态对照
-> 与暗室模型外形/姿态配置建立形态关联
```

同时允许一条非常窄的合法接口：

```text
ISAR 解出的姿态参考
-> 作为同一几何模型的姿态输入
-> 驱动 OCS / 图像前向仿真
-> 生成“该真实在轨参考姿态下，v0.4 前向模型预测的光度/图像表现”
```

这条接口是允许的，因为它只是把 ISAR 提供的姿态参数作为共同几何输入，并未拿 Ka 雷达回波与可见光光度做保真互证。必须写清：

```text
允许：ISAR 姿态参考 -> OCS 前向仿真输入。
禁止：ISAR 回波/图像 -> OCS 光度保真证据。
```

禁止写成：

```text
ISAR 姿态参考 -> 光度反演真值
ISAR 姿态参考 -> GEO 光度库监督标签
ISAR 成像成功 -> OCS 光度前向模型真实闭环
```

## 5. 对路线三的定位影响

### 5.1 正面增益

若 L0-L4 通过，ISAR 子线可给路线三增加三类价值：

1. **同型目标真实性**  
   暗室模型对应的真实在轨同型目标确实存在，并有独立观测记录。

2. **真实在轨姿态参考**  
   在暗室“姿态真值”之外，提供真实在轨目标姿态参考锚点，增强路线三与真实航天器场景的关联。作者持有多帧、数据量较多，具备形成多姿态参考样本集合的潜力；具体规模留待后续数据处理确定。

3. **投稿叙事增强**  
   对 TAES / AIAA Journal / AST / JGCD 类目标，ISAR 子线可作为“同型在轨目标旁证”，提升工程可信度。

4. **真实图像反演案例 / 样本研究**  
   若姿态参考可解，可把 ISAR 图像作为反演方法在真实在轨图像上的案例或样本：展示方法如何处理真实在轨图像、输出候选姿态，并与 ISAR 姿态参考做定性或半定量对照。是案例研究还是有一定规模的样本对照，留待后续数据处理确定；无论哪种，都不等同于统计意义上的反演成功率验证。

### 5.2 负面风险

这条子线也有明显风险：

- 数据处理链长：TLE 外推、站点几何、ISAR 成像理解、双站配准、姿态判读。
- 物理通道不同：Ka 雷达与可见光 OCS 无法直接互证。
- 容易被误写成真实在轨闭环。
- 容易把路线三从暗室实验扩展成“暗室 + ISAR 在轨姿态解算”大工程，拖慢主线。

### 5.3 推荐定位

推荐定位为：

```text
路线三的可选增强子线，而非路线三 pilot 的必做项。
```

路线三最小 pilot 仍应保持：

```text
暗室同系统仿真 vs 实测 sanity check
+ 小规模有真值反演闭环
+ roll-aware 样本
+ scale-model gap 说明
```

ISAR 子线只有在 L0-L4 快速通过、数据质量明确可用时，才进入主论文增强证据；否则放入 Discussion / Future Work 或后续独立工作。

## 6. 投稿影响

ISAR 子线对投稿的作用是“增强工程可信度”，不是“替代暗室真实闭环”。

```text
暗室真实有真值反演闭环 = 路线三上探的核心证据；
ISAR 双站在轨姿态参考 = 同型在轨目标旁证 / 姿态参考增强；
ISAR 单图像反演案例 = 真实案例研究 / 可信度增强；
GEO 光度库 = 真实光度统计与多几何现实性锚点。
```

若三者边界清楚，投稿叙事会更强：

```text
暗室提供有真值闭环；
GEO 提供真实光度统计；
ISAR 提供同型在轨姿态参考。
```

但若三者被写成串联闭环：

```text
暗室 -> ISAR -> GEO 光度 -> 在轨反演成功
```

则会形成严重一票否决风险。

## 7. 一票否决风险清单

后续使用 ISAR 条件时必须避免：

- 把 ISAR 姿态参考写成姿态真值。
- 把 ISAR 图像写成光度数据。
- 把 ISAR 姿态当作 GEO 光度库的监督标签。
- 把 Ka 雷达成像与 OCS 可见光前向模型做跨模态保真。
- 把 ISAR 子线写成真实在轨光度反演闭环。
- 把 ISAR 子线变成路线三主 pilot 的必做项。
- 未给出图像质量、成像模式和误差评估前，就声称可解算三轴姿态。
- 两站成像时刻不同步或不可配准时，仍声称双站联合姿态解算成立。
- 未定义共同卫星本体坐标系时，把 ISAR 姿态与暗室台架姿态直接比较。
- 把单图像案例研究写成反演成功率统计验证。

## 8. 对现有文件的小修建议

### 8.1 路线三总览

路线三总览已补入 ISAR 条件，但建议后续进一步收紧为：

```text
ISAR 双站在轨图像是同型目标形态/姿态参考锚点候选；
其使用需通过元数据、时间同步/配准、双站几何、图像可解释性和姿态误差五级闸门；

```

### 8.2 路线三 R01 审阅

若作者确认采纳本审阅，可在路线三 R01 后续小修或总裁决中补入：

```text
ISAR 子线为路线三可选增强；
不改变路线三“条件触发增强层”定位；
不改变暗室成功率只限暗室系统内的红线；
不提供光度确认；

允许将 ISAR 姿态参考作为 OCS 前向仿真的姿态输入，但不能把 ISAR 回波当作 OCS 光度保真证据。
```

### 8.3 路线三冻结文件

## 9. 最终裁决

```text
Codex 补充审阅结论：多帧 ISAR 双站在轨图像条件有价值，应作为路线三的可选真实在轨姿态参考锚点子线处理。

它不是第四条腿，不是光度锚点，不是姿态真值，不是 GEO 光度库标签，
也不是路线三暗室 pilot 的必做项。

它的合理作用是：
在元数据、时间同步/配准、几何、图像解释和误差评估通过后，
为路线三提供“真实在轨同型号目标的姿态参考旁证”，
增强路线三与真实航天器场景的联系。
具体做成统计样本对照还是案例研究、覆盖多少姿态构型，
留待后续数据处理确定，现阶段只定大致框架，不说死。

若该子线处理成本过高或数据质量不足，
应降级为 Discussion / Future Work，
不得拖慢路线一主干、路线二 GEO 锚点或路线三暗室最小 pilot。
```
