## 2. 总体判断

```text
Codex 复审结论：路线三可通过，但必须冻结为“条件触发增强层”，不是路线一/路线二成立的前置条件。
```

路线三的最大价值是：

```text
暗室是当前三路线中唯一能提供“真实光度 + 姿态真值”的场域，
因此它可以做真实有真值的监督反演闭环，并可纳入 roll-aware / 小规模三轴姿态验证。
```

但路线三的最大红线同样明确：

```text
暗室系统与 GEO 数据库互不连通。
暗室通过只能证明“暗室缩比系统内”的前向保真与反演闭环，
不能外推为 GEO 在轨目标反演验证，也不能写成真实望远镜/外场验证。
```

因此，路线三通过的正确定位是：

```text
路线一 = 必选主干；
路线二 = 优先增强层；
路线三 = 条件触发增强层。

路线三 pilot 通过，则作为主论文/高水平投稿的强增强证据；
路线三 pilot 不通过，则降级为 Discussion / Future Work 或后续独立论文，
不阻塞路线一主干，也不反向阻塞路线二真实光度锚点。
```

## 4. 与投稿目标的关系

路线三对投稿目标的作用是“显著抬高上限，但不应成为最低闭合条件”。

### 4.1 对高水平 SCI 的增益

相较路线一和路线二，路线三新增了高水平投稿很看重的两个证据：

```text
1. 点对点真实测量闭环：同一暗室系统内，仿真输出与实测光度/图像对照。
2. 真实有真值反演闭环：暗室姿态真值可控，可算暗室系统内的真实反演误差/成功率。
```

这两点能明显增强 IEEE TAES / AIAA Journal / Aerospace Science and Technology / JGCD 等高水平航天、制导控制类期刊的说服力。若路线三 pilot 成功，三腿并联证据链会比“纯仿真 + GEO 统计锚点”更抗审稿。

> 期刊层级与目标校准（对照 `03_项目说明与规划材料/01_写作规划/01_学校认定论文表解读_投稿依据.md`）：
> 1. TAES / AIAA / AST / JGCD 在学校认定表中属于**二类A（主攻高水平档）**，不属于“一档”。学校表“一档”指一类A/B（Nature / Science / 子刊 / NSR / Science Bulletin / Engineering / PRL / Progress in Aerospace Sciences）。路线三冻结文件 §0/§7 中“主攻一档”措辞应理解为“主攻二类A高水平档，强结果上探一类B”，避免与最高冲刺档混淆（小修见 §9）。
> 2. **IEEE TGRS 从路线三默认目标中剔除**：TGRS 面向地球观测遥感，暗室缩比卫星姿态反演与其口径错位，命中率低。路线三主攻收敛为 TAES / AIAA / AST / JGCD；涉及真实成像/遥感口径的目标（若有）由路线二 GEO 真实成像线另行评估，不作为路线三默认期刊。

### 4.2 对最高档目标的限制

路线三不能自动把论文推到 Nature / Science / 子刊级别。原因是：

```text
暗室是地面缩比系统，不是真实在轨系统；
缩比材料、尺度、BRDF、杂散光和定标链路都会引入 scale-model gap；
它提供的是方法论真实闭环，不是 GEO 在轨任务级验证。
```

因此投稿策略应保持“高目标牵引、证据强度定档”：

> 上探门槛（对照投稿依据 §7.1“强证据 + 框架普适”）：路线三若要上探一类B，**唯一够分量的稀缺证据是“暗室真实有真值反演闭环成功率”**——即在真实光度上算出的姿态反演性能。点对点保真验证本身只是前向背书，不足以单独支撑上探一类B。

```text
路线一闭合 -> 稳健 SCI 主体；
路线二 pilot 成功 -> 高水平冲刺有现实依据；
路线三 pilot 成功 -> 高水平冲刺更稳，并为更高档保留上探空间；
路线三 pilot 不成功 -> 不影响路线一/二投稿闭合，降为 Discussion / Future Work。
```

## 5. 路线三能力边界

### 5.1 上界

若暗室 pilot 顺利，路线三可提供：

- 暗室系统内前向模型点对点保真验证；
- 暗室真实光度/图像上的监督反演闭环；
- 小规模 roll-aware / 三轴姿态验证；
- 仿真可观测性地图与真实测量反演行为的一致性验证；
- 对专家“反演需要真实闭环”的正面回应；
- 投稿层级从路线二的“高水平冲刺有依据”提升为“高水平冲刺更稳”。

### 5.2 下界

若暗室 pilot 结果一般，但管线能通：

- 可作为方法学 sanity check；
- 可放入 Discussion / Limitation / Future Work；
- 可支撑“后续真实有真值闭环路线”；
- 不应硬并入主论文主证据链。

### 5.3 硬天花板

路线三永远不能写成：

```text
暗室通过 -> GEO 在轨目标姿态反演通过；
暗室成功率 = GEO / 真实空间目标成功率；
暗室缩比 = 真实望远镜验证 / field-proven / operational-ready；
暗室光度可与 GEO 实测光度直接互证；
暗室结果证明真实未知目标完整姿态反演系统成立。
```

### 5.4 缩比尺度效应的物理机理预案（保真验证命门）

路线三冻结文件与本审阅多处把 “scale-model gap / BRDF 差异 / 尺度效应” 作为名词列出，但高水平审稿（尤其 TAES）会追问其**物理机理**，必须提前写死预案，否则保真主轴会被一刀打掉：

```text
缩比改变的是绝对几何尺寸，而 BRDF 是与尺度无关的面反射率；
但缩比会改变镜面/漫反射占比、边缘衍射、亚像素填充因子，
从而改变光度相位曲线的形状——这才是“暗室光度能否代表卫星光度”的真正命门。
```

因此保真验证的 claim 必须收敛为：

```text
暗室保真验证只比较“同系统内仿真 vs 实测的相对趋势 / 相位曲线形状一致性”，
不声称缩比光度等于真实卫星的绝对光度量级。
失配项归入 scale-model / BRDF / stray-light / calibration 边界，逐项标注。
```

这样既守住“同系统内点对点保真”这一可成立的强证据，又不越界声称缩比绝对光度代表在轨绝对光度。

## 6. 与路线一、路线二的兼容性

### 6.1 不阻塞路线一

路线三不得变成路线一主干闭合的前置条件。

路线一已经定位为：

```text
model-known 条件下 fixed-roll yaw-pitch controlled benchmark，
研究 OCS/image 姿态信息可观测性、互补性和置信一致性。
```

路线三的 roll-aware / 三轴能力是增强项，不是对路线一 fixed-roll 主干的否定。若路线三未完成，路线一仍可独立成立。

### 6.2 不反向改写路线二

路线二负责 GEO 真实光度锚点：

```text
真实在轨光度统计、真实多帧多几何现实性、sim-to-real gap 边界。
```

路线三负责暗室真实有真值闭环：

```text
同系统点对点保真、暗室姿态真值反演、roll-aware 小规模验证。
```

两者是并联互补，不是串联传递。路线三不能替代路线二的在轨统计锚点；路线二也不能替代路线三的有真值反演闭环。

### 6.3 三腿并联成立

路线三冻结文件提出“三腿并联”是正确的，但后续写作必须把并联边界放在显眼位置：

```text
路线一证明：在受控 model-known 仿真中，姿态信息在哪里可观测。
路线二证明：真实 GEO 监测中，光度统计、多帧多几何和异常观测实践确实存在。
路线三证明：在独立暗室缩比系统中，真实光度 + 姿态真值闭环可跑通。
```

三者共同支撑同一个科学问题，但任何一腿的成功都不能越界替另一腿给出结论。

## 7. pilot 闸门

路线三必须设置 pilot 闸门。未过 pilot，不得并入主论文主证据链。

建议最低 pilot 为：

```text
P1：一个缩比模型；
P2：少量姿态网格，至少包含 1-2 个 roll != 0 的姿态；
P3：同系统仿真 vs 实测光度 sanity check；
P4：小规模 OCS-only / image-only / joint 反演闭环；
P5：报告暗室误差、失败样本和 scale-model gap；
P6：若保真或反演结果不可解释，降级为 Discussion / Future Work。
```

pilot 通过标准不宜写成“必须达到某个成功率”，现阶段更适合写成：

```text
管线可复现；
同姿态同几何的仿真-实测趋势可解释；
反演成功/失败区域与可观测性分析有可解释对应；
失配项可归入明确的 scale-model / calibration / BRDF / stray-light 边界。
```

## 8. 一票否决风险清单

后续路线三所有写作、汇报和代码规划必须排除：

- 暗室验证 GEO 在轨目标反演。
- 暗室成功率外推为 GEO / 在轨 / 真实外场成功率。
- 暗室缩比写成真实望远镜验证、field-proven 或 operational-ready。
- 暗室与 GEO 光度直接互证。
- 暗室结果反向要求路线一全量 3-DOF。
- 路线三成为路线一主干闭合必做项。
- 忽略 scale-model gap、材料 BRDF 差异、暗室杂散光和相机定标误差。
- 把路线三写成真实未知目标完整姿态反演系统。

## 10. 最终裁决

```text
Codex 复审结论：路线三通过，定位为条件触发增强层。

路线三是当前三路线中唯一可提供“真实光度 + 姿态真值”的场域，
因此它对专家“反演需要真实闭环”的回应最强，
也最能提高高水平 SCI 投稿的证据强度。

但路线三必须严格限定为暗室缩比系统内的真实有真值闭环：
它不验证 GEO 数据库，不验证在轨目标，不提供真实望远镜外场性能。

路线三 pilot 成功时，可作为主论文增强章或后续独立论文核心；
路线三 pilot 不成功时，降级为 Discussion / Future Work，
不得阻塞路线一 fixed-roll 主干，也不得反向阻塞路线二 GEO 真实光度锚点。

允许下一步进入四路线综合审阅与最终路线裁决；
四路线总裁决完成前，仍不进入全量训练、全量数据生成或暗室全量实验。
```
