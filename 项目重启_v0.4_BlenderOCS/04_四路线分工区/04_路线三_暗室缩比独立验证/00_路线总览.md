# 路线三总览：暗室缩比独立验证

最后更新：2026-06-22

## 1. 路线定位

路线三是条件触发增强层：

```text
暗室缩比独立系统
-> 同系统点对点前向保真验证
-> 姿态可控监督反演闭环
-> 可纳入 roll-aware / 三轴小规模验证
```

路线三与 GEO 数据库互不连通，不能把暗室结果外推成 GEO 在轨反演验证。

新增可用条件（2026-06-18 补充）：

```text
作者另有该暗室模型对应卫星在天 ISAR 图像；
图像由两个不同站点拍摄；
拍到的姿态图像较多，当前文件名仅为样例；
在天目标与暗室模型卫星外形一致；
ISAR 图像可用于形态 / 姿态判断辅助；
该数据不能用于光度确认。
```

样例命名：

```text
ISAR_0012_68414_260408_173830_507_173844_157_Ka_Line
```

当前解释边界：

- 该条件可能补强路线三“暗室模型与真实在天同型目标”的外形关联，并可作为姿态判断/形态识别的辅助证据。
- 真实图像可为单图像反演方法提供真实案例研究，增加方法可信度；但在未形成可统计样本、真值误差和统一评估口径前，不能写成反演成功率验证。
- 该条件不改变路线三红线：暗室成功率仍只能限定在暗室系统内，不能外推为 GEO 或在轨反演成功率。
- ISAR 图像不能替代 GEO 光度数据，也不能作为光度保真锚点；光度确认仍不成立。
- 允许的窄接口：若 ISAR 姿态参考可解，可作为同一几何模型的姿态输入，驱动 OCS / 图像前向仿真；禁止把 ISAR 回波或图像当作 OCS 光度保真证据。
- 文件名初看可能包含观测类型、站点/任务编号、目标编号、日期、起止时刻、频段 Ka 与成像/线模式等信息；是否包含可用轨道信息、精确观测几何或姿态判读真值，需原始元数据、说明文件或专家确认，不能仅凭文件名推断。
- 双站联合姿态参考必须以两站时间同步或可精确配准为硬前提；若不同步或不可配准，只能退回单站/单图像案例研究。

## 3. 审阅重点

- 是否明确暗室与 GEO 不串联、不互证。
- 是否把暗室成功率限定在暗室系统内。
- 是否以 pilot 作为并入主论文的闸门。
- 是否避免让路线三阻塞路线一主干。
- 是否正确处理新增双站 ISAR 在天图像：只能作为同型目标形态/姿态判断辅助，不能作为光度确认或在轨反演成功率证据。
- 是否区分“真实单图像案例研究”与“反演成功率验证”，避免把案例研究写成统计验证。

## 4. 当前下一步

路线三审阅已完成，当前不作为下一执行入口。

路线三后续启动时，需要被保持为以下口径：

- 暗室是否只作为条件触发增强层，而非路线一主干闭合条件。
- 暗室是否是唯一可算“真实有真值闭环成功率”的场域。
- 暗室成功率是否严格限定在暗室系统内，不外推到 GEO 在轨目标。
- pilot 未通过时是否能降级为 Discussion / Future Work，不阻塞路线一和路线二。
- 暗室可以验证三轴小项目预测的最亮/高信息构型，但不能把暗室闭环外推成在轨闭环。
- 双站 ISAR 在天图像是可选增强子线，不是路线三 pilot 的必做项。
- ISAR 子线是否通过元数据、时间同步/配准、双站几何、图像可解释性和姿态误差闸门；未通过前只作为辅助信息或 Discussion / Future Work。
