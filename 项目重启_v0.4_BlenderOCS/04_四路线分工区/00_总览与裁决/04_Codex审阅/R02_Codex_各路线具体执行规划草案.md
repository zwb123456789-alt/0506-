## 4. 三轴小项目具体执行规划

### 4.1 目标

三轴小项目不是路线一 roll sensitivity 的简单放大，也不是真实未知目标三轴姿态反演系统。它的目标是：

```text
在 yaw / pitch / roll 三轴姿态空间中，
寻找最亮构型、高信息构型、最优可观测姿态和低信息/不值得观测区域，
并把路线一 C 的可观测性工具转化为观测规划提示。
```

### 4.2 输入与依赖

必须等待路线一 C 至少完成以下输出：

- 可运行的 v0.4 pixel-level OCS/image 同源前向链路。
- Phong-like 主 BRDF 与 GGX mismatch 分支。
- G1/G3/G5 中至少一套可复用几何配置。
- fixed-roll 高亮、高混淆、高信息代表姿态。
- roll sensitivity 初步结果。

### 4.3 任务拆解

| 编号 | 任务 | 输出 | 完成标准 |
|---|---|---|---|
| 3A-P1 | 种子点选择 | fixed-roll 高亮/高混淆/高信息种子姿态清单 | 种子覆盖亮度、信息量、混淆和低信息区域 |
| 3A-P2 | roll 局部扫描 | 种子点附近 roll 扰动结果 | 判断最亮点和混淆结构是否迁移 |
| 3A-P3 | 稀疏三轴采样 | yaw/pitch/roll 稀疏候选池 | 资源可控，能覆盖主要姿态空间 |
| 3A-P4 | 候选池筛选 | 高亮、高信息、低信息、风险候选清单 | 明确最亮不等于最有信息 |
| 3A-P5 | 局部加密 | 候选区域加密搜索结果 | 输出更稳定的最亮/高信息构型 |
| 3A-P6 | glint/saturation 风险标注 | 风险区域图表 | 亮但不可用或不稳定的区域被单独标出 |
| 3A-P7 | geometry utility score | 几何-姿态组合效用表 | 能给出值得观测、低价值、风险几何 |
| 3A-P8 | 路线二/三接口清单 | 真实趋势锚点与暗室验证任务候选 | 明确哪些结论可由 GEO/暗室增强 |

### 4.4 指标体系

至少保留：

- brightness / OCS magnitude：寻找最亮和最暗构型。
- local contrast：判断局部可分性。
- entropy / margin：判断候选分布集中程度。
- top-k stability：判断最优姿态是否稳定。
- JS / overlap：判断 OCS 与 image 是否一致或冲突。
- saturation / glint flag：判断亮但不可用的风险区。
- geometry utility score：判断观测几何是否值得投入。

### 4.5 最低完成标准

三轴小项目完成时，至少应输出：

1. 三轴候选搜索流程。
2. 最亮构型、高信息构型、低信息区域三类图表或清单。
3. fixed-roll 结论在 roll-aware 空间中的稳定/迁移判断。
4. 值得观测几何、低价值几何和风险几何建议。
5. 与路线二真实趋势锚点、路线三暗室真值闭环的接口。

### 4.6 对 Claude 的提示词生成顺序


## 5. 路线二 GEO 真实光度锚点具体执行规划

### 5.1 目标

路线二服务路线一 C 与三轴小项目，用真实 GEO 光度数据提供趋势级、分布级和多帧多几何现实性锚点。

路线二不能成为监督姿态反演路线，因为 GEO 数据库没有三轴姿态真值。

### 5.2 输入与依赖

依赖：

- 路线一 C 的仿真光度输出和几何定义。
- 三轴小项目的高亮/低亮趋势或几何效用判断。
- GEO 数据库中型号已知、几何可反算、同目标多帧较充分的样本。

高警惕边界：

```text
轨道根数 != 姿态
天球测角 != 本体姿态
型号身份 != 姿态
机动统计 != 姿态
真实 GEO 数据不能提供 yaw / pitch / roll 真值
```

### 5.3 任务拆解

| 编号 | 任务 | 输出 | 完成标准 |
|---|---|---|---|
| R2-P1 | 样本目标筛选 | 型号已知、可建模、同目标多帧样本清单 | 至少选出 1 个 pilot 目标 |
| R2-P2 | PRE 几何反算 | 每帧 sun/view 几何、相位角、距离等 | 几何范围物理合理，通过 sanity check |
| R2-P3 | DET 光度整理 | 真实视星等随时间/几何变化表 | 数据质量、缺失和异常点明确 |
| R2-P4 | REG 型号匹配 | NORAD/CODE 到可建模几何的对应关系 | 明确可建模覆盖率，不强行覆盖全部目标 |
| R2-P5 | 真实多帧多几何分析 | 同目标多帧几何覆盖图 | 证明多几何是监测数据固有结构 |
| R2-P6 | 趋势/分布级对照 | 仿真 vs 真实的分布、量级、趋势对照 | 不要求绝对数值匹配，只报告一致/失配/不可解释区 |
| R2-P7 | mismatch 归因 | 材料、定标、大气、观测链、几何误差边界表 | 失配不被强行解释为姿态真值问题 |
| R2-P8 | 三轴小项目接口 | 真实几何覆盖与高低亮趋势锚点 | 只锚趋势和几何现实性，不锚姿态真值 |

### 5.4 最低完成标准

路线二完成时，至少应证明：

1. 真实 GEO 数据中存在同目标多帧、多几何光度结构。
2. PRE 字段可支撑 sun/view 几何反算，并通过 sanity check。
3. DET 真实视星等可用于趋势级或分布级对照。
4. 仿真高低亮趋势能被真实数据部分支持、部分失配或明确无法解释。
5. 所有失配进入 mismatch / limitation，而不是强行写成姿态反演误差。

### 5.5 禁止事项

不得写成：

```text
GEO 真实数据验证了路线一 C 的姿态反演精度。
GEO 数据库提供三轴姿态真值。
真实 GEO 光度可监督训练 yaw / pitch / roll 反演器。
GEO 数据验证某个三轴姿态就是最亮姿态。
```

### 5.6 对 Claude 的提示词生成顺序

```text
R2-C01：读取路线二指导文件和 GEO 数据库整合文件，生成样本目标筛选标准。

R2-C04：设计仿真光度与真实光度的趋势/分布级对照。
R2-C05：设计 mismatch 归因和 limitation 输出。
```

## 7. 路线四 LEO 未来方向具体执行规划

### 7.1 目标

路线四只作为未来独立方向，不进入当前路线一 C 与三轴小项目的必做闭环。

一句话定位：

```text
以 v0.4 前向模型为起点，面向 LEO 动态观测，
研究姿态运动、自旋、进动、翻滚、时域光变曲线与光学特性之间的关系。
```

### 7.2 可继承内容

路线四未来可继承：

- v0.4 pixel-level 几何和可见性链路。
- 五参数冯/书中材料参数主锚点。
- GGX/Cook-Torrance mismatch 分支。
- OCS/image consistency 思路。
- 三轴小项目输出的高亮、高信息构型。

### 7.3 新增内容

路线四若未来启动，必须新增：

1. 姿态动力学模型：自旋、进动、翻滚、帆板运动等。
2. 时域光变曲线 L2：不再只是跨几何静态向量。
3. 动态采样策略：时间步长、曝光、相位角变化、轨道几何耦合。
4. 新指标：周期、频谱、状态转移、运动特征识别。

### 7.4 当前处理方式
