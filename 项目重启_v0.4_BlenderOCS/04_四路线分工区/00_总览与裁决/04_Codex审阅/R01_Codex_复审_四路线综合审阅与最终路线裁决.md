## 2. 总体裁决

```text
Codex 综合裁决：采用“路线一主干 + 路线二优先增强 + 路线三条件增强 + 路线零封存待裁决”的分层结构。
```

最终路线关系应冻结为：

```text
路线零 = v0.3 旧稿封存待解封评估，不阻塞 v0.4
路线一 = 必选主干，fixed-roll yaw-pitch 纯仿真可观测性 benchmark
路线二 = 优先增强层，GEO 真实光度 sim-to-real 锚点
路线三 = 条件触发增强层，暗室缩比真实有真值闭环
ISAR 子线 = 路线三可选增强，真实在轨同型目标姿态参考/真实图像案例候选
```

当前最稳的论文主线不是“真实未知目标姿态反演系统”，而仍是 24 号主线：

```text
model-known 条件下，独立 OCS 光度通道与图像成像通道共享同一物理前向模型时，
跨几何 OCS 多观测光度向量与图像通道对姿态信息的可观测性、互补性和置信一致性研究。
```

路线二和路线三的价值是提高现实锚定和发刊上限，但不能改写主线边界：

- 路线二回答“真实 GEO 光度统计、多帧多几何现实性是否存在”。
- 路线三回答“在独立暗室系统内，真实光度 + 姿态真值闭环能否跑通”。
- 二者均不能证明“GEO / 在轨真实未知目标姿态反演已经成立”。

## 3. 四路线逐条裁决

### 3.1 路线零：旧路线投稿

裁决：

```text
封存待解封评估，不进入当前 v0.4 主线，不阻塞路线一/二/三。
```

理由：

- v0.3 已完稿可作为保底 SCI 候选，但存在旧 OCS 口径与 v0.4 Blender-derived OCS 的一致性风险。
- 当前不能把旧稿直接恢复投稿；必须先评估旧模块 A face-center OCS 是否影响主结论。
- 旧稿若解封，应作为独立投稿策略，不与 v0.4 证据链混用。

### 3.2 路线一：fixed-roll 纯仿真主干

裁决：

```text
通过，作为硕士论文与 v0.4 主体必选主干。
```

路线一负责把科学问题讲清：

- what can be known；
- when OCS and image are complementary；
- when should we trust the estimate。

路线一允许保持 fixed-roll yaw-pitch controlled benchmark，但必须保留 roll sensitivity 探针。反演只作为可观测性验证工具，不写成真实反演成功率。

路线一的边界：

- 纯仿真不是现实验证；
- fixed-roll 是受控研究切片，不是现实姿态全貌；
- 不声称真实望远镜验证、field-proven 或 operational-ready。

#### 反演在路线一/路线二之间的分层递进定位

路线一与路线二的反演不是同一比重，而是分层递进，二者不冲突：

```text
路线一反演 = 最轻量的可观测性验证探针，
            只回答 what can be known / when complementary / when trustworthy，
            不写成真实反演成功率。

路线二反演 = 在路线一之上升格为“配角偏重”的独立验证模块，
            用 OCS-only / image-only / joint 对比、几何覆盖影响、
            mismatch 退化曲线、可观测性高低区与反演成败一致性等，
            把“可观测性地图是否有工程意义”落到估计器行为上。
```

边界：

- 路线二反演分量可以加重，但只能加重到“配角偏重”，不得翻为论文主轴。
- 路线一保持最轻探针，不被路线二反演加重反向拉高为反演主线。
- 二者真值都只能来自仿真 / STK / 暗室等有真值场域，不能来自真实 GEO 数据。

### 3.3 路线二：GEO 真实光度锚点

裁决：

```text
通过，作为路线一之上的优先增强层。
```

路线二的核心价值：

- GEO 数据库有光度、有几何、有型号、有时序；
- PRE / DET / REG / MAN 等表可支持真实光度统计、真实多帧/多几何现实性、型号定位与光度异常实践；
- 能回应专家“仿真必须有大量真实数据打底”和“多几何观测现实性不足”的质疑。

路线二的硬边界：

- GEO 数据库没有 yaw / pitch / roll 姿态真值；
- 不能做监督姿态反演验证；
- 不能把天球测角、轨道根数、身份识别或机动统计写成本体姿态；
- 反演可适度提高为“配角偏重”的验证模块，但不得翻成论文主轴；
- STK 几何升级不是路线二成立条件，只是总裁决后可选 P3 增强；
- 反演 benchmark 必须注入 model mismatch（BRDF/F0/albedo、定标 gain-offset、几何反算误差、噪声），报告 sim-to-real gap 下的反演鲁棒性；不得在无 mismatch 的 inverse crime 设定下报告成功率（与路线二 R02 §3.1 一致，并因反演加重升级为路线二必守项）；
- 反演配角加重缓解的是“可观测性是否有工程意义”，不等于已答复专家方向三“反演需真实闭环”；真实有真值闭环只归路线三暗室，且暗室成功率不外推 GEO。

### 3.4 路线三：暗室缩比独立验证

裁决：

```text
通过，但只能作为条件触发增强层。
```

路线三的核心价值：

- 暗室是当前路线中唯一可同时提供“真实光度 + 姿态真值”的场域；
- 可做同系统仿真 vs 实测的点对点保真 sanity check；
- 可在暗室系统内计算真实有真值反演误差/成功率；
- 可小规模纳入 roll-aware / 三轴姿态验证，回应固定姿态质疑。

路线三的硬边界：

- 暗室相机、模型、光源与 GEO 数据库互不连通；
- 暗室成功率只限暗室缩比系统内；
- 暗室不能写成 GEO / 在轨反演验证；
- 暗室缩比不是真实望远镜外场验证；
- scale-model gap、BRDF/材料差异、杂散光、定标误差必须显式写入。

路线三的并入闸门：

```text
暗室 pilot 通过 -> 可并入主论文增强章或作为后续独立论文核心；
暗室 pilot 不通过 -> 降级为 Discussion / Future Work；
无论是否通过 -> 不阻塞路线一主干，不反向阻塞路线二。
```

### 3.5 ISAR 双站在轨图像子线

裁决：

```text
有价值，但只作为路线三可选增强子线，不作为路线三通过条件。
```

ISAR 子线可提供：

- 同型真实在轨目标的形态/姿态参考候选；
- 真实图像案例研究或样本对照候选；
- 若姿态参考可解，可作为同一几何模型的姿态输入，驱动 OCS / 图像前向仿真。

ISAR 子线不能提供：

- 光度确认；
- OCS 可见光保真证据；
- 姿态真值，除非后续建立误差模型与坐标配准；
- GEO 光度库监督标签；
- 统计意义上的反演成功率，除非后续样本、真值/参考误差和评估口径均成立。

双站 ISAR 必须先过五级闸门（与路线三 R02 §4 一致）：

```text
L0 元数据与样本集合确认（TLE、站点坐标、时刻时区、图像本体、Line 模式、图像数量与多姿态）
L1 时间同步 / 精确配准硬闸门（两站不同步且不可配准 -> 退回单站 / 单图像案例）
L2 几何可复现（TLE+站点+时间重建双站几何）
L3 ISAR 图像可解释（散射中心 / 主体 / 帆板可稳定识别）
L4 姿态参考误差评估与共同本体坐标系配准
```

其中 L4 是最容易卡住的子项，必须显式写出：未定义暗室模型与 68414 同型目标的共同卫星本体坐标系（本体坐标轴、帆板零位、初始姿态定义、模型装配基准）前，ISAR 姿态只能作为定性 / 半定量参考，不能作为可计算误差的姿态真值。若两站不同步且不可配准，只能退回单站 / 单图像案例研究。

## 4. 专家质疑覆盖矩阵

| 专家质疑 | 最终回应方式 | 裁决 |
|---|---|---|
| 前向模型统一但真实光度要能对上 | 路线一保证内部物理一致；路线二做 GEO 真实光度统计/趋势锚定；路线三做暗室同系统点对点 sanity check | 可回应，但不能声称绝对真实匹配 |
| 仿真与真实偏差大 | 路线一降级为 controlled benchmark；路线二补真实 GEO 光度；路线三补真实暗室测量 | 可回应，前提是写清 mismatch 与 scale-model gap |
| 固定姿态无说服力 | 路线一保留 fixed-roll 主干 + roll sensitivity；路线三 pilot 中小规模纳入 roll-aware | 可回应，不要求路线一全量 3-DOF |
| 光度多用于异常监测，不用于精确定姿 | 24 号主线改成 what-can-be-known/when-to-trust；路线二 MAN 表可作为异常实践锚点；反演降级为可观测性验证工具 | 可回应，避免部署式精确定姿 claim |
| 多几何观测现实条件严苛 | 路线一用受控 G1/G3/G5；路线二用同目标多帧天然几何；路线三用暗室可控多几何 | 可回应，避免写成多台设备同步刚需 |
| 反演需要真实闭环和成功率 | 路线三在暗室系统内提供真实有真值闭环；路线二不能做监督闭环 | 可回应，但成功率只限暗室系统内 |

## 5. 投稿目标裁决

当前投稿策略应写成：

```text
高目标牵引，证据强度定档。
```

分层建议：

- 路线一纯仿真主体：二类B至二类A；证据强则冲 TAES / AIAA / AST / JGCD / TGRS 等，保底 Acta / ASR。
- 路线二 GEO 真实光度锚点：二类A主攻，强结果可上探一类B；核心卖点是真实光度与多几何现实性。
- 路线三暗室真实闭环：二类A主攻，强结果可上探一类B；核心卖点是暗室真实有真值反演闭环。
- 旧 v0.3 稿：二类B / 基本 SCI 保底候选，先解封评估。

路线三默认目标应收敛为：

```text
IEEE TAES / AIAA Journal / Aerospace Science and Technology / Journal of Guidance, Control, and Dynamics
```

IEEE TGRS 可作为全项目二类A目标之一，但不作为路线三暗室默认目标；若后续真实成像/遥感口径成立，再单独评估。
