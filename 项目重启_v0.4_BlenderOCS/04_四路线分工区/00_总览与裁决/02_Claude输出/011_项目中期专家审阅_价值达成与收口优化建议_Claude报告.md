## 2. 作者最初目标与当前实际定位

作者最初想做的是：光度信息用于姿态反演的空白填补——光度辅助姿态反演、光度-图像双模态联合反演、图像反演中的光度辅助方案，最终支撑大论文、SCI、并评估一区 TOP 潜力。

项目实际走到的位置是（24 号冻结）：model-known 条件下，独立 OCS 跨几何多观测光度向量与图像通道共享同一物理前向模型时的**可观测性、互补性、置信一致性**研究。这不是最初目标的直接实现，而是一次战略降级加科学化：从"反演系统（成功率叙事）"转为"信息边界研究（可观测性叙事）"。

作为专家我的判断是：**这次转向是正确的，而且是被专家质疑和 v0.3 口径缺陷逼出来的正确**。原目标在几何/材料未知、无真实姿态真值的条件下是欠定问题，按成功率叙事写出去几乎必然被拒。当前定位诚实、可审计、有明确边界，是可发表的形态。但必须清醒看到代价：转向之后，作者最初最想要的两件事——"光度真的帮到了图像反演"（价值 1、6、7）和"双模态联合增益"——**在当前证据链里恰恰是没有被证明的那一块**（R125 明确 joint 强互补性未闭口，R127 增强实验后仍不支持）。也就是说，项目现在最强的证据支撑的是"作者转向后的问题"，而不是"作者最初的问题"。这是本报告后续所有建议的出发点。

## 3. 最初路线目的达成度评估

**已达到：**
- 统一物理前向模型下 OCS 与图像同源仿真框架（pixel-level 同源，修复 v0.3 face-center 口径污染）——这是全项目最扎实的工程资产。
- OCS 光度通道对姿态信息的可观测性刻画：L1 多几何向量 P-INT 下 yaw cMAE 76.56°→38.22°→22.77°（G1→G3→G5）、hit@30 0.277→0.811，multi-seed 稳定，mild/moderate/severe 退化下增益优雅收缩不消失（R115/R117/R127）。这条正结果链是干净的。
- 可观测性的负边界：P-EXT yaw-block 外推全档坍缩（146–157°）、单几何单标量信息下界——负结果有归因（B6-FIX01 circular regression 排除了判据假象）。
- P-DB 模板检索强于 neural 回归（G5 hit@30 0.949 vs 0.811、cMAE 8.19° vs 22.77°）与 conformal set_size 随几何收紧——置信一致性有了第一层证据。

**部分达到：**
- "置信一致性"三问中的第三问：有 conformal/margin/四象限证据，但 neural margin risk-coverage 近平坦、image_only 欠覆盖，只能写成初步刻画。
- 三轴"最亮构型与光路解释"：fixed 几何 top-1 已闭口（yaw=245/pitch=27.5/roll=+15，OCS=0.2089），光路归因干净（金属主体近镜面 95.0%，N·H≥0.99 像素 81.3%），机制普遍性 PARTIAL_GENERALITY；但组合几何角落异常（C_R3 在 sun+7/view−7 下 0.2256 反超）未定性，小项目尚未收口。

**未达到但已合理转化：**
- 光度-图像联合反演增益（价值 1/6/7）：joint 相对 image_only 增量 ≤+0.0068，且归因明确——clean 与 severe 下 image_only 均近饱和（severe hit@30 仍 0.9966+），是天花板问题不是互补性被证伪。这一条已经合理转化为 R128 的核心科学问题："在什么真实退化条件下 OCS 才从单独有信息变成对图像真正互补"。转化是对的，但**当前论文若以"互补性"为标题级承诺，这块是空的**。
- 姿态运动特征与动态光变（价值 4/5）：正确推迟为路线四，不应在本轮追。

**不应继续强追：**
- "真实未知目标姿态反演成功率"叙事——25 号已备案否定，专家 0624 也确认三方向中只有前向模型方向有直接应用价值。任何回摆都是自毁。
- 完整三轴 roll 网格化训练（约 19 万姿态）——03 号价值思考已论证不必要，M-roll ±15° 探针足以支撑 fixed-roll 边界声明。

## 4. 当前最成立的科学问题

本项目最应该被写成的形态是三者组合，按权重排序：

1. **可观测性研究（主体，约 60%）**：跨几何稀疏光度向量对姿态信息的可观测性地图、信息下界、外推边界。这是证据最厚的部分，也是文献里真正的空白——现有光变反演文献（Wetterer & Jah UKF 系、PSO 系、Kaasalainen 系）全部基于时序 light curve，"跨几何离散多观测光度向量"这一形态加"可观测性地图"这一产出，检索确认没有直接对标工作。
2. **前向仿真与光路解释研究（次主体，约 25%）**：统一前向模型框架 + 三轴最亮构型与近镜面机制归因。三轴小项目的光路归因链（per-part 分解、法向-半程向量角、机制富集 ×6.36、corr≈+0.95）在光度建模文献里是少见的可审计解释，独立成一章或一节都站得住。
3. **互补性与置信边界研究（收尾，约 15%）**：当前只能写成"边界刻画 + 负结果 + 开放问题"，除非 R128 落地，否则不能升格为标题级贡献。

不建议写成"姿态反演系统"（红线），也不建议写成纯"互补性边界研究"——后者恰是证据最薄处，标题写它等于把最弱的板亮给审稿人。

## 6. 专家质疑与审稿风险

**已被实质回应的：**
- "仿真与图像应在更前一步物理统一"——v0.4 同源前向架构正是照此做的，这是项目与专家意见最对齐的一点，论文里应显式引用这条动机。
- "多几何观测过于严苛、不现实"——GEO PRE 表已确认可反算每帧 sun/view 几何、多台站覆盖东经 60°–175°，一旦做出真实相位角覆盖统计图，这条质疑基本可拆除。目前只是"能拆但还没拆"。
- "反演好坏与仿真好坏无法解耦"——model-known + 统一前向模型 + 可观测性叙事，把反演从"成功率主张"降为"验证工具"，解耦问题被定义级地绕开了。这是转向的最大收益。

**仍然危险的：**
- "电脑仿真根本不能说明现实情况"——**这是当前最大审稿风险，且尚未被任何已完成实验缓解**。M3 退化只是仿真内部的退化，GEO 锚点未启动，暗室未启动。审稿人问一句"你的 OCS 量级和真实测光对得上吗"，目前无一张图可答。
- 图像通道过于理想——image_only 在 severe 档 hit@30 仍 ≈1.0，等于承认所设"severe"离真实观测难度还很远。这既解释了 joint 无增益，也削弱了"图像需要光度辅助"的立论前提。R128 Phase 0 的真实难度审计正是对症药。
- "光度对姿态精确判断基本无用"——L1 正结果（多几何下 cMAE 22.77°、P-DB 8.19°）是直接反证，但仅在 model-known 仿真内插条件下成立。写作时必须主动把 P-EXT 坍缩摆在正文，抢在审稿人前面说"单帧/外推场景专家是对的，多几何内插场景存在可用信息"。

**必须主动降调的表述：** joint 互补性、三轴"最亮"的全局性（只是 fixed 几何 ±7° 邻域内）、conformal 作为最终校准、任何 sim-to-real 有效性暗示。

## 7. 增补路线二（R128）的价值判断

**结论：值得采纳，但必须裁剪，且它是补短板而非发散——前提是砍掉一半。**

理由：R125/R127 收口后全项目唯一标题级空洞就是 joint 互补性，而 R128 的 Phase 0–2（真实难度审计 → 三档退化 → 五方法互补性矩阵）正是针对这个空洞的最小闭环，同时顺带回应专家"图像通道过于理想"的质疑。它的三档可接收结论（强正向/中性/负向）设计得当——即使做出负向，"OCS 更适合作可观测性与置信边界"也能与现有主线自洽，不存在"做了白做"的风险。

但按原方案全做会发散：Phase 3 的 C（patch photometry）与 D（part-aware matching）带 semi-oracle 与口径混写双重风险，E 是对照性杂项；这三项建议整体后置或放弃。附录 A 指出的两个缺口必须先补：一是退化参数与判定阈值**预注册**（先定后看，防"调参造增益"的指控——这是审稿人对这类实验的第一反应）；二是 GEO 目标地基观测多为欠分辨近点源，Phase 0 需先确认图像通道在真实像素尺度下还剩多少可用结构，否则"真实难度"档可能直接把图像打成点源，实验退化为 OCS-only 对照。

放置建议：若 Phase 0–2 做出中性以上结果，进主文 Results 一节；若负向，进主文但写成边界结论；Phase 3 无论如何只进 Future Work。执行时机维持 Codex 既定顺序（三轴 P4-PHYS-F 收口后回看裁决），不建议插队。

## 8. 面向大论文 / SCI / 目标期刊 / 一区 TOP 的分层建议

- **硕士大论文：现有证据已足够。** 8 章"主干+增强腿"结构下，第 3–5 章（前向模型、可观测性/互补性/置信、mismatch 边界）证据完备，三轴小项目收口后可作独立一章。无需任何新大实验。
- **一篇稳健 SCI（Acta Astronautica / ASR / AST / Remote Sensing，二类 B 档）：现在就够。** 以可观测性研究为主线、三轴机制归因为特色章、负结果为边界，按 24 号 Results 组织即可成稿。
- **上探 TAES / TGRS / AIAA J（二类 A 档）：需要最小补强包，缺一不可：**
  1. R128 Phase 0–2（修复 joint 空洞，或把它钉死成有真实依据的边界结论）；
  2. GEO 锚点最小版：相位角覆盖统计一张图 + 仿真 vs 真实光度分布/量级对比一张图（不做反演，只做保真度锚定）；
  3. 一个已发表方法对比锚点（见下节问题 8 的边界）。
  三项合计是受控工作量（GEO 最小版基本是数据统计，无新渲染），做完后"可观测性地图 + 真实锚点 + 方法参照"的组合在 TAES 是有竞争力的。
- **一区 TOP（Nature 系/PRL/PAS）：当前形态不具备，也不建议以此为规划目标。** 缺真实闭环验证、缺跨目标泛化、问题影响面属领域内而非跨领域。24 号"claim 不随目标期刊膨胀"的红线在此完全正确。把一区 TOP 从心理预期中移除，能显著降低写作阶段的叙事膨胀风险。

## 9. 项目方案优化建议（按优先级）

**建议 1：把论文主叙事从"互补性"重心移到"可观测性地图 + 外推边界"。**
问题：24 号三问并列，但证据厚度悬殊，互补性最薄。重要性：决定审稿第一印象。做法：标题与摘要以 observability/information boundary 为主词，complementarity 降为 research question 之一。风险：与作者最初情感投入（联合反演）冲突。需作者确认。

**建议 2：GEO 最小锚点提前做（不等路线二正式启动）。**
问题：专家"仿真不能说明现实"是最大悬置风险，而 PRE/DET 表统计不需要任何渲染或训练。重要性：一张真实相位角覆盖图 + 一张光度分布对比图，成本约数天，是全项目性价比最高的补强。做法：作为独立只读数据分析任务下发，产出两图一表，写入 Method/Discussion。风险：量级若对不上需诚实写成 mismatch 证据（这本身也是可发表内容）。需 Codex 放行（涉及新分析任务）。

**建议 3：R128 裁剪为 Phase 0–2 + 预注册，Phase 3 C/D/E 移出本轮。**
问题与做法见第 7 节。重要性：高。风险：Phase 0 可能发现真实难度下图像退化为近点源，届时实验设计需改判（这恰是应该提前知道的事实）。需 Codex 裁决。

**建议 4：三轴小项目以 P4-PHYS-F 为收口终点，写作定位锁定为"机制解释章"。**
问题：sun/view 扩展存在无限加密的诱惑（C_R3 之后还会有新角落）。重要性：防发散。做法：F 完成后无论结论如何，均以"fixed 几何 top-1 + 机制富集 + 组合几何下机制迁移的诊断性观察"收口，全局最优声明永久放弃。风险：低。需 Codex 在 F 后裁决。

**建议 5：补一层轻量理论锚（Fisher-like 局部灵敏度）。**
问题：当前全部结论是经验性的，二类 A 期刊审稿人会问"为什么多几何单调增益、为什么 yaw 外推坍缩"有没有理论解释。重要性：中高；文献区已备 Gerwe & Idell 2003 CRLB 分析作参照。做法：24 号已预留"Fisher-like local sensitivity 不作唯一理论主轴"的口子——对前向模型做数值雅可比，输出姿态-几何灵敏度图，与 D4 可观测性地图互证。成本低（前向模型现成，无训练）。风险：与经验图不一致时需解释，但不一致本身也是发现。需 Codex 放行。

**建议 6：把 P-DB 强于 neural 回归升格为显式发现。**
问题：G5 下 8.19° vs 22.77° 的差距目前只是 L1D3 的附带观察。重要性：它是"信息在数据里、神经头没吃到"的直接证据，且与四象限（P-DB only 44 vs neural only 3）互证，是审稿人会喜欢的诚实结论，也为"model-known 下模板检索是更合理的使用方式"提供了应用出口。做法：Results 单列小节。风险：无。不需新实验。

**建议 7：方法对比按"参照锚点"而非"SOTA 竞争"设计（详见问题 8）。**

**建议 8：修复入口文件不一致。**
问题：大根目录 AGENTS.md 滞后于 CLAUDE.md 一个阶段。重要性：低但零成本。做法：由作者/Codex 同步更新（本报告无权修改）。

## 10. 论文收口建议

- **推荐主线**：单一主论文 = "统一前向模型 + 跨几何稀疏光度向量姿态可观测性地图 + 外推/退化/融合边界"，三轴机制归因作特色章或第二篇短文（若主文超长，三轴部分独立成 letter/短文投 AST/Optics 类刊是干净的切分）。
- **Results 组织**（按 24 号十类产出裁剪为六节）：① 多几何 OCS-only 可观测性地图与单几何信息下界（主图：G1/G3/G5 误差地图 + 单调增益曲线）；② 退化鲁棒性（M3+multi-seed）；③ 外推边界（P-EXT 坍缩 + B6 归因，负结果正面写）；④ P-DB 检索与置信一致性（conformal set_size、四象限）；⑤ 融合边界（joint 无增益 + image 饱和归因；R128 若落地则升级本节）；⑥ 三轴最亮构型与光路机制（若不拆分）。
- **图表优先级**：第一优先是 D4 式可观测性地图与 G1→G5 增益曲线（这是论文的"脸"）；第二是 consistency vs error / set_size 收紧图；第三是三轴 per-part 归因与 N·H 富集图；误差表全部降为 SI。
- **负结果写法**：统一为"边界地图"框架——每条负结果写成"在 X 条件下信息不可用，归因为 Y，检验过替代解释 Z"。C2/C3 的 0.00% 与 P-EXT 坍缩合并为一节外推边界，禁写清单（不写"光度无用""yaw 不可观测"）严格执行。
- **三轴小项目放置**：作为"前向模型解释能力"的展示章，标题用 brightest-configuration and light-path attribution，绝不出现 inversion/estimation 字样；全局性限定语（fixed 几何、±7° 邻域、part-level proxy）进图注而不只进正文。
- **真实数据边界写法**：GEO 库固定表述为"attitude-truth-free, fidelity-anchoring dataset"；所有真实数据段落以"no three-axis attitude ground truth is available or claimed"显式收尾；暗室与 LEO 各一段 Future Work，不给时间承诺。

## 11. 最终专家判断

**当前项目具备收口基础。** 路线一 C 的证据链（正结果、负结果、归因、稳健性检验）在同类仿真研究中是完备的；三轴小项目距收口只差 P4-PHYS-F 一步。不需要任何新的大实验。

**最优策略：受控补强后进入整理写作**，而不是继续推进新路线，也不是立即纯写作。具体节奏：P4-PHYS-F 收口三轴 → GEO 最小锚点两图（建议 2，可并行）→ Codex 回看裁决 R128，若采纳则只做裁剪版 Phase 0–2 → 进入写作。若时间紧张，R128 可放弃，代价是投稿档位从 TAES 线回落到 Acta/AST 线——这是一个作者可以自主选择的档位-工时交换，两个选项都是体面的。

**必须避免的表述**：真实未知目标反演、joint 强互补已证明、三轴全局最亮、仿真等价真实观测、GEO 库含姿态真值、外推问题已解决、conformal 为最终校准。

**最值得保留为核心贡献的**（按顺序）：① OCS-图像 pixel-level 同源统一前向模型框架；② 跨几何稀疏光度向量的姿态可观测性地图与单调增益证据（含退化与 multi-seed 稳健性）；③ 外推边界与融合边界的归因式负结果；④ 三轴最亮构型的近镜面机制归因；⑤ P-DB 检索优于神经回归的发现。这五条合起来，是一个诚实、有边界感、方法可审计的研究——这正是当前审稿环境下仿真类工作能拿到的最好牌面。作者最初的"光度辅助联合反演"梦想没有死，它只是被正确地改写成了"先证明信息在哪里、边界在哪里"；R128 是它在本项目内的最后一次受控尝试，之后的部分属于下一个项目。
