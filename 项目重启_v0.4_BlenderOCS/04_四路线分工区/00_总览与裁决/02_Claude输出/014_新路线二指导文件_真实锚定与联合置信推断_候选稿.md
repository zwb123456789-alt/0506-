## 1. 文件性质与定位

本路线是路线一 C 与三轴小项目之后、进入论文写作与真实数据深处理之前的**价值增强主路线**。它不替代路线一 C，不改写 24 号主线；它的定位是：

```text
把路线一 C 与三轴小项目产出的"仿真内结论"，
在真实 GEO 观测数据的锚定与约束下，
升级为"有真实依据的边界结论 + 被真实现象印证的机制预测 + 有实际含义的置信推断"，
从而把论文从稳健 SCI 档推进到目标期刊（TGRS/TAES/AIAA J）档，
并为一区 TOP 冲刺构建"发现级"贡献候选。
```

它不是：

```text
真实未知目标姿态反演系统；
真实望远镜监督验证；
把图像人为打残制造 joint 增益的路线；
替代暗室验证（原路线三）或 LEO 动态方向（原路线四）。
```

## 2. 一句话主线

```text
以真实 GEO 观测统计为锚，回答三个递进问题：
一、真实观测条件下图像通道还剩多少信息、光度何时接管（信息接管边界）；
二、当两通道并存时，结果级/置信级联合推断能否回答"什么时候该信谁"（置信联合）；
三、仿真发现的高亮光路机制能否在真实光度数据中被检索证实（机制—现实闭环）。
```

## 3. 三支柱结构

本路线由三个支柱组成，每个支柱独立可发表、共同构成顶刊叙事：

### 支柱一：真实观测难度与信息接管边界（吸收并重构 R128 Phase 0–2）

核心问题从 R128 的"什么退化条件下 joint 才互补"升级为：

```text
在从可分辨图像到欠分辨点源的连续退化谱上（退化参数全部溯源真实 FITS 统计），
图像通道的姿态信息何时衰减、何时消失；
独立多几何 OCS 光度向量的姿态信息何时保持、何时成为唯一信息源。
```

关键设计要求：
- Phase 0 必须先做真实图像难度审计，并显式给出点源 kill/branch 判据：若真实 GEO 成像本质为近点源，路线主叙事切换为"信息接管边界"，而非"退化后 joint 救回"——这不是失败分支，而是光度价值的最强现实论据。
- 退化档位（mild/realistic/severe 的物理参数）与主指标、判定阈值必须**预注册**（见 015 号文件与工作流建议 5）。
- R128 原 Phase 3 的 patch photometry（C）与 part-aware matching（D）整体后置为可选扩展，不进入本路线必做项。

### 支柱二：结果级/置信级联合推断（作者想法 3 的正式落地）

核心问题：

```text
当特征级融合无增益时，决策级与置信级融合改变的是"什么时候该信"：
posterior-level fusion、consistency gating、selective prediction（risk-coverage）
能否在真实难度退化谱上给出可测的可信性收益？
```

关键设计要求：
- 复用路线一 C 已有的候选分布输出（top-k、entropy、margin、JS、overlap），原则上零新渲染、零新训练（除支柱一新增退化档下的评估）。
- 评价目标不是"平均精度提高"，而是 risk-coverage 曲线、拒识后误差下降、冲突样本识别率——即 24 号 consistency-as-confidence 的正式实验闭合。
- 必须与支柱一绑定：在 clean 与真实难度各档下同时评估，避免"图像饱和压扁置信增益"的假阴性。

### 支柱三：高亮机制的真实数据验证闭环（专家补充方向 7a，一区 TOP 的核心弹药）

核心问题：

```text
三轴小项目确认的"金属主体近镜面对齐探测器"高亮机制，
预测了 glint 事件的太阳-目标-探测器几何条件；
GEO 库 PRE 表可反算每帧 sun/view 几何、DET 表有每帧实测星等——
在预测的镜面几何窗口内，真实多帧光度是否系统性出现亮度尖峰？
```

关键设计要求：
- 不需要任何姿态真值；验证对象是"机制预测的几何—亮度关联"，不是姿态反演。
- 必须预注册检验统计量（窗口内 vs 窗口外亮度尖峰发生率、效应量、显著性口径）。
- 阴性结果同样可发表（机制的现实边界），但必须预先定义阴性/阳性/不确定三档判读。

## 4. 两个配套加强件（独立小任务，不阻塞三支柱）

```text
加强件 A：外部方法基线锚点。
  图像分支引入 1 个 SPEED 社区已发表代表方法，
  光度分支引入 1 个光变反演已发表代表方法（UKF 或 PSO 类），
  在本项目协议下运行，作为"坐标系锚定"而非 SOTA 竞争。
  作用：坐实"图像近饱和"归因，回应"为什么不与已有方法对比"。

加强件 B：第二卫星模型泛化检查。
  用一个结构差异明显的简化第二模型，
  复现"多几何单调增益结构 + 近镜面高亮机制"是否保持。
  作用：把"规律"与"个例"区分开，是一区 TOP 的硬性门槛。
```

另有两个轻量增值项（D 类，可打包执行，见 015 号）：

```text
增值项 C：GEO 最小锚点两图（真实相位角覆盖统计图 + 仿真 vs 真实光度分布对比图）。
  可在三轴收口前并行申请放行，是全项目性价比最高的一步。
增值项 D：Fisher-like 局部灵敏度理论锚 + 观测规划信息论表述（恢复价值 3 原意）。
```

## 9. 写作定位

本路线服务的论文主叙事：

```text
标题级贡献：可观测性边界 + 信息接管边界 + 机制的真实数据印证。
互补性（joint）：降为 research question 之一，按支柱一/二的实际结果定档，不作标题级承诺。
```

可用表述：

```text
We characterize an information takeover boundary along a degradation continuum calibrated from real GEO survey statistics.
Decision-level and confidence-level fusion are evaluated for when to trust, rather than average accuracy gains.
The near-specular brightening mechanism identified in simulation is tested against real multi-epoch GEO photometry via preregistered geometric-window statistics.
```

禁用表述：

```text
真实未知目标姿态反演已实现或已验证；
真实 GEO 数据证明 joint 反演成功率；
glint 检索阳性 = 姿态已被真实数据确认；
人为强退化下的增益 = 真实工程互补性；
GEO 库含三轴姿态真值。
```

## 10. 最低完成标准

1. N0 审计完成，点源判据落判，路线主叙事口径（接管边界 vs joint 救回）确定。
2. 预注册文件在任何正式实验前冻结并入档。
3. 信息接管边界矩阵完成：至少 4 档退化 × 3 通道 × 既有多几何梯度，产出接管边界图。
4. 结果级/置信级融合完成：risk-coverage、拒识收益、冲突识别三类曲线在 clean 与真实难度档下齐备。
5. 支柱三完成：预注册几何窗口统计落判（阳性/阴性/不确定三档之一），并给出效应量。
6. 加强件 A 完成（基线锚点表）；加强件 B 至少完成第二模型的可观测性结构复现检查。
7. 全部结论按"可写/禁写"清单自查通过。

## 11. 红线

```text
不把本路线写成真实未知目标姿态反演系统或其验证。
不在预注册前跑正式退化矩阵；预注册后不得反向调参。
```
