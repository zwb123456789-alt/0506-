# 第四部分 支柱三：glint 机制真实检索验证（N5）

## N5.1 目标

把三轴小项目的近镜面高亮机制变成可证伪的真实数据检验：预测的镜面几何窗口内，真实光度是否系统性偏亮/出现尖峰。

## N5.2 步骤

1. **机制→几何窗口翻译（仿真侧）**：用三轴前向模型对目标型号在其真实姿态先验下（GEO 通信星标称对地定向 ± 小扰动；该先验必须显式声明为假设）扫描 sun/view 几何，输出"预测增亮几何窗口"——镜面对齐角 δ（太阳-表面法向-探测器的半程向量偏角）小于阈值的几何集合。新增仿真扫描 ≤ 500 渲染单元（可用低采样快速模式，需 smoke 验证与全采样一致性）。
2. **真实帧几何标注（数据侧）**：对增值项 C 已反算几何的目标帧集，逐帧计算 δ，分为窗口内（δ ≤ δ_in）与窗口外（δ ≥ δ_out）两组（δ_in < δ_out，中间带丢弃，防边界污染）。
3. **统计检验**：比较两组的亮度分布与尖峰发生率。
4. **稳健性**：换 1–2 个同型号目标重复；对 δ 阈值做 ±30% 敏感性。

## N5.3 预注册检验统计量（N1 冻结）

```text
主检验：窗口内帧的"增亮事件率"P_in vs 窗口外 P_out。
  增亮事件定义：该帧星等比该目标同相位角带基线中位数亮 ≥ 0.5 mag。
  统计：两比例检验 + bootstrap 置信区间；效应量 = P_in / P_out。
判读三档：
  阳性：P_in/P_out ≥ 2 且 95% CI 下界 > 1.2 → "机制预测的几何-亮度关联在真实数据中成立"。
  不确定：CI 跨 1 或样本不足（窗口内帧数 < 30）→ 如实报告，写数据量边界。
  阴性：P_in/P_out ≤ 1.2 → 机制在真实条件下被姿态先验偏差/材料失配/大气效应掩盖，写成机制现实边界。
姿态先验敏感性：对地定向扰动 ±5°/±10° 两档重算窗口，检验结论稳健性。
```

## N5.4 边界声明（写作用）

```text
被验证的是"机制预测的几何—亮度关联"，不是姿态反演；
姿态先验是假设输入，不是估计输出；
阳性结论表述上限：the geometric predictions of the near-specular mechanism are
consistent with real multi-epoch GEO photometry。
```

```text
     必须回查本项目图像评估头是否过强/过弱，并在论文中说明。
训练部分为 C 类，须单独放行。
```

## 加强件 B：第二卫星模型泛化结构复现

```text
模型选择：结构差异明显（如帆板/本体比例不同、无隐身板类部件）、几何可公开获得或可简化构建；
最小矩阵：fixed-roll 2664 姿态 × G1/G3/G5 的 OCS 渲染（渲染预算另列，约 8000 单元，
         超出本路线上限——列为独立 C 类阶段门，由 Codex 按资源单独裁决；
         可先做 1/4 抽样网格版 ≤ 2000 单元的先导）。
检验目标（结构复现，不比数值）：
  1. 多几何单调增益结构是否保持（G1→G3→G5 方向一致）；
  2. 高亮候选是否同样被"金属大面元近镜面对齐"机制签名富集（富集倍数 > 2 即记为结构复现）；
  3. yaw 外推坍缩是否同样出现。
写作口径：structural reproducibility check，不写 cross-target generalization proven。
```

## 增值项 D：Fisher 灵敏度理论锚 + 观测规划表述

```text
Fisher 锚：对前向模型在姿态网格上做数值雅可比（OCS 向量对 yaw/pitch 的差分灵敏度），
  输出 Fisher-like 局部灵敏度图；与 D4 经验可观测性地图做秩相关对照（预期 ρ > 0.5）；
  不一致区域单独列出并解释（visibility/shadow 不连续、镜面峰混叠）——不一致本身是发现。
观测规划表述：基于 D4 地图 + conformal set_size，定义几何信息效用分 U(g)，
  输出"给定 k 次观测预算的贪心几何选择策略"与其相对随机选择的增益曲线；
  恢复价值 3 原意，作为论文应用出口一节。
两项均为 D 类零渲染任务，可打包执行。
```

```text
定位：一区 TOP B 线叙事或独立第二篇；不阻塞本路线收口；启动须 Codex 单独裁决（C 类）。
```
