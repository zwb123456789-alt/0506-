## 二、最终采用的主线

最终采用 24 号主线：

```text
不是做真实未知目标姿态反演系统，
而是在 model-known 条件下，
研究独立 OCS 光度通道与图像成像通道共享同一物理前向模型时，
跨几何 OCS 多观测光度向量与图像通道对姿态信息的可观测性、互补性和置信一致性。
```

这个主线的关键限定是：

- non-cooperative but model-known target。
- OCS = independent non-imaging photometric channel。
- 主线 OCS 形态 = multi-observation photometric vector across controlled sun/view geometries。
- image-derived OCS 只作 common-mode failure 对照。
- F1 单瞬时总光通量只作信息下界。
- F2 per-part OCS 只作 semi-oracle / diagnostic。
- L2 时域光变曲线、完整 Earthshine、完整探测器链路和真实锚点路线放入 19 号 / Discussion / Future Work。

## 三、为什么旧主线不能继续

### 3.1 “真实未知非合作目标姿态反演系统”过度宣称

旧主线容易被理解为：

```text
给定真实未知目标的图像和 OCS，即可直接反演可靠姿态。
```

这个说法不成立。OCS lookup / OCS-image fusion 依赖：

```text
目标几何 + 材料/BRDF + sun/view 几何 + 姿态 -> OCS/image signature
```

如果目标几何、材料和 BRDF 都未知，就没有目标专属前向表。姿态、形状、尺度、材料反射和观测链增益会共同影响亮度与图像，问题会变成欠定反演。

### 3.2 仿真 OCS 不能默认等于真实 OCS

即使有 STL，也不能直接写：

```text
真实观测 OCS 可以与仿真 OCS lookup 绝对匹配，从而得到可靠姿态。
```

偏差来自材料、BRDF、几何误差、观测链、定标、背景、phase 分布和真实光照环境。没有真实/半真实锚点时，纯仿真只能声明“在假设物理内成立”。

### 3.3 v0.3 结果不能作为 v0.4 主结果

旧 v0.3 中 OCS 来自 face-level / face-center / module-A 采样，而图像来自 Blender pixel-level geometry/pass。二者不是同一前向模型下的同源采样口径。

这会影响：

- OCS-only。
- fusion。
- OCS noise。
- branch masking。
- 2b / 12c / 12f / 12g 等结果。

因此 v0.3 数值只能作为历史证据、机制假设和代码结构参考，不能作为 v0.4 主论文结果。

### 3.4 继续旧主线会降低投稿可信度

旧主线看起来更像“系统工程应用论文”，但证据链支撑不住 field-ready / operational-ready 宣称。审稿风险集中在：

- 真实未知目标前提不成立。
- 仿真与真实 OCS 绝对匹配缺少锚点。
- OCS 与图像的旧采样口径不一致。
- 结果表可能只是受控仿真内的误差下降，科学问题不够明确。

因此旧主线不是更强，而是更容易被审稿人抓住根本漏洞。

## 四、为什么 24 号主线更合理

### 4.1 model-known 边界诚实且有现实场景

“非合作”不等于“完全未知”。合理对象包括：

- 己方失效卫星。
- 已知型号或结构公开的航天器。
- 有设计资料或历史模型的目标。
- 实验室缩比模型。
- 由其他传感器或先验重建得到近似几何的目标。

这个边界既不夸大成任意未知目标，也不是无应用价值的玩具问题。

### 4.2 统一物理前向模型修复 v0.3 的根问题

24 号主线要求 OCS 与图像共享：

- 目标几何。
- 姿态。
- sun/det 几何。
- BRDF / 材料参数。
- visibility / shadow / render pass。

这样 OCS 和 image 的差异来自观测通道，而不是来自两个不一致的仿真口径。它把问题从“结果是否偶然由采样差异造成”转为“两个通道在同一物理下各携带什么信息”。

### 4.3 OCS 口径 A 是 consistency-as-confidence 的前提

主线 OCS 采用：

```text
independent non-imaging photometric channel
```

理由是：只有当 OCS 与图像具有不同退化源和失败模式时，OCS-image consistency 才有独立证据相互印证的意义。

如果 OCS 是 image-derived photometry，那么 OCS 与图像共享同一退化链路。一致性可能只是 common-mode error，不再能直接解释为高置信。

因此：

- 口径 A 是主线。
- 口径 B 是对照，用于证明共模退化下 consistency 何时失效。

### 4.4 OCS 必须采用 L1 跨几何多观测光度向量

独立非成像光度通道在单瞬时只能给出一个总光通量标量。一个标量对 2-3 自由度姿态约束极弱，容易导致：

- OCS-only posterior-like distribution 接近均匀。
- OCS 与 image 无法形成真正互补。
- consistency-as-confidence 缺少有效的 OCS 候选分布。

因此，主线 OCS 不能是单点总光通量，而必须是：

```text
同一目标姿态下，跨多个受控 sun/view 几何得到的总光通量序列。
```

这既保留 independent photometric channel 的物理自洽，又让 OCS 有足够信息量参与可观测性和置信分析。

### 4.5 论文主线从“误差表”升级为科学问题

24 号主线不再只追求 mean error / Hit@5，而是回答三类问题：

- What can be known：OCS/image 各自携带多少姿态信息。
- When complementary：哪些几何下二者互补，哪些几何下共同失败。
- When trustworthy：跨通道一致性是否能作为置信或拒识判据。

这比单纯证明“融合后误差更低”更像一条可审稿、可复现、可扩展的科学主线。

## 五、为什么不采用其他路线

| 路线 | 处理 | 原因 |
|---|---|---|
| 真实未知目标姿态反演系统 | 放弃为主线 | 几何、材料、BRDF 未知时缺少目标专属前向表，宣称过强 |
| 旧 v0.3 OCS + image fusion 数值 | 封存为历史 | OCS 与 image 采样口径不统一，不能作为 v0.4 主结果 |
| image-derived OCS 作为主线 | 降为对照 | 与 image 共享退化链，容易形成 common-mode consistency |
| 单瞬时 OCS 总光通量 F1 | 降为信息下界 | 单标量对姿态约束不足 |
| 静态 per-part OCS F2 | 降为 semi-oracle / diagnostic | 非成像光度通道无法给出部件级贡献 |
| L2 时域光变曲线 | Future Work | 需要自转动力学、曝光积分、运动模糊、时变轨道几何 |
| 19 号完整保真度路线 | Discussion / Future Work | 八层物理链会拖入 sim-to-real 工程，超出当前主论文 |
| mean error / Hit@5 结果表主线 | 降为验证工具 | 不能支撑 observability / confidence 的论文贡献 |

## 七、投稿影响判断

采用 24 号主线对投稿总体是正向作用。

作者最新确认：最终投稿目标以外部 `文献/00投稿目标/` 中列出的较高期刊为参照，目标是尽量向上冲刺，越高越好。该目标文件夹当前以截图形式列出 Nature、Science、Nature/Science 子刊、National Science Review、Science Bulletin、Engineering、Physical Review Letters、Progress in Aerospace Sciences，以及 AIAA Journal、Aerospace Science and Technology、Chinese Journal of Aeronautics、IEEE TAES、JGCD、IEEE TGRS、Acta Astronautica、ASR 等候选层级。

正向原因：

- 降低过度宣称风险。
- 把问题从“工程反演系统是否真实可用”转为“同一物理前向模型下两类观测的信息结构是什么”。
- 能形成更清晰的论文贡献：observability、complementarity、confidence consistency。
- 能诚实报告 mismatch 和 common-mode failure 边界，提升审稿可信度。
- 让论文可以按高水平期刊的科学问题密度和证据链完整度来设计，而不是从 Acta/ASR 稳健稿起步后再被动改写。

投稿层级判断：

| 档位 | 判断 |
|---|---|
| 最高冲刺 | 以 `文献/00投稿目标/` 中的 Nature / Science / 子刊 / NSR / Science Bulletin / Engineering / PRL / Progress in Aerospace Sciences 等为上探参照；风险很高，但可作为最终质量牵引 |
| 高水平 SCI 冲刺 | IEEE TGRS / AIAA Journal / IEEE TAES / JGCD / Optics Express / 高水平遥感光学与航天方向期刊；必须把信息量、置信指标、mismatch 和 source data 做扎实 |
| 稳健 SCI | Aerospace Science and Technology / Chinese Journal of Aeronautics / Acta Astronautica / ASR / Remote Sensing 等，可作为结果强度不足以支撑更高层级时的稳健选择 |

因此，24 号不是降低论文目标，而是把论文从容易被击穿的“大系统宣称”调整为更可审稿、也更有机会向高水平期刊上探的科学问题。最终投稿位不在现在提前降档，而应由后续 v0.4 结果、指标闭合程度、文献对话质量和是否补入真实/半真实锚点共同决定。
