## 2. 当前总裁决路线

R01 已通过的最终分层结构为：

```text
路线零 = v0.3 旧稿封存待解封评估，不阻塞 v0.4；
路线一 = 必选主干，fixed-roll yaw-pitch 纯仿真可观测性 benchmark；
路线二 = 优先增强层，GEO 真实光度 sim-to-real 锚点；
路线三 = 条件触发增强层，暗室缩比系统内真实光度 + 姿态真值闭环；
ISAR 子线 = 路线三可选增强，真实在轨同型目标姿态参考/真实图像案例候选。
```

含义：

- 路线一：fixed-roll yaw-pitch 纯仿真可观测性 benchmark，是硕士论文和 v0.4 主体。
- 路线二：GEO 真实光度数据库作为 sim-to-real 锚点升级层；无姿态真值，只做保真度/多几何现实性锚定，不做监督姿态反演。
- 路线三：暗室缩比独立验证腿；只有 pilot 通过后才并入主论文增强层，不阻塞路线一主体；暗室闭环成功率只限暗室缩比系统内，不外推 GEO / 在轨目标。
- ISAR 子线：只作为可选增强，不能写成光度确认、姿态真值、GEO 监督标签或路线三暗室 pilot 的必做项。

该分层结构已经 R01 确认，后续入口文件与发刊规划应保持这一口径。

### 7.1 路线一 C

路线一 C 是路线一主干的当前执行形态：

```text
v0.4 pixel-level OCS-image 同源前向架构
+ B0 工程 baseline
+ B1 书中改进冯模型待确认 Method 目标
+ GGX / Cook-Torrance 对照与 mismatch 分支
```

反演继续作为可观测性、互补性和置信一致性的验证工具，不作为真实未知目标反演成功率。

### 7.2 三轴小项目

三轴小项目是路线一 C 后的必做桥接层，负责：

```text
三轴最亮构型；
高信息姿态；
最优可观测姿态；
低信息/不值得观测区域；
fixed-roll 结论在 roll-aware 空间中的稳定性或迁移。
```

它不等同于路线一 roll sensitivity，也不得写成真实未知目标三轴反演系统。

### 7.3 路线二/三/四的新边界

路线二服务路线一 C 与三轴小项目，只做真实光度趋势、分布、多帧多几何现实性和 sim-to-real 光度锚点，不提供姿态真值。

路线三服务路线一 C 与三轴小项目，可用暗室真实光度 + 姿态真值检查三轴最亮/高信息构型，但只限暗室缩比系统内，不外推 GEO / 在轨。

路线四是未来方向，研究 LEO 光学特性与姿态运动特征关系，需要动态光变曲线与姿态动力学建模，不进入当前必做闭环。
