# 路线四：LEO 光学特性与姿态运动特征关系未来方向指导文件

最后更新：2026-06-22

## 1. 文件性质

本文用于记录路线四未来方向。它不是当前路线一 C、三轴小项目、路线二或路线三的前置条件，不进入当前必做闭环。

## 2. 一句话定位

```text
以 v0.4 前向模型为起点，面向低轨目标动态观测，
研究姿态运动、自旋/进动、时域光变曲线与光学特性之间的关系。
```

## 3. 与当前主线的区别

| 维度 | 当前路线一 C / 三轴小项目 | 路线四 |
|---|---|---|
| 姿态 | 静态姿态网格，三轴小项目做姿态搜索 | 姿态随时间变化 |
| 数据形态 | 单姿态/多几何 OCS 向量、图像、置信指标 | 光变曲线、动态序列、周期/频谱特征 |
| 目标 | 可观测性、互补性、最亮/高信息构型、观测规划 | 姿态运动特征与光学响应关系 |
| 风险 | fixed-roll / 三轴搜索规模 | 动力学建模、时间采样、真实序列复杂度 |

## 4. 为什么暂不并入当前主线

路线四价值高，但它需要新增：

1. 姿态动力学模型：自旋、进动、翻滚、帆板运动等。
2. 时域光变曲线 L2：不再只是跨几何向量。
3. 动态采样策略：时间步长、曝光、相位角变化、轨道几何耦合。
4. 新指标：周期、频谱、状态转移、运动特征识别。

这些内容会显著扩大当前论文范围。因此路线四应写入 Future Work 或后续独立论文方向，而不反向改变路线一 C 与三轴小项目。

## 5. 可继承的基础

路线四未来可以继承：

```text
v0.4 pixel-level 几何与可见性；
五参数冯 / 书中材料参数主锚点；
GGX / Cook-Torrance mismatch 分支；
OCS/image 双通道一致性分析；
三轴小项目中的高亮/高信息构型搜索结果。
```

## 6. 初步研究问题

1. 不同姿态运动模式是否产生可区分的光变曲线形态。
2. 最亮构型在动态运动中是否对应光变峰值或 glint 事件。
3. 三轴高信息姿态是否能指导动态观测窗口选择。
4. 光度异常是否可从“姿态运动特征变化”角度解释。
5. OCS/image consistency 是否能扩展为时序置信一致性。

## 7. 红线

路线四当前不能写成：

```text
已经完成 LEO 姿态运动识别；
路线一 C 已经覆盖动态光变曲线；
三轴小项目已经解决姿态动力学；
GEO 真实光度数据可直接替代 LEO 动态数据。
```

路线四只作为后续研究方向保留。
