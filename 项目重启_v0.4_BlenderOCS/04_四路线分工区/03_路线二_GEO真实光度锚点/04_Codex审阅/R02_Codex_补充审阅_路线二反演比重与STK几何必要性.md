## 2. 总体裁决

```text
路线二应适度提高反演比重，但不能把反演翻为论文主轴。
STK 几何升级不是路线二通过的必要条件，应定位为“可选增强件 / 二级增强件”，不应成为路线二冻结成立的前置条件。
```

更精确地说：

```text
路线二主轴仍为：
24 号可观测性主线 + GEO 真实光度 sim-to-real 锚点。

反演的合理位置是：
从“单纯误差表验证工具”提高为“配角偏重的反演验证模块”，
服务于可观测性地图、互补性判断和置信一致性验证。

STK 的合理位置是：
真实轨道几何时序发生器，用于提升仿真 benchmark 的几何现实性；
但它不是路线二回应专家质疑的核心证据，也不能替代真实 GEO 光度锚点。
```

## 3. 关于“提高反演比重”的裁决

### 3.1 可以提高，但只能提高到“配角偏重”

专家与发刊需求确实要求路线二不能只停在“真实光度数据证明仿真更像现实”这一层。若完全不加强反演，论文容易被质疑为：

```text
有真实光度锚点，但最后仍只是在谈观测信息结构；
工程上到底能不能帮助姿态估计，不够直观。
```

因此，路线二可以、也应该把反演从 24 号中的“结果表末行验证工具”提高为一个更完整的验证模块，例如：

- OCS-only / image-only / joint estimator 对比；
- 多几何数量、几何覆盖范围对反演误差的影响；
- model mismatch 下的反演退化曲线；
- 可观测性高低区与反演成功/失败区的一致性；
- posterior-like confidence、top-k overlap、JS divergence 与误差之间的对应关系；
- roll sensitivity 与姿态简并模式的反演验证。

这类提高是正向的，因为它把“可观测性地图是否有用”落到估计器行为上，使路线二更能回应专家“反演是否有实际意义”的关切。

但必须同时提高对 inverse crime 的防护。反演戏份加重是一把双刃剑：

```text
反演从末行误差表升格为独立模块 -> 反演结果在论文里分量变重
-> 若 benchmark 用前向模型 F 生成、又用假设 F 的估计器去反演
-> inverse crime：成功率虚高，本质在量“自洽性”而非“方法鲁棒性”
-> 正中专家方向三“无法解耦是仿真不好还是反演不好”。
```

因此反演比重提高到哪里，防 inverse crime 的约束就必须跟到哪里：反演 benchmark 必须注入 model mismatch（BRDF/F0/albedo、定标 gain-offset、几何反算误差、噪声），报告 sim-to-real gap 下的反演鲁棒性，不得在无 mismatch 的 inverse crime 设定下报告成功率。此条与 R01 §6.3 红线 R3 一致，且因本轮主张加重反演分量而升级为路线二必守项。

此外需诚实界定缓解范围：反演配角加重缓解的是“可观测性地图有没有工程意义”，**不是**专家方向三“反演需真实闭环”的完整答复。配角加重给的仍是仿真/STK 有真值场域下的可观测性验证，专家仍可质疑“这还是仿真”。真正“有真值的真实闭环”只能由路线三暗室提供，且暗室成功率不外推 GEO。路线二不应把反演加重宣称为已闭合专家真实闭环诉求。

### 3.2 不能提高为“反演主轴”

路线二不能把最终主轴改写为：

```text
提出一种真实 GEO 目标姿态反演方法，并验证其真实反演成功率。
```

原因不是保守，而是事实地基不允许：

```text
GEO 数据库有光度、有几何、有型号、有时序，
但没有目标三轴姿态 / yaw / pitch / roll 真值。
```

因此，真实 GEO 数据只能用于：

- 真实光度分布/量级/趋势锚定；
- 同目标多帧多几何现实性坐实；
- 光度统计用于异常观测的工程下界佐证；
- sim-to-real gap 与 mismatch 边界量化。

它不能用于：

- 监督姿态反演训练；
- 真实姿态误差计算；
- 真实目标反演成功率统计；
- field-proven / operational-ready 式外场性能声明。

### 3.3 推荐写法

路线二后续若小修冻结文件，建议采用以下口径：

```text
本文不把真实 GEO 数据写成姿态监督数据集。
真实 GEO 数据用于校准和约束仿真前向模型的光度现实性，
并证明多帧多几何光度观测在真实监测中天然存在。
在此基础上，反演实验作为可观测性验证模块，
在仿真/STK/暗室等有真值场域内评估不同观测通道和估计器能否提取姿态信息。
反演结果用于验证 what can be known / when complementary / when trustworthy，
而不是宣称真实 GEO 目标姿态反演成功率。
```

## 4. STK 几何是否有必要

### 4.1 结论：非必要，但有条件地有价值

STK 几何升级对路线二不是必要条件。

路线二的核心回应链已经由 GEO 数据库本身支撑：

```text
DET IPD 真实视星等 -> 回应“仿真光度凭什么可信”
PRE 几何字段 -> 回应“多几何是否现实”
MAN 光度统计 -> 回应“光度是否只用于异常观测”
REG 型号字段 -> 支撑 model-known / known-type 目标选择
```

这条链足以让路线二作为“真实光度锚点增强层”成立。STK 不参与也不影响路线二通过。

### 4.2 STK 的真正价值

STK 的价值不是“真实数据验证”，而是“几何现实性升级”。

推荐定位为：

```text
STK = 轨道/场景几何发生器。
它生成更接近真实轨道动力学的相位角、距离、太阳方向、观测方向和可见弧段时序；
OCS 与图像仍必须由 v0.4 已冻结 Blender 前向模型计算。
```

它能把路线一/路线二中的多几何 benchmark 从：

```text
人为挑选的 G1/G3/G5 受控几何
```

升级为：

```text
真实轨道动力学驱动的连续几何轨迹采样
```

这对发刊有加分意义，因为它会让审稿人更容易接受“多几何不是人为拼出来的玩具设定”。

### 4.3 STK 不能解决的问题

STK 不能替代真实 GEO 光度锚点，也不能解决真实姿态真值缺失。

必须写清：

```text
STK 不是真实观测数据；
STK 不提供真实辐射渲染；
STK 不提供真实目标姿态真值；
STK 反演成功率只能写成仿真成功率，不能写成真实目标成功率。
```

若 STK 被写成“真实闭环验证”，会同时撞上两条红线：

```text
1. 把仿真成功率外推为真实外场性能；
2. 引入 Blender 之外的第二条 OCS / 辐射计算链，破坏 v0.4 同源前向模型口径。
```

### 4.4 纳入优先级

建议优先级如下：

| 优先级 | 内容 | 是否阻塞路线二 |
|---|---|---|
| P0 | GEO 数据库字段边界确认：无姿态真值 | 是，已完成 |
| P1 | 单型号真实光度校准 pilot | 是，路线二真实锚点章的闸门 |
| P1 | PRE 几何反算 sanity check | 是，支撑真实多几何 |
| P2 | 反演模块配角加重：仿真有真值 benchmark | 建议做，提升发刊说服力 |
| P3 | STK 轨道几何升级 benchmark | 可选增强，不阻塞路线二 |
| P3 | STK + 反演综合实验 | 仅在时间、工具、管线稳定后做 |

因此，STK 的结论是：

```text
不必为了路线二成立而强上 STK。
如果路线二 pilot 顺利、时间允许、STK 接入成本可控，可以作为高水平冲刺的增强实验。
如果 STK 会拖慢路线一/路线二核心闭合，应暂缓到总裁决后或 Discussion / Future Work。
```

```text

4. 反演 benchmark 必须注入 model mismatch（BRDF/定标/几何反算误差/噪声），报告 sim-to-real gap 下的反演鲁棒性，不得在无 mismatch 的 inverse crime 设定下报告成功率。
```

### 5.2 建议新增一节：STK 定位

建议标题：

```text
STK 几何升级的可选定位
```

建议写入三点：

```text
1. STK 只作为轨道/观测几何发生器，不作为第二条辐射或 OCS 计算链。
```

## 6. 一票否决风险

后续路线二写作与汇报必须避免：

```text
1. 把 GEO 数据库写成有姿态真值。
2. 把真实光度校准写成真实姿态反演验证。
3. 把 STK 写成真实数据或真实闭环。
4. 把 STK 成功率写成真实目标成功率。
5. 为了加入 STK 而引入第二条 OCS / 辐射计算链。
6. 把反演成功率写成论文最终主结论。
7. 把路线二变成路线一成立的前置条件。
8. 在无 mismatch 的 inverse crime 设定下报告反演成功率。
9. 把反演配角加重宣称为已完整答复专家“反演需真实闭环”诉求。
```

## 7. 最终建议

```text
路线二冻结文件可通过，但建议在后续小修中补入“反演配角偏重”和“STK 可选增强”两组边界。

反演比重：应提高。
提高幅度：提高为独立验证模块，而不是论文主轴。

STK 几何：不必要。
使用条件：仅当路线一主干、路线二真实光度 pilot 与几何反算 sanity check 已经稳定后，
作为高水平冲刺的 P3 增强项纳入；否则暂缓。

路线二的核心发刊价值仍应落在：
真实 GEO 光度锚点 + 真实多几何坐实 + 可观测性/置信一致性主线 + 反演导向验证。
```
