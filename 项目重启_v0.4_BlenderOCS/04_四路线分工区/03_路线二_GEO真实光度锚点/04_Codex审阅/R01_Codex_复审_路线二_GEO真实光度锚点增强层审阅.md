## 2. 总体判断

路线二可通过，冻结定位为**路线一之上的优先增强层（sim-to-real 真实光度锚点）**，无 P0/P1 阻断。

复审结论不是"路线二已经把仿真证明为真实正确"，而是：

```text
路线二在"真实 GEO 光度统计背书 + 真实多几何坐实"范围内独立成立；
它把 24 号主线从"纯仿真内部自洽"升级为"仿真光度结论被真实数据统计级背书"；
但 GEO 数据库无三轴姿态真值，路线二只能做保真度锚定，不能做监督姿态反演；
路线二是路线一的增强层，不是路线一主干成立的前置条件，不得反向阻塞路线一。
```

路线二全文正确守住生死线：**GEO 数据库有光度、有几何、有型号、有时序，但无 yaw/pitch/roll 真值**。该判断与 GEO 数据库整合文件逐表核对一致（五表 OMM/PRE/DET/REG/MAN 均无姿态字段），是路线二全文的承重点，站得住。

## 5. 路线二能力边界（上界 / 下界 / 硬天花板）

```text

  - 真实多几何坐实（PRE 表反算 sun/view 几何，破法 C）
  - 可观测性下界真实锚点（MAN 表光度统计 = 真实异动检测实践）

下界（校准失配较大）：失配诚实写成 sim-to-real gap 边界，降回路线一稳健 SCI 档，风险隔离，不连累主体。

硬天花板（触碰即一票否决，原因唯一：无三轴姿态真值）：
  - 不做监督姿态反演 / 真实成功率
  - 不声称真实望远镜验证
  - 不声称仿真光度 = 真实光度
```

主体写法：骨架不变，仍是路线一可观测性主轴（24 号 what can be known / when complementary / when trustworthy），路线二在地基上加一章"真实光度锚点与保真度校准"。"大量真实数据作保"的正确措辞是"真实数据在统计/趋势层面背书仿真，失配部分诚实归入边界"，claim 从"绝对数值匹配"（做不到）降级为"统计一致性 + 边界诚实"（做得到）。

较路线一的增量：真实光度正面回应"纯仿真凭什么说明现实"；多几何从受控配置升格为真实数据固有结构；"光度只能告警"从软肋转化为可观测性下界证据；新增 sim-to-real 保真度校准独立贡献点；发刊上限从偏稳健 SCI 顶到高水平冲刺档。

## 6. 反演可做范围与 claim 边界（本轮新增核心节）

### 6.1 三个有真值场域 + 一个永不可用场域

反演研究**可以做**，但反演真值只能来自以下三个场域；真实 GEO 数据永远只做光度锚点、不做反演真值。

| 场域 | 真值来源 | 反演能产出什么 | claim 边界 |
|---|---|---|---|
| 仿真 benchmark（路线一/二主体） | Blender 自设姿态，有真值 | 反演误差表 / OCS-only vs image-only vs joint 对比 / 多估计器对比 / 不确定度-误差一致性 / roll sensitivity / 简并模式 | **仿真成功率**（conditional on 前向模型），非真实目标成功率 |
| STK 几何升级 benchmark | STK 给真实轨道几何时序，姿态仍自设，有真值 | 同上，且几何现实性更强 | **仿真成功率**，非真实成功率；详见 §7 |
| 暗室缩比（路线三） | 实验者自控目标朝向，有真值 | 暗室内真实闭环反演 + 暗室成功率 | **暗室成功率**，严禁外推为 GEO 在轨反演 |
| 真实 GEO 数据 | **无姿态真值** | 仅光度锚点 / 多几何坐实 / 异动统计 | 永不做反演真值，永不算真实成功率 |

### 6.2 "真实背书→仿真正确→可做真实反演"逻辑链的两个断点

作者提出的自然推理（真实数据背书 ⟹ 仿真正确 ⟹ 可做反演方法研究并视同接近真实反演），后半段有跳跃，断点如下：

```text
断点①：背书强度被高估。真实光度背书只到 distribution/trend 级，证明的是
       "光度统计层面可信"，不是"姿态→光度映射在全部细节上正确"；
       而反演精度最敏感的恰是细节（BRDF、定标、姿态-几何耦合细微结构），
       不在光度统计背书覆盖范围内。

断点②：真值缺口未被填上。即便光度统计完全对上，真实数据仍无姿态真值，
       反演方法在真实数据上永远无法验证成功率。背书填的是"光度像不像真"，
       没填"反演对不对得上真实姿态"这个洞。
```

结论：反演方法研究**可做，但只能在仿真/STK benchmark 上做，claim 钉死在仿真成功率**；真实数据的正确作用是"提升合成 benchmark 的光度现实性可信度，间接给反演方法研究加现实意义"，而非把仿真成功率升级为真实成功率。

### 6.3 三条必须同时满足的红线（缺一条则塌成"硬做真实监督反演"）

```text
R1：反演真值只来自仿真/STK/暗室；真实 GEO 永不做反演真值。
    违反后果：撞"无姿态真值仍硬做监督反演"，专家一刀致命。

R2：反演成功率分两类写清——仿真/STK = 仿真成功率，暗室 = 暗室成功率；
    都不外推为真实目标成功率。
    违反后果：撞"真实望远镜验证 / operational-ready / 真实外场性能"。

R3：仿真/STK 反演必须注入 model mismatch、避开 inverse crime。
    违反后果：成功率虚高 = 循环论证，正撞专家"无法解耦仿真好还是反演好"。
```

## 7. STK 几何升级定位与红线（本轮新增）

作者提出在 STK 中模拟卫星运动 + 地面望远镜，生成 OCS 与图像观测以研究反演方法。可行，定位如下：

```text
STK = 轨道/场景几何引擎，提供真实轨道动力学下的几何时序
     （相位角/距离/太阳角/可见弧段随真实过境演化）。
STK 不渲染真实辐射；OCS 与图像仍须喂进同一个已冻结 Blender 前向模型（13/14）计算。
价值：把"多几何"从"人为挑的 G1/G3/G5"升级为"真实轨道力学生成的几何轨迹"——
     这是几何现实性升级，是破法 C（真实数据证多几何存在）之外的第二个角度
     （真实轨道力学证多几何几何自洽），两者互补。
```

STK 三条必钉红线：

```text
STK-R1：STK ≠ 真实数据。它是更精致的仿真，不回应专家"需要真实闭环"；
        STK 成功率 = 仿真成功率，永不写成真实目标成功率。
        真实统计背书仍只来自路线二 GEO 光度；真实有真值闭环仍只来自路线三暗室。
STK-R2：STK 只当几何发生器，必须喂进同一个 Blender 前向模型；
        不得引入第二条辐射/OCS 计算链，否则撞"不混用两条 OCS 链"红线。
STK-R3：STK/仿真反演必须注入 model mismatch、避开 inverse crime（同 §6.3 R3）。
```

工具治理：STK 是当前 Blender 冻结管线之外的新工具，现阶段仅作候选方法讨论；是否纳入须经四路线总裁决通过后才进 13/14 方法冻结规范，不在路线二单方面写死。

## 8. 可观测性 vs 反演 主配角边界（附 24 号 §八锚点）

### 8.1 两个概念的 24 号原意

- **可观测性（24 号主角，§六）**：研究"姿态信息能不能被观测到、在哪、有多少"，产物是可观测性地图 / 混淆图 / 信息量地图 / 置信曲线；回答 what can be known / when complementary / when trustworthy。它**不是**"我能不能把姿态算准"。
- **反演 = 验证工具（24 号配角，§八原文）**：24 号 §八明文冻结——"mean error / Hit@5 / worst-case ... 角色降级为信息验证工具"；结果表末行"反演误差表 | 作为验证工具，而不是应用终点"。即：反演误差表的作用是**印证可观测性地图说得对不对**（可观测处反演果然能恢复，不可观测处果然失败），而非自身拿性能高分。

### 8.2 对"路线二补反演研究"的精确卡位

```text
✅ 配角加重（路线二/总裁决范围内，不改 24 号）：
   反演从"印证可观测性地图"的单一工具，扩展成"多估计器对比 + 可观测性界定"模块；
   STK/仿真/暗室喂有真值数据；
   但论文最终落点仍是"姿态信息可观测性与置信"，不是"我反演多准"。

❌ 翻主角（必须进四路线总裁决改 24 号 §八）：
   论文主轴变成"反演方法/成功率"，可观测性退为背景——
   这直接推翻 §八"误差表只是验证工具"的冻结决策，不在路线二权限。
```

自检判据：论文**最终结论句**若是"姿态信息在哪可观测、跨通道一致性能否指示置信"→ 配角加重，路线二可行；若是"我的反演方法成功率达到 X"→ 翻主轴，须走总裁决。

### 8.3 作者诉求定位

作者"路线二加真实数据后不止说科学性、仍要补充反演研究"的真实诉求 = **配角偏重版**：反演分量加大、单独成模块，但主轴仍是"真实锚定的可观测性"。该版本落在路线二 + 总裁决范围内，**可行**；只要不把"反演成功率是论文最终目的"写成主轴，就不需要推翻 24 号。
