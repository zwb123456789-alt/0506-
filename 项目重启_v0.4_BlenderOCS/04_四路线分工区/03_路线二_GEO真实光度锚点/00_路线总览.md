# 路线二总览：GEO 真实光度锚点

最后更新：2026-06-22

## 1. 路线定位

路线二是路线一 C 与三轴小项目之后的优先增强层，已经通过 Codex R01/R02 复审：

```text
GEO 真实光度数据库
-> sim-to-real 光度保真度锚点
-> 真实多帧/多几何现实性背书
```

它不能写成监督姿态反演路线，因为当前 GEO 数据库没有三轴姿态真值。
经 R02 补充审阅后，路线二允许把反演适度提高为“配角偏重”的验证模块，但不得翻为论文主轴；STK 几何升级不是路线二成立的必要条件，只作为总裁决后可选 P3 增强。

## 3. 审阅重点

路线二复审已完成；后续总裁决只需回查以下边界是否被保持：

- 是否明确“有光度、有几何、有型号、有时序，但无姿态真值”。
- 是否只做统计/趋势/分布级光度锚定，不做监督姿态反演。
- 是否用真实多帧几何破解“多几何不现实”。
- 是否避免把 GEO 数据写成真实反演闭环。
- 是否将反演保持为配角偏重验证模块，主报告包含 mismatch 条件，避免 inverse crime。
- 是否将 STK 保持为 P3 可选增强，而非路线二成立条件。

## 4. 当前下一步

```text
路线二审阅已完成，当前不作为下一执行入口。
执行顺序为：路线一 C -> 三轴小项目 -> 路线二 -> 路线三 -> 路线四未来方向。
```

路线二后续启动时，应服务于路线一 C 与三轴小项目，而不是反向改写主线：

- 用 GEO 真实光度检查仿真光度的趋势、分布和多帧/多几何现实性。
- 为三轴小项目筛出的高信息/低信息几何提供真实观测可行性背景。
- 反演只能作为验证工具或配角偏重模块，不得写成真实监督姿态反演主轴。
