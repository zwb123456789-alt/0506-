# R04 Codex：更正 1C-E02 书籍页码与 BRDF / 材料参数定位

最后更新：2026-06-23

## 1. 文件性质

本文是对 Claude 输出 `1C-E02` 及现有书籍知识库页码定位的 Codex 更正记录。

本次更正依据作者提供的外部原始书籍图片目录：

```text
D:\我的文件\研究生学术\光学项目\书籍工作\书籍\第三章\
```

本文件只记录 Codex 对原始图片的查询结果与路线一 C 执行口径影响，不修改书籍知识库源文件，不复制外部图片，不修改 13/14/24/25 冻结文件，不进入代码实现。

## 2. 总体结论

1C-E02 中关于书籍页码、五参数冯模型和材料参数位置的结论需要降级并更正。

现有书籍知识库将以下位置写成“精确定位”：

```text
五参数冯模型：第3章 48-50页 / 截图1693-1695
典型空间材料 BRDF 系数表：第3章 64-70页 / 截图1712-1718
```

经 Codex 直接查看原始图片后，判定上述定位不可靠：

```text
48-50页主要是 BRDF 测量系统、相对测量公式、定标板 BRDF 曲线和测量步骤；
不是五参数冯模型。

64-70页主要是 Torrance-Sparrow 五参数模型、改进六参数模型与若干材料参数反演样例；
未发现此前知识库所称的“典型空间材料 BRDF 系数表”。
```

因此：

```text
1C-E02：只保留为“发现旧知识库存在候选线索”的材料；
不得作为路线一 C BRDF / 材料参数正式裁决依据；
后续 Codex 裁决必须以本 R04 的原始图片核对结果为准。
```

## 5. 路线一 C 执行口径影响

### 5.1 不再使用“书中材料参数已定位”的口径

在作者未进一步提供书中对应材料参数前，路线一 C 不得写成：

```text
已采用书中金属主体、太阳能板、MLI 等材料参数。
```

当前只能写：

```text
书中第3章提供 BRDF 测量、经典冯模型、改进冯模型、Torrance-Sparrow 五参数模型和若干材料参数反演样例；
但与路线一 C 三部件直接对应的材料参数尚未可靠定位。
```

### 5.2 Legacy Phong 的位置

历史代码中的 Legacy Phong：

```text
f_r = rho_d / pi + rho_s * (N·H)^n
```

不能等同于书中第59页的改进冯模型，也不能等同于第64页的 Torrance-Sparrow 五参数模型。

更稳妥的执行口径是：

```text
路线一 C 可用 Legacy Phong / simple Phong-like 作为初始受控主锚点；
但必须标注为 project provisional Phong-like baseline，
不得称为“完整书中五参数冯模型实现”。
```

### 5.3 后续 BRDF 分支建议

后续可分为三层：

```text
B0：Legacy/simple Phong-like baseline
    参数来自历史 materials.py 或作者给定 provisional 参数；
    用于路线一 C smoke test 和最小链路闭合。

B1：书中改进冯模型
    对应第3章 56-59页，式 (3.16)，参数 rho_d, rho_s, alpha, a, b；
    作为后续升级分支。

B2：Torrance-Sparrow 五参数 / 改进六参数模型
    对应第3章 63-67页，式 (3.18)、式 (3.23)；
    作为后续材料 BRDF 专项分支，不作为当前最小 smoke test 的必要条件。
```
