## 1. 现有结果的定位（留存对照，条件性负结果）

### 1.1 现有结果是什么（正名）

现有 C2/C3/B6 结果的准确表述：

```text
输入形态：单几何 + 4维 per-part OCS（C2）/ 单姿态灰度图像（C3 image）/ early-concat（C3 joint）
反演方法：简单 CNN + exact-bin 分类头（B6 改连续 circular regression）
评估协议：yaw-block 5-fold 严格外推（训练未见整段 yaw）
结果：exact-bin yaw=0%；relaxed metrics 下 yaw 外推整体弱、强位置异质；pitch 在回归头下改善
```

### 1.2 这些结果说明什么、不说明什么

```text
说明：在【单几何 + per-part/单帧 + 简单CNN + 严格外推】这一组条件下，当前未得到稳定 yaw 外推。
不说明：光度无用 / 多几何 OCS 不行 / 光变曲线不行 / yaw 物理不可观测。
```

**负结果是条件性的**，这是写进论文与收口时不可松动的措辞红线。

#### 1.2.1 归因链：已排除的非主因（代码级 + 实验级证据）

负结果不是"哪里都可能错"的笼统失败，已逐层剥离，两条候选主因被实证排除：

```text
✗ exact-bin 判据/输出头 —— 不是主因（B6-FIX01 实验否定）
   依据：102_1C-B6-FIX01 报告。换 circular regression 后相对 fold-matched P1-A 的
   yaw cMAE 普遍改善（image/joint per-fold mean delta −8.7~−21.2°），
   但绝对 cMAE 仍 60–73°、coarse90≈0.43–0.51 仅略高于 chance 0.25 → 救不回 yaw 外推。
   结论：更合适的输出头能改善读数，但解决不了外推 → 主因不在判据。
   （注：101 曾误判"B6 比 baseline 差"，系拿 B6 最差 fold0 比 P1-A pooled 的口径错误，已被 fold-matched 修正反转。）

✗ 几何处理埋雷/泄漏 —— 不存在（代码查实否定）
   依据：render_full_2664_shadow.py:80-81 单一固定 phase63 几何（sun=[1,0,0.3],det=[0.5,-1,0.1],roll=0）；
   几何非模型输入（feature_extract_ocs.py:216-228，phase_angle_cos 标 c2_participant=False）；
   split_dataset.py:119-170 按 yaw 弧段切，train/test 几何完全一致，无几何外推、无泄漏。
   结论：当年是干净的设计A（单几何/几何同组/holdout姿态），负结果是真的，但没有几何处理的雷。
```

#### 1.2.2 归因链：主因指向（两实证共同支撑）

```text
→ single-frame 信息形态不足
   依据：B6-FIX01 即使换回归头，yaw 外推仍坍缩，coarse90 近 chance；
        且多几何(L1) 当年根本没测——config OBS_GEOMETRIES(G0~G4) 已预留但全量渲染未启用。
   含义：多几何破歧义这条路是【空白】，不是被否定的死路 → L1 主线正当性来自此。

→ yaw-block 严格外推协议过狠
   依据：B6-FIX01 yaw-block 分层给出 5-fold 稳定的外推距离依赖——
        worst block 恒为远端弧段([0,45)~141-155°)、best 恒为邻近弧段([315,360)~10-22°)。
   含义：失败不是均匀"yaw 物理不可观测"，而是远端外推坍缩、近端可内插
        → 协议应降级为边界诊断(P-EXT)，主线改用 P-INT 插值（见轴B）。
```

一句话归因：**负结果 = 单几何 × single-frame × yaw严格外推 下的远端外推坍缩；判据与几何处理均已排除为主因；真正瓶颈是信息形态(指向多几何L1/多帧)与外推协议。**

## 2. 三轴受控矩阵（防爆炸的核心设计）

把作者六点设想组织成三个正交轴 + 分析维，**主跑只取受控子集，不做全笛卡尔积**。

### 2.1 轴 A — 观测方式（对齐 24 号 F/L 口径）

**先分清两个独立概念，避免"多几何"含混（这是本规划的关键澄清）：**

```text
姿态（attitude）= 被反演的目标，yaw×pitch 网格（roll 安排见 §2.1.2）。对单次反演而言是待测的那一个。
观测几何（sun/view geometry）= 观测配置，即"从哪个太阳-视线方向去看"。这是"多几何"里"多"的那个东西。

"多几何 OCS" 多的是【观测几何】，不是【姿态】：
  同一个姿态，从多个 sun/view 方向各得一个总光度 → 拼成多观测光度向量。
```

| 代号 | 形态 | 24 号定位 | 在本规划中 |
|---|---|---|---|
| F1 | 单几何（G1）总光通量标量 | 信息**下界** baseline | 必做 |
| L1 | G1→G3→G5 跨 sun/view 几何的多观测光度向量 | **主线 OCS** | 必做·主干 |
| L2 | 时域光变曲线 | Future Work | **条件触发分支**（见 §4） |
| (诊断) F2 | per-part OCS | semi-oracle 上界/诊断 | **仅分析，不入反演输入** |

#### 2.1.1 L1 多几何的核心 = G1/G3/G5 几何阶梯增益曲线

```text
G1 = 1 个 sun/view 观测几何（= F1 的几何配置，单几何）
G3 = 3 个 sun/view 观测几何
G5 = 5 个 sun/view 观测几何

同一姿态，G 个几何各得一个总光度 → 长度为 G 的多观测光度向量。
L1 可观测性分析 = 比较 G1 vs G3 vs G5 下姿态反演质量，画出"几何越多→姿态越可反演"的增益曲线。
```

这条 G1→G3→G5 增益曲线，是 L1 主线区别于"又一个单帧 CNN"的核心证据，也是直接回答价值一 "what can be known" 的主图。

**几何处理协议（设计 A · 固定几何配置）——本规划暂定口径：**

```text
1. G1/G3/G5 = 预定义的固定 sun/view 观测几何方向集合；具体取向需预注册（开放点 §8）。
   预注册默认（复用 config_v0_4.py 已预留 OBS_GEOMETRIES G0~G4，嵌套设计）：
     G1 = {phase63}                          ← 复用现有，与 C2/C3 负结果同几何，可直接对照、免重渲
     G3 = {phase63, G_低相位, G_高相位}        ← 在 G5 内拉开相位角跨度
     G5 = {G0,G1,G2,G3,G4} 全 5 组            ← 已预留完整集
   约束：G1⊂G3⊂G5（嵌套）→ "加几何=单调加信息"，增益曲线无混淆、可解释。
2. 观测几何是【已知条件参数】，不是待泛化变量。对齐 model-known：真实场景几何永远已知
   （路线二 PRE 表可反算 sun/view 即为佐证）。
3. 训练与测试用【同一组】几何配置；不做"几何A训练 → 几何B测试"的几何外推
   —— 单几何训练的反函数 f_A⁻¹ 是"几何A条件下"的反函数，换几何在物理上注定系统性失败。
4. 真正的 holdout 是【姿态】，不是几何：测试姿态必须是训练未见的 yaw×pitch（划分见轴B）。
   → 几何同组 + 姿态 holdout = 反演（P-INT/P-EXT）；几何同组 + 姿态训练已见 = 查表（P-DB，另算）。
5. 结论是条件性的：只 claim"在这组已知几何下姿态可观测性"，不 claim 跨几何泛化。
   增益曲线建议在 1~2 组不同几何配置上复测，避免结论被单一几何选择绑架。
```

为什么单几何本就不该够：单视角存在姿态歧义（多个姿态给出近乎相同光度，即 Wetterer & Jah 的 near-identical light curves）。
多几何破歧义 = 同一姿态在 G 个已知方向各看一眼，单视角分不清的姿态对在多视角组合下被区分开（Kaasalainen：几何覆盖 > 样本数）。
故 G1→G3→G5 增益曲线量化的是"几何已知 + 几何越多 → 姿态歧义越小 → 越可反演"，**不是几何外推**。

**关键区分**：L1 的多几何 = 仿真中**同一姿态、多个 sun/view 方向、姿态冻结、几何为已知自变量**，可做反演、是主线。
这与**路线二真实 GEO 的"跨时间多几何"不是一回事**（后者姿态与几何随时间一起变、纠缠、无姿态真值、不入反演）。两者全文必须分名：L1 = simulated multi-view geometry；路线二 = sim-to-real temporal anchor。

#### 2.1.2 roll 的三层安排（fixed-roll 主 + 探针辅 + 三轴小项目放开）

roll 在路线一 C 不是主变量，按三层处理（依据 R110 §1.1/§3.2/§5.3）：

```text
第1层 路线一C 主跑：roll = 0°（fixed-roll）。主战场是 yaw×pitch（72×37 网格）。
                     上面 F1/L1、G1/G3/G5、反演协议、真实性，全部默认 roll=0。

第2层 M-roll roll sensitivity 探针：抽样若干 roll ≠ 0，重跑关键配置，
                     验证 fixed-roll 下得到的可观测性结论是否稳健。
                     这是路线一C 内必做的【小探针】，不是全面三轴扫描。
                     预注册默认：roll ∈ {0°(基准), +15°, −15°, +30°, −30°}，
                     仅在 1 个代表几何(G3) × {image_only, joint} 两通道上重跑（小探针量级，不铺满全矩阵）。

第3层 三轴小项目（闭口后）：真正放开 roll，做 yaw/pitch/roll 三轴的最亮构型/高信息姿态搜索。
                     roll sensitivity 探针是它的【接口】，不是它的替代品（R110 §5.3）。
```

一句话：路线一C 把 roll 冻在 0° 做主线，用 M-roll 探针验证"冻 roll 不致命",真正的三轴 roll-aware 搜索留给三轴小项目。

### 2.2 轴 B — 反演协议（作者三层任务）

| 代号 | 协议 | R110 定位 | 在本规划中 |
|---|---|---|---|
| P-EXT | 严格外推（少数据→整段未见 yaw） | strict extrapolation stress test | **降级**为压力测试/边界诊断，不独占主线 |
| P-INT | 多数据训练，插值/局部泛化（测未训练精确姿态） | 更贴近 model-known 主线 | **主任务** |
| P-DB | 近全训练 + 查库/查表后验反演 | posterior/template/database 框架 | 可做，**价值在候选分布/置信，不写成功率** |

红线：P-DB 的查库**不得写成真实未知目标反演成功率**；其价值是支撑 what-can-be-known / 候选分布 / 置信标定。
预注册默认设计：
```text
库     : 训练姿态网格(72×37)对应的 OCS/特征模板（多观测光度向量）
相似度 : L2 / cosine on 多观测光度向量
输出   : top-k 候选姿态 + 置信分布（不输出唯一姿态、不写"成功率"）
```

### 2.3 轴 C — 真实性（噪声/退化）

| 代号 | 形态 | 定位 |
|---|---|---|
| clean | 干净图像 | 受控上界对照 |
| degraded | 物理合理退化 | 贴合真实 + 鲁棒性 + 防 inverse crime |

degraded 退化建模应含：PSF/模糊、曝光、Poisson/read noise、背景、运动拖影、低分辨率、测光误差。
预注册默认参数范围（物理合理、可做 ablation）：
```text
PSF      : 高斯 σ ∈ {0.5, 1.0, 1.5} px
噪声     : Poisson(shot) + Gaussian(read)，SNR ∈ {30, 20, 10} dB
背景     : 均匀天光 + 线性梯度
分辨率   : 下采样 ×{1, 2}
明确避开 : B6 那组 σ=0.01+亮度±10%+整数平移（已证 fold0 有害，不复用）
```
教训（R110 §1.9）：B6 那组粗增广（高斯σ=0.01+亮度±10%+平移）在 fold0 明显负面——**乱加增广有害，必须物理合理**。噪声定位不是"为了提分",而是"贴合真实 + 测鲁棒 + 防伪闭环"。

### 2.4 分析维（非输入，叠在三轴之上）

```text
D1 per-part OCS 归因：哪个部位贡献 yaw 信息（semi-oracle 诊断，不入反演输入）
D2 互补性：image vs OCS vs joint 的可观测性差与 top-k overlap / disagreement
D3 置信一致性 consistency-as-confidence：OCS 与 image 估计一致性 vs 误差，做置信标定（价值二核心，作者六点中遗漏，本规划补入）
D4 可观测性地图：哪段 yaw/pitch 可观测/不可观测，为三轴小项目铺路
```

### 2.5 受控主跑矩阵（预注册，防爆炸）

```text
主跑：{F1=G1, L1∈{G3,G5}} × {P-INT 主, P-EXT 留存} × {clean, degraded}
      其中 F1/L1 沿 G1→G3→G5 几何阶梯，输出"几何越多→姿态越可反演"的增益曲线
roll：主跑默认 roll=0（fixed-roll）；M-roll 探针抽样 roll≠0 验稳，不进全三轴扫描
先进方法：仅在 L1 主线上与 CNN baseline 对照（1~2 个代表方法）
分析维 D1~D4：在主跑结果上做，不额外起新训练
条件分支：L2、P-DB、路线二、三轴小项目（见 §4，不阻塞主干闭口）
```

不做：全笛卡尔积、超参搜索、无限扩 backbone、放开 roll 做全三轴（守红线，三轴留给小项目）。

## 3. 主干模块（M1~M5）与可行性

| 模块 | 内容 | 类别 | 可行性 |
|---|---|---|---|
| M1 | F1=G1 单几何总光度下界复测（正名现有 + 补真下界 F1） | A/D | ✅ 既有派生，工作量小 |
| M2 | L1 多几何主线（G1→G3→G5 几何阶梯增益 + 1~2 先进方法对照） | **C 类** | ✅ 需完整阶段门、单独放行 |
| M3 | 真实性轴 clean vs degraded（物理退化模型） | A/C | ✅ loader 级，需放行 |
| M4 | 互补性 D2 + 置信一致性 D3（+ D1 归因、D4 地图） | A | ✅ 主跑结果上分析 |
| M5 | 反演三协议对比（P-EXT 降级/P-INT 主/P-DB 后验） | C | ✅ P-DB 不写成功率 |
| M-roll | roll sensitivity 探针（抽样 roll≠0 验 fixed-roll 结论稳健） | C | ✅ 小探针，非全三轴，需放行 |

先进方法池（R91/R93，作者选 1~2）：Kaasalainen 光变反演族、Wetterer&Jah facet+UKF、ChiNet/Rondao 2022、SPEED+ sim-to-real、conformal prediction（用于 D3 置信标定）。
预注册默认选型（一偏物理 + 一偏多观测聚合，均不上重 backbone）：
```text
主选：facet/BRDF-aware 回归（对齐 Wetterer&Jah facet 思想）—— 物理可解释、契合多几何
次选：轻量 attention/set 模型处理"G 个几何的多观测光度向量"集合输入
对照：保留现有 CNN baseline
D3 置信：conformal prediction
```
注：换 backbone / 换方法是主变量改动 → **C 类，必须走完整阶段门单独放行**，不能并进 D 类补齐。

## 4. 分支结构

```text
路线一C 主干（必做，决定闭口）
├─ M1 F1=G1 单几何下界复测            [必做]
├─ M2 L1 多几何主线 G1→G3→G5 增益 + 先进方法 [必做·主干·C类放行]
├─ M3 真实性 clean vs degraded        [必做·横切]
├─ M4 互补性 + 置信一致性 + 归因 + 地图 [必做·价值二]
├─ M5 反演三协议（外推降级/插值主/查库后验）[必做·查库≠成功率]
└─ M-roll roll sensitivity 探针        [必做·小探针·验 fixed-roll 稳健·三轴小项目接口]

条件触发分支（不阻塞主干闭口）
├─ B-LC L2 光变曲线仿真   ← 触发：M2 失败 或 作者确认真实数据以序列为主（R105/R106）
├─ 路线二 sim-to-real 锚点 ← 增强现实性，不入反演，随时可平行做
└─ 三轴小项目             ← 主干闭口后启动（放开 roll 全三轴搜索，M-roll 为其接口）
```
