### 3.6 P0-1 阶段性结论

```text
1. 最关键差异是 split 方式：V0.4 的 circular yaw-block holdout 是 strict cross-yaw 外推协议，
   而 V0.3 很可能使用 random/弱 holdout。仅此一项即可解释大部分"V0.3 成功 → V0.4 失败"的表观差异。
   
2. 第二关键差异是判据口径：exact-bin 5° 是极严哨兵判据，V0.4 coarse45/within-6 虽弱于 random split
   但仍高于 chance。若 V0.3 使用更粗/更宽松判据，则两版不在同一难度档。

3. 第三差异是 OCS 前向模型不同（face-center vs Blender），但 CLAUDE.md 红线已禁止混用，
   且 C2 OCS-only exact-bin 也为 0.00%，说明这不是差异主导项。

4. 综合判断：V0.3 与 V0.4 之间的表观"成功 vs 失败"差异，
   主要来自 split 变严 + 判据变严，而非 V0.4 仿真本身的质量问题或科学假设被推翻。
   这与 84 号 Q5 的分析一致。

5. 不可写"V0.3 结果无效"或"V0.4 恢复 V0.3 成功"。
   只能写"当前协议差异使两版结果不可直接横向比较，需同口径重算后再做判断"。
```

### 4.3 方法设计

由于 image embedding 和 joint embedding 不存在，本轮 P0-2 只能对 **OCS 特征空间**（raw 4-dim 和 enhanced 各配置）做 signature distance 分析。具体步骤：

```text
步骤 1: 提取 yaw bin 标注
  从 record_ids 中解析 yaw/pitch（格式: phase63_yawNNN_pitch±NNN），
  将 yaw 角度映射到 72 bin（0-71）。

步骤 2: 按 yaw bin 聚合特征
  对每个 yaw bin（0-71），取属于该 bin 的所有样本的 OCS 特征，计算均值向量。
  均值向量 = yaw bin 的"OCS 签名"。

步骤 3: 计算 yaw-yaw 距离矩阵
  距离度量：cosine distance（首选，因为 OCS 特征跨 bin 的幅值可能不同、
  且 cosine 对尺度不敏感，更适合判断"方向相似性/形状相似性"）。
  备选：euclidean distance。

步骤 4: 分层检查
  按 pitch 分层重新计算距离矩阵，检查低距离区域是否依赖 pitch。
  按 fold 的 train/test yaw 分区，标记哪些 yaw pair 是"训练 yaw vs 测试 yaw"对。

步骤 5: 提取最近邻对和低距离簇
  对每个 test yaw bin，找最近的 train yaw bin（1-NN）。
  识别距离矩阵中的低距离块（可能是等价或近似等价簇）。

步骤 6: 交叉比对
  将低距离 yaw 对与 P0-3 的混淆矩阵高频混淆对交叉比对。
```

### 4.4 距离度量选择理由

```text
cosine distance:
- OCS 特征的绝对幅值随目标-光源-观测几何变化显著（总 ocs 跨 2-3 个数量级），
  euclidean 会主要被幅值差异主导。
- 我们关心的是"两个 yaw 的 OCS 形态是否相似"（即不同角度的光子反射模式是否相近），
  cosine 衡量方向相似性，更贴近这一目标。
- 在 symmetry-based ambiguity（Wetterer & Jah 2009）中，对称目标在对称角度下
  光变曲线几乎相同——cosine 比 euclidean 更能捕获这种"形状相似性"。
```

### 4.6 基于现有数据的初步发现

对 raw 4-dim OCS（baseline_4dim）按 yaw bin 聚合后的初步核查（本报告不声称完整分析，完整距离矩阵需在后续诊断脚本中生成）：

```text
1. OCS 特征空间是 4 维（ocs_total + 金属主体 + 太阳能板 + 隐身板）。
   4 维空间中 72 个 yaw bin 不可能被充分分离——维度远小于类别数，
   仅靠 OCS 单帧 4 维向量区分 72 种 yaw 姿态在几何上就是欠定的。

2. 即使取 enhanced 特征（最高 13 维 M6_all_nongeo），仍远小于 72 类，
   yaw-yaw 在 OCS 空间中必然存在大量近似等价和低距离对。

3. 这解释了 C2 OCS-only exact-bin = 0.00%：
   在 4-13 维空间中，区分 72 个 yaw bin 的 linear separability 极低，
   yaw-block 外推时，test yaw 的 OCS 向量很可能落入 train yaw 向量的近邻。
   模型预测坍缩到 train yaw 区间是合理行为，不是模型失败。

4. 但 coarse45 约为 15-18%（高于 chance 12.5%）表明在 45° 粗粒度上
   OCS 空间仍有一定可分结构——只是不足以支持 5° 精确分类。

5. 要完成完整的 yaw-yaw distance heatmap 和最近邻对列表，
   需运行只读分析脚本（从 enhanced_ocs_features.npz + record_ids + split manifest 合并计算）。
   该脚本不需要新训练，只需要 numpy/scipy/matplotlib，属 D 类只读诊断。
```

## 5. P0-3 Confusion Cluster

### 5.1 要回答的问题

R04 负结果是否集中在特定 yaw、pitch、fold、几何区域？是否存在近似等价解簇（即多个不同的 true yaw 被模型系统性地预测到同一个 pred yaw）？

### 5.2 可用数据确认

| 数据类型 | 存在性 | 详情 |
|---|---|---|
| **C2 yaw 混淆矩阵（72×72）** | ✅ 65 个 npz | 13 configs × 5 folds |
| **C3 yaw 混淆矩阵（72×72）** | ✅ 10 个 npz | image_only 5 + joint 5 |
| **Per-sample predictions** | ✅ 75 个 npz | 含 yaw_pred_bin, yaw_true_bin, pitch_pred_bin, pitch_true_bin |
| **Split manifest** | ✅ 5 个 JSON | 含 train/val/test record IDs |

### 5.3 方法设计

```text
步骤 1: 加载并聚合 C3 混淆矩阵
  对 C3 image_only 5 折和 joint 5 折的 72×72 混淆矩阵求和/平均。
  每行 = true yaw bin，每列 = pred yaw bin。
  热图可视化。

步骤 2: 识别高频混淆对
  从混淆矩阵中提取 top-K 非对角线混淆对（true yaw → pred yaw）。
  这些对是"模型最容易混淆的 yaw 组合"。

步骤 3: 按 train/test 分区标注
  用 split manifest 标注哪些 yaw bin 属于 train、哪些属于 test。
  C3 中每个 fold 的 test yaw block 不同（连续弧段），
  检查 test yaw 的预测是否集中坍缩到 train yaw 的特定区域。

步骤 4: 按 pitch 分层
  用 per-sample npz 的 pitch_pred_bin/pitch_true_bin，
  检查 pitch 层是否改变 yaw 混淆模式。

步骤 5: 与 P0-2 OCS distance 交叉比对
  高频混淆对 vs 低距离 yaw 对是否一致？
  如果一致 → "签名重叠"假说成立。
  如果不一致 → 可能是判据/模型容量/其他原因。
```

### 5.4 基于现有数据的初步发现

从已读取的 C3 fold0 detail JSON 和 C2 baseline_4dim fold0 的 per-sample 数据：

```text
1. C3 image_only fold0 的 test_primary per_yaw 全部 yaw bin（0-14）的 acc 均为 0.0。
   这说明即使是 train yaw bin，在 val_primary split 下也是全 0。
   但 val_primary 使用的 per_yaw 键值（65-71 等不同范围）提示不同 split 下
   "primary"的含义不同——需确认 val_primary/test_primary 的 split 方式。

2. C2 baseline_4dim fold0 per-sample 数据显示：
   true yaw=0 的样本被预测为 yaw_pred=23 或 54（都在 train yaw 区间内）。
   这直接验证了 E45A/R80 的结论：预测系统性坍缩到训练可见 yaw 区间。

3. 72×72 混淆矩阵的初步检查（C2 baseline_4dim fold0）显示：
   每行（true yaw）的非零条目高度集中在 2-4 个 pred yaw bin 上，
   且这些 pred yaw bin 全部落在 train yaw 区间内。
   不存在跨 yaw-block 的外推成功。

4. 这意味着混淆簇分析的核心发现已经清楚：
   yaw-block 失败的机制是"模型将所有 test yaw 预测为某些 train yaw"，
   而不是"模型在 test yaw 之间随机猜测"。
   前者说明签名重叠/外推失败，后者才说明完全无信息。
```

### 5.5 典型失败案例

从 C2 baseline_4dim fold0 前 5 个样本：

```text
record_id: phase63_yaw000_pitch+000 → true_yaw=0, pred_yaw=23
record_id: phase63_yaw000_pitch+005 → true_yaw=0, pred_yaw=23
record_id: phase63_yaw000_pitch+010 → true_yaw=0, pred_yaw=23
record_id: phase63_yaw000_pitch+015 → true_yaw=0, pred_yaw=64
record_id: phase63_yaw000_pitch+020 → true_yaw=0, pred_yaw=64
```

```text
所有 true yaw=0（对应 yaw=0°）的样本全部被预测为 train yaw 区间内的 bin 23（115°）
或 bin 64（320°）。bin 23 和 64 在 circular yaw 空间中距 bin 0 的角距离分别为
115° 和 40°（circular：|320-0|=40° via 355→0→5）。pred_yaw=64（320°）在角度上
更接近 0°，模型倾向于选择 circular 近邻，但完全在 train yaw 区间内。
```

## 6. P0-4 Pseudo-Light-Curve Probe

### 6.1 要回答的问题

在不生成新数据的前提下，把现有 yaw-ordered 单帧样本串联成伪序列，是否能观察到比单帧更清晰的可分性线索？即：序列形态是否比单帧 OCS 标量更能区分不同 yaw？

### 6.2 关键约束

```text
必须明确：这只能叫 probe，不能叫 light-curve experiment。
- 真实 light curve 是同一目标在连续时间/几何演化下的亮度序列记录。
- 当前数据是同一 pitch 下、按 yaw 步进 5° 采样的独立 Blender 渲染帧。
- 串联产生的"伪曲线"不反映真实时间演化（无运动连续性、无光度时间相关性）。
- 它的价值是"零成本预检"：如果伪序列已经显示明显的 yaw 间曲线形态差异，
  则真实 light-curve sequence 值得投入；如果伪序列也几乎不可分，
  则需先解决更基本的信息源问题（如多几何覆盖）。
```

### 6.3 可用数据确认

| 数据类型 | 存在性 | 详情 |
|---|---|---|
| **raw OCS（4 维）全部 2664 样本** | ✅ | `enhanced_ocs_features.npz` → `baseline_4dim` |
| **enhanced OCS（各配置）** | ✅ | 同上 npz |
| **record_ids（含 yaw/pitch 标注）** | ✅ | 同上 npz |
| **对应渲染图像** | ✅（但不用于 probe） | C3 训练使用的 PNG |
| **真实时间序列数据** | ❌ | 当前数据中不存在时间/几何演化的连续帧 |

### 6.4 方法设计

```text
步骤 1: 固定 pitch，提取 yaw-ordered 序列
  选择一个 pitch（如 pitch=0°），提取该 pitch 下所有 yaw（0°-355°，5°步长=72帧）。
  对每个 yaw，取 baseline_4dim OCS（4 维）作为该帧的"光度签名"。

步骤 2: 构建伪光变曲线
  按 yaw 递增排序，将各 yaw 的 OCS 值串联成 72 帧的 4 通道"伪序列"。
  曲线 = yaw 角 vs ocs_total（或各通道分别）。

步骤 3: 描述性可分性分析
  a) 单帧可分性基线：对每个 yaw bin，计算其 OCS 向量到其他 yaw bin 的最近邻距离。
     如果在 OCS 空间中某 yaw 的 1-NN 是相邻 yaw（±5-10°），说明单帧已有局部结构。
  b) 最近邻曲线形态相似性：对两个不同 yaw，比较它们前后 ±3 帧的 OCS 曲线段形态。
     如果相邻 yaw 的 OCS 序列段相似、远距 yaw 的序列段不同，说明序列形态携带可分信息。
  c) 线性可分性/趋势检查：沿 yaw 轴，检查 OCS 值是否存在单调趋势或可辨识模式。

步骤 4: 判定是否值得 P2
  如果伪序列已显示不同 yaw 区间有系统性不同的 OCS 模式（如某些区间 OCS 单调上升、
  某些区间平坦、某些区间振荡），则正式 light-curve sequence 有基础。
  如果 72 帧伪曲线近乎平坦或噪声化，则 P2 前需要多几何覆盖或不同信息源。
```

### 6.5 初步预期（未执行，待生成）

```text
基于 OCS 的物理性质：
- 同一 pitch、不同 yaw 下，目标朝向光源-观测器的角度变化会导致 OCS 系统性地变化。
  yaw=0°（迎头）与 yaw=180°（背光）的 OCS 差异最大，这是可预期的曲线形态。
- 但 72 帧中仅靠 4 维 OCS，相邻 yaw（5°步进）的 OCS 差异可能很小（几何变化小），
  导致伪曲线在局部近似光滑但全局区分度不足。
- 伪光变曲线最有价值的贡献可能是：展示"相邻 yaw 的 OCS 高度相关、远距 yaw 的 OCS
  差异显著"这一事实，从而说明 single-frame 信息的不足是几何固有的，
  而 sequence 可以通过建模演化打破简并。
```

### 6.6 是否值得进入 P2 的判定标准

```text
支持进入 P2 的信号：
  a) 伪序列中不同 yaw 区间的 OCS 模式存在系统性差异（可通过肉眼或统计检验识别）。
  b) 序列段（如 5-10 帧滑动窗口）的形态特征比单帧 OCS 标量区分度显著更高。
  c) circular yaw 空间中存在"对称 OCS 模式"（如 yaw=0°和 yaw=180°的 OCS 相似），
     这正是 Wetterer & Jah 2009 描述的 symmetry-based ambiguity。

暂缓 P2 的信号：
  a) 伪曲线在 72 帧中近乎平坦，相邻和远距 yaw 的 OCS 无系统性差异。
  b) 序列段形态特征不比单帧有信息增益。
  c) 当前 fixed-roll + 单 pitch 协议下 OCS 变化主要来自 pitch 而非 yaw。
```
