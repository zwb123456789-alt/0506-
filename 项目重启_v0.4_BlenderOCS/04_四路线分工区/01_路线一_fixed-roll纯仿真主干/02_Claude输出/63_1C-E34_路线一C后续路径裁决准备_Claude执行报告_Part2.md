## 4. 两路径对比与资源评估

### 4.1 核心维度对比

| 维度 | 路径 A（接受 null） | 路径 B（执行 C3） |
|------|-------------------|------------------|
| **科学完整性** | ⭐⭐⭐ 只有 OCS-only | ⭐⭐⭐⭐⭐ 完整对照链 |
| **论文 novelty** | ⭐⭐⭐ 负结果方法学价值 | ⭐⭐⭐⭐⭐ 互补性验证（场景1-2） / ⭐⭐⭐（场景3） |
| **时间成本** | ✅ 低（~11 小时） | ⚠️ 高（~30-40 小时 GPU + 开发） |
| **资源需求** | ✅ 零计算资源 | ⚠️ 1 × RTX 3090 + 代码开发 |
| **风险** | ✅ 低风险 | ⚠️ 场景 4 风险（全部 null） |
| **可逆性** | ✅ 可随时转 C3 | ⚠️ 若 null 则时间沉没 |
| **与其他路线协同** | ✅ 不阻塞三轴/路线二 | ⚠️ 延迟其他路线 1-2 周 |

### 4.2 时间线对比

**路径 A 时间线**：
```
Day 1-2: 表格转论文格式、生成图注
Day 3-4: Results 段落骨架详细文字
Day 5: Supplementary Material 清单
Day 6: 整理成 Results 草案，提交 Codex
总计：~6 个工作日
```

**路径 B 时间线**：
```
Day 1-3: 开发 image dataloader + joint fusion 代码
Day 4-5: C3 训练（fold 0-1，观察 early stop）
Day 6-10: 继续训练（fold 2-4，若未 early stop）
Day 11-12: 结果整理、C3 证据包
Day 13-14: 合并 C2+C3 为完整 Results 草案
总计：~14 个工作日（若无 early stop）
```

**关键差异**：路径 B 比路径 A 多 ~8 个工作日（约 1.5-2 周）

- 人力：1 人 × 6 天

- 总成本：~48 人时

**路径 B 资源**：
- 人力：1 人 × 14 天

- 存储：~5 GB
- 代码开发：image dataloader, joint fusion, training script
- 总成本：~112 人时 + GPU 成本

**成本差异**：路径 B 比路径 A 多 ~64 人时 + GPU 成本

### 4.4 风险-收益分析

**路径 A 风险-收益**：
- **收益**：低成本快速产出 Results 草案
- **风险**：论文 novelty 依赖负结果接受度
- **期望价值**：稳定中等收益

**路径 B 风险-收益**（按场景概率估算）：

- **期望价值**：高方差，可能很高也可能低于路径 A

### 5.2 候选决策方案（待 Codex 裁决）

**方案 1：先路径 A，保留路径 B 为备选**
```
理由：
1. 快速产出 Results 草案，不阻塞其他路线
2. 若审稿人要求补 image 对照，再执行路径 B（C3）
3. 若三轴小项目或路线二有新发现，再决定是否 C3

优势：低风险、快迭代、可逆
劣势：论文初稿 novelty 依赖负结果
```

**方案 2：直接执行路径 B（C3）**
```
理由：
1. 科学完整性优先，完整对照链
2. 若场景 1-2，论文价值显著提升
3. early stop 机制可控制风险

优势：一次性闭合路线一 C
劣势：时间成本高，场景 4 风险
```

**方案 3：混合路径（分阶段）**
```
阶段 1：执行路径 A，生成 C2 Results 草案（~6 天）
阶段 2：并行启动路径 B fold 0-1（~5 天）
阶段 3：根据 fold 0-1 结果决定是否继续
  - 若 image positive：完成 C3，合并 Results
  - 若 image null：停止 C3，沿用路径 A

优势：并行推进，灵活调整
劣势：资源协调复杂
```

### 5.3 当前不推荐的选项

❌ **不推荐**：后验 OCS-only 架构/特征搜索
```
理由：
1. C2 是预注册固定协议，后验搜索需另立任务
2. 在全部配置 yaw_acc=0 的情况下，架构搜索收益不明确
3. 若要探索，应作为 exploratory，不回填 C2 结论
```

❌ **不推荐**：同时启动三轴小项目、路线二、路线三
```
理由：
1. 路线一 C 主线尚未收束（C2 null + C3 待定）
2. 三轴小项目依赖路线一 C 的基础结论
```
