## 4. 与历史 Legacy Phong 公式对比

### 4.1 历史代码公式

用户提供的历史代码公式：
```
f_r = rho_d / pi + rho_s * (N·H)^n
```

**公式结构分析**：
- **漫反射项**：`rho_d / pi`（Lambert 朗伯模型，ρ_d 归一化到球面）
- **镜面项**：`rho_s * (N·H)^n`（Phong 或 Blinn-Phong 高光项）
  - N：表面法向量
  - H：半程向量（入射方向与反射方向的角平分线）
  - n：高光指数（控制镜面高光集中程度）

### 4.2 书籍知识库中的五参数冯模型结构

根据 **13号文件第4.2节**：
> **模型结构**：BRDF = 漫反射项 + 镜面项，其中镜面项包含高光指数N控制的余弦幂次项。

根据 **05_第3章精读笔记.md**：
> 五参数冯模型（Phong-like 改进）：含漫反射比 ρd、镜面项 ρs、粗糙度 m 等参数（具体参数命名待作者核对）。

根据 **11_公式图表模型索引.md** 第4节：

| 模型/算法 | 输入 | 输出 | 适用条件 |
|---|---|---|---|
| 五参数冯模型 | ρ_d, ρ_s, N, C_1, C_2 | f_r(漫反射+镜面) | 光滑表面 |

### 4.3 形式对比结论

**对比维度1：整体结构**
- 历史公式：`漫反射项 + 镜面项`
- 书中模型：`漫反射项 + 镜面项`
- **结论**：✅ **形式一致**

**对比维度2：漫反射项**
- 历史公式：`rho_d / pi`（Lambert 模型）
- 书中模型：包含 ρ_d（漫反射比）
- 书中 Lambert 模型（11号文件第3章）：`f_r = ρ_d/π`
- **结论**：✅ **形式一致**

**对比维度3：镜面项**
- 历史公式：`rho_s * (N·H)^n`（Blinn-Phong 形式，使用半程向量 H）
- 书中模型：包含 ρ_s（镜面反射比）和 N 或 m（高光指数）控制的余弦幂次项
- **结论**：✅ **部分一致**
  - 均包含镜面反射系数（ρ_s 或 rho_s）
  - 均包含高光指数控制的幂次项（N^n 或 m^n）
  - 历史公式明确使用半程向量 (N·H)，书中模型未在当前截图识别内容中明确向量形式
  - 需作者确认书中公式是否为 (N·H)^m、(N·R)^m 或其他形式

**对比维度4：参数数量**
- 历史公式：3个参数（rho_d, rho_s, n）
- 书中模型：声称"五参数"（ρ_d, ρ_s, N, C_1, C_2）
- **结论**：⚠️ **证据不足**
  - 历史公式未包含 C_1, C_2
  - 书中 C_1, C_2 的含义、是否为归一化系数、Fresnel 项或其他修正项，均待作者确认
  - 无法判断历史公式是否为书中"五参数冯模型"的简化版本

### 4.4 总体对比结论

| 对比项 | 一致性判断 | 证据 |
|---|---|---|
| 整体结构（漫反射+镜面） | ✅ **形式一致** | 历史公式与书中模型均为两项和 |
| 漫反射项（ρ_d/π） | ✅ **形式一致** | 历史公式 rho_d/pi 与书中 Lambert 模型一致 |
| 镜面项（ρ_s 系数） | ✅ **形式一致** | 均包含镜面反射系数 |
| 镜面项（幂次项） | ✅ **形式一致** | 均包含高光指数控制的余弦幂次 |
| 镜面项（向量形式） | ⏳ **部分一致/证据不足** | 历史公式为 (N·H)^n，书中未明确是否为同一形式 |
| 参数数量（3 vs 5） | ⏳ **证据不足** | C_1, C_2 含义待确认，无法判断关系 |

**核对结论**：
1. 历史代码公式与书籍知识库中的五参数冯模型在**核心结构**（漫反射+镜面高光）上**形式一致**。
2. 漫反射项（Lambert）**形式一致**。
3. 镜面项在**系数和幂次结构**上**形式一致**，但向量形式（N·H vs N·R 或其他）需作者确认原书。
4. 历史公式为3参数，书中为5参数，C_1, C_2 的物理含义和是否可省略，需作者确认。
5. **不能替 Codex 裁决**历史公式是否可直接采用，或是否需要补充 C_1, C_2 项。
