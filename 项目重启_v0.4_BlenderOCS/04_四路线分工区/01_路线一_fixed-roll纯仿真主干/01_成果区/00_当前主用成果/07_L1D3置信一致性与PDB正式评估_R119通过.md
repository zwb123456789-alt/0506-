## 1. 成果定位

本成果把 R117 的 P-DB/conformal smoke 升级为正式可审计评估包，用于支撑路线一 C 的“多观测 OCS 可观测性、互补性和置信一致性”证据链。

本成果不等于路线一 C 整体闭口，不等于真实未知目标反演验证，不等于最终概率校准完成，也不放行三轴小项目、T3/L2 光变正式训练或路线二/三/四扩展。

## 2. P-DB 正式评估

P-DB 使用 train split 的多观测总光度向量作为 template 库，val/test 不进入 template。检索是 model-known simulated template retrieval，不是真实观测反演成功率。

test / matched-degraded / neg-L2 下，P-DB top1 yaw hit@30 随几何数单调上升，并随退化强度优雅下降：

| degrade | G1 | G3 | G5 |
|---|---:|---:|---:|
| clean | 0.291 | 0.821 | 0.949 |
| degraded-mild | 0.270 | 0.774 | 0.892 |
| degraded-moderate | 0.230 | 0.625 | 0.780 |

clean G5 下，P-DB top1 yaw cMAE=8.19°、hit@30=0.949，高于 neural ocs_only best 的 cMAE=22.77°、hit@30=0.811。可写结论：多观测总光度向量中存在可检索 yaw 信息，且 neural ocs_only 回归尚未充分利用这些信息。

## 3. 互补与置信

neural 与 P-DB 的 yaw error 在 clean G5 上几乎不相关：ocs_only Spearman=0.066，image_only=-0.085，joint=0.013。clean G5 ocs_only 互补四象限为：

| both correct | neural only | P-DB only | both wrong | oracle hit@30 |
|---:|---:|---:|---:|---:|
| 237 | 3 | 44 | 12 | 0.960 |

这支持“P-DB 与 neural ocs_only 是互补证据链”的写法。但 oracle 是上界，不代表可无监督选中正确一方。

诚实负向观察也必须保留：neural margin 的 risk-coverage 曲线近乎平坦，当前工程置信分数区分度弱，不能写成选择性预测已经强可用。

## 4. Conformal

split-conformal 使用 val 校准、test 评估。它只代表当前 simulated split 下的覆盖率与集合宽度，不是真实天文观测不确定度，也不是最终概率校准。

ocs_only clean α=0.10 下，set_size 随几何数收紧：

| G1 | G3 | G5 |
|---:|---:|---:|
| 321.8° | 245.7° | 126.2° |

coverage 多接近 target=0.90，说明当前 split 下校准自洽。P-DB G5 clean α=0.10 的 set_size 约 10°，但 G1/G3 的 P-DB set_size 仍很宽，因此不能泛化为“P-DB 所有几何均高精度校准”。

image_only conformal 系统性略欠覆盖（约 0.83-0.85），应写作当前 val->test 分布或误差形态存在偏移，留待后续分层或更难协议复核。

## 5. Hard-case

hard-case index 共 1231 行，覆盖五类：

| label | count |
|---|---:|
| ocs-hard | 121 |
| image-hard(image_only) | 2 |
| image-hard(joint) | 0 |
| disagreement-hard | 748 |
| ambiguous-flux | 148 |
| robust-easy | 351 |

该索引可作为后续 P-INT-hard / stronger degraded 的候选输入，但不等于阶段门放行。推荐下一步若做训练，应另行下达 degraded-severe 或 P-INT-hard 小矩阵任务，并以 joint 相对 image_only 的增量作为主判据。

## 6. 后续使用口径

R119 后可以稳定引用：

1. P-DB 正式评估证明 L1 多观测总光度向量含强 yaw 可检索信息，且 G1->G3->G5 单调增强。
2. P-DB 与 neural ocs_only 回归存在互补空间，说明神经回归并未完全吸收光度向量信息。
3. conformal set_size 随几何数收紧，与多观测 OCS 信息量增益一致。
4. 当前 neural margin 置信区分度弱、image_only 欠覆盖，是必须保留的负向观察。

仍不得引用为：真实未知目标姿态反演成功、真实望远镜验证、Bayesian posterior、最终概率校准完成、P-EXT yaw-block 已解决、路线一 C 整体闭口、三轴小项目完成。
