# 路线一投稿目标与证据门槛

最后更新：2026-06-18

> 性质：路线一发刊规划文件。本文不启动代码、不生成数据、不修改 24/25/13/14，只规定路线一完成后的投稿目标与证据门槛。

## 1. 论文定位

路线一是 v0.4 主体论文与硕士论文主干：

```text
model-known 条件下，fixed-roll yaw-pitch controlled benchmark 中，
独立 OCS 多观测光度向量与图像通道对姿态信息的可观测性、互补性和置信一致性研究。
```

路线一不是真实未知目标完整姿态反演系统；反演结果只作为可观测性验证工具。

## 2. 推荐投稿档位

| 档位 | 推荐目标 | 条件 |
|---|---|---|
| 稳健档 | Acta Astronautica / Advances in Space Research | Phase 0 gate、H1-H5、single-geom baseline、roll sensitivity 与基本 mismatch 边界闭合 |
| 主攻档 | Aerospace Science and Technology / Chinese Journal of Aeronautics | 可观测性、互补性、置信一致性指标完整，退化与 mismatch 结果扎实 |
| 冲刺档 | IEEE TAES / IEEE TGRS / AIAA Journal / JGCD | 需要非常强的信息量地图、置信一致性、mismatch 鲁棒性、可复现实验协议；不得写成真实监督反演 |

默认建议：

```text
先按 Acta / ASR 可稳投标准完成主体；
若结果强，再重构叙事冲 AST / TAES / TGRS / AIAA / JGCD。
```

## 3. 必须完成的证据门槛

1. Phase 0 gate 通过：environment、smoke test、depth round-trip、20 姿态 shadow validation。
2. v0.4 Blender-derived OCS/image 同源生成链路闭合。
3. single-geom 公平基线完整：OCS-only / image-only / joint。
4. G1/G3/G5 多几何 OCS 信息量对比完成。
5. roll sensitivity 作为主线探针完成。
6. H1-H5 与信息量、posterior-like、consistency 指标落地。
7. mismatch 条件下报告退化边界，避免 inverse crime。

## 4. 必守红线

- 不声称真实望远镜验证。
- 不声称 field-proven / operational-ready。
- 不把 fixed-roll 写成完整 3-DOF。
- 不把路线二 GEO 或路线三暗室作为路线一成立前提。
- 不复用路线零 face-center OCS 作为 v0.4 主结果。
