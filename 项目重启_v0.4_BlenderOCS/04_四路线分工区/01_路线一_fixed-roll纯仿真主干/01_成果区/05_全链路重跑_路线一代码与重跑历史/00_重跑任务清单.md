## 一、重跑原则（方法冻结后统一口径）

### 1.1 核心原则

v0.4 不做局部替换，不延续旧采样口径。所有 OCS 特征、OCS 图、image、OCS-only、image-only、fusion 实验全部使用**同一统一前向物理模型**重跑。

本轮重跑必须服务 24 号项目/论文主线，而不是复刻 v0.3 的误差表：

```text
model-known 条件下，
独立 OCS 光度通道与图像成像通道共享同一物理前向模型时，
跨几何 OCS 多观测光度向量与图像通道对姿态信息的可观测性、互补性和置信一致性研究。
```

因此，重跑输出必须能够回答：

```text
What can be known?
When are OCS and image complementary?
When should we trust the estimate?
```

**统一前向模型三要素**（见方法冻结文件 `13` §1）：
1. OCS 与图像均由同一 STL 几何、同一姿态、同一 sun/det 方向、同一 BRDF、同一 camera visibility、同一 `V_sun_macro` 生成
2. OCS 是积分读出，image 是空间分布读出
3. OCS 公式 `Σ A_pix·f_r·NoL·V_sun_macro`，图像公式 `I_linear(p) = f_r(p)·NoL(p)·V_sun_macro(p)`

### 1.2 冻结参数

| 参数 | 取值 | 说明 |
|---|---|---|
| **姿态网格（训练/反演/manifest）** | yaw ∈ [0°, 355°], pitch ∈ [-90°, 90°], 步长 5° | **72 yaw × 37 pitch = 2664 姿态**（0° 和 360° 不重复）|
| **绘图 heatmap seam** | yaw ∈ [0°, 360°] 复制 0° 为 360° | 仅绘图，73 yaw 值 |
| ortho_scale | 2.2 × r_max | 正交投影视口宽度 |
| resolution | 256×256 | 像素分辨率 |
| BRDF | GGX/Cook-Torrance | 材料参数见 `_GGX_DB` |
| eps | 1e-6 | NoL/NoV 有效像素阈值 |
| sun_visibility 主线 | Level 2 (`camera_visible_nol_plus_sun_shadow_pass`) | 优先实现，降级预案为 Level 1 |
| log1p α | 10.0（初始） | quick ablation α∈{5,10,20}+raw |

### 1.3 禁止的旧口径

- ❌ `yaw73`（旧版含 360°，现为 72 yaw 唯一值）
- ❌ `multi_geom_ggx_yaw73_pitch37`（旧 manifest 命名）
- ❌ 只替换 OCS 采样、图像链不同步
- ❌ OCS 含 `V_sun_macro`、图像不含
- ❌ 混用不同 geometry/brdf/visibility 版本

### 4.4 中间产物保留与清理原则

全量生成会产生大量 EXR、npy 和 PNG。实施阶段必须先记录存储估算，再决定清理策略。

默认保留：

- manifest、source_data、summary、split、训练结果、论文 figure source data。
- validation reports、depth round-trip 报告、20 姿态 shadow validation 报告。
- 用于复现 OCS/image 的必要配置、矩阵、版本与统计信息。

可在确认后归档或清理：

- 重复生成且可由 manifest + 原始配置再生的中间可视化 PNG。
- 已完成统计且不再用于审计的临时 debug 图。

暂不自动清理：

- camera geometry EXR、sun depth EXR、V_sun_macro `.npy`、linear EXR。是否清理必须等 single-geom 全链路复核后再决定，并记录清理依据。

### 4.5 禁止 latest-run 自动发现

所有脚本必须**显式传入** `--ocs-manifest` / `--image-manifest` / `--split-file` / `--output-dir`，不设默认值，不自动扫描（见 `14` §7）。

## 五、一致性检查清单

每次实验/训练前必须通过以下检查（见 `14` §8.1）：

```python
assert ocs_manifest.geometry_version == image_manifest.geometry_version
assert ocs_manifest.brdf_version == image_manifest.brdf_version
assert ocs_manifest.visibility_version == image_manifest.visibility_version
assert ocs_manifest.sun_visibility == image_manifest.sun_visibility
assert ocs_manifest.shadow_mapping_method == image_manifest.shadow_mapping_method

if ocs_manifest.sun_visibility == "camera_visible_nol":
    assert image_manifest.preprocessing.v_sun_macro_mode == "identity"
else:
    assert image_manifest.preprocessing.v_sun_macro_mode == "shadow_mask"

assert image_manifest.preprocessing.v_sun_macro_applied_to_image == True
assert source_data.brdf_model == "ggx_cook_torrance"
```

## 六、写作边界（v0.4 必须遵守）

见 `24`、`25` 与 `13` §13：

1. Synthetic forward model only（无真实望远镜）
2. No real telescope validation
3. Nominal material parameters
4. Sun-side visibility 按实现结果诚实声明（Level 2 成功/降级）
5. Observation-consistent, not observation
6. No inter-satellite occlusion
7. OCS 与图像必须同源（同一 sun_visibility + shadow_mapping_method + v_sun_macro_mode）
8. 不写真实未知目标姿态反演系统。
9. 主线 OCS 是 independent photometric channel 下的 multi-observation photometric vector。
10. image-derived OCS 只作 common-mode failure 对照。
