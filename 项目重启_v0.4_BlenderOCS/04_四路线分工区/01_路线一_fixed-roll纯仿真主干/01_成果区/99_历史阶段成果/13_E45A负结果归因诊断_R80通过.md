## 稳定结论

E45A 在不训练、不改 split/模型/超参/seed 的条件下，对已训练 checkpoint 做了只读推理复算与后处理诊断。先行门通过：

```text
C3：10/10 run PASS
C2：65/65 run PASS
```

最关键失败模式：

```text
全部 75 个逐样本 npz、39960 个样本中，预测 yaw bin 落入对应 fold 的 holdout yaw 块比例为 0.0。
```

这说明 fixed-protocol 下的 exact-bin yaw=0.00% 不是“yaw 信息完全不存在”的证据，而是：

```text
strict cross-yaw extrapolation + 72-bin exact 5 deg 命中判据下，
模型预测系统性坍缩到训练可见 yaw 区间，未能外推到未见 holdout yaw 块。
```

## 使用边界

- 可作为 R77/R78 负结果的 exploratory secondary diagnostics。
- 可写“存在弱粗粒度 yaw 残留信息”，不可写“可可靠反演 yaw”。
- 可写“pitch 显著强于 yaw，fixed-roll 下存在 yaw/pitch 各向异性”。
- 当前证据不支持“joint 相比 image_only 有实质互补增益”。
- 不得外推到真实 GEO、三轴姿态、暗室实验或所有模型。
