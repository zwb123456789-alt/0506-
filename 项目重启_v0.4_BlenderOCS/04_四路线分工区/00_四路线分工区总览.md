# 四路线分工区总览

最后更新：2026-06-17

## 1. 本目录职能

`04_四路线分工区/` 是 v0.4 后续工作的主工作区。四条路线分别管理，且每条路线内部采用同一结构：

```text
00_路线冻结文件区/
01_成果区/
02_Claude输出/
03_GPT输出/
04_Codex审阅/
```

规则：

- Claude 输出先进入 `02_Claude输出/`。
- GPT 输出进入 `03_GPT输出/`。
- Codex 审阅进入 `04_Codex审阅/`。
- 审阅通过后的稳定文件进入 `01_成果区/`。
- 路线指导思想、主线说明和冻结判断进入 `00_路线冻结文件区/`。

## 2. 路线划分

| 区域 | 定位 |
|---|---|
| `00_旧路线投稿/` | 旧路线投稿：v0.3 已完稿论文作为独立投稿路线（封存待裁决） |
| `00_总览与裁决/` | 四路线总裁决、全局冻结文件、跨路线审阅 |
| `01_路线一_fixed-roll纯仿真主干/` | 主体路线：fixed-roll yaw-pitch 纯仿真可观测性 benchmark |
| `02_路线二_GEO真实光度锚点/` | 增强路线：GEO 真实光度数据库 sim-to-real 锚点 |
| `03_路线三_暗室缩比独立验证/` | 条件增强路线：暗室缩比前向保真与姿态可控反演闭环 |

## 3. 当前工作假设

```text
路线零（旧路线投稿） = 封存待裁决，不阻塞路线一/二/三
路线一 = 必选主干
路线二 = 优先增强层
路线三 = 条件触发增强层
```

该假设仍需 Codex 审阅确认。当前不能直接把路线二/三写成必做主线，也不能绕过路线一直接进入真实数据或暗室路线。
