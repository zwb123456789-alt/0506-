# 四路线分工区总览

最后更新：2026-06-23

## 1. 本目录职能

`04_四路线分工区/` 是 v0.4 后续工作的主工作区。四条路线分别管理，且每条路线内部采用同一结构：

```text
00_路线冻结文件区/
01_成果区/
02_Claude输出/
03_GPT输出/
04_Codex审阅/
```

规则：

- `02_Claude输出/`：存 Claude 执行结果、候选材料和 Claude 自检记录。Claude 自检不能替代 Codex 审阅，Claude 不得自行放行、扩展路线设计、技术裁决或改写成果区。
- `03_GPT输出/`：存 GPT 候选方案、候选文本和辅助构思。GPT 输出不是稳定成果，不得直接进入成果区。
- `04_Codex审阅/`：存 Codex 审阅、阶段门判断、问题清单、返工单、执行规划、方法说明审阅意见和给 Claude 的下一步提示词。Codex 判断和调度文件默认进入本目录，不进入成果区。
- `01_成果区/`：只存已经通过 Codex 审阅、可作为路线后续依据的稳定成果本体，包括通过审阅的报告、代码、脚本、配置、数据输出、图表、表格、路线结论、可引用文本或最终说明文档。
- Codex 审阅分流：作者将 Claude/GPT 输出路径交给 Codex 后，Codex 必须审阅并自动分流；通过时，成果本体进入对应路线 `01_成果区/`，Codex 审阅/规划/提示词文件仍进入 `04_Codex审阅/`；不通过、需要返工、存在阻塞或只形成问题清单时，返工审阅文件进入对应路线 `04_Codex审阅/`，可直接交给 Claude 继续执行。
- 若成果本体已写入 `01_成果区/`，不再把同一成果本体重复写入 `04_Codex审阅/`；但对应的 Codex 审阅记录、阶段门判断、执行规划或提示词仍应保留在 `04_Codex审阅/`。
- 路线指导思想、主线说明和冻结判断进入 `00_路线冻结文件区/`。

路线零（旧路线投稿） = v0.3 旧稿封存待解封评估，不阻塞路线一/二/三
路线一 C = 必选主干，v0.4 pixel-level 同源架构 + B1 书中改进冯模型待确认主线 + B0 工程 baseline + GGX 对照

路线一、路线二、路线三旧 R01/R02 边界仍有效；2026-06-22 新增裁决是在旧分层上补入“路线一 C -> 三轴小项目 -> 路线二 -> 路线三 -> 路线四”的执行链。当前不能绕过路线一 C 直接进入三轴小项目，也不能把路线二写成监督姿态反演，不能把路线三暗室写成 GEO / 在轨验证。路线四只作为未来方向，不阻塞当前主链。

## 4. 路线一二三与投稿安排

当前路线安排不是互斥选择，而是“路线一 C 先闭合，三轴小项目必做桥接，路线二/三增强证据，路线四保留未来方向”的分层执行结构。

路线一 C 支撑 v0.4 主体论文和硕士论文主干，先独立完成 fixed-roll yaw-pitch 纯仿真可观测性 benchmark，回答 model-known 条件下 OCS 光度向量与图像通道的可观测性、互补性和置信一致性。路线一 C 采用 v0.4 pixel-level 同源架构；B0 仅作为工程 smoke test / 兜底 baseline，B1 书中改进冯模型在作者确认公式与材料对应关系后作为正式 Method 优先目标，GGX 作为对照与 mismatch 分支。

三轴小项目在路线一 C 之后必做，负责把 fixed-roll 可观测性工具扩展到 yaw / pitch / roll 三轴空间，寻找最亮构型、高信息构型、最优可观测姿态和低信息/不值得观测区域。它是价值三的主要落点，不等同于路线一 roll sensitivity。

路线二在路线一 C 与三轴小项目之后作为 GEO 真实光度锚点升级层；真实数据 pilot 成功时，用于补强 sim-to-real 光度趋势、分布、多帧/多几何现实性和投稿上限。路线二不得写成真实监督姿态反演路线，也不得提供三轴姿态真值。

路线三作为暗室缩比条件增强层；只有 pilot 跑通同系统仿真与实测光度 sanity check、以及暗室缩比系统内小规模姿态可控闭环后，才考虑并入主论文增强章或后续独立论文。路线三可以验证三轴小项目预测的最亮/高信息构型，但不得外推为 GEO 在轨目标姿态反演验证。

路线四作为未来方向，研究低轨目标光学特性与姿态运动特征关系，需要动态光变曲线、姿态动力学和三轴运动建模；不并入当前路线一 C 与三轴小项目的必做闭环。

路线三新增 ISAR 双站在轨图像条件只作为可选增强子线：可候选为同型在轨目标姿态参考或真实图像案例研究，但不提供光度确认、不提供 GEO 监督标签、不作为路线三暗室 pilot 的必做项；具体统计强度与用法待后续数据处理确认。

专家与一线实践对“光度结合姿态反演”的谨慎态度，不应被理解为路线无价值，而应转化为 v0.4 的研究空白：当前工程实践多将空间目标光度用于异常监测，而较少用于精确定姿；因此本项目不直接宣称光度可完成真实未知目标姿态反演，而是系统研究在 model-known 条件下，光度通道究竟携带多少姿态可观测信息、何时能与图像通道互补、何时只能作为置信或异常判据。

投稿策略采用“高目标牵引、证据强度定档”：路线一先形成可独立投稿的稳健 SCI 主体；路线二/三若 pilot 和证据链充分，则用于上探更高水平 SCI；若增强层未通过，不影响路线一主体闭合，可降级为 Discussion / Future Work 或后续独立路线。
