## 1. 稳定定位

三轴小项目当前唯一最高目标是：

```text
在已知卫星模型和前向光学模型下，
找出卫星在哪个 yaw/pitch/roll 姿态、哪个太阳入射几何、哪个探测器观测几何下最亮；
并解释这束最亮光从哪里入射，照到卫星哪个部位、哪种材料/表面，
再沿什么方向进入探测器。
```

后续任务规划必须遵循 R144 的顺序：

```text
1. 先确认 single-pose top-1 最亮点。
2. 再解释 top-1 的入射-表面/材料-探测器光路。
3. 再检验同类光路机制是否普遍对应高亮候选簇。
4. 最后再扩展 sun/view 几何和路线二/三接口。
```

高信息、低信息、易混淆和观测规划只作为辅助标注，不能替代“找最亮”主目标。

## 2. 当前阶段边界

P1/P2/P3 当前只覆盖固定几何：

```text
phase63 / L1-G1
SUN = [1, 0, 0.3]
DET = [0.5, -1, 0.1]
```

因此当前直接任务不是完整 sun/view 全局搜索，而是：

```text
先在固定 phase63/L1-G1 sun/view 下，确认 yaw/pitch/roll single-pose top-1。
```

固定几何 top-1、光路机制和机制普遍性稳定后，才进入单独的 sun/view 扩展阶段门。

## 3. 当前证据与下一步

P3 当前 sampled-grid top-1 候选为：

```text
R1_high_info
yaw = 245.0
pitch = +30.0
roll = +15
ocs_total = 0.208377
glint_flag = 0
saturation_flag = 1
```

但该点不能直接作为最终最亮姿态结论，因为：

```text
top-1 与 top-2 仅差 0.224%；
top-1 与 R4 最高 single-pose 仅差 3.15%；
R1 在 roll=+15 呈尖峰；
现有 roll 只覆盖 {-60,-45,-30,-15,0,+15,+30,+45,+60}。
```

所以当前下一步必须按 R141/R142/R143/R144 执行：

```text
建立 23A 包；
输出 006A 报告；
围绕 R1 top 簇做局部 roll/yaw/pitch 加密；
保留 R4 鲁棒亮区作少量机制对照；
确认 fixed-geometry top-1 是否稳定。
```
