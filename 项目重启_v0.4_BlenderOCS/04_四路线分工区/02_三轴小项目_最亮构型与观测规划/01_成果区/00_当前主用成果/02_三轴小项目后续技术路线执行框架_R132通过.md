## 1. 总定位

三轴小项目的目标不是真实未知目标三轴姿态反演。按 2026-07-06 冻结指导文件，唯一且最高标准是：

```text
在已知卫星模型和前向光学模型下，
找出卫星在哪个 yaw / pitch / roll 姿态、哪个太阳入射几何和哪个探测器观测几何下最亮，
并解释这束光从哪里入射、照到卫星哪个部位/材料/表面，
再沿哪个方向进入探测器。
```

核心边界：

```text
最亮构型与其光路解释是主目标；
执行顺序必须是先确认 top-1 最亮点，再检验同类光路机制是否形成普遍高亮候选簇；
高信息、低信息、易混淆和观测规划只作为辅助标注；
高亮但低对比或饱和风险仍然可以是最亮构型，但必须标注风险；
本小项目不提供真实未知目标反演成功率。
```

## 3. 后续阶段

### P2 sparse 3-axis grid

目标：

```text
从 seed-roll smoke 扩展到受控稀疏三轴网格，
验证最亮构型是否随 roll 与局部 yaw/pitch 邻域迁移，
并初步形成高亮区域、风险区域和辅助高信息/低信息标注。
```

建议重点区域：

```text
yaw~240 high-info 区；
yaw~285 dark / roll-sensitive 区；
yaw~065 low-info / ocs-hard 区；
yaw~145/150 bright / robust-easy 对照区；
少量中性姿态作为背景对照。
```

最低输出：

```text
稀疏三轴姿态表；
OCS magnitude / rank / local contrast / roll sensitivity；
高亮候选图；
光路/材料/探测器解释所需字段清单；
辅助高信息、低信息与易混淆区域图；
P3 局部加密候选清单。
```

限制：

```text
不训练；
不做全三轴爆炸网格；
不启动真实数据或 R128；
不写三轴最终结论。
```

### P3 local refinement

触发条件：

```text
P2 找到稳定高亮区域、潜在 single-pose 最亮候选或强 roll-sensitive 高亮候选。
```

目标：

```text
围绕 P2 候选区域局部加密，
确认 single-pose 最亮点是否迁移，并为后续解释入射-表面-探测器光路准备局部证据。
```

P3 不应在 P2 前启动。

### P4 最亮构型与光路解释综合

触发条件：

```text
P2/P3 已形成足够的最亮构型候选、roll 迁移证据和风险标注。
```

目标：

```text
汇总为最亮构型与光路解释材料：
哪个 yaw/pitch/roll + sun/view 构型最亮；
光从哪里入射、照到哪里、经什么材料/表面响应、如何进入探测器；
同类入射-表面/材料-探测器光路是否对应一片普遍高亮候选；
该最亮构型是否伴随 glint/saturation 风险；
高信息/低信息/观测规划只作为辅助标注。
```

## 4. 指标体系

当前稳定使用：

```text
brightness / OCS magnitude；
local contrast；
brightness rank shift；
roll sensitivity score；
glint / saturation risk；
image usability；
seed category / source traceability。
```

后续可升级但需阶段门：

```text
P-DB top-k；
candidate entropy；
margin；
JS / overlap；
conformal set_size；
roll-aware neural model。
```

其中 roll-aware neural model 属 C 类新训练，未放行。
