# 三轴小项目：最亮构型与观测规划指导文件

最后更新：2026-06-22

## 1. 文件性质

本文是路线一 C 之后、路线二/三之前必须执行的小项目指导文件。它不替代路线一 C，也不把当前论文改写成真实未知目标三轴姿态反演系统；它的任务是把路线一的可观测性工具扩展到三轴姿态空间，形成观测规划价值。

## 2. 一句话主线

```text
基于路线一 C 的 v0.4 pixel-level 同源前向模型、B0 工程 baseline 与 B1 书中改进冯模型待确认主线，
在 yaw / pitch / roll 三轴姿态空间中搜索最亮构型、高信息构型、最优可观测姿态，
并识别光度信息量低、易混淆或不值得投入观测的姿态/几何区域。
```

## 3. 它要解决的问题

本小项目不是简单回答“哪些 sun/view 几何更值得观测”，而是同时回答三类问题：

1. **姿态层面**：哪些 yaw / pitch / roll 姿态最亮、最暗、最容易产生 glint 或饱和风险。
2. **信息层面**：哪些姿态虽然亮但信息量低，哪些姿态不一定最亮但最有利于区分。
3. **观测规划层面**：在哪些 sun/view 几何下，某类姿态的光度信息量最高；哪些几何/姿态组合不值得投入。

## 4. 输入与继承

必须继承路线一 C 的以下内容：

```text
v0.4 pixel-level OCS-image 同源架构；
B0 工程 baseline；
B1 书中改进冯模型待确认 Method 目标；
GGX / Cook-Torrance 对照与 mismatch 分支；
OCS-only / image-only / fusion / consistency 指标；
candidate distribution、top-k、entropy、margin、JS、overlap、reject/conflict 输出。
```

不得继承旧 v0.3 face-center OCS 作为主结果链。

## 5. 推荐实验结构

### 5.1 姿态空间设计

先做可控规模三轴搜索，不直接全量爆炸：

```text
阶段 A：从路线一 fixed-roll 高亮/高混淆/高信息代表姿态中选种子点。
阶段 B：围绕种子点扫描 roll，观察最亮点和混淆结构是否迁移。
阶段 C：做稀疏三轴随机/网格采样，建立三轴高亮与高信息候选集。
阶段 D：对候选集做局部加密，输出最亮构型和最优可观测姿态。
```

### 5.2 指标

最少应输出：

| 指标 | 用途 |
|---|---|
| brightness / OCS magnitude | 找最亮/最暗构型 |
| local contrast | 判断姿态邻域是否可区分 |
| entropy / margin | 判断候选分布集中程度 |
| top-k stability | 判断最优姿态是否稳定 |
| JS / overlap | 判断 OCS 与 image 是否一致或冲突 |
| saturation / glint flag | 判断亮但不可用的风险区域 |
| geometry utility score | 判断该几何是否值得观测 |

### 5.3 关键区分

```text
最亮姿态 != 最有信息姿态。
最亮可能来自 glint 或饱和，反而可能不稳定；
高信息姿态应兼顾亮度、局部可分性、候选集中度和通道一致性。
```

## 6. 与路线二/三的接口

### 6.1 路线二接口

路线二提供 GEO 真实光度趋势和多几何现实性锚点。三轴小项目不能要求路线二提供姿态真值，只能使用它验证：

```text
真实光度中是否存在与仿真高亮/低亮预测相符的趋势；
真实 GEO 数据是否覆盖小项目认为有价值的几何区域；
仿真高信息几何是否在真实多帧监测中具有现实出现条件。
```

### 6.2 路线三接口

路线三暗室可提供小规模真实光度 + 姿态真值验证。优先验证：

```text
仿真预测最亮姿态是否在暗室实测中仍然高亮；
roll-aware 最亮点是否相对 fixed-roll 发生迁移；
高信息姿态是否比低信息姿态更容易被真实实测反演区分。
```

## 7. 写作定位

本小项目的价值表述应是：

```text
从“光度能否反演姿态”转为“哪些姿态/几何组合值得观测，哪些不值得”。
```

可用表述：

```text
The proposed three-axis search converts the observability map into an observation-planning cue by identifying attitude-geometry configurations with high brightness, high discriminability, or low expected photometric utility.
```

禁用表述：

```text
本文解决了真实未知目标三轴姿态反演。
最亮姿态就是最优反演姿态。
GEO 数据验证了三轴姿态真值。
暗室三轴结果可直接外推在轨目标。
```

## 8. 最低完成标准

1. 完成三轴姿态候选搜索流程设计。
2. 输出最亮构型、高信息构型、低信息区域三类清单或图。
3. 明确 fixed-roll 结论在 roll-aware 空间中的稳定/迁移情况。
4. 给出观测规划建议：值得观测的几何、低价值几何、风险几何。
5. 写清与路线二真实趋势锚点、路线三暗室真值闭环的接口。

```text
P3：生成最亮构型搜索任务。

P5：生成观测规划图表与解释任务。
P6：生成路线二/路线三接口任务。
```
