## 3. 采纳与修正

采纳 1：R141 正式执行时必须显式区分两个对象。

```text
主对象：single-pose top-1，即 R1_high_info yaw245.0 pitch+30.0 roll+15。
辅助对照：R4_bright_info_boundary yaw147.5 pitch+12.5 的 roll-robust 高亮区。
```

但不得把 R4 与 R1 改写成并列 top-1。小项目最高标准仍是先确认 single-pose 最亮点；R4 的角色是机制对照和鲁棒高亮区，不替代 top-1。

采纳 2：R141 正式执行必须加入可复现的加密触发门。

最低门槛如下：

```text
top-1 与 top-2/top-3 相对差 < 5%；
或 top-1 与 R4 最高 single-pose 相对差 < 5%；
或 top-1 roll profile 在相邻 roll 档出现尖峰；
或未采样 roll（如 +10/+12.5/+17.5/+20）可能超过当前 +15。
```

按现有数值，R141 应触发小范围局部加密，而不应停留在只读表格分析。

采纳 3：R141 正式执行必须记录 sun/view 边界。

006A 报告需要明确：P1/P2/P3 目前是固定 `phase63/L1-G1` 几何。若后续要完整回答指导文件中的 `yaw/pitch/roll + sun/view` 最亮构型，必须另设阶段门扩展 sun/view；当前 23A 只解决固定 sun/view 下的三轴姿态 top-1。

修正 1：讨论稿中“R4 roll0 高亮”只能作为 roll0/均值说明，不能替代 R4 的 single-pose 表述。R4 最高 single-pose 是 `roll=-15`，不是 `roll=0`。

修正 2：讨论稿中关于 R1 可能是 glint 尖峰的说法只能作为待检验假设。现表显示 R1 top-1 `glint_flag=0`、`saturation_flag=1`，因此正式报告应写成“roll-sharp / saturation-associated high-brightness peak”，不得在未做光路诊断前直接称为 glint 机制。
