## 1. 当前结论边界

三轴小项目的最高目标仍是：

```text
在已知卫星模型和前向光学模型下，
找出卫星在哪个 yaw/pitch/roll 姿态、哪个太阳入射几何和哪个探测器观测几何下最亮，
并解释光从哪里入射、照到哪个部位/材料/表面，再沿什么方向进入探测器。
```

但 P1/P2/P3 当前只覆盖固定几何：

```text
phase63 / L1-G1
SUN = [1, 0, 0.3]
DET = [0.5, -1, 0.1]
```

因此下一步只能先解决：

```text
固定 phase63/L1-G1 sun/view 几何下，yaw/pitch/roll 三轴姿态空间中的 single-pose 最亮点。
```

不得把本轮结果写成所有 sun/view 几何上的全局最亮构型。

## 3. 为什么必须遍历/加密 roll

现有 roll 只覆盖：

```text
-60, -45, -30, -15, 0, +15, +30, +45, +60
```

P3 当前 sampled-grid top-1 是：

```text
region = R1_high_info
yaw = 245.0
pitch = +30.0
roll = +15
ocs_total = 0.208377
glint_flag = 0
saturation_flag = 1
```

但该点不能直接作为最终最亮姿态，原因：

```text
1. top-1 与 top-2 仅差 0.224%。
2. top-1 与 R4 最高 single-pose 仅差 3.15%。
3. 同一 yaw/pitch 下，R1 的 roll=+15 是尖峰：
   roll=0 和 roll=+30 均约 0.04084，而 roll=+15 达到 0.208377。
4. 因此真实峰值可能落在 +10、+12.5、+17.5、+20 等未采样 roll 上。
```

结论：

```text
只靠现有 roll 档位很难严肃锁定最亮姿态。
下一步必须做局部 roll 加密遍历。
```

但不应做全空间无差别暴力遍历。当前合理方案是围绕最可能区域做受控局部加密。

## 4. 修正后的执行方案

### 4.1 第一步：现有数据复核

R141/006A 必须先重聚合 P1/P2/P3，输出 current sampled-grid 口径下：

```text
top-1 / top-N
R1 top 簇 roll profile
R4 鲁棒亮区 roll profile
P1/P2/P3 量纲一致性
固定 sun/view 几何边界声明
```

当前 sampled-grid top-1 只能写成候选：

```text
fixed phase63/L1-G1 下，已有采样中的 single-pose top-1 candidate。
```

不得直接写成最终全局最亮姿态。

### 4.2 第二步：R1 top 簇局部 roll/yaw/pitch 加密

优先围绕当前 top-1 候选做局部加密：

```text
yaw   = {242.5, 245.0, 247.5}
pitch = {27.5, 30.0, 32.5, 35.0}
roll  = {+5, +10, +12.5, +15, +17.5, +20, +25}
```

规模：

```text
3 × 4 × 7 = 84 单位
```

目的：

```text
1. 确认当前 +15 峰是否仍为局部最大。
2. 检验峰值是否迁移到 +10/+12.5/+17.5/+20。
3. 判断 yaw/pitch 是否也发生小范围迁移。
```

### 4.3 第三步：R4 鲁棒亮区少量对照

R4 不是当前 single-pose top-1，但它是 roll-robust 高亮区，应保留为机制对照：

```text
中心：yaw=147.5, pitch=+12.5
roll 对照：{-30, -15, 0, +15, +30}
```

若资源允许，可加少量 yaw/pitch 邻域：

```text
yaw ∈ {145.0, 147.5, 150.0}
pitch ∈ {10.0, 12.5, 15.0}
roll 只保留少量代表档
```

R4 的角色：

```text
辅助判断“R1 尖锐最亮峰”和“R4 鲁棒高亮区”是否代表两类不同高亮机制。
```

不得把 R4 改写成并列 top-1，除非后续加密结果实际超过 R1。

### 4.4 第四步：停止/追加规则

加密后按以下规则裁决：

```text
若新 top-1 位于 R1 加密网格内部，且相邻 roll/yaw/pitch 均未显示继续上升趋势：
  停止加密，进入 P4-PHYS-B 光路归因。

若新 top-1 从 roll=+15 迁移到 +10/+12.5/+17.5/+20，但仍位于内部：
  以新 top-1 作为光路归因对象，停止加密。

若新 top-1 落在边界，例如 roll=+5 或 +25，或 yaw/pitch 边界：
  只沿该边界方向追加一小圈，不扩展成全局搜索。

若 R4 对照超过 R1：
  重新定义 fixed-geometry top-1 为 R4 新点，并记录 R1 为尖锐高亮簇对照。
```

### 4.5 第五步：top-1 稳定后再做光路归因

只有当 006A 确认 fixed-geometry top-1 稳定后，才进入 P4-PHYS-B：

```text
太阳入射方向；
卫星受光部位；
主贡献材料/表面；
法向、反射/散射方向与探测器方向关系；
同类机制是否普遍高亮。
```

在 top-1 未稳定前，不做完整物理光路归因。

### 4.6 第六步：后续单独扩展 sun/view

完整小项目目标包含 `sun/view`，但不应在当前阶段同时展开所有变量。

推荐顺序是：

```text
先锁定固定 phase63/L1-G1 下的 yaw/pitch/roll top-1；
再做该 top-1 的物理光路归因；
再围绕已识别的高亮机制设计 sun/view 扩展阶段门。
```
