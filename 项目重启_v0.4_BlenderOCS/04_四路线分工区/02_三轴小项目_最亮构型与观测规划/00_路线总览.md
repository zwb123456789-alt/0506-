## 2. 一句话定位

```text
在 yaw / pitch / roll 三轴姿态空间中，利用路线一 C 的统一前向模型和可观测性指标，
先寻找 single-pose top-1 最亮姿态-几何构型，
再解释最亮光对应的太阳入射路径、卫星受光部位、材料/表面响应和探测器接收路径，
并检验同类光路机制是否普遍对应高亮候选簇。
```

## 3. 与其他路线关系

```text
路线一 C -> 提供前向模型、BRDF 主锚点、OCS/image 指标和 fixed-roll 基础结论。
三轴小项目 -> 扩展到 roll-aware 三轴姿态与 sun/view 几何搜索，最高目标是先找 top-1 最亮构型，再解释并检验其高亮光路机制。
路线二 -> 用 GEO 真实光度提供趋势级、分布级和多几何现实性锚点。
路线三 -> 用暗室真实光度 + 姿态真值优先检查三轴最亮构型及其光路解释。
路线四 -> 动态光变与姿态运动未来方向，不阻塞本小项目。
```
