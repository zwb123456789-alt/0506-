# 路线三投稿目标与证据门槛

最后更新：2026-06-18

> 性质：路线三发刊规划文件。本文仅规定投稿目标与证据门槛，不启动暗室实验，不修改路线三冻结文件。

## 1. 论文定位

路线三是条件触发增强层：

```text
暗室缩比独立系统
-> 同系统点对点前向保真验证
-> 姿态可控监督反演闭环
-> 可小规模纳入 roll-aware / 三轴验证
```

路线三的真实闭环只限暗室缩比系统内，不能外推为 GEO 或在轨目标姿态反演验证。

## 2. 推荐投稿档位

| 档位 | 推荐目标 | 条件 |
|---|---|---|
| 稳健档 | Acta Astronautica / Advances in Space Research / Aerospace Science and Technology | 暗室同系统仿真 vs 实测光度 sanity check 与小规模姿态闭环成功 |
| 主攻档 | IEEE TAES / JGCD / AIAA Journal / Aerospace Science and Technology | 姿态真值闭环、误差统计、roll-aware 小样本、scale-model gap 分析完整 |
| 远期上探 | Engineering / Science Bulletin / NSR 等一类 B | 仅在暗室闭环强、系统方法普适性强，并有真实图像案例辅助时考虑 |

默认建议：

```text
路线三按二类 A 主攻潜力设计；
pilot 未通过时不并入主论文主证据，只作为 Discussion / Future Work 或后续独立路线。
```

## 3. 必须完成的证据门槛

1. 一个缩比模型跑通同系统仿真与实测光度 sanity check。
2. 姿态真值可控，至少少量 yaw/pitch/roll 样本。
3. 小规模真实光度 + 姿态真值反演闭环完成。
4. 明确 scale-model gap、BRDF/材料差异、杂散光、定标误差。
5. 成功率和误差只报告暗室系统内，不外推 GEO / 在轨。
6. 若使用 ISAR 双站在轨图像，必须通过元数据、时间同步/配准、几何可复现、图像可解释性和姿态误差闸门。

## 4. ISAR 子线边界

ISAR 双站在轨图像可作为：

- 同型目标形态 / 姿态判断辅助。
- 真实图像案例研究。
- 若姿态参考可解，作为同一几何模型的姿态输入，驱动 OCS / 图像前向仿真。

ISAR 子线不能作为：

- 光度确认。
- 可见光 OCS 保真证据。
- GEO 监督标签。
- 暗室 pilot 的必做项。
- 在轨反演成功率统计，除非后续真值误差与统一评估口径成立。

## 5. 必守红线

- 暗室与 GEO 数据库互不连通，不互证。
- 暗室成功率只限暗室系统内。
- 暗室不是地基望远镜外场验证。
- 路线三不阻塞路线一主干。
- pilot 未通过时自动降级，不强行并入主论文主证据。

## 6. 下一步

路线三启动前先做 pilot 方案：

```text
1. 明确缩比模型、材料、光源、相机、定标方式。
2. 设计少量含 roll 的姿态真值样本。
3. 做同系统仿真 vs 实测光度 sanity check。
4. 做小规模监督反演闭环。
5. 根据 pilot 决定并入路线一增强章、独立成文或降级 Future Work。
```
