# 发刊路线规划与旧文评估说明

最后更新：2026-06-17

## 1. 阶段定位

本目录用于四路线审阅通过后的 SCI 发刊路线规划与旧 v0.3 稿件解封评估。

当前目标不是直接投稿，也不是直接改论文正文，而是先明确四条论文路线的依赖、风险和顺序，为硕士大论文与 SCI 投稿建立进度规划。

## 2. 四条论文路线

| 路线 | 暂定用途 | 状态 |
|---|---|---|
| 旧项目 v0.3 已写稿 | 可能作为保底 SCI/短文/技术说明，但必须先评估是否可解封 | 封存，未自动解封 |
| 路线一纯仿真文 | v0.4 主体论文，fixed-roll yaw-pitch 可观测性 benchmark | 主干，等待代码与实验 |
| 路线二 GEO 真实光度文 | 路线一基础上的真实光度锚点升级层 | 优先增强，需真实数据 pilot |
| 路线三暗室真实文 | 暗室缩比保真 + 姿态可控反演闭环 | 条件增强，需暗室 pilot |

推荐总顺序：

```text
旧文解封评估
-> 路线一纯仿真主体论文
-> 路线二 GEO 真实光度升级论文/章节
-> 路线三暗室真实验证论文/章节
-> 硕士大论文整合
```

投稿层级和学校成果认定优先依据：

```text
01_学校认定论文表解读_投稿依据.md
```

## 3. 旧 v0.3 稿件解封评估

旧文不能因“已经写好”而自动恢复投稿。必须先评估以下问题：

| 编号 | 问题 | 判定意义 |
|---|---|---|
| E1 | 旧模块 A face-center OCS 是否影响主结论、OCS-only、fusion、OCS noise、branch masking 与补充实验 | 若影响核心结论，不能原样投稿 |
| E2 | 能否把旧文定位为旧口径 benchmark / technical note，而不与 v0.4 主线混读 | 若可以，可能小修保底 |
| E3 | 是否需要用 v0.4 Blender-derived OCS 重跑替换旧结果 | 若需要，则失去“先保底投”的时间优势 |
| E4 | 目标期刊是否仍适合 Acta/ASR 或更稳健 SCI | 决定是否值得解封 |
| E5 | 与路线一/二/三后续论文是否存在数据重复、自我抄袭或 claim 冲突 | 决定投稿风险 |

旧文评估输出建议：

```text
03_项目说明与规划材料/01_写作规划/04_Codex审阅/R01_Codex_评估_旧v0.3稿件解封与保底投稿.md
```

## 4. 路线一纯仿真文

定位：

```text
model-known 条件下，独立 OCS 多观测光度向量与图像通道的姿态可观测性、互补性和置信一致性研究。
```

必要前提：

- v0.4 Blender-derived OCS 全链路重跑完成。
- phase0 depth / Position / sun shadow / manifest 一致性门控通过。
- G1/G3/G5 多几何证据链完成。
- roll sensitivity 探针完成。
- 反演误差表降级为可观测性验证工具。
- H1-H5 硬补丁已落实。

投稿定位：

- 稳健 SCI：Acta / ASR / Remote Sensing / Aerospace Science and Technology 等。
- 主攻冲刺：若指标、mismatch 和置信一致性闭合充分，可上探 TAES / TGRS / AIAA Journal。

## 5. 路线二 GEO 真实光度文

定位：

```text
GEO 真实光度数据对 v0.4 前向模型与跨几何光度向量现实性的 sim-to-real 锚定。
```

必须守住：

- GEO 数据有光度、有几何、有型号、有时序，但没有三轴姿态真值。
- 只能做光度统计校准、多几何现实性、异常观测下界和 sim-to-real gap。
- 不能写成真实监督姿态反演。

启动前 pilot：

1. 确认某一型号可对到可建模几何。
2. 验证 PRE 表几何反算合理。
3. 验证 DET IPD 光度定标口径能用于分布或趋势对比。
4. 先做单型号小样本校准，再决定是否扩展。

## 6. 路线三暗室真实文

定位：

```text
暗室缩比自洽系统中的点对点前向保真验证与姿态可控监督反演闭环。
```

必须守住：

- 暗室与 GEO 数据库互不连通。
- 暗室通过不能外推为 GEO 在轨目标反演通过。
- 暗室是地面缩比验证，不是真实在轨望远镜验证。
- roll-aware 只作为暗室条件增强腿，不反向要求路线一全量 3-DOF。

启动前 pilot：

1. 一个缩比模型。
2. 少量姿态，至少含 1-2 个 roll 不为 0 的姿态。
3. 同系统仿真 vs 实测光度 sanity check。
4. 小规模真实数据反演闭环。
5. 若缩比 gap 不可解释，则只作为 Discussion / Future Work，不并入主论文主证据。

## 7. 大论文整合建议

硕士大论文建议采用“主干 + 增强腿”的结构：

```text
第 1 章：背景、问题定义与专家质疑转化
第 2 章：相关工作、OCS/光度观测与图像姿态估计
第 3 章：统一前向模型与 v0.4 数据规范
第 4 章：路线一纯仿真可观测性、互补性与置信一致性
第 5 章：roll sensitivity、mismatch 与边界分析
第 6 章：GEO 真实光度锚点 pilot / 完整实验（视进度）
第 7 章：暗室缩比验证 pilot / 完整实验（视进度）
第 8 章：总结、SCI 发刊路线与后续 3-DOF/真实闭环路线
```

如果路线二或路线三 pilot 未通过，不应影响第 3-5 章主干闭合；它们可降级为 Discussion / Future Work。
