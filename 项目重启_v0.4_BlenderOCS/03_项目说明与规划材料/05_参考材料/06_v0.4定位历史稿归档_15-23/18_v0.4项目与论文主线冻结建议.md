## 一、总判断

当前不应急于进入全链路重跑。v0.4 的核心问题已经不只是 OCS 采样口径修正，而是项目与论文定位本身发生了切换：

```text
旧定位：提出一个 OCS + 图像融合姿态反演方法/系统，并证明其仿真精度与鲁棒性。
新定位：在同源、可审计的物理前向模型下，研究 OCS 与图像两种光度读出对姿态信息的可观测性、互补性和置信一致性。
```

这个变化总体是正向的。它牺牲了“做出可部署系统”的气势，但换来了更清楚、更可防守、更像 SCI 论文的科学问题。

对投稿的影响判断：

| 方向 | 判断 |
|---|---|
| SCI 可投性 | 正向。主张更稳，审稿攻击面更小。 |
| 中高水平 SCI | 正向。更容易写成物理建模、信息分析、多模态一致性研究。 |
| 一区/强刊冲刺 | 有条件正向。必须把 observability / confidence 指标做实。 |
| TAES / JGCD 类强系统期刊 | 可能变弱。它们更期待 estimation system 与高保真或真实验证。 |
| Nature / Science 级顶刊 | 目前不现实，除非后续出现真实观测验证或更普适的理论突破。 |

## 二、建议冻结的新项目定位

建议将项目定位冻结为：

```text
面向几何已知或近似已知的非合作航天器，建立 OCS 与光学图像同源的可审计物理前向模型，
系统研究积分光度读出与空间分布图像读出在姿态信息表达、可观测性、互补性和置信一致性中的作用边界。
```

更短版本：

```text
不是做真实未知目标姿态反演系统，
而是做 OCS/image 双读出的姿态信息可观测性与置信评估框架。
```

适用对象应限定为：

```text
non-cooperative but model-known target
```

即目标不通信、不主动配合、无合作标志器，但几何模型、候选几何模型或近似结构模型已知。

可接受场景包括：

- 己方失效卫星。
- 已知型号或结构公开的航天器。
- 有设计资料或历史模型的目标。
- 实验室缩比模型。
- 由其他传感器或先验重建得到近似几何的目标。

不应声称覆盖：

- 完全未知几何、未知材料、无先验类别的任意空间目标。
- 真实外场可部署姿态反演系统。
- 仿真 OCS 与真实 OCS 的绝对值直接匹配。

## 三、建议冻结的新论文主线

英文主线：

```text
OCS and optical images are two readouts of the same physically consistent forward model:
OCS is an integrated photometric readout, while images are spatially resolved photometric readouts.
This paper studies what attitude information each readout carries, where they are ambiguous or complementary,
and whether their consistency can indicate confidence under controlled model-known conditions.
```

中文主线：

```text
OCS 与图像是同一物理前向模型下的两种光度读出：
OCS 是积分读出，图像是空间分布读出。
本文研究二者在 model-known 受控条件下分别携带什么姿态信息、在哪些观测几何下混淆或互补，
以及跨模态一致性是否可以作为置信判据。
```

一句话投稿定位：

```text
本研究不声称解决真实未知航天器姿态反演，而是在同源、可审计的物理前向模型下，
研究积分光度 OCS 与空间图像两类读出对姿态信息的可观测性、互补性和置信一致性，
为 model-known 非合作目标的观测规划与可信姿态估计提供基础。
```

## 四、核心科学问题

论文应围绕三个问题展开，而不是围绕单一误差表展开。

### 4.1 What can be known?

在已知几何和名义材料条件下，OCS 与图像分别对姿态有多少可区分信息？

对应结果形态：

- OCS-only 可观测性地图。
- image-only 可观测性地图。
- 姿态混淆图。
- pairwise distance / nearest-neighbor ambiguity / top-k confusion。

### 4.2 When are they complementary?

哪些姿态或观测几何下 OCS 有效，哪些地方图像有效，哪些地方二者互补或共同失效？

对应结果形态：

- OCS/image 错误或混淆互补图。
- top-k candidate overlap。
- branch masking / OCS noise monotonicity。
- fusion 机制诊断，但 fusion 不是论文的唯一终点。

### 4.3 When should we trust the estimate?

OCS 与图像的候选姿态是否一致，能不能作为置信度或拒识依据？

对应结果形态：

- OCS-image posterior-like distribution agreement。
- JS divergence / top-k overlap / margin。
- consistency vs error 曲线。
- ECE / reliability diagram。
- 可选：conformal prediction 拒识机制。

## 五、贡献点建议

建议贡献点按以下顺序组织。

1. 建立 OCS 与图像同源的统一物理前向模型，将 OCS 定义为 integrated photometric readout，将图像定义为 spatially resolved photometric readout，避免旧流程中 OCS 与图像采样口径不一致。
2. 构建姿态空间和观测几何空间中的 OCS/image 可观测性与混淆性分析框架，回答二者分别在何处携带有效姿态信息。
3. 定量研究 OCS 与图像的互补性和 fusion 机制，区分真正互补、单模态主导和退化继承。
4. 提出 OCS-image consistency-as-confidence 思路，验证跨模态一致性是否能提示高置信、低置信和冲突样本。
5. 通过材料、几何、观测链和 phase mismatch 试验，明确该框架在何种假设下有效、何种条件下失效。

注意：贡献点 1 是地基，贡献点 2 和 4 是论文的科学核心，贡献点 3 和 5 是支撑与边界，不宜喧宾夺主。

## 六、结果形态必须从误差表升级

v0.4 主结果不应再以 mean error / Hit@5 / worst-case 为唯一中心。它们可以保留，但角色应降级为信息验证工具。

主结果建议包括：

| 结果类型 | 目的 |
|---|---|
| OCS-only / image-only 可观测性地图 | 展示两种读出分别在哪里有姿态信息 |
| 姿态混淆图 | 找出天然不可区分姿态 |
| 观测几何信息量地图 | 支撑最优观测窗口 / observation planning |
| OCS-image top-k overlap / disagreement map | 展示互补与冲突区域 |
| consistency vs error 曲线 | 支撑 consistency-as-confidence |
| mismatch 边界图 | 说明材料、几何、观测链和 phase 偏差下何处失效 |
| 反演误差表 | 作为验证工具，而不是应用终点 |

## 七、方法学冻结前的待定项

17 号文件中提出的 FIM / CRLB / D-optimality / conformal prediction 方向有价值，但不能直接作为已闭合方法写入代码主线。进入反演与补充实验代码前，需要另行冻结一份“信息量与置信指标实现规范”。

### 7.1 FIM / CRLB 的谨慎处理

当前前向模型包含 visibility、shadow mask、边缘像素和 GGX 镜面峰，对 yaw/pitch 未必处处光滑。因此：

- 不建议一开始就把 FIM / CRLB 写成唯一硬理论主轴。
- 可先写为 Fisher-like local sensitivity / local observability score。
- 若实现中证明数值梯度稳定，再升级为 FIM / D-optimality。

### 7.2 posterior 的定义必须补齐

confidence / JS divergence / entropy / ECE 都依赖某种候选姿态分布。若模型是角度回归，天然没有 posterior。

进入训练代码前必须确定：

- posterior-like score 来自网格分类 softmax，还是 kNN likelihood，还是距离归一化分布。
- OCS 和 image 是否输出同一姿态网格上的候选分布。
- top-k、entropy、JS divergence、margin 的计算口径。

### 7.3 最小指标集建议

在 FIM 完全落地前，建议先冻结一组更稳的离散指标：

```text
pairwise signature distance
nearest-neighbor ambiguity
top-k confusion
posterior-like entropy
top-k overlap between OCS and image
JS divergence between OCS/image candidate distributions
consistency-error correlation
```

FIM / D-optimality 可作为增强项，不作为 phase 0 代码实施前置阻断。

## 八、重跑必须服务的新指标

v0.4 代码与 manifest 设计必须确保后续能计算上述信息量与置信指标。因此重跑时除保存传统 summary 外，还应尽量保存以下中间量：

- 每个姿态的 OCS total / per-part / multi-geom features。
- 每个姿态的 clean image linear response 与 log1p PNG。
- 姿态 record_id、yaw、pitch、geom_id、sun_dir、det_dir。
- OCS-only 模型的候选姿态分数或 posterior-like distribution。
- image-only 模型的候选姿态分数或 posterior-like distribution。
- fusion 模型的候选姿态分数或 posterior-like distribution。
- top-k candidates。
- per-attitude error。
- branch masking / OCS noise / modality attribution 相关输出。

如果训练代码只输出 mean error 和 model_best.pt，后续新论文主线会缺证据。因此重跑前必须把“保存候选分布和 per-attitude 结果”列为训练阶段要求。

## 九、投稿策略判断

这次改定位对投稿总体是正向作用。

### 9.1 正向作用

1. 更容易通过审稿人的逻辑审查。新定位主动避开“无真实望远镜、无真实材料、无真实定标却声称真实反演”的致命问题。
2. 更像 SCI 论文，而不是工程报告。新线关注可观测性、信息量、互补性和置信一致性。
3. 可选期刊变宽。论文可以往遥感、光学、传感、信息融合方向靠，而不仅限航天工程。

### 9.2 负向作用

1. 对强 estimation/system 期刊可能变弱，例如 TAES / JGCD 这类更期待完整系统、高保真或真实验证的方向。
2. 如果只停留在“画热图 + 说信息量”，会被认为方法学不够硬。
3. 新定位对指标定义要求更高，不能只靠误差表支撑。

### 9.3 现实投稿分层

| 档位 | 方向 | 判断 |
|---|---|---|
| 冲刺 | IEEE TGRS / Optics Express / 高水平遥感光学期刊 | 有机会，但要求 observability / confidence 方法非常扎实 |
| 主投稳健 | Aerospace Science and Technology / Acta Astronautica / ASR / Remote Sensing | 更现实，适合物理建模 + 信息分析 + 航天应用背景 |
| 保底 SCI | Sensors / Applied Sciences 类或更应用型期刊 | 可投性较高，但不建议一开始就降到这里 |

本文不建议当前阶段把 Nature / Science 级别作为现实目标。若未来有真实观测验证或普适理论突破，可重新评估。

建议冻结如下判断：

```text

v0.4 的主线是：在同源、可审计的物理前向模型下，
```

```text
未明确新论文主线与信息量/置信指标前，不启动全链路重跑。
重跑不是为了重新得到一张更好看的误差表，
```

```text
该定位对 SCI 投稿总体正向，对一区或强刊冲刺有条件正向；
```
