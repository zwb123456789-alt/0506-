## 一、最终冻结结论

### 1.1 项目主线

v0.4 不再以“真实未知非合作目标姿态反演系统”为主线。

v0.4 的项目主线冻结为：

```text
面向几何已知或近似已知的非合作航天器，
建立 OCS 独立光度通道与光学图像通道共享同一物理前向模型的可审计仿真框架，
系统研究积分光度读出与空间分布图像读出在姿态信息表达、
可观测性、互补性和置信一致性中的作用边界。
```

短版本：

```text
不是做真实未知目标姿态反演系统，
而是做 model-known 条件下 OCS/image 双观测通道的姿态信息可观测性与置信评估框架。
```

### 1.2 论文主线

英文主线：

```text
OCS and optical images are two observation channels generated from the same physically consistent forward model:
OCS is treated as an independent integrated photometric channel, while images are spatially resolved optical observations.
This paper studies what attitude information each channel carries,
where they are ambiguous or complementary,
and whether cross-channel consistency can indicate confidence under controlled model-known conditions.
```

中文主线：

```text
OCS 与图像是同一物理前向模型下的两类观测通道：
OCS 被定义为独立积分光度通道，图像为空间分辨成像通道。
本文研究二者在 model-known 受控条件下分别携带什么姿态信息、
在哪些观测几何下混淆或互补，
以及跨通道一致性是否可以作为置信判据。
```

### 1.3 关键修正：OCS 不是默认图像导出量

本文吸收 18 号文件的定义级决策：

```text
当前主线中的 OCS 采用口径 A：
OCS = 独立非成像光度通道 / independent photometric channel。

图像采用成像通道。
二者共享目标几何、姿态、sun/det 几何、BRDF 和物理前向模型，
但不共享图像退化链路。
```

这意味着：

- OCS 对图像退化的免疫性只在 independent photometric channel 假设下成立。
- OCS-image consistency 作为置信信号，只在两条通道退化源相对独立时有独立印证意义。
- 如果 OCS 是从同一张退化图像中孔径测光导出的 image-derived OCS，则会出现共模误差，一致性可能只是共同失败。

因此，后续论文必须显式写明：

```text
under an independent photometric channel assumption
```

不能让该假设隐式存在。

## 二、旧定位为什么不再成立

旧 v0.3 定位大致是：

```text
提出一种 OCS + 图像融合的非合作目标姿态反演方法，
并在受控仿真中证明其精度和鲁棒性。
```

该定位有三类根本风险。

### 2.1 任意未知非合作目标没有目标专属前向表

OCS lookup / OCS-image fusion 依赖：

```text
目标几何 + 材料/BRDF + 太阳/观测方向 + 姿态 -> OCS signature
```

如果目标几何未知，就无法生成目标专属 OCS 查找表。目标姿态、几何形状、尺度、材料反射特性和观测链增益会共同影响亮度与图像，单独从 OCS 或图像中反演姿态是欠定问题。

### 2.2 仿真 OCS 与真实 OCS 不能默认绝对匹配

即使有 STL，真实 OCS 也不能默认等于仿真 OCS。偏差来源包括：

- 材料/BRDF 参数未知。
- 名义 STL 与真实在轨结构不一致。
- 观测链增益、曝光、背景、PSF、定标误差未知。
- 姿态、轨道、太阳和观测几何可能有误差。

因此不能写：

```text
真实观测 OCS 可以直接与仿真 OCS 查找表匹配，从而得到可靠姿态。
```

### 2.3 旧 OCS 与图像不是同源口径

旧 v0.3 中 OCS 来自模块 A face-level / face-center 扫描，图像来自 Blender pixel-level geometry/pass。二者采样口径不统一，影响 OCS-only、fusion、OCS noise、branch masking、12b/12c/12f/12g 等结果。

因此旧 v0.3 数字不能作为 v0.4 主结果，只能作为历史证据、机制假设和代码结构参考。

## 三、适用对象与边界

### 3.1 适用对象

论文中的非合作目标限定为：

```text
non-cooperative but model-known target
```

含义：

- 目标不通信。
- 目标不主动配合。
- 没有人工标志器或合作信标。
- 但目标几何模型、候选几何模型或近似结构模型已知。

可接受场景：

- 己方失效卫星。
- 已知型号或结构公开的航天器。
- 有设计资料或历史模型的目标。
- 实验室缩比模型。
- 由其他传感器或先验重建得到近似几何的目标。

不可接受场景：

- 完全未知几何、未知材料、无先验类别的任意空间目标。
- 真实外场可部署姿态反演系统。
- 仿真 OCS 与真实 OCS 的绝对值直接匹配。

### 3.2 OCS 口径边界

主线口径：

```text
OCS = independent non-imaging photometric channel。
```

对照口径：

```text
image-derived OCS = 从同一成像图像做孔径测光、背景扣除、积分得到的光度量。
```

主线只在口径 A 下写“OCS 对图像退化免疫”和“跨通道一致性可作为置信信号”。

口径 B 必须作为边界讨论或对照实验：

```text
当 OCS 从退化图像中导出时，OCS 与 image 共享退化源，
一致性可能来自 common-mode error，而非独立印证。
```

## 四、核心科学问题

论文围绕三个科学问题展开。

### 4.1 What can be known?

在已知几何和名义材料条件下，独立 OCS 光度通道与图像通道分别对姿态有多少可区分信息？

对应结果：

- OCS-only 可观测性地图。
- image-only 可观测性地图。
- 姿态混淆图。
- pairwise distance。
- nearest-neighbor ambiguity。
- top-k confusion。
- posterior-like entropy。

### 4.2 When are they complementary?

哪些姿态或观测几何下 OCS 有效，哪些地方图像有效，哪些地方二者互补或共同失效？

对应结果：

- OCS/image 错误互补图。
- OCS/image 混淆互补图。
- top-k candidate overlap。
- OCS-image disagreement map。
- branch masking。
- OCS noise monotonicity。
- modality attribution。

### 4.3 When should we trust the estimate?

OCS 与图像的候选姿态是否一致，能否作为置信度或拒识依据？

对应结果：

- OCS-image posterior-like distribution agreement。
- JS divergence。
- top-k overlap。
- top1-top2 margin。
- consistency vs error 曲线。
- ECE / reliability diagram。
- 可选 conformal prediction 拒识机制。
- image-derived OCS 对照下的 common-mode failure 分析。

## 五、贡献点冻结

建议贡献点按以下顺序组织。

1. 建立 OCS 独立光度通道与图像成像通道共享同一物理前向模型的可审计仿真框架，避免旧流程中 OCS 与图像采样口径不一致。
2. 将 OCS 定义为 independent integrated photometric channel，将图像定义为 spatially resolved imaging channel，明确二者共享物理前向模型但不共享图像退化链路。
3. 构建姿态空间和观测几何空间中的 OCS/image 可观测性与混淆性分析框架，回答二者分别在何处携带有效姿态信息。
4. 定量研究 OCS 与图像的互补性和 fusion 机制，区分真正互补、单模态主导和退化继承。
5. 提出 OCS-image consistency-as-confidence 思路，验证跨通道一致性是否能提示高置信、低置信和冲突样本。
6. 通过 image-derived OCS 对照和 mismatch 试验，明确共模退化、材料、几何、观测链和 phase 偏差下该框架何时失效。

贡献点主次：

```text
贡献点 1-2 是定义地基。
贡献点 3 和 5 是科学核心。
贡献点 4 和 6 是机制支撑与边界，不宜喧宾夺主。
```

## 七、OCS 口径对照实验建议

### 7.1 主线数据：口径 A

主线采用：

```text
OCS_A = independent photometric channel
image = imaging channel
```

仿真上对应：

- OCS 由统一前向模型的解析/像素积分得到。
- 图像由同一物理前向模型下的空间分布响应得到。
- 二者共享几何、姿态、sun/det、BRDF、visibility 定义。
- 图像退化只施加在 image channel，不污染 OCS_A。

写作限定：

```text
OCS robustness to image degradation is evaluated under an independent photometric channel assumption.
```

### 7.2 对照数据：口径 B

对照采用：

```text
OCS_B = image-derived photometry
```

即从退化后的图像中做孔径测光、背景扣除和积分，得到 image-derived OCS。

该对照用于回答：

- 图像退化是否会污染 image-derived OCS。
- OCS_B 与 image 的错误是否相关。
- 口径 B 下 consistency 指标是否失去鉴别力。
- common-mode error 下“一致”是否可能意味着共同失败。

该对照不是主线削弱，而是 consistency-as-confidence 的边界证明。

## 八、方法学待冻结项

进入训练与反演代码前，需要另行冻结“信息量与置信指标实现规范”。

### 8.1 可观测性指标

优先采用离散姿态网格上的稳健指标：

```text
pairwise signature distance
nearest-neighbor ambiguity
top-k confusion
posterior-like entropy
```

FIM / CRLB 的处理：

- 先写为 Fisher-like local sensitivity / local observability score。
- 不把 FIM / CRLB 写成唯一硬理论主轴。
- 若数值梯度在 visibility、shadow mask、边缘像素、GGX 镜面峰附近稳定，再升级为 FIM / D-optimality。

### 8.2 posterior-like distribution 必须定义

confidence / JS divergence / entropy / ECE 都依赖候选姿态分布。若模型是角度回归，天然没有 posterior。

进入训练代码前必须确定：

- posterior-like score 来自网格分类 softmax，还是 kNN likelihood，还是距离归一化分布。
- OCS 和 image 是否输出同一姿态网格上的候选分布。
- top-k、entropy、JS divergence、margin 的计算口径。

### 8.3 consistency-as-confidence 指标

建议最小指标集：

```text
H_img        = image posterior-like entropy
H_ocs        = OCS posterior-like entropy
H_fusion     = fusion posterior-like entropy
M_img        = top1-top2 margin of image branch
M_ocs        = top1-top2 margin of OCS branch
Overlap_k    = top-k candidate overlap between image and OCS
JS_img_ocs   = Jensen-Shannon divergence between image and OCS distributions
Conf_consist = function(M_img, M_ocs, Overlap_k, -JS_img_ocs)
```

解释方式：

- image 与 OCS 高一致且候选分布集中：高置信。
- image 高置信、OCS 低置信：可能是图像主导，需检查 OCS 是否本身不可观测。
- OCS 高置信、image 低置信：可能是图像退化或空间结构弱。
- image 与 OCS 高冲突：不应强行输出姿态，应标记低置信或模型失配。
- image-derived OCS 与 image 高一致：需额外检查是否为 common-mode failure，不可直接判高置信。

## 九、重跑必须服务的新指标

v0.4 代码与 manifest 设计必须确保后续能计算信息量、互补性和置信指标。因此重跑时除传统 summary 外，应保存以下中间量：

- 每个姿态的 OCS total / per-part / multi-geom features。
- 每个姿态的 clean image linear response 与 log1p PNG。
- 姿态 record_id、yaw、pitch、geom_id、sun_dir、det_dir。
- OCS-only 模型的候选姿态分数或 posterior-like distribution。
- image-only 模型的候选姿态分数或 posterior-like distribution。
- fusion 模型的候选姿态分数或 posterior-like distribution。
- top-k candidates。
- per-attitude error。
- branch masking 输出。
- OCS noise monotonicity 输出。
- modality attribution 输出。
- image-derived OCS_B 及其退化条件、测光参数和背景扣除参数。

如果训练代码只输出 mean error 和 model_best.pt，v0.4 新论文主线会缺证据。因此训练阶段必须要求保存候选分布、per-attitude 结果和口径 A/B 可追踪字段。

## 十二、写作红线

后续论文、汇报和答辩必须遵守：

1. 不写“任意未知非合作目标姿态反演”。
2. 不写“真实 OCS 与仿真 OCS 可直接绝对匹配”。
3. 不写“真实图像 + 仿真 OCS 可直接部署反演”。
4. 不写 field-proven、operational-ready、fully robust。
5. 不把合成实验写成真实望远镜验证。
6. 不把名义材料参数写成真实材料参数。
7. 不把反演误差写成外场性能。
8. 不隐瞒 phase 外推、BRDF mismatch、STL mismatch 和 severe degradation 下的失败边界。
9. 不把旧 v0.3 数字写成 v0.4 主结果。
10. 不把 FIM / CRLB / conformal prediction 写成已经闭合的强理论结果，除非后续实现和验证支撑。
11. 不隐式使用 independent photometric channel 假设；凡写 OCS 对图像退化免疫，必须标注 under independent photometric channel assumption。
12. 不在 image-derived OCS 口径下声称 OCS 免疫图像退化。
13. 不在共模退化场景下把 OCS 与 image 一致直接解释为高置信。
14. 不混用口径 A 与口径 B 的结论。

允许写：

1. known-geometry / model-known non-cooperative target。
2. idealized but physically consistent synthetic forward model。
3. independent photometric channel assumption。
4. OCS-image information complementarity。
5. attitude observability under controlled observation geometry。
6. confidence-aware cross-channel consistency analysis。
7. image-derived OCS as a common-mode failure boundary。
