论文主线：

> Unified BRDF-driven OCS and photometric image simulation enables a controlled benchmark for space object attitude inversion. Clean synthetic images provide an upper-bound case where strong CNNs achieve high accuracy, whereas OCS provides an interpretable, low-dimensional photometric constraint with different failure modes from resolved images. Multi-modal fusion is architecture- and training-dependent: naive feature-level fusion can become image-dominant and fail under image degradation, while degradation-aware training can form coupled OCS-image co-utilization under tested synthetic degradations, subject to explicit failure boundaries and no real-telescope validation claim.

## 3. 当前可用核心证据

物理建模链条：

- 真实卫星 STL 几何
- 非均匀材料分区
- GGX/Cook-Torrance BRDF
- 解析射线自遮挡
- 多观测几何 OCS 扫描
- 光度图像渲染
- yaw-pitch 姿态反演，fixed roll
- OCS-only / image-only / late fusion / feature fusion

核心结果：

- ResNet image-only clean：1.69 ± 0.07 deg, Hit@5 = 97.6%
- ResNet + concat5 per_part_log：1.47 ± 0.07 deg
- worst-case：9.9 deg -> 6.6 deg
- 1% Gaussian image noise：ResNet 退化到 85.85 deg, Hit@5 = 2.2%
- ResNet-fusion 图像退化鲁棒性（实验11）：clean 1.47 ± 0.07 deg；noise σ=0.01 退化到 73.36 ± 5.07 deg，Hit@5 = 2.8%；noise σ=0.10 为 73.57 ± 4.33 deg，Hit@5 = 3.3%
- 实验12 naive fusion 分支诊断：clean normal 1.57 deg；clean image-masked 52.84 deg；clean OCS-masked 18.14 deg；noise σ=0.01 normal 75.08 deg；noise image-masked 52.84 deg；noise OCS-masked 88.88 deg
- 实验12 U1 图像退化增强 fusion：clean 1.95 ± 0.21 deg, Hit@5 = 97.8%, p90 = 3.53 deg；noise σ=0.01 1.95 ± 0.21 deg, Hit@5 = 97.8%；noise σ=0.10 2.31 ± 0.26 deg, Hit@5 = 96.6%, p90 = 3.73 deg；但 worst-case 仍有 100 deg 以上离群点
- 实验12b image-only same augmentation 对照：noise σ=0.10 下 image-only+aug 9.55 deg, Hit@5 = 41.4%，U1 augmented fusion 2.31 deg, Hit@5 = 96.6%；说明 U1 不能由图像增强单独解释
- 实验12b U1 分支遮蔽：noise σ=0.10 normal 2.31 deg；image_train_mean 30.87 deg；ocs_train_mean 58.56 deg；说明 OCS 在 U1 joint representation 中活跃，但遮蔽图像后远高于 OCS-only 5.91 deg，不能写成 OCS-standalone fallback
- 实验12b U1 OCS 噪声：OCS 0% -> 20% 时，clean 1.95 -> 5.36 deg，noise σ=0.10 2.31 -> 5.95 deg；支持 OCS active joint constraint，但不支持图像失效后离散切换到 OCS
- 实验12b 未见退化：U1 在 noise σ=0.03/0.05、blur、downsample 下保持约1.96-2.06 deg，image-only+aug 为2.84-6.43 deg；说明 U1 对未见合成退化也更稳，但不等于真实望远镜验证
- 实验12b rare outliers：49,950 次评估中 error>30 deg 为42条（0.084%），50% 位于 |pitch|>75 deg；只能写 mean/p90/Hit@5 稳定，不能写 fully robust
- 实验12c-12g 投稿前非真实数据补实验总包：12c 合成 observation-style 退化下 U1 在 read/background/starfield/combined_medium 保持约2 deg，但 combined_severe 退至13.88 deg；12d phase120 下 image-only/fusion 均约80 deg；12e 居中后 ResNet image-only 1.69 -> 2.88 deg；12f 噪声下 oracle best beta=0 回到 OCS 端6.58 deg；12g 确认 rare outliers 为42/49,950（0.084%）
- OCS MLP per_part_log：5.91 deg，实用 OCS-only 结果
- OCS MLP all_raw 45D：3.98 ± 0.60 deg, Hit@5 = 90.7%，只能写成 semi-oracle 上界
- TinyCNN image-only：12.38 ± 0.74 deg, Hit@5 = 26.1%，只能作为轻量 CNN baseline
- Early feature fusion per_part_log：4.10 ± 0.77 deg, Hit@5 = 87.3%
- OCS-CNN 误差相关性 r = 0.003
- OCS-noise fusion gain 从 +1.97 deg 增至 +6.29 deg，随 OCS noise 0% 到 20% 增加
- 新主线证据：当前 clean-trained feature fusion 呈图像主导，图像噪声下不会自动回退到干净 OCS；实验12证明退化图像会污染融合输出，OCS 仍有缓冲作用但 naive fusion head 未学会 OCS-standalone fallback；实验12b证明 U1 的鲁棒性不能由 image-only same augmentation 完全解释，OCS 在 U1 联合表示中是活跃约束，但 U1 仍不是 OCS-standalone fallback，而是 OCS-image co-utilization

重要边界：

- 没有真实光学望远镜图像验证
- clean rendered images 是 idealized photometric imagery
- 真实 atmosphere、detector response、PSF、earthshine、background contamination 未由真实仪器链验证；12c 仅为 observation-chain-inspired synthetic degradation stress test
- 当前任务估计 yaw-pitch，roll 固定
- 图像主分支主要基于 phase63
- 材料参数为 nominal
- ISAR 数据不进入本文主线，只能作为 Future Work 或 modality boundary

## 5. 双模型工作流

### Step A：Codex 生成两套指导文件

同一阶段分别生成：

- GPT 交互提示词：适合多轮问答、路线对比、风险等级标注。
- Claude 指导文件：适合一次性完整执行、结构严格、输出格式固定。

两者共享证据边界，但提示风格可以不同。

### Step B：作者分别发给 GPT 和 Claude

作者把对应文件发给对应模型：

- 初稿生成阶段已归档：GPT 使用 `01_初稿生成与整合/GPT交互/` 文件，Claude 使用 `01_初稿生成与整合/Claude交互/` 文件。
- 当前后整合阶段：GPT 使用 `02_后整合双线修订/GPT交互/` 文件，Claude 使用 `02_后整合双线修订/Claude交互/` 文件。

输出建议命名：

```text
02_后整合双线修订/GPT交互/GPT输出/01_GPT输出_作者确认与数值审计.md
02_后整合双线修订/Claude交互/Claude输出/01_Claude输出_作者确认与数值审计.md
```

### Step C：作者返回任意一边输出给 Codex

作者可以一次只返回 GPT 或 Claude 的输出，也可以两边都返回。Codex 不要求两边同时完成。

示例：

```text
这是 Claude 的 Step 1 输出：<粘贴或文件路径>
请按它的输出给修改意见，或判断是否可以进入 Claude Step 2。
```

Codex 应：

1. 只审阅当前返回的这一边输出。
2. 标记红线问题、证据不足、过度承诺和需要降调的表述。
3. 给出该模型下一轮返修意见，或确认该模型可以进入下一阶段。
4. 必要时生成返修提示词给当前模型。
5. 初稿阶段单边审阅记录保存在 `01_初稿生成与整合/对比评分/`；后整合阶段单边审阅记录保存到 `02_后整合双线修订/Codex审阅/`。
6. 更新本总控文件的阶段状态。

### Step D：阶段内不做胜负判断

在完整初稿完成前，Codex 不判断 GPT 和 Claude 哪一边更优，也不强制整合两边。

阶段内只做两类动作：

- 对当前模型输出提出修改意见。
- 如果当前阶段质量达标，为当前模型生成下一阶段指导文件。

`01_初稿生成与整合/对比评分/` 中的评分表只在最终两边初稿都完成后使用，用于最终选择、混合和定稿。后整合阶段不再重复初稿胜负判断，只评估当前任务输出能否改进主稿。

### Step E：最终完整初稿完成后再对比

当 GPT 和 Claude 都完成至少一版完整初稿后，Codex 才进行正式对比评分。

可选最终策略：

- 以 GPT 初稿为主，吸收 Claude 的局部表达。
- 以 Claude 初稿为主，吸收 GPT 的局部表达。
- GPT 负责结构，Claude 负责语言润色。

## 6. 双模型写作红线

两边都必须遵守：

0. 禁止编造实验结果、引用文献、方法细节、模型配置、期刊要求或任何作者尚未确认的事实。
1. 不发明实验结果。
2. 不发明引用。
3. 不把 clean image 结果写成真实场景性能。
4. 不写 fusion 永远最优。
5. 不写 OCS 永远强于图像。
6. 不宣称真实光学数据已验证。
7. 不把 ISAR 并入论文主线。
8. 不使用 state-of-the-art、first、novel 等过度承诺词，除非作者后来提供严格证据。
9. 所有结论必须能映射到已有证据。
10. 不写 OCS 会自动托住任何融合模型；实验12表明 naive fusion head 未学会 OCS-standalone fallback。实验12b支持 U1 优于 image-only same augmentation 且 OCS 在 U1 joint representation 中活跃，但不能写成 OCS-standalone fallback 或自动切换式 fallback。
11. 不写 U1 为 near-perfect / fully robust；U1 仍有 rare large outliers，worst-case 需进补充或限制说明。
12. 12b 后推荐写法是 OCS-image co-utilization / active joint constraint，不写 image masking 后接近 OCS-only，不写真实望远镜泛化已验证。
13. 12c 只能写成 observation-chain-inspired synthetic degradation stress test，不得写成 real telescope validation；IEEE TAES / JGCD 只作为高风险冲刺预筛，不得写成当前证据已充分支撑。
14. 三档投稿不并行写作；12c-12g 补实验总包经 Codex 审阅后，只能先生成 Acta Astronautica / Advances in Space Research 主投优先版。CJA/AST 与 TAES/JGCD 写作必须等待作者确认第一档完结。
