## 1. 当前三档策略

```text
主投优先：Acta Astronautica / Advances in Space Research
冲刺优先：Chinese Journal of Aeronautics / Aerospace Science and Technology
高风险冲刺：IEEE TAES / JGCD
```

当前论文不应继续按“泛候选期刊”处理。三档路线的区别不是期刊名字不同，而是证据门槛和叙事重心不同。

Optics Express 和 Remote Sensing 暂不作为主路线。它们不是不能投，而是会把审稿压力转向“光学系统创新”或“遥感实测/应用验证”，与当前仿真基准主线不完全同心。

执行顺序已经锁定：

```text
投稿前非真实数据实验12c-12g已完成
-> Codex 已完成 07c 技术审阅
-> 只写第一档 Acta Astronautica / Advances in Space Research 主投优先版
-> v0.2 工作稿已生成：论文写作/03_投稿定稿/manuscript_md/主稿_v0.2_Acta_ASR主投优先版.md
-> 作者确认第一档完结
-> 再决定是否进入 CJA/AST 或 TAES/JGCD 写作
```

因此，三档策略是投稿路线储备，不是并行写作计划。

## 2. 主投优先：Acta Astronautica / ASR

| 期刊 | 角色 | 叙事重点 |
|---|---|---|
| Acta Astronautica | 主投优先 | 空间目标姿态反演、光变/OCS、digital-twin-like controlled benchmark、融合机制诊断 |
| Advances in Space Research | 主投优先/备选保底 | SSA、空间碎片/空间目标光学表征、光度反演、受控仿真研究接受面 |

主稿写法：

- 标题突出 BRDF-driven OCS and photometric image simulation。
- Abstract 强调 physically consistent simulation and controlled inversion benchmark。
- Results 主线为 clean-image upper bound -> degradation fragility -> OCS robustness -> conditional fusion -> 12b/12c-12g synthetic stress tests。
- Discussion 明确 no real optical telescope validation。
- 12c-12g 结果可增强主文审稿防御；12c/12d/12f 可压缩进入 Results，12e/12g 优先进入 Supplementary 和 Limitations。

适合写入的贡献：

```text
The study provides a controlled simulation benchmark for paired OCS and photometric image attitude inversion under shared geometry, BRDF, attitude, and self-occlusion assumptions.
```

不能写：

```text
operationally validated telescope performance
```

## 3. 冲刺优先：CJA / Aerospace Science and Technology

| 期刊 | 角色 | 前提 |
|---|---|---|
| Chinese Journal of Aeronautics | 冲刺优先 | 第一档完成后再评估；12c 支持 U1 相对 clean-trained image-only 更稳，但 U2/obs-aug 不强 |
| Aerospace Science and Technology | 冲刺优先 | 第一档完成后再评估；可强调合成传感器退化压力测试，但不能写真实观测验证 |

主稿写法需要比 Acta/ASR 更强调：

- 工程问题：地基光学观测质量不稳定导致图像姿态反演脆弱。
- 观测链：PSF/defocus、photon/read noise、background contamination、saturation/clipping、low resolution。
- 模型机制：退化感知训练与 OCS-image co-utilization，而非自动 fallback。
- 工程边界：仍是 synthetic observation-style stress test，不是 field validation。

补实验总包已显示 U1 在多类合成 observation-style 退化下优于 clean-trained image-only，但 combined_severe 与 phase120 仍是失败/边界案例。因此，后续冲刺写作若启动，只能谨慎强化：

```text
Observation-chain-inspired stress tests further indicate that degradation-aware OCS-image fusion can retain stable mean and tail errors under moderate sensor-like image degradations.
```

如果后续冲刺写作需要更工程化表述，仍必须保留降调句：

```text
The observation-style tests reveal remaining sensitivity and motivate explicit sensor-aware training as future work.
```

## 4. 高风险冲刺：IEEE TAES / JGCD

| 期刊 | 角色 | 高风险原因 |
|---|---|---|
| IEEE Transactions on Aerospace and Electronic Systems | 高风险冲刺 | 通常更重视 aerospace/electronic systems、估计系统、传感器融合、可靠性与工程验证 |
| Journal of Guidance, Control, and Dynamics | 高风险冲刺 | 更重视制导、导航、控制、估计理论或任务级动态系统，当前 yaw-pitch 静态反演主线偏弱 |

这一档不是当前最稳路线。当前 12c-12g 尚未满足高风险冲刺所需的系统级证据；若未来要冲，需要至少补足：

1. 更强的可部署自适应加权或门控，而不是 12f 的 oracle beta 上界。
2. 论文叙事从“仿真基准”进一步强化为“degradation-aware estimation and sensor-fusion benchmark”。
3. Methods 中必须更严格地说明 split、target encoding、uncertainty/failure modes 和可复现实验协议。
4. Discussion 中承认没有动态跟踪、没有闭环滤波、没有真实观测数据，避免被 JGCD/TAES 审稿人抓成致命外推。

当前不建议为了高风险冲刺而强行改写核心结论。由于 U2/obs-aug 不强、combined_severe 与 phase120 仍是失败案例，高风险档应作为远期或大修后目标。

更严格地说：在第一档主投优先版完成并经作者确认前，不启动 TAES/JGCD 文本写作。当前论文无真实观测数据、无动态跟踪、无闭环滤波、无 3-DOF 完整估计，不能按 TAES/JGCD 的系统/控制叙事强行包装。

## 5. 投稿前补实验总包

本轮已补齐除真实数据相关外、且不改变当前论文主线的投稿前实验：

| 编号 | 实验 | 作用 |
|---|---|
| 12c | Observation-style image degradation stress test |
| 12d | Cross-phase image generalization sanity test |
| 12e | Centered-image / centroid-control experiment |
| 12f | Late-fusion beta sweep under image degradation |
| 12g | U1 / 12b outlier gallery and audit package |

Codex 07c 审阅结论：通过，可进入第一档 Acta/ASR v0.2 审慎整合；不得写成真实望远镜验证、自动 OCS fallback、fully robust 或 operational robustness。

暂不做：

| 项目 | 原因 |
|---|---|
| 真实望远镜数据 / 半实测 / 硬件回路 | 属真实数据或硬件验证，不进入本轮 |
| 全 3-DOF roll 扩展 | 会改变本文 yaw-pitch benchmark 范围，作为远期工作 |
| 控制闭环 / 动态滤波 | 属 TAES/JGCD 高风险档新论文范围 |
| 更大 backbone / SOTA 卷模型 | 不符合本文受控 benchmark 主线 |

## 6. 补实验结果对投稿路线的判定

| 已得结果 | 投稿影响 |
|---|---|
| 12c 中 U1 在 read/background/starfield/combined_medium 下约 2 deg，但 combined_severe 为 13.88 deg | 第一档主投版更强；必须保留 conditional robustness 与 severe failure boundary |
| 12d phase24 退化、phase120 约 80 deg | 强化 clean image upper bound 依赖 phase63 同分布；不写跨 phase 鲁棒 |
| 12e 居中后 1.69 -> 2.88 deg | 写入 limitation，说明 clean-image 部分依赖固定框定，但仍不只是质心泄漏 |
| 12f 噪声下 oracle best beta=0，best=6.58 deg | 可写 explicit weighting 是推理端鲁棒上界路径；不得写自动门控或 U1 自动 fallback |
| 12g outliers 为 42/49,950，集中极区 | 主文只写 mean/p90/Hit@5 稳定，worst-case 与极区 outlier 放限制 |
| obs-aug 本轮表现不佳 | 作为诚实负结果；不把 obs-aug 写成有效方法 |
